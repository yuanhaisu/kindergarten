# 页面：家长端 · 积分与成就

## 1. 页面位置

- 路由：`pages/points/index`，从「我的」或首页积分入口进入
- 二级页：返回栏（无边框 chevron + 小标题 `我的`），**没有**底部悬浮导航
- 视口：390 × 844，单列纵向

## 2. 用户与场景

妈妈想知道孩子这学期攒了多少积分、最近为什么加分、拿到了哪些徽章。页面要有“被鼓励”的感觉，但不能变成游戏化压力：不显示排行榜上的其他人，不制造攀比。

1. **状态栏**：`9:41` + 信号/电池。
2. **返回栏**：左侧 chevron；中间小标题 `我的`；右侧留空。
3. **页头**：H1 `积分与成就`
4. **积分总览**（松绿实底卡，骨白文字）
   - 眉题 `总分`；衬线大数字 `1245`（56px / 400）
   - 右上文字按钮 `积分规则`（骨白 78%）
   - 下方三格（上发丝线，骨白 18%）：`本周获得 +45`、`本月获得 +180`、`班级排名 3/28`
5. **最近明细**（区块标题 + 右侧 `全部明细` 文字按钮）
   - 白卡列表行：
     - `任务打卡` / `11 月 12 日 · 余额 1245` / `+10`
     - `周全勤` / `11 月 11 日 · 余额 1235` / `+5`

6. **成就**（区块标题 + 右侧 `已获得 8 / 20`）
   - 2 列卡片网格，每张浅暖底、圆角、内边距紧：
