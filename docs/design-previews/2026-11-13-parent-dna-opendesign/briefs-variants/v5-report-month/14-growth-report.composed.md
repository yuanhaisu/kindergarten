# 页面：家长端 · 成长报告

## 1. 页面位置

- 路由：`pages/growth/report`，从成长时光进入
- 二级页：返回栏（无边框 chevron + 小标题 `成长时光`），**没有**底部悬浮导航
- 视口：390 × 844，长报告页

## 2. 用户与场景

学期末，妈妈想整体看看孩子这学期怎么样：出勤、积分、任务、发展维度、老师寄语。她不需要冷冰冰的仪表盘，而是一份可以慢慢读、可以导出分享的成长报告。

## 3. 产品事实（照抄，不要发明字段）

1. **状态栏**：`9:41` + 信号/电池。
2. **返回栏**：左侧 chevron；中间小标题 `成长时光`；右侧留空。
3. **页头**
   - H1：`本学期成长报告`
   - 眉题：`2026 秋季学期 · 小一班`
4. **导语卡**（sage 浅底 `--surface-soft` 或 `--sage-pale`，圆角 20px）
   - H2 衬线 26px / 400：`乐乐，正在长成他自己`
   - 正文 14px / 1.7：`这个学期他学会了自己穿外套、系鞋带，也开始在集体里主动说话。比起「学会了什么」，我们更高兴看到他愿意试一试。`
5. **四格统计**（无卡片，上下发丝线）
   - `48/50` / `出勤（天）`
   - `+128` / `本期积分`
   - `10/12` / `任务完成`
   - `32` / `成长记录`
   - 数字衬线 21px / 400；`/50`、`/12` 用 13px 弱文字
6. **发展维度**（区块标题 `发展维度` + 右侧 `满分 100`）
   - 四个维度，每个：名称（14px / 600）+ 分数（衬线 20px / 400）+ 6px 进度条（松绿填充）+ 说明 12.5px
   - `语言表达` 88：`能用完整的句子讲清一件事，最近总爱追问「为什么」。`
   - `社交交往` 82：`开始主动邀请同伴一起玩，遇到争执会先说自己的想法。`
   - `大动作` 76：`跑跳稳了，攀爬时还是会在最高一格停下来看看。`
   - `自理能力` 90：`自己穿外套、系鞋带，午睡后会把被子叠好。`
7. **高光时刻**（区块标题）
   - 3 列 3:4 照片色块（gold / sage / clay），圆角 12px
   - 说明：`从本学期的成长记录中选出的 3 张照片`
8. **老师想对你说**
   - 衬线引语 17px / 1.8，左侧 2px sage 竖线：`乐乐，你系鞋带的时候特别认真。老师希望你知道，慢一点没关系，愿意再试一次就很了不起。`
   - 署名：`王老师 · 11 月 12 日`
9. **操作**
   - 主按钮（通栏，松绿）：下载图标 + `导出报告 PDF`
   - 次按钮（ghost）：分享图标 + `分享给家人`

口径说明：四格统计与 `backend/api/api-parent/` 的成长报告字段一致；高光照片来自本期成长记录，不是报告接口自带图片。

不要出现：排名、百分比击败同龄人、付费解锁、广告。

## 4. DNA 硬规则（必须遵守）

- 画布 `#ECE6D7`；导语卡浅 sage；主按钮松绿 `#173220`
- H1 衬线 30px / 400；导语 H2 衬线 26px / 400；区块标题衬线 21px / 400；引语衬线 17px / 1.8
- 衬线永远 400，不得加粗
- 卡片无阴影、1px 发丝线；四格统计用上下发丝线，不套卡片
- 进度条：6px 轨道、full 圆角、松绿实色填充；无网格、无渐变、无阴影
- 小字颜色 `#55616F`（bone 上）/ `#5E6B7A`（白卡上），不得用 `#728173` 作小字
- 照片位用色块占位；不抓外网图片
- 触控区不小于 44px
