# 页面：家长端 · 接送

## 1. 页面位置

- 路由：`pages/pickup/index`，家长端底部 tab 第 3 个（接送）
- 视口：390 × 844 微信小程序原型，单列纵向滚动，底部悬浮胶囊导航
- 需要 3 个状态：默认「在园中」、`?state=away`（未入园）、`?state=done`（已接走）

## 2. 用户与场景

下午 16:50，妈妈在幼儿园门口排队，单手举着手机，只想快速确认：孩子现在在园里吗、什么时候能接、接送码在哪。也可能早上送园前打开，确认“还没入园、几点前送到”。页面第一屏必须把**当前状态 + 接送码入口**放在最显眼的位置，历史记录只作辅助。

## 4. DNA 硬规则（必须遵守）

- 画布 `#ECE6D7`；卡片 `#FFFFFF`；次级面 `#F2EDDE` / `#FCFAF4`
- 主色松绿 `#173220`；橙色 `#F97316` 只做角标/圆点/待处理，**不得做主按钮**
- 标题：衬线 400；H1 30px / 1.35 / 字距 0；状态标题可用衬线 32px / 400
- 正文无衬线 15px / 1.65；小字 11.5–13px
- 衬线永远 400，不得加粗
- 卡片无阴影、1px 发丝线；唯一阴影是底部悬浮导航
- 内容标签用行内高亮，不是胶囊 chip；胶囊只用于筛选/操作
- 小字颜色 `#55616F`（bone 上）/ `#5E6B7A`（白卡上），不得用 `#728173` 作小字
- 时间线：竖线 `--hair-strong`，完成点松绿实心，未完成点松绿描边
- `接走` 类型文字用 `--terracotta-text`，不要用 `--terracotta` 直接写字
- info 提示条正文 `#55616F`，图标灰蓝，不得用橙色
