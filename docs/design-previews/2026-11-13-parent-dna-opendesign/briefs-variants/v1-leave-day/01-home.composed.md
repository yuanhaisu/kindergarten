# 页面：家长端 · 首页

## 1. 页面位置

- 路由：`pages/index/index`，家长端底部 tab 第 1 个（首页）
- 视口：390 × 844 微信小程序原型，单列纵向滚动，底部悬浮胶囊导航
- 这是家长打开小程序的第一屏，也是整个 DNA 的基准页

## 2. 用户与场景

早上 8 点左右，妈妈刚把孩子送进幼儿园，站在门口或通勤路上打开小程序。她只想知道三件事：孩子到了吗、今天状态怎么样、有没有需要我做的事。她单手操作、时间碎片化、情绪需要被安抚。页面必须让她在 3 秒内看完“孩子没事”，并清楚看到今晚的一件事和未读通知。

## 3. 产品事实（照抄，不要发明字段）

按以下顺序组织，文案逐字使用：

1. **状态栏**：左侧 `9:41`，右侧信号/Wi-Fi/电池图标（用内联 SVG 或纯 CSS 绘制）。
2. **页头**
   - 眉题：`11 月 12 日 · 周四 · 晴`
   - H1：`早上好，妈妈`
   - 右侧圆形头像：`乐`
3. **孩子卡**（浅暖底 `--surface-soft`，圆角卡片，发丝线）
   - 大 avatar：`乐`；姓名 `乐乐`；副行 `小一班 · 5 岁 2 个月`
   - 右侧小胶囊按钮：`切换孩子`（这是筛选/操作，允许胶囊）
   - 下面一行正文：`今天 已入园，07:52 到园，情绪很好，早餐吃了一碗粥。`
   - `已入园` 与 `情绪很好` 必须是**行内高亮**（sage / marigold），不是胶囊
4. **今日在园卡**（白卡）
   - 标题行：`今日在园` + 右侧 `10:20 更新`
   - 四格统计（2×2 或 1×4，按 390 宽度取舍，保证不挤）：`已入园 / 07:52`、`进餐 / 很好`、`午睡 / 进行中`、`情绪 / 很好`
   - 每格一个圆形浅色图标底 + 短标签
5. **快捷入口**（4 个，圆形图标 + 文字，横向等分）
   - `请假`、`接送码`、`成长`、`通知`
   - `通知` 右上角有橙色数字角标 `1`（橙色仅此用途）
6. **今晚一件事**（松绿实底卡，白/骨白文字）
   - 眉题：`今晚一件事`
   - H2：`亲子阅读 15 分钟`
   - 说明：`和孩子一起读《好饿的毛毛虫》，聊聊毛毛虫都吃了什么。`
   - 底部左侧：`约 15 分钟 · 已完成 1 天`；右侧 CTA：`去完成 →`
7. **最新动态**
   - 区块标题 `最新动态` + 右侧 `全部`
   - 第一条：眉题 `通知 · 未读`；标题 `秋季亲子运动会报名`；摘要 `本周六上午在园内操场举行，请在本周四前完成报名。`；元信息 `李老师 · 今天 08:30`
   - 第二条：眉题 `成长记录`；标题 `乐乐主动帮小朋友分餐具`；摘要 `午餐时他注意到同伴需要帮助，自己走过去递了勺子。`；元信息 `王老师 · 昨天 12:10`
   - 两条之间用 `--hair-soft` 发丝线分隔，不加卡片外框
8. **底部悬浮导航**：`首页 / 成长 / 接送 / 我的`，首页激活（sage 胶囊底 + 松绿）

不要出现：搜索框、Banner 轮播、营销文案、排行榜、编造的天气接口字段。

## 4. DNA 硬规则（必须遵守）

- 画布 `#ECE6D7`；卡片 `#FFFFFF`；次级面 `#F2EDDE` / `#FCFAF4`
- 主色松绿 `#173220`；橙色 `#F97316` 只做角标/圆点/待处理，**不得做主按钮**
- 标题：衬线 400；H1 30px / 1.35 / 字距 0；H2 21px / 1.4；正文无衬线 15px / 1.65
- 衬线永远 400，不得加粗
- 卡片无阴影、1px 发丝线；唯一阴影是底部悬浮导航
- 内容标签用行内高亮（词背后色块），不是胶囊 chip；胶囊只用于筛选/操作
- 小字颜色 `#55616F`（bone 上）/ `#5E6B7A`（白卡上），不得用 `#728173` 作小字
- 橙色角标里的数字用白色或深色均可，但必须保证对比度；角标尺寸 18px 左右
- 一屏一个焦点：焦点是“孩子卡 + 今日在园”，其余层级依次降低

## 5. 输出要求

- 三件套：`index.html`、`styles.css`、`app.js`，每个文件 < 20KB
- `styles.css` 开头原样粘贴 `tokens.css` 的 `:root { ... }` 块；只写本页布局
- 不引外链字体、CDN、网络图片；照片/插画用色块或内联 SVG
- 390 × 844 无横向溢出；中文标题不得出现单字孤行
- 不写 lorem / TODO / “示例”
- 页面可直接打开预览；底部导航 4 项可点击但只需 `#` 占位
