# 页面：家长端 · 设置

## 1. 页面位置

- 路由：`pages/settings/index`，从「我的」设置区进入
- 二级页：返回栏（无边框 chevron + 小标题 `设置`），**没有**底部悬浮导航
- 视口：390 × 844，单列

## 2. 用户与场景

妈妈想调整消息通知、查看隐私协议，或者注销账号。页面是标准的设置列表：分组清楚、行尾值明确、危险操作有颜色提示但不吓人。

## 3. 产品事实（照抄，不要发明字段）

1. **状态栏**：`9:41` + 信号/电池。
2. **返回栏**：左侧 chevron；中间小标题 `设置`；右侧留空。
3. **页头**：H1 `设置`
4. **消息设置**（分组标题 + 白卡列表，行高 48px，行间发丝线）
   - `接收园所通知` + 状态标签 `已开启` + chevron
   - `接收老师消息` + `已开启` + chevron
   - `免打扰时段` + 行尾值 `20:00–07:30` + chevron
5. **隐私与账号**（分组标题 + 白卡列表）
   - `隐私政策` + chevron
   - `用户协议` + chevron
   - `儿童信息授权管理` + chevron
   - `注销账号`（危险色文字 + 危险色 chevron）
6. **关于**（分组标题 + 白卡列表）
   - `当前版本` + 行尾值 `v1.0.0`（静态行，无 chevron）
   - `检查更新` + 行尾值 `已是最新` + chevron
7. **退出登录**：居中文字按钮，弱文字色，48px 高，不要红色

不要出现：主题切换、字体大小、清缓存、切换语言、开发者选项。

## 4. DNA 硬规则（必须遵守）

- 画布 `#ECE6D7`；白卡；主色松绿 `#173220`
- H1 衬线 30px / 400；分组标题无衬线 17px / 600；设置行 15px / 500
- 衬线永远 400，不得加粗
- 卡片无阴影、1px 发丝线；行间 `--hair-soft`
- `注销账号` 用 `--danger` 文字与图标；不要红色实底按钮
- 小字颜色 `#55616F`（bone 上）/ `#5E6B7A`（白卡上），不得用 `#728173` 作小字
- 触控区不小于 44px

## 5. 输出要求

- 三件套：`index.html`、`styles.css`、`app.js`，每个文件 < 20KB
- `styles.css` 开头原样粘贴 `tokens.css` 的 `:root { ... }` 块；只写本页布局
- 不引外链字体、CDN、网络图片；图标用内联 SVG
- 390 × 844 无横向溢出；中文标题不得出现单字孤行
- 不写 lorem / TODO / “示例”
- 没有底部导航
