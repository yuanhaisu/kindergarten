## 变体事实

- 消息设置只保留 3 行：
  - `接收园所通知` + `已开启` + chevron
  - `接收老师消息` + `已开启` + chevron
  - `免打扰时段` + `20:00–07:30` + chevron
- 隐私与账号：`隐私政策` / `用户协议` / `儿童信息授权管理` / `注销账号`。
- 关于：`当前版本 v1.0.0` / `检查更新 已是最新`。
- 退出登录保留。

## 必须改变的区块

1. 状态栏 `10:20`。
2. 消息设置只保留上述 3 行；不要出现 6 个细分通知开关或隐私开关。
3. `隐私政策/用户协议` 要能进 05 的对应文档（不能是死按钮）。
4. `免打扰时段` 行要有编辑 affordance（picker/弹层），并注明“提案：需后端补字段”。
5. `注销账号` 补确认页/后果说明；接口未就绪标 Phase 2。
6. `退出登录` 加二次确认。
7. 页面顶部或页脚 11px 弱文字标 `简化提案`，不要遮挡内容。

## 不要出现

- 把简化版写成“当前 API 已支持免打扰”。
- 6 个细分通知开关（那是 baseline）。
- 点了没反应的设置行。

## 输出要求
