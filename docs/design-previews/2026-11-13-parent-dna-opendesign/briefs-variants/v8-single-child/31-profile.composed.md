# 页面：家长端 · 我的

## 1. 页面位置

- 路由：`pages/profile/index`，家长端底部 tab 第 4 个（我的）
- 视口：390 × 844 微信小程序原型，单列纵向滚动，底部悬浮胶囊导航

## 2. 用户与场景

妈妈想确认自己的账号与孩子绑定是否正确，顺手进入幼儿信息、班级信息、积分与设置。页面是“账号 + 家庭 + 服务入口”的汇总，不需要仪表盘式的密集数据，只要一眼看清“我是谁、我的孩子是谁、下一步去哪”。
