## DNA 硬规则（每份 brief 原样附带）

- 画布 `#ECE6D7`；卡片 `#FFFFFF`；次级面 `#F2EDDE` / `#FCFAF4`
- 主色松绿 `#173220`；橙色 `#F97316` 只做角标/圆点/待处理，**不得做主按钮**
- 标题：衬线 400；H1 30px / 1.35 / 字距 0；H2 21px / 1.4；H3 18px / 1.4
- 衬线长正文：17px / 1.8 / 0（仅反思性长文）；无衬线正文 15px / 1.65
- 衬线永远 400，不得加粗
- 卡片无阴影、1px 发丝线；唯一阴影是底部悬浮导航
- 内容标签用行内高亮（词背后色块），不是胶囊 chip；胶囊只用于筛选/操作
- 小字颜色 `#55616F`（bone 上）/ `#5E6B7A`（白卡上），不得用 `#728173` 作小字
- 空态：圆形浅底 + 衬线标题 + 无衬线说明 + 主 CTA（有明确下一步才放 CTA）
- 状态标签用带色底小方标签：待审批（橙 12% 底 + 松绿字）、已同意（sage 浅底 + 松绿）、已拒绝（赤陶软底 + 松绿）、已取消（次级面 + 弱文字）
- 图标：内联 SVG，24 网格，`fill="none" stroke="currentColor"`，线宽 1.6–2.0
- 二级页页头：无边框 chevron 返回 + 页面小标题；**没有**底部悬浮导航
- 底部悬浮胶囊导航仅 4 个 tab 页：首页 / 成长 / 接送 / 我的
- 危险操作用独立确认区或底部抽屉，不用居中弹窗
- 不做暗色模式；不抓外网字体/图片；不写 lorem / TODO
- 390 × 844 无横向溢出；中文标题不得出现单字孤行
