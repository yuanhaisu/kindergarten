# 页面：家长端 · 任务详情

## 1. 页面位置

- 路由：`pages/tasks/detail`，从亲子任务列表进入
- 二级页：返回栏（无边框 chevron + 小标题 `乐乐 · 小一班`），**没有**底部悬浮导航
- 视口：390 × 844，表单 + 历史记录

## 2. 用户与场景

妈妈准备陪孩子完成任务并打卡。她需要看清任务说明、三个步骤、今天还剩多少时间，然后上传照片/写一句话提交。历史提交让她知道老师会回应。

## 3. 产品事实（照抄，不要发明字段）

1. **状态栏**：`9:41` + 信号/电池。
2. **返回栏**：左侧 chevron；中间小标题 `乐乐 · 小一班`；右侧留空。
3. **页头**
   - 眉题：`亲子任务 · +10 积分`
   - H1（两行，手动断行）：`给家人讲一件` / `今天开心的事`
   - 导语：`晚饭后问问乐乐今天在幼儿园最开心的事，听他讲完，再请他说说当时的心情。不用引导答案，他愿意讲就好。`
   - 元信息：`每天 · 今天 21:00 前 · 王老师布置`
4. **打卡步骤卡**（白卡）
   - 标题 `打卡步骤`；右侧 `已完成 1 / 3`
   - 三条清单，方形勾选框 20px：
     - 已完成：`先问问孩子今天在幼儿园最开心的一件事`
     - 未完成：`听孩子讲完，不打断，也不急着评价`
     - 未完成：`拍一张他讲故事时的照片（选填）`
5. **今日打卡卡**（白卡）
   - 标题 `今日打卡`；右侧 `还剩 11 小时`
   - 提示：`照片和一句话都可以，交过之后老师晚上统一回应。`
   - 照片网格 3 列：sage 色块、gold 色块、虚线 `+ 加照片`
   - 多行输入框，占位 `写一句今天的记录，老师会看到`，计数 `0 / 200`
6. **提交按钮**（通栏，松绿）：`提交打卡`
7. **说明**：`每日任务每天可提交一次`
8. **我的提交记录**（区块标题 + 右侧 `共 1 条`）
   - 浅暖底卡：眉题 `11 月 11 日 · 周三`；状态标签 `老师已回应`
   - 记录：`晚上讲了在滑梯上帮小朋友捡帽子的事，他说下次还要帮忙。`
   - 回复：头像 `王` + `王老师` + `讲得很完整。明天可以问问他当时的心情，他大概会说得更多。`

不要出现：积分排行榜、任务放弃、补卡付费、其他孩子的提交。

## 4. DNA 硬规则（必须遵守）

- 画布 `#ECE6D7`；白卡；主按钮松绿 `#173220`
- H1 衬线 30px / 400；卡标题衬线 18px / 400；正文无衬线 15px / 1.65
- 衬线永远 400，不得加粗
- 卡片无阴影、1px 发丝线
- 勾选框 20px、5px 圆角；完成松绿实底 + 骨白对勾
- 积分文字用 marigold 软色或松绿，不要橙色
- 小字颜色 `#55616F`（bone 上）/ `#5E6B7A`（白卡上），不得用 `#728173` 作小字
- 触控区不小于 44px

## 5. 输出要求

- 三件套：`index.html`、`styles.css`、`app.js`，每个文件 < 20KB
- `styles.css` 开头原样粘贴 `tokens.css` 的 `:root { ... }` 块；只写本页布局
- 不引外链字体、CDN、网络图片；图标用内联 SVG
- 390 × 844 无横向溢出；中文标题不得出现单字孤行
- 不写 lorem / TODO / “示例”
- 没有底部导航
