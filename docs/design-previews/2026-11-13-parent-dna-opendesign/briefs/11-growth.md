# 页面：家长端 · 成长时光

## 1. 页面位置

- 路由：`pages/growth/index`，家长端底部 tab 第 2 个（成长）
- 视口：390 × 844 微信小程序原型，单列纵向滚动，底部悬浮胶囊导航
- 状态：默认（有记录）+ `?state=empty`（空态）

## 2. 用户与场景

午休或晚上，妈妈想看看老师今天发了什么：孩子有没有被记录、有没有照片、老师说了什么。她不是在“管理数据”，而是在找能让她安心的细节。页面要像一本缓慢翻阅的成长册：日期清楚、照片呼吸感、文字可读，不要信息仪表盘。

## 3. 产品事实（照抄，不要发明字段）

### 默认态

1. **状态栏**：`9:41` + 信号/电池。
2. **页头**
   - 眉题：`乐乐 · 小一班`
   - H1：`成长时光`
   - 右侧图标按钮：相册（图片图标，无文字）
3. **本周概况卡**（浅暖底 `--surface-soft`，三格）
   - `5` / `条成长记录`
   - `12` / `张照片`
   - `3` / `句老师寄语`
   - 数字用衬线 26px / 400
4. **筛选**（胶囊 chip，横向可滚动）：`全部`（选中）、`本月`、`有照片`、`老师寄语`
5. **记录一**
   - 眉题：`今天 · 11 月 12 日`；右上状态标签：`已阅读`
   - 标题：`第一次自己系好了鞋带`
   - 正文：`午睡起床后，乐乐坐在床边试了很久，最后自己系好了鞋带，还转头给老师看。他今天的专注力比往常更久。`
   - `专注力` 必须是行内高亮（sage），不是胶囊
   - 照片网格 3 列：sage / gold / pine 色块；第三格右上角或中央显示 `+4`
   - 底部：头像 `王` + `王老师 · 12:10`；右侧评论图标 `2`、实心爱心 `8`（爱心用赤陶色）
6. **记录二**
   - 眉题：`昨天 · 11 月 11 日`；标签：`自动归档`
   - 标题：`午餐时的一次主动`
   - 正文：`他注意到旁边的小朋友没有勺子，自己起身去拿了一把递过去。`
   - 引用块（左侧 2px sage 竖线，衬线 16px）：`“老师，他需要这个。” —— 乐乐`
   - 底部：头像 `李` + `李老师 · 12:40`；右侧 `写一句`、空心爱心 `6`
7. **记录三**
   - 眉题：`11 月 8 日 · 周日`；标签：`有更新`
   - 标题：`户外活动：第一次爬过攀爬架`
   - 正文：`在老师的保护下，他爬到最高一格，停下来看了看下面，然后自己下来了。`
   - 照片网格 3 列：blue / sage / gold 色块
   - 底部：头像 `张` + `张老师 · 16:20`；右侧 `写一句`、空心爱心 `3`
8. **底部悬浮导航**：`首页 / 成长 / 接送 / 我的`，成长激活

### `?state=empty` 空态

- 无本周卡、无筛选、无记录
- 圆形浅底插画（120 网格，芽/叶意象，用松绿 + sage + marigold + terracotta，不贴边）
- 衬线标题：`还没有成长记录`
- 说明：`老师记录下孩子在园的瞬间后，会出现在这里。`
- 主按钮：`看看班级相册`
- 底部悬浮导航保留，成长激活

> 空态与默认态共用同一页外壳，用 `?state=empty` + `app.js` 切换，不要复制整页文件。

## 4. DNA 硬规则（必须遵守）

- 画布 `#ECE6D7`；卡片 `#FFFFFF`；次级面 `#F2EDDE` / `#FCFAF4`
- 主色松绿 `#173220`；橙色 `#F97316` 只做角标/圆点/待处理，**不得做主按钮**
- 标题：衬线 400；H1 30px / 1.35 / 字距 0；记录标题衬线 18px / 400
- 正文无衬线 13.5–15px / 1.65；引用行用衬线 16px / 1.8
- 衬线永远 400，不得加粗
- 卡片无阴影、1px 发丝线；唯一阴影是底部悬浮导航
- 内容标签用行内高亮，不是胶囊 chip；胶囊只用于筛选
- 小字颜色 `#55616F`（bone 上）/ `#5E6B7A`（白卡上），不得用 `#728173` 作小字
- 照片位用色块占位，保留 12px 圆角；不要抓外网图片

## 5. 输出要求

- 三件套：`index.html`、`styles.css`、`app.js`，每个文件 < 20KB
- `styles.css` 开头原样粘贴 `tokens.css` 的 `:root { ... }` 块；只写本页布局
- 不引外链字体、CDN、网络图片；图标用内联 SVG
- 390 × 844 无横向溢出；中文标题不得出现单字孤行
- 不写 lorem / TODO / “示例”
- `?state=empty` 必须能直接打开并截图
