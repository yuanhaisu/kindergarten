# 页面：家长端 · 新建请假

## 1. 页面位置

- 路由：`pages/leave/create`，从请假列表或首页进入
- 二级页：返回栏（无边框 chevron + 小标题 `乐乐 · 小一班`），**没有**底部悬浮导航
- 状态：默认 + `?state=error` 校验错误态

## 2. 用户与场景

早上发现孩子发烧，妈妈要在一两分钟内提交请假。表单必须短、字段少、默认值合理；提交前告诉她会由谁审批、多久回复。错误态要明确指出哪一项没填，而不是只弹一个 toast。

## 3. 产品事实（照抄，不要发明字段）

1. **状态栏**：`9:41` + 信号/电池。
2. **返回栏**：左侧 chevron；中间小标题 `乐乐 · 小一班`；右侧留空。
3. **页头**：H1 `新建请假`
4. **表单卡**（白卡，字段间距 14px，字段间用发丝线分隔）
   - 请假类型：分段控件 `病假`（选中）/ `事假` / `其他`
   - 请假日期：
     - 两列：`开始` `11 月 12 日`；`结束` `11 月 12 日`；右侧日历图标
     - 错误态：结束日期显示 `请选择`，picker 变红（`--danger`），下方 11.5px 错误文案 `请选择结束日期`
   - 请假事由：
     - 多行输入框，占位 `请简单说明原因，老师会据此照顾孩子`
     - 右下计数 `0 / 120`
     - 错误态：输入框红描边，下方 11.5px `请填写请假事由`
   - 上传行（虚线描边，整行可点）：`上传就医凭证（选填）` / `最多 3 张，仅支持图片`；左侧 sage 相机图标，右侧加号
5. **info 提示条**：`提交后由班级老师审批，通常 2 小时内回复`
6. **主按钮**（通栏）：`提交申请`

状态切换：`?state=error` 时显示结束日期与事由两项错误；默认态不显示错误。

不要出现：请假额度、审批人选择、抄送、费用、医院名称必填。

## 4. DNA 硬规则（必须遵守）

- 画布 `#ECE6D7`；卡片 `#FFFFFF`；主按钮松绿 `#173220`
- H1 衬线 30px / 400；字段标签无衬线 12.5px / 500；正文 15px
- 衬线永远 400，不得加粗
- 卡片无阴影、1px 发丝线；字段之间用 `--hair-soft` 发丝线
- 输入框：高 44px、圆角 12px、1px `rgba(23,50,32,.22)` 描边、白底；聚焦 3px 松绿 12% 光晕
- 错误：`--danger` 描边 + 11.5px 错误文案；不要只用 toast
- 分段控件选中态：松绿实底 + 骨白文字；未选透明底 + 松绿文字
- 小字颜色 `#55616F`（bone 上）/ `#5E6B7A`（白卡上）
- 触控区不小于 44px

## 5. 输出要求

- 三件套：`index.html`、`styles.css`、`app.js`，每个文件 < 20KB
- `styles.css` 开头原样粘贴 `tokens.css` 的 `:root { ... }` 块；只写本页布局
- 不引外链字体、CDN、网络图片；图标用内联 SVG
- 390 × 844 无横向溢出；中文标题不得出现单字孤行
- 不写 lorem / TODO / “示例”
- `?state=error` 必须能直接打开并截图；没有底部导航
