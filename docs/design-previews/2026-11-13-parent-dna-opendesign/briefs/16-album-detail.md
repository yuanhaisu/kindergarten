# 页面：家长端 · 相册详情

## 1. 页面位置

- 路由：`pages/album/detail`，从班级相册进入
- 二级页：返回栏（无边框 chevron + 小标题 `班级相册`），**没有**底部悬浮导航
- 视口：390 × 844，单列纵向

## 2. 用户与场景

妈妈点开“秋日远足”，想快速浏览照片、找到孩子的身影，并保存/分享给家人。页面要让照片成为主角，文字只做简短说明，操作放在浏览之后。

## 3. 产品事实（照抄，不要发明字段）

1. **状态栏**：`9:41` + 信号/电池。
2. **返回栏**：左侧 chevron；中间小标题 `班级相册`；右侧留空。
3. **页头**
   - H1：`秋日远足`
   - 元信息：`10 月 24 日 · 32 张照片 · 李老师`
4. **说明**（15px / 1.65）：
   `秋游那天，孩子们在公园里捡了满满一袋落叶。回园后，每个人挑出最喜欢的一片，贴成了教室后墙上的秋天。`
   - `落叶` 是行内高亮（sage）
5. **照片网格**：3 列，方形，间距 6px，圆角 12px；共 12 格
   - 色块顺序：sage / gold / clay / blue / sage / clay / pine（视频格）/ gold / blue / sage / gold / clay
   - 视频格：时长 `00:24`，中央白色半透明圆形播放按钮 + 松绿三角
6. **操作**（网格下方，横向）
   - 主按钮（松绿，flex:1）：下载图标 + `保存全部`
   - 次按钮（ghost）：分享图标 + `分享`

不要出现：评论、点赞、上传、删除、幻灯片自动播放、广告。

## 4. DNA 硬规则（必须遵守）

- 画布 `#ECE6D7`；照片网格直接排在暖纸底上，不套白卡
- H1 衬线 30px / 400；正文无衬线 15px / 1.65
- 衬线永远 400，不得加粗
- 网格间距 6px；圆角 12px；不要阴影
- 视频播放按钮：白色 90% 底 + 松绿三角；时长标签用骨白小字 + 半透明松绿底
- 操作按钮：主按钮松绿填充 + 骨白文字；次按钮白底 + 松绿描边
- 小字颜色 `#55616F`（bone 上），不得用 `#728173`
- 照片位用色块占位；不抓外网图片
- 触控区不小于 44px

## 5. 输出要求

- 三件套：`index.html`、`styles.css`、`app.js`，每个文件 < 20KB
- `styles.css` 开头原样粘贴 `tokens.css` 的 `:root { ... }` 块；只写本页布局
- 不引外链字体、CDN、网络图片；图标用内联 SVG
- 390 × 844 无横向溢出；中文标题不得出现单字孤行
- 不写 lorem / TODO / “示例”
- 没有底部导航
