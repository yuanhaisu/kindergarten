# 页面：家长端 · 成长相册

## 1. 页面位置

- 路由：`pages/growth/album`，从成长时光页头图标进入
- 二级页：返回栏（无边框 chevron + 小标题 `成长时光`），**没有**底部悬浮导航
- 视口：390 × 844，单列纵向

## 2. 用户与场景

妈妈想翻孩子这个学期的照片和视频，按时间找某个瞬间。页面要像相册而不是文件管理器：月份清楚、网格密但不挤、视频有明确的播放标记。

## 3. 产品事实（照抄，不要发明字段）

1. **状态栏**：`9:41` + 信号/电池。
2. **返回栏**：左侧 chevron；中间小标题 `成长时光`；右侧留空。
3. **页头**
   - H1：`成长相册`
   - 副行：`乐乐 · 共 48 张照片 · 6 段视频`
4. **筛选**（胶囊 chip）：`全部`（选中）、`照片`、`视频`
5. **按月分组**，每组：
   - 月份标题：`11 月`（衬线 19px / 400）；右侧 `18 张照片 · 2 段视频`（11.5px 弱文字）
   - 3 列方形照片网格，间距 6px，圆角 12px
   - 11 月：6 格（sage / gold / clay / blue / sage / pine 视频格）
   - 10 月：6 格（gold / sage / pine 视频格 / clay / sage / blue）
   - 9 月：6 格（clay / sage / gold / blue / sage / clay）
   - 视频格：右下或左上角时长标签 `00:18` / `00:32`，中央白色半透明圆形播放按钮 + 松绿三角
6. **页脚**：无额外统计，滚动到底即结束

不要出现：上传按钮、删除、编辑、按孩子切换、云盘式文件列表。

## 4. DNA 硬规则（必须遵守）

- 画布 `#ECE6D7`；照片网格直接排在暖纸底上，不套白卡
- H1 衬线 30px / 400；月份标题衬线 19px / 400
- 衬线永远 400，不得加粗
- 网格间距 6px；圆角 12px；不要阴影
- 视频播放按钮：白色 88% 底 + 松绿三角；时长标签用骨白小字 + 半透明松绿底
- 小字颜色 `#55616F`（bone 上），不得用 `#728173`
- 照片位用色块占位；不抓外网图片
- 触控区不小于 44px（缩略图整块可点）

## 5. 输出要求

- 三件套：`index.html`、`styles.css`、`app.js`，每个文件 < 20KB
- `styles.css` 开头原样粘贴 `tokens.css` 的 `:root { ... }` 块；只写本页布局
- 不引外链字体、CDN、网络图片；图标用内联 SVG
- 390 × 844 无横向溢出；中文标题不得出现单字孤行
- 不写 lorem / TODO / “示例”
- 没有底部导航
