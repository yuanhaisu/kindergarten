# 页面：家长端 · 幼儿信息

## 1. 页面位置

- 路由：`pages/student/index`，从「我的 · 幼儿信息」进入
- 二级页：返回栏（无边框 chevron + 小标题 `幼儿信息` + 右侧 `编辑` 文字按钮），**没有**底部悬浮导航
- 视口：390 × 844，单列

## 2. 用户与场景

妈妈要核对孩子的档案（姓名、生日、健康、紧急联系人），或给老师提供过敏/特殊照护信息。页面要像一份安静的资料页，信息分组清楚，电话一键可达。

## 3. 产品事实（照抄，不要发明字段）

1. **状态栏**：`9:41` + 信号/电池。
2. **返回栏**：左侧 chevron；中间小标题 `幼儿信息`；右侧文字按钮 `编辑`。
3. **档案头**
   - 大头像 `乐`（sage 浅底）
   - H1 `乐乐`
   - 副行 `小一班 · 5 岁 2 个月`；`5 岁 2 个月` 是行内高亮（sage）
   - 元信息 `2025 年 9 月入园`
4. **基本信息**（区块标题 + 白卡，2 列 fact grid，gap 17×18）
   - `姓名` `乐乐`
   - `性别` `女`
   - `生日` `2021 年 9 月 8 日`
   - `民族` `汉族`
   - `户籍` `湖南 · 湘潭`（跨两列）
5. **健康信息**（区块标题 + 白卡，2 列）
   - `身高` `108cm`
   - `体重` `18kg`
   - `过敏史` `无`
   - `特殊照护` `无`
   - 数字用衬线 20px / 400，单位小字
6. **紧急联系人**（区块标题 + 白卡列表）
   - 头像 `妈`（sage 浅底）+ `妈妈 · 李静` / `138****6721` + 圆形电话按钮
   - 头像 `爸`（赤陶浅底）+ `爸爸` / `138****9034` + 圆形电话按钮
7. **info 提示条**：`信息有误请联系班级老师修改`

不要出现：编辑表单直接展开、删除孩子、疫苗记录、体检报告、成绩。

## 4. DNA 硬规则（必须遵守）

- 画布 `#ECE6D7`；白卡；主色松绿 `#173220`
- H1 衬线 30px / 400；区块标题衬线 18px / 400；健康数字衬线 20px / 400
- 衬线永远 400，不得加粗
- 卡片无阴影、1px 发丝线
- 事实标签 11.5px 弱文字；值 14px / 500
- 电话按钮：36px 圆形白底 + 1px 松绿描边 + 松绿图标，热区补到 44px
- 小字颜色 `#55616F`（bone 上）/ `#5E6B7A`（白卡上），不得用 `#728173` 作小字
- 触控区不小于 44px

## 5. 输出要求

- 三件套：`index.html`、`styles.css`、`app.js`，每个文件 < 20KB
- `styles.css` 开头原样粘贴 `tokens.css` 的 `:root { ... }` 块；只写本页布局
- 不引外链字体、CDN、网络图片；图标用内联 SVG
- 390 × 844 无横向溢出；中文标题不得出现单字孤行
- 不写 lorem / TODO / “示例”
- 没有底部导航
