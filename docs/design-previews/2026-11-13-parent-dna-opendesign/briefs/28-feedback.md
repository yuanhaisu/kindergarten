# 页面：家长端 · 意见反馈

## 1. 页面位置

- 路由：`pages/feedback/index`，从「我的 · 意见反馈」进入
- 二级页：返回栏（无边框 chevron + 小标题 `意见反馈`），**没有**底部悬浮导航
- 视口：390 × 844，表单 + 常见问题

## 2. 用户与场景

妈妈遇到问题或有建议，想告诉园所。她需要先选类型、写清楚、可选传照片，然后提交；页面要让她知道“会发给园所管理员”，并给出常见问题的自助入口。

## 3. 产品事实（照抄，不要发明字段）

1. **状态栏**：`9:41` + 信号/电池。
2. **返回栏**：左侧 chevron；中间小标题 `意见反馈`；右侧留空。
3. **页头**
   - H1：`意见反馈`
   - 副行：`你的建议会直接发送给园所管理员`
4. **反馈表单卡**（白卡）
   - 反馈类型：胶囊 chip `功能建议`（选中）、`使用问题`、`内容投诉`、`其他`
   - 发丝线
   - 问题描述：多行输入框，占位 `请描述你遇到的问题或建议`；下方提示 `尽量写清操作步骤，方便我们定位` + 计数 `0 / 500`
   - 发丝线
   - 上传照片：`上传照片` / `选填 · 最多 3 张`；右侧两个 56×56 虚线 `+` 上传位
   - 发丝线
   - 联系方式（选填）：输入框，预填 `138 0013 6721`
5. **主按钮**（通栏）：`提交反馈`
6. **常见问题**
   - 眉题 `常见问题`
   - 白卡列表：`如何绑定第二个孩子` / `如何修改接送人`，行尾 chevron

不要出现：反馈进度查询、客服电话、投诉模板、附件以外的复杂字段。

## 4. DNA 硬规则（必须遵守）

- 画布 `#ECE6D7`；白卡；主按钮松绿 `#173220`
- H1 衬线 30px / 400；字段标签无衬线 12.5px / 500；正文 15px
- 衬线永远 400，不得加粗
- 卡片无阴影、1px 发丝线
- 输入框：高 44px、圆角 12px、1px `rgba(23,50,32,.22)` 描边、白底；聚焦 3px 松绿 12% 光晕
- chip 只用于反馈类型；选中态松绿实底 + 骨白字
- 小字颜色 `#55616F`（bone 上）/ `#5E6B7A`（白卡上），不得用 `#728173` 作小字
- 触控区不小于 44px

## 5. 输出要求

- 三件套：`index.html`、`styles.css`、`app.js`，每个文件 < 20KB
- `styles.css` 开头原样粘贴 `tokens.css` 的 `:root { ... }` 块；只写本页布局
- 不引外链字体、CDN、网络图片；图标用内联 SVG
- 390 × 844 无横向溢出；中文标题不得出现单字孤行
- 不写 lorem / TODO / “示例”
- 没有底部导航
