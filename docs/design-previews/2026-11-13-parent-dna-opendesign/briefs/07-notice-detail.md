# 页面：家长端 · 通知详情

## 1. 页面位置

- 路由：`pages/notice/detail`，从通知列表进入
- 二级页：返回栏（无边框 chevron + 小标题 `通知`），**没有**底部悬浮导航
- 视口：390 × 844，长文 + 底部固定操作条

## 2. 用户与场景

妈妈点开运动会报名通知，需要快速确认时间、地点、要准备什么、什么时候截止，然后直接报名。长文要能读，但操作条必须一直在手边；附件能下载。

## 3. 产品事实（照抄，不要发明字段）

1. **状态栏**：`9:41` + 信号/电池。
2. **返回栏**：左侧 chevron；中间小标题 `通知`；右侧留空。
3. **页头**
   - 眉题：`园所通知 · 今天 08:30`
   - H1：`秋季亲子运动会报名`
   - 作者行：头像 `李`（赤陶浅底）+ `李老师` / `小一班 · 班主任`
   - 下方 1px 发丝线
4. **正文**（无卡片容器，直接排在暖纸底上；段落间距 12px，15px / 1.65）
   - `各位家长：`
   - `11 月 14 日（周六）上午 9:00，我们将在幼儿园操场举行秋季亲子运动会，小一班全体家庭参加。请提前 10 分钟带孩子到班级集合。`
   - `当天有亲子接力、袋鼠跳和拔河三个项目。孩子穿园服和运动鞋，家长穿方便活动的衣服，每位幼儿由一位家长陪同。`
   - `活动预计 11:30 结束，当天不设午餐，请安排好接回时间。如遇雨天，顺延至下周三同一时间。`
5. **warning 提示条**（12% 橙底，三角图标；正文用松绿 `#173220`，只有图标是橙）
   - `报名截止本周四 18:00，逾期不再补报。`
6. **附件卡**（白卡，紧凑）
   - 圆形 sage 图标（文件）
   - `报名表.xlsx` / `Excel 表格 · 24 KB`
   - 右侧下载图标按钮
7. **页脚小字**：`如有疑问，可以在班级群里直接问李老师。`
8. **底部固定操作条**（白底，上发丝线，贴在手机壳底部）
   - 左：`已读 32 人`（11.5px 弱文字）
   - 右：主按钮 `我要报名`（松绿）

不要出现：评论、点赞、分享、相关推荐、悬浮 FAB。

## 4. DNA 硬规则（必须遵守）

- 画布 `#ECE6D7`；卡片 `#FFFFFF`；主按钮松绿 `#173220`
- H1 衬线 30px / 400；正文无衬线 15px / 1.65
- 衬线永远 400，不得加粗
- 卡片无阴影、1px 发丝线；底部操作条用上发丝线，不加阴影
- warning 条：橙 12% 底 + 松绿正文 + 橙色三角图标；不要用橙色文字
- 小字颜色 `#55616F`（bone 上）/ `#5E6B7A`（白卡上），不得用 `#728173` 作小字
- 附件下载按钮热区 ≥44px
- 操作条不能遮挡正文：正文底部留出足够 padding

## 5. 输出要求

- 三件套：`index.html`、`styles.css`、`app.js`，每个文件 < 20KB
- `styles.css` 开头原样粘贴 `tokens.css` 的 `:root { ... }` 块；只写本页布局
- 不引外链字体、CDN、网络图片；图标用内联 SVG
- 390 × 844 无横向溢出；中文标题不得出现单字孤行
- 不写 lorem / TODO / “示例”
- 没有底部导航
