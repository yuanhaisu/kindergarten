# 页面：家长端 · 班级墙

## 1. 页面位置

- 路由：`pages/tasks/wall`，从亲子任务页进入
- 二级页：返回栏（无边框 chevron + 小标题 `乐乐 · 小一班`），**没有**底部悬浮导航
- 视口：390 × 844，2 列照片墙

## 2. 用户与场景

妈妈想看看班里其他孩子今天怎么完成任务，也想让自己的孩子被看见。页面要像一面温暖的照片墙，不像排行榜：突出照片、孩子名字和任务，不展示分数排名。

## 3. 产品事实（照抄，不要发明字段）

1. **状态栏**：`9:41` + 信号/电池。
2. **返回栏**：左侧 chevron；中间小标题 `乐乐 · 小一班`；右侧留空。
3. **页头**
   - H1：`班级墙`
   - 说明：`今天有 18 位小朋友完成了任务`；`18 位小朋友` 是行内高亮（sage）
4. **筛选**（胶囊 chip）：`全部`（选中）、`小一班`、`我的`
5. **2 列照片墙**（卡片间距 12px，圆角 26px，白底，1px 发丝线）
   - 卡片结构：方形照片色块（占卡片上半）+ 下方 `名字`（15px / 600）+ 点赞（赤陶实心爱心 + 数字）+ 任务名（11.5px，最多 2 行）
   - 8 张卡：
     - `乐乐` / 12 / `给家人讲一件今天开心的事`（sage）
     - `豆豆` / 9 / 同任务（gold，左上角小标签 `老师点赞`）
     - `朵朵` / 7 / `睡前整理书包`（clay）
     - `小宇` / 5 / `给家人讲一件今天开心的事`（blue）
     - `安然` / 4 / `帮忙摆碗筷`（pine）
     - `辰辰` / 3 / `给家人讲一件今天开心的事`（sage）
     - `果果` / 2 / `帮忙摆碗筷`（gold）
     - `阳阳` / 1 / `睡前整理书包`（clay）
6. **页脚**：`只展示家长公开、老师审核通过的打卡`（11px 弱文字，居中）

不要出现：排名、分数、点赞按钮（点赞数只展示）、评论、分享、广告。

## 4. DNA 硬规则（必须遵守）

- 画布 `#ECE6D7`；白卡；主色松绿 `#173220`
- H1 衬线 30px / 400；孩子名字无衬线 15px / 600；任务名 11.5px
- 衬线永远 400，不得加粗
- 卡片无阴影、1px 发丝线；照片块与卡片同宽，底部一条发丝线
- 点赞爱心用赤陶 `#C36540`，数字用弱文字；不要橙色
- 小字颜色 `#55616F`（bone 上）/ `#5E6B7A`（白卡上），不得用 `#728173` 作小字
- 触控区不小于 44px（整卡可点）

## 5. 输出要求

- 三件套：`index.html`、`styles.css`、`app.js`，每个文件 < 20KB
- `styles.css` 开头原样粘贴 `tokens.css` 的 `:root { ... }` 块；只写本页布局
- 不引外链字体、CDN、网络图片；照片用色块占位
- 390 × 844 无横向溢出；中文标题不得出现单字孤行
- 不写 lorem / TODO / “示例”
- 没有底部导航
