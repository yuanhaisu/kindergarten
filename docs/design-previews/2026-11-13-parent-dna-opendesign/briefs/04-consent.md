# 页面：家长端 · 同意与协议

## 1. 页面位置

- 路由：`pages/auth/consent`（首次登录后的同意页）
- 二级页：返回栏（无边框 chevron + 小标题 `隐私与协议`），**没有**底部导航
- 视口：390 × 844，单列

## 2. 用户与场景

第一次登录后，妈妈需要确认三份协议。她不会逐字读长文，但需要一眼看清“同意的是什么、随时可以撤回”。页面要坦率、不诱导，主按钮明确，次要选项不隐藏。

## 3. 产品事实（照抄，不要发明字段）

1. **状态栏**：`9:41` + 信号/电池。
2. **返回栏**：左侧 chevron；中间小标题 `隐私与协议`；右侧留空。
3. **页头**
   - H1：`开始之前`
   - 导语（衬线 17px / 1.8）：`在开始之前，有三份约定需要你确认。它们说明我们会怎样使用你和孩子的信息，以及你随时可以收回哪些授权。`
4. **同意项卡片**（白卡，内边距 2px 16px；每行上下 15px，行间 `--hair-soft` 发丝线）
   - 行一：方形勾选框（已勾选，松绿实底 + 骨白对勾）；`隐私政策` + 副行 `我们如何收集、使用与保护你的信息`；行尾 chevron
   - 行二：`未成年人个人信息保护规则` + `孩子的信息如何被专门保护`；行尾 chevron
   - 行三：`用户协议` + `使用养成星球服务的约定`；行尾 chevron
   - 整行可点击切换勾选
5. **操作**
   - 主按钮（通栏）：`同意并继续`
   - 文字按钮：`暂不同意`
6. **底部说明**（11.5px，居中，弱文字）：`随时可以在「我的 · 隐私与协议」中查看全文或撤回授权。`

不要出现：默认不勾选、强制滚动到底部才能同意、倒计时、营销式利益说明。

## 4. DNA 硬规则（必须遵守）

- 画布 `#ECE6D7`；卡片 `#FFFFFF`；主按钮松绿 `#173220`
- H1 衬线 30px / 400；导语衬线 17px / 1.8；行标题无衬线 15px / 600；副行 11.5px
- 衬线永远 400，不得加粗
- 卡片无阴影、1px 发丝线；圆角 20px
- 勾选框 18px 方形、4px 圆角、松绿实底 + 骨白对勾；未选白底 + 1px 深发丝线
- 小字颜色 `#55616F`（bone 上）/ `#5E6B7A`（白卡上），不得用 `#728173` 作小字
- 触控区不小于 44px（整行可点）

## 5. 输出要求

- 三件套：`index.html`、`styles.css`、`app.js`，每个文件 < 20KB
- `styles.css` 开头原样粘贴 `tokens.css` 的 `:root { ... }` 块；只写本页布局
- 不引外链字体、CDN、网络图片；图标用内联 SVG
- 390 × 844 无横向溢出；中文标题不得出现单字孤行
- 不写 lorem / TODO / “示例”
- 没有底部导航，不要补
