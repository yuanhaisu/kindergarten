# 页面：家长端 · 亲子任务

## 1. 页面位置

- 路由：`pages/tasks/index`，从首页「今晚一件事」或「我的」进入
- 二级页：返回栏（无边框 chevron + 小标题 `乐乐 · 小一班`），**没有**底部悬浮导航
- 状态：默认 + `?state=empty`（今日任务全部完成）

## 2. 用户与场景

晚饭后，妈妈想看看今晚要陪孩子做什么、打卡能得多少积分。她只有十几分钟，页面要突出“今天这一件”，其余任务作为清单；不要让她在多个任务之间做选择。

## 3. 产品事实（照抄，不要发明字段）

1. **状态栏**：`9:41` + 信号/电池。
2. **返回栏**：左侧 chevron；中间小标题 `乐乐 · 小一班`；右侧留空。
3. **页头**：H1 `亲子任务`
4. **今日任务卡**（松绿实底，骨白文字）
   - 眉题 `今日任务`
   - H2：`给家人讲一件今天开心的事`
   - 说明：`晚饭后问问乐乐今天在幼儿园最开心的事，听他讲完，再请他说说当时的心情。`
   - 三段虚线进度：2 段亮、1 段暗（骨白 42% 虚线）
   - 下方：`本周 2 / 3 天 · 今天还没打卡`
   - 底部左：`+10 积分`（marigold 软色数字）；右：ghost 按钮 `去打卡`
5. **筛选**（胶囊 chip）：`待完成`（选中）、`已完成`、`全部`
6. **任务清单**（区块标题 + 右侧 `共 3 项`；白卡列表）
   - `睡前整理书包` / `每天 · 20:30 前完成` / `+10 积分` / 标签 `待完成`
   - `帮忙摆碗筷` / `每天 · 晚饭前完成` / `+10 积分` / `待完成`
   - `周末一起买菜` / `本周六 · 和乐乐一起列清单` / `+15 积分` / `待完成`
   - 左侧圆形浅色图标：书包 / 碗筷 / 菜篮
7. **班级墙入口**（白卡列表行）
   - 标题 `班级墙`；副行 `今天 18 位小朋友完成了任务`；行尾 chevron
8. **`?state=empty`**
   - 圆形浅底 + 勾选线稿插画
   - 衬线标题：`今天的任务都完成啦`
   - 说明：`乐乐今天的三项任务都交了，去班级墙看看大家的分享。`
   - 主按钮：`看看班级墙`

不要出现：积分商城、排行榜、连续打卡惩罚、补卡付费。

## 4. DNA 硬规则（必须遵守）

- 画布 `#ECE6D7`；白卡；今日任务卡松绿实底；主色松绿 `#173220`
- H1 衬线 30px / 400；今日任务 H2 衬线 21px / 400；任务行标题无衬线 15px / 600
- 衬线永远 400，不得加粗
- 卡片无阴影、1px 发丝线
- 三段虚线进度：松绿卡上用骨白虚线，亮段用实心骨白；不要用进度条
- 积分数字用 marigold 软色，避免橙色主色化
- 小字颜色 `#55616F`（bone 上）/ `#5E6B7A`（白卡上）；松绿卡上小字用骨白 75–88%
- 触控区不小于 44px

## 5. 输出要求

- 三件套：`index.html`、`styles.css`、`app.js`，每个文件 < 20KB
- `styles.css` 开头原样粘贴 `tokens.css` 的 `:root { ... }` 块；只写本页布局
- 不引外链字体、CDN、网络图片；图标与插画用内联 SVG
- 390 × 844 无横向溢出；中文标题不得出现单字孤行
- 不写 lorem / TODO / “示例”
- `?state=empty` 必须能直接打开并截图；没有底部导航
