# 页面：家长端 · 班级信息

## 1. 页面位置

- 路由：`pages/class/index`，从「我的 · 班级信息」进入
- 二级页：返回栏（无边框 chevron + 小标题 `班级信息`），**没有**底部悬浮导航
- 视口：390 × 844，单列

## 2. 用户与场景

妈妈想知道孩子在哪个班、教室在哪、几点接送，以及两位老师怎么联系。页面要像一张班级名片，信息清楚、联系电话一键可达。

## 3. 产品事实（照抄，不要发明字段）

1. **状态栏**：`9:41` + 信号/电池。
2. **返回栏**：左侧 chevron；中间小标题 `班级信息`；右侧留空。
3. **页头**
   - H1：`小一班`
   - 副行：`阳光幼儿园 · 28 名幼儿`
4. **班级信息卡**（白卡，dl 行，行间 `--hair-soft` 发丝线）
   - `班级` `小一班`
   - `教室` `教学楼 2 层 203`
   - `在园时间` `08:00–17:00`（tabular-nums）
5. **班级老师**（区块标题 + 右侧 `2 位`；白卡列表）
   - 头像 `李`（sage 浅底）+ `李老师` / `主班 · 语言` + 右侧圆形电话按钮
   - 头像 `王`（赤陶浅底）+ `王老师` / `配班 · 艺术` + 圆形电话按钮
6. **班级公告**（浅暖底卡）
   - 眉题 `秋游通知`
   - 标题 `本周五去城市公园`
   - 正文：`定于 11 月 13 日（周五）上午组织秋游，请给孩子准备轻便水壶和遮阳帽，周四前交回执。`；`11 月 13 日（周五）` 是行内高亮（marigold）
   - 署名：`李老师 · 11 月 10 日`
7. **页脚**：`有疑问请先联系班级老师`

不要出现：班级成员名单、其他家长联系方式、群聊入口、成绩排名。

## 4. DNA 硬规则（必须遵守）

- 画布 `#ECE6D7`；白卡；公告卡 `#FCFAF4`；主色松绿 `#173220`
- H1 衬线 30px / 400；区块标题衬线 18px / 400；公告标题衬线 17px / 400
- 衬线永远 400，不得加粗
- 卡片无阴影、1px 发丝线
- 电话按钮：36px 圆形白底 + 1px 松绿描边 + 松绿图标，热区补到 44px
- 小字颜色 `#55616F`（bone 上）/ `#5E6B7A`（白卡上），不得用 `#728173` 作小字
- 触控区不小于 44px

## 5. 输出要求

- 三件套：`index.html`、`styles.css`、`app.js`，每个文件 < 20KB
- `styles.css` 开头原样粘贴 `tokens.css` 的 `:root { ... }` 块；只写本页布局
- 不引外链字体、CDN、网络图片；图标用内联 SVG
- 390 × 844 无横向溢出；中文标题不得出现单字孤行
- 不写 lorem / TODO / “示例”
- 没有底部导航
