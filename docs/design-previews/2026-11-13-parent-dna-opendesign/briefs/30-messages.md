# 页面：家长端 · 消息

## 1. 页面位置

- 路由：`pages/messages/index`，从「我的」或首页消息入口进入
- 二级页：返回栏（无边框 chevron + 小标题 `消息`），**没有**底部悬浮导航
- 状态：默认 + `?state=empty`

## 2. 用户与场景

妈妈想集中看老师和系统的消息，区分哪些还没读。她需要快速扫读：谁发的、什么时候、一句话摘要；未读用圆点标记，不要用大红点或数字轰炸。

## 3. 产品事实（照抄，不要发明字段）

1. **状态栏**：`9:41` + 信号/电池。
2. **返回栏**：左侧 chevron；中间小标题 `消息`；右侧留空。
3. **页头**：H1 `消息` + 右侧 `2 条未读`
4. **分段控件**（seg）：`全部`（选中）、`系统`、`老师`
5. **消息列表**（白卡，行间发丝线）
   - `李老师`（sage 浅底头像 `李`）/ `09:24` / `乐乐今天午睡很好，起来自己叠了小被子` / 未读橙点
   - `系统`（灰蓝圆形铃铛图标）/ `昨天 16:40` / `接送码已更新，可在接送页查看本学期的接送码` / 未读橙点
   - `王老师`（赤陶浅底头像 `王`）/ `昨天 08:10` / `明天请带水彩笔，美术课要画秋天的树` / 无点
   - `系统`（铃铛）/ `11-10` / `成长报告已生成，看看乐乐这学期的四个发展维度` / 无点
   - `园长`（默认头像 `园`）/ `11-09` / `11 月 21 日上午 9 点，多功能厅秋季家长会` / 无点
   - 未读行标题字重 600，已读 500；时间 11.5px tabular-nums
6. **页脚**：`已显示全部消息`
7. **`?state=empty`**
   - 圆形浅底 + 对话气泡线稿插画
   - 衬线标题：`暂时没有新消息`
   - 说明：`老师和园所的消息会出现在这里`
   - 主按钮：`回到首页`

不要出现：搜索、删除、标记已读按钮、聊天输入框、红点数字。

## 4. DNA 硬规则（必须遵守）

- 画布 `#ECE6D7`；白卡；主色松绿 `#173220`
- H1 衬线 30px / 400；消息发送者 15px / 500–600；摘要 13px
- 衬线永远 400，不得加粗
- 卡片无阴影、1px 发丝线
- 未读圆点 7px 橙色（仅提示层）；不要用橙色文字或红色数字
- 分段控件选中态松绿实底 + 骨白文字
- 小字颜色 `#55616F`（bone 上）/ `#5E6B7A`（白卡上），不得用 `#728173` 作小字
- 触控区不小于 44px（整行可点）

## 5. 输出要求

- 三件套：`index.html`、`styles.css`、`app.js`，每个文件 < 20KB
- `styles.css` 开头原样粘贴 `tokens.css` 的 `:root { ... }` 块；只写本页布局
- 不引外链字体、CDN、网络图片；图标与插画用内联 SVG
- 390 × 844 无横向溢出；中文标题不得出现单字孤行
- 不写 lorem / TODO / “示例”
- `?state=empty` 必须能直接打开并截图；没有底部导航
