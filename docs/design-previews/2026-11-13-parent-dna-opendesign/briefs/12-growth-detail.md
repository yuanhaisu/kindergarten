# 页面：家长端 · 成长详情

## 1. 页面位置

- 路由：`pages/growth/detail`，从成长时光列表进入
- 二级页：返回栏（无边框 chevron + 小标题 `成长时光`），**没有**底部悬浮导航
- 视口：390 × 844，单列纵向滚动

## 2. 用户与场景

妈妈点开老师发的一条成长记录，想看完整故事、照片和老师的观察，也想回应一句。页面要有杂志式的阅读节奏：大图先声夺人，文字可读，互动在底部但不抢内容。

## 3. 产品事实（照抄，不要发明字段）

1. **状态栏**：`9:41` + 信号/电池。
2. **返回栏**：左侧 chevron；中间小标题 `成长时光`；右侧留空。
3. **首图**：通栏 220px 高，sage 色块占位，左上角白色小标签 `09:20 · 教室门口`，圆角 20px。
4. **标题区**
   - 眉题：`今天 · 11 月 12 日 · 王老师`
   - H1：`第一次自己系好了鞋带`
5. **正文**（无卡片容器，15px / 1.65，段间距 12px）
   - `午睡起床后，乐乐坐在床边试了很久。第一次鞋带滑开了，他皱了皱眉，低头重来。`
   - `第三次系好以后，他抬头看着老师，说「老师你看」。这两周我们一直在练，今天他没有等人帮忙，也没有放弃。` —— `没有放弃` 是行内高亮（sage）
   - `对他来说，把一件小事做完，比做得快更重要。`
6. **照片网格**：2×2，方形，圆角 12px；sage / gold / clay / pine 色块；最后一格中央显示 `+2`（半透明松绿遮罩 + 骨白衬线数字）
7. **老师的观察**（浅暖底卡 `--surface-soft`）
   - 眉题 `老师的观察`
   - 衬线正文 17px / 1.8：`他今天愿意多试几次，而不是立刻求助。对一个五岁的孩子来说，这比「系好了」本身更重要。`
   - 署名 `王老师 · 12:10`
8. **家人的回应**
   - 区块标题 `家人的回应` + 右侧 `2 条`
   - 评论一：头像 `妈`（赤陶浅底）+ `妈妈` / `12:26` + `在家也练了好几天，今天居然自己系上了。晚上回来给爸爸演示一遍？`
   - 回复：缩进 24px，头像 `王`（sage 浅底）+ `王老师` / `12:32` + `好呀，明天早上再练一次，让他教教旁边的小朋友。`
   - 行间用 `--hair-soft` 发丝线
9. **底部互动条**（白卡，左右两格，上发丝线）
   - 左：实心赤陶爱心 + `点赞` + 数字 `8`
   - 右：评论气泡 + `评论` + 数字 `2`
   - 两格之间 1px 发丝线

不要出现：转发、收藏、打赏、相关推荐、广告。

## 4. DNA 硬规则（必须遵守）

- 画布 `#ECE6D7`；白卡；`--surface-soft` 观察卡；主色松绿 `#173220`
- H1 衬线 30px / 400；观察正文衬线 17px / 1.8；正文无衬线 15px / 1.65
- 衬线永远 400，不得加粗
- 卡片无阴影、1px 发丝线
- 内容标签用行内高亮，不是胶囊 chip
- 点赞的实心爱心用赤陶 `#C36540` 或 `--terracotta-text`；不要用橙色
- 小字颜色 `#55616F`（bone 上）/ `#5E6B7A`（白卡上），不得用 `#728173` 作小字
- 照片位用色块占位，保留 12px 圆角；不抓外网图片
- 触控区不小于 44px

## 5. 输出要求

- 三件套：`index.html`、`styles.css`、`app.js`，每个文件 < 20KB
- `styles.css` 开头原样粘贴 `tokens.css` 的 `:root { ... }` 块；只写本页布局
- 不引外链字体、CDN、网络图片；图标用内联 SVG
- 390 × 844 无横向溢出；中文标题不得出现单字孤行
- 不写 lorem / TODO / “示例”
- 没有底部导航
