# 页面：家长端 · 绑定孩子

## 1. 页面位置

- 路由：`pages/auth/bind`
- 二级页：有返回栏（无边框 chevron + 页面小标题 `绑定孩子`），**没有**底部悬浮导航
- 视口：390 × 844，单列纵向

## 2. 用户与场景

老师给了妈妈一个 6 位绑定码。她需要在 30 秒内完成：填孩子姓名、选关系、输绑定码、点绑定。页面要让她相信“这是园所给的、信息只用于家园沟通”，并且不出现多余的注册流程。

## 3. 产品事实（照抄，不要发明字段）

1. **状态栏**：`9:41` + 信号/电池。
2. **返回栏**：左侧无边框 chevron；中间小标题 `绑定孩子`；右侧留空。
3. **页头**
   - H1：`找到你的孩子`
   - 右侧 120 网格内联插画（约 92×92）：sage 圆底 + 赤陶/松绿两个相交圆 + marigold 小点 + sage 叶片；不贴边
4. **导语**（15px / 1.65，`--muted-on-surface` 或 `--muted`）：
   `绑定码由班级老师在入园时提供，一共 6 位。绑定后，孩子的通知、成长与接送都会出现在这里。`
5. **表单**（纵向，间距 14px）
   - 幼儿姓名：输入框，预填 `乐乐`
   - 与孩子关系：picker 行，当前值 `母亲`，右侧下箭头
   - 绑定码：输入框，预填 `384216`，数字键盘，`letter-spacing: .22em`，用衬线 19px；下方提示 `由园所老师在入园时提供`
   - 主按钮（通栏）：`绑定孩子`
   - 文字按钮：`没有绑定码？联系园所老师`
6. **底部 info 提示条**（灰蓝 14% 底，正文 `#55616F`）：
   `孩子信息只用于家园沟通，不会对外公开。`

不要出现：密码、验证码倒计时、邀请码扫码入口、孩子头像上传、多个孩子列表。

## 4. DNA 硬规则（必须遵守）

- 画布 `#ECE6D7`；输入框白底；主按钮松绿 `#173220`
- 标题衬线 400；H1 30px / 1.35；输入框文字可衬线，但正文与标签用无衬线
- 衬线永远 400，不得加粗
- 输入框：高 44px、圆角 12px、1px `rgba(23,50,32,.22)` 描边、白底；聚焦加 3px 松绿 12% 光晕
- 表单标签 12.5px / 500；提示 11.5px
- 卡片无阴影；表单区可不加卡片，直接排在暖纸底上；若用容器，只用发丝线
- 小字颜色 `#55616F`（bone 上）/ `#5E6B7A`（白卡上）
- 插画只用 DNA 填充白名单，无渐变
- 触控区不小于 44px

## 5. 输出要求

- 三件套：`index.html`、`styles.css`、`app.js`，每个文件 < 20KB
- `styles.css` 开头原样粘贴 `tokens.css` 的 `:root { ... }` 块；只写本页布局
- 不引外链字体、CDN、网络图片；插画用内联 SVG
- 390 × 844 无横向溢出；中文标题不得出现单字孤行
- 不写 lorem / TODO / “示例”
- 没有底部导航，不要补
