# 页面：家长端 · 通知列表

## 1. 页面位置

- 路由：`pages/notice/index`，从首页「通知」或最新动态进入
- 二级页：返回栏（无边框 chevron + 小标题 `乐乐 · 小一班`），**没有**底部悬浮导航
- 状态：默认 + `?state=empty` 空态

## 2. 用户与场景

妈妈想快速知道园所和班级发了什么，尤其是需要她行动的通知（报名、接种、家长会）。她通常只有几十秒，所以置顶通知要第一眼看到，未读要有明显但不刺眼的标记。

## 3. 产品事实（照抄，不要发明字段）

1. **状态栏**：`9:41` + 信号/电池。
2. **返回栏**：左侧 chevron；中间小标题 `乐乐 · 小一班`；右侧留空。
3. **页头**：H1 `通知`。
4. **筛选**（胶囊 chip，横向）：`全部`（选中）、`未读`、`园所`、`班级`
5. **置顶通知**（浅暖底卡 `--surface-soft`，下方 10px 间距）
   - 眉题：`置顶 · 园所通知` + 橙色小圆点（未读）
   - 标题：`秋季亲子运动会报名`
   - 摘要：`本周六上午 9:00 在园内操场举行，请在本周四 18:00 前完成报名。`
   - 元信息：`李老师 · 今天 08:30`
6. **通知列表**（白卡，卡片间距 12px）
   - 一：眉题 `园所通知` + 橙点（未读）；标题 `流感疫苗接种安排`；摘要 `本周四上午社区卫生服务中心到园接种，请填写知情同意书，由孩子周一带来。`；元信息 `王老师 · 昨天 16:20`
   - 二：眉题 `班级通知`；标题 `本月家长会安排`；摘要 `11 月 21 日（周六）上午 10:00 在小一班教室召开，请尽量一位家长参加。`；元信息 `李老师 · 11 月 10 日`
   - 三：眉题 `园所通知`；标题 `本周食谱已更新`；摘要 `本周新增南瓜小米粥与清蒸鲈鱼，孩子的过敏信息请在「幼儿信息」中确认。`；元信息 `园务办公室 · 11 月 9 日`
   - 摘要最多 2 行，超出用省略号
7. **`?state=empty` 空态**
   - 圆形浅底插画（120 网格，铃铛/通知意象，松绿线稿 + marigold 点缀）
   - 衬线标题：`还没有通知`
   - 说明：`园所有新通知时会出现在这里`
   - 主按钮：`回到首页`

不要出现：搜索框、通知分类 tab 之外的复杂筛选、无限滚动提示、营销 Banner。

## 4. DNA 硬规则（必须遵守）

- 画布 `#ECE6D7`；卡片 `#FFFFFF`；置顶卡 `#FCFAF4`；主按钮松绿 `#173220`
- H1 衬线 30px / 400；卡标题衬线 18px / 400；摘要无衬线 13px / 1.6
- 衬线永远 400，不得加粗
- 卡片无阴影、1px 发丝线；唯一阴影是底部悬浮导航（本页没有导航）
- 未读标记：橙色 6px 圆点（仅提示层）；不要用橙色文字
- 小字颜色 `#55616F`（bone 上）/ `#5E6B7A`（白卡上），不得用 `#728173` 作小字
- 触控区不小于 44px（卡片整块可点）

## 5. 输出要求

- 三件套：`index.html`、`styles.css`、`app.js`，每个文件 < 20KB
- `styles.css` 开头原样粘贴 `tokens.css` 的 `:root { ... }` 块；只写本页布局
- 不引外链字体、CDN、网络图片；图标与插画用内联 SVG
- 390 × 844 无横向溢出；中文标题不得出现单字孤行
- 不写 lorem / TODO / “示例”
- `?state=empty` 必须能直接打开并截图；没有底部导航
