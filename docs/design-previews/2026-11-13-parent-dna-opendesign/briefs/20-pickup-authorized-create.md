# 页面：家长端 · 添加授权人

## 1. 页面位置

- 路由：`pages/pickup/authorized/create`，从可接送人页进入
- 二级页：返回栏（无边框 chevron + 小标题 `接送`），**没有**底部悬浮导航
- 视口：390 × 844，单列表单

## 2. 用户与场景

妈妈要给外婆加一个接送授权。她需要填姓名、关系、手机号、有效期，并上传一张人像照片供门口核对。页面要说明“提交后要审核、审核通过才能接孩子”，避免她以为填完就生效。

## 3. 产品事实（照抄，不要发明字段）

1. **状态栏**：`9:41` + 信号/电池。
2. **返回栏**：左侧 chevron；中间小标题 `接送`；右侧留空。
3. **页头**
   - H1：`添加授权人`
   - 副行：`为乐乐（小一班）添加一位可接送人`
4. **表单卡**（白卡，字段间距 8px，字段间发丝线）
   - 姓名：输入框，预填 `陈秀兰`，占位 `请填写身份证上的姓名`
   - 与孩子的关系：picker，当前 `外婆`；下方提示 `可选：爷爷、奶奶、外公、外婆、其他`
   - 手机号：输入框，预填 `13700004418`，占位 `用于接收审核结果`
   - 有效期：picker，当前 `长期授权`；提示 `可指定日期，到期自动失效`
   - 人像照片：52×52 sage 色块缩略图（人像图标）+ `已上传 1 张` / `用于老师与门卫在门口核对身份` + 右侧文字按钮 `更换`
5. **warning 提示条**：`授权人接走孩子时需出示接送码`
6. **主按钮**（通栏）：`提交审核`
7. **底部隐私说明**（11.5px 弱文字，居中）：`授权信息仅用于接送核验，园所不会对外提供。`

不要出现：身份证号、住址、关系自定义输入、多个孩子选择、删除。

## 4. DNA 硬规则（必须遵守）

- 画布 `#ECE6D7`；白卡；主按钮松绿 `#173220`
- H1 衬线 30px / 400；字段标签无衬线 12.5px / 500；正文 15px
- 衬线永远 400，不得加粗
- 卡片无阴影、1px 发丝线
- 输入框：高 44px、圆角 12px、1px `rgba(23,50,32,.22)` 描边、白底；聚焦 3px 松绿 12% 光晕
- warning 条：橙 12% 底 + 松绿正文 + 橙色三角图标
- 小字颜色 `#55616F`（bone 上）/ `#5E6B7A`（白卡上），不得用 `#728173` 作小字
- 触控区不小于 44px

## 5. 输出要求

- 三件套：`index.html`、`styles.css`、`app.js`，每个文件 < 20KB
- `styles.css` 开头原样粘贴 `tokens.css` 的 `:root { ... }` 块；只写本页布局
- 不引外链字体、CDN、网络图片；图标用内联 SVG
- 390 × 844 无横向溢出；中文标题不得出现单字孤行
- 不写 lorem / TODO / “示例”
- 没有底部导航
