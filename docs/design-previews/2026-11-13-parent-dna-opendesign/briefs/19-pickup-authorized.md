# 页面：家长端 · 可接送人

## 1. 页面位置

- 路由：`pages/pickup/authorized`，从接送页「可接送人」进入
- 二级页：返回栏（无边框 chevron + 小标题 `接送`），**没有**底部悬浮导航
- 状态：默认 + `?state=empty` 空态

## 2. 用户与场景

妈妈要确认谁能接孩子，或者给外婆加一个授权。她需要一眼看清每个人的审核状态，以及“未通过的人不能接走孩子”这条规则。

## 3. 产品事实（照抄，不要发明字段）

1. **状态栏**：`9:41` + 信号/电池。
2. **返回栏**：左侧 chevron；中间小标题 `接送`；右侧留空。
3. **页头**
   - H1：`可接送人`
   - 副行：`只有名单内的家人可以接走孩子`
4. **授权人列表**（白卡列表行，行间发丝线，行尾 chevron）
   - `李静` / `妈妈 · 长期授权 · 138****6721` / 状态标签 `已通过`
   - `王磊` / `爸爸 · 长期授权 · 139****2035` / `已通过`
   - `陈秀兰` / `外婆 · 137****4418` / `待审核`
   - `赵国强` / `叔叔 · 135****8890` / `已拒绝`
   - 头像用姓氏首字：李 / 王 / 陈 / 赵；不同浅色底（默认 / sage / clay / plain）
5. **添加按钮**（通栏，松绿）：加号 + `添加授权人`
6. **info 提示条**：`名单有变更时会通知班级老师；新添加的家人需审核通过后才能接走孩子。`
7. **`?state=empty` 空态**
   - 圆形浅底 + 两个人物线稿插画（sage / clay / marigold）
   - 衬线标题：`还没有添加其他接送人`
   - 说明：`添加后，家人可在园门口凭码接走乐乐。`
   - 主按钮：`添加授权人`

状态口径（`backend/api/api-parent/` 接送授权）：`已通过 / 待审核 / 已拒绝`；`长期授权` 作为授权类型文案。

不要出现：删除、编辑、邀请二维码、家长之间的聊天。

## 4. DNA 硬规则（必须遵守）

- 画布 `#ECE6D7`；白卡；主按钮松绿 `#173220`
- H1 衬线 30px / 400；行标题无衬线 15px / 600
- 衬线永远 400，不得加粗
- 卡片无阴影、1px 发丝线
- 状态标签：小方标签，不是行内高亮；已通过 sage 浅底 + 松绿字；待审核橙 12% 底 + 松绿字；已拒绝赤陶软底 + 松绿字
- 小字颜色 `#55616F`（bone 上）/ `#5E6B7A`（白卡上），不得用 `#728173` 作小字
- 触控区不小于 44px（整行可点）

## 5. 输出要求

- 三件套：`index.html`、`styles.css`、`app.js`，每个文件 < 20KB
- `styles.css` 开头原样粘贴 `tokens.css` 的 `:root { ... }` 块；只写本页布局
- 不引外链字体、CDN、网络图片；插画用内联 SVG
- 390 × 844 无横向溢出；中文标题不得出现单字孤行
- 不写 lorem / TODO / “示例”
- `?state=empty` 必须能直接打开并截图；没有底部导航
