# 02 登录 · 无插画重设计 v2

## 上一版的问题（必须避免）

上一版把品牌/标题放上半部、登录卡压在最底部，中间留下约 1/3 屏的无意义空白；上半部“飘”，下半部“重”，登录卡内部又偏挤。这一版不要再用“顶部品牌 + 底部卡片 + 中间空白”的构图。

## 页面

家长端首启登录，390×844。无插画。请用明确的版式结构把上下连起来，而不是靠留白硬撑。

## 必须保留

- DNA 版 logo 56×56（`_shared/logo-dna.svg`）
- 眉题 `养成星球 · NURTURE PLANET`
- 主标题 `孩子的每一天 / 都值得被看见`（衬线 30px/400/1.35）
- 副文案 `家园沟通、成长记录与接送，都在这一个地方。`
- 微信一键登录（主按钮）、手机号验证码登录（次按钮）
- 同意行默认未勾选：`我已阅读并同意《用户协议》与《隐私政策》`，链接可点
- 支持说明 `遇到问题？请联系园所老师协助绑定`
- `?state=need-consent` 行内错误态

## 版式方向（二选一，做 strongest）

1. **上下分区，但用结构连接**：上半部约 42–48% 是品牌宣言区，下半部是白色登录面板，面板顶部圆角、从约 46% 处开始，不贴底；面板内部 24–32px 节奏。中间用一条细规则线 + 一个很小的编辑式标记（如年份/一句短说明）连接，而不是空白。
2. **整页编辑排版**：不做底部卡片，整个页面是一张“纸”：大标题、细规则线、登录按钮组按基线网格排布，登录区用浅色底或发丝线框区分；靠字阶和网格建立秩序，不靠卡片。

不要新增插画、卡通、3D、渐变光晕、装饰性大图；不要居中带阴影的弹窗式卡片；不要为了填空加无意义装饰。

## DNA 硬规则

- 画布 `#ECE6D7`；卡片/面板 `#FFFFFF`；次级面 `#F2EDDE`
- 主色松绿 `#173220`；橙色 `#F97316` 只做角标/圆点/待处理；terracotta/marigold 小面积
- 标题衬线 400，H1 30px/1.35；正文无衬线 15px/1.65
- 卡片无阴影、1px 发丝线；小字 `#55616F` / `#5E6B7A`
- 390×844 无横向溢出；中文换行无孤字；底部安全区

## 输出

`index.html` / `styles.css` / `app.js` 三件套，各 <20KB；不抓外网图；不写 lorem/TODO；登录/同意链接有可点交互。
