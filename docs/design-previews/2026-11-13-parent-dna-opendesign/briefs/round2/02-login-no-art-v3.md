# 02 登录 · 紧凑无插画 v3

## 上一版的问题（必须避免）

v1 / v2 都把品牌区放上半部、登录面板压在下半部，中间留出一条大而无内容的空白带（超过 1/4 屏）。这一版是「紧凑 no-art」：品牌区、三条纯文字连接、登录面板必须读作一个连续构图，**品牌区与登录面板之间不允许出现大于 24px 的无内容空白带**。

## 页面

家长端首启登录，390×844，无插画。只做一屏，不滚动。

## 构图（按这个顺序，垂直排列）

1. **品牌区**（约 300–330px 高，含状态栏下方留白）
   - DNA 版 logo 56×56（`_shared/logo-dna.svg`），可参考 v2 的 `_shared/` 相对引用
   - 眉题 `养成星球 · NURTURE PLANET`（11px / 0.14em 字距 / `#55616F`）
   - 两行 H1 `孩子的每一天<br>都值得被看见`（衬线 30px / 400 / 1.35 / 字距 0），可给「被看见」加行内高亮（词背后色块，不是胶囊）
   - 一行副文案 `家园沟通、成长记录与接送，都在这一个地方。`（无衬线 15px / 1.65 / `#55616F`）
2. **三条纯文字连接**（品牌区与登录面板之间，必须填满这段过渡，不允许空着）
   - 纯文字，**不用图标、不用卡片、不用插图**；三行之间用 1px 发丝线分隔
   - 固定三组文案（组名必须一字不差，后缀可精简到一行）：
     - `每日成长` —— 在园照片与老师寄语，当天就能看到
     - `接送安全` —— 谁接走孩子，授权一次就够
     - `家园沟通` —— 通知、请假与班级安排，都在这里
   - 三行整体高度约 120–150px，行内左组名右说明；组名用 `#173220` / 500，说明用 `#55616F` / 13px
3. **登录面板**（白色 `#FFFFFF`，左右与画布各留 20px，顶部圆角 20–26px，内边距 20px）
   - 只放**唯一一个**微信 CTA：松绿 `#173220` 底、`#ECE6D7` 字、高 54px、胶囊圆角、带微信图标，文案 `微信一键登录`
   - **无**「手机号验证码登录」或任何第二种登录方式
   - 单条同意行，默认未勾选：
     `我已阅读并同意《隐私政策》《未成年人个人信息保护规则》与《用户协议》`
     三个链接分别指向 `../../../parent-chosen/05-policy/index.html?doc=privacy|minor|terms&from=login`，可点
   - 未勾选点登录 → 行内错误 `请先阅读并同意《隐私政策》《未成年人个人信息保护规则》与《用户协议》`，留在本页，不跳转
   - 勾选后点登录 → 按钮 `aria-busy`、文案变 `正在唤起微信…`，随后跳转 `../../../parent-chosen/04-consent/index.html`
   - 面板底部支持说明 `遇到问题？请联系园所老师协助绑定`
   - 面板距屏幕底部留 16px 安全区

## 明确不要

- 不要插画、轨道、星球、卡通、3D、渐变光晕、装饰性大图
- 不要「2026 · 秋季学期」之类的学期营销信息
- 不要自定义授权前置层（微信授权抽屉、协议摘要抽屉、任何居中弹窗）；微信 CTA 不做前置 sheet
- 不要「手机号验证码登录」按钮及相关代码
- 不要居中带阴影的弹窗式卡片；卡片/面板无阴影，只用 1px 发丝线
- 不要 lorem / TODO / 占位假文案

## 可量化的验收（生成后按 390×844 截图核对）

- 品牌区底部（副文案最后一行）到第一条连接行的垂直距离 ≤ 24px
- 第三条连接行底部到登录面板顶部的垂直距离 ≤ 24px
- 页面中部无任何 > 24px 的连续无内容空白带
- 无插图、无第二种登录方式、无学期字样
- 三份文档同意行存在且默认未勾选；唯一微信 CTA

## DNA 硬规则

- 画布 `#ECE6D7`；卡片/面板 `#FFFFFF`；次级面 `#F2EDDE` / `#FCFAF4`
- 主色松绿 `#173220`；橙色 `#F97316` 只做角标/圆点/待处理，**不得做主按钮**
- 标题：衬线 400；H1 30px / 1.35 / 字距 0；H2 21px / 1.4；H3 18px / 1.4
- 衬线永远 400，不得加粗
- 卡片无阴影、1px 发丝线；唯一阴影是底部悬浮导航
- 内容标签用行内高亮（词背后色块），不是胶囊 chip；胶囊只用于筛选/操作
- 小字颜色 `#55616F`（bone 上）/ `#5E6B7A`（白卡上），不得用 `#728173` 作小字
- 图标：内联 SVG，24 网格，`fill="none" stroke="currentColor"`，线宽 1.6–2.0
- 不做暗色模式；不抓外网字体/图片；不写 lorem / TODO
- 390 × 844 无横向溢出；中文标题不得出现单字孤行；底部安全区

## 输出

- `index.html` / `styles.css` / `app.js` 三件套，**各自 <20KB**
- 不抓外网资源；字体走本地 `_shared/` 或系统衬线回退
- 状态栏时间 `10:20`，与 chosen 页集一致
- 登录 CTA、同意行、三份文档链接都有真实可点交互
