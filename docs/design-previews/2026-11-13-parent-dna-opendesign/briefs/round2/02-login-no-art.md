# 02 登录 · 无插画重设计

## 页面

家长端首启登录页，390×844。当前版本去掉了中间的星球/轨道插画，但只是留白，版面没有重新组织。请用排版、字阶、留白和品牌 mark 重做一版，不要用插画填空。

## 目标

- 首屏要有编辑感、可信、低摩擦，不像一个被删掉插图的空页面。
- 不新增插画、卡通、3D、渐变光晕或装饰性大图；不要用居中的带阴影卡片。
- 保留 DNA v1 的纸感、衬线标题和松绿主色。

## 必须保留的内容

- DNA 版 logo 56×56（`_shared/logo-dna.svg`）
- 眉题：`养成星球 · NURTURE PLANET`
- 主标题：`孩子的每一天 / 都值得被看见`（可换行；衬线 30px/400/1.35）
- 副文案：`家园沟通、成长记录与接送，都在这一个地方。`
- 微信一键登录（主按钮）
- 手机号验证码登录（次按钮）
- 同意行：默认未勾选；文案 `我已阅读并同意《用户协议》与《隐私政策》`；两个链接可点
- 支持说明：`遇到问题？请联系园所老师协助绑定`
- `?state=need-consent`：未勾选点登录时显示行内错误，不跳转

## 设计方向（选一个最强方案，不要平均用力）

1. **纸感编辑排版**：品牌 mark 与大标题形成上半部，用细规则线/大留白过渡，登录动作锚定在下半部；标题可以更大胆地占版，不要居中卡片。
2. **克制的品牌锚点**：用一条窄色块、竖排字标或极简几何线作为视觉锚点，但不抢登录；不要变成新的插画。

宁可留白，不要为了填空加无意义装饰。

## DNA 硬规则

- 画布 `#ECE6D7`；卡片 `#FFFFFF`；次级面 `#F2EDDE`
- 主色松绿 `#173220`；橙色 `#F97316` 只做角标/圆点/待处理；terracotta/marigold 只做小面积强调
- 标题衬线 400，H1 30px / 1.35 / 字距 0；正文无衬线 15px / 1.65
- 卡片无阴影、1px 发丝线；不要居中弹窗
- 小字用 `#55616F`（bone）/ `#5E6B7A`（白卡），不用 `#728173`
- 390×844 无横向溢出；中文换行无孤字；留出底部安全区

## 输出要求

- `index.html` / `styles.css` / `app.js` 三件套，各自 <20KB
- 不抓外网图、不写 lorem/TODO
- 登录按钮有模拟交互；同意行有默认未勾选与错误态；协议链接可点
