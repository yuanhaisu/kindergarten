# 页面：家长端 · 接送码

## 1. 页面位置

- 路由：`pages/pickup/qrcode`，从接送页「出示接送码」进入
- 二级页：返回栏（无边框 chevron + 小标题 `接送`），**没有**底部悬浮导航
- 视口：390 × 844，单列

## 2. 用户与场景

妈妈站在幼儿园门口，把手机屏幕递给老师核验。页面只需要做好一件事：让二维码/核验码在昏暗门口也能一眼看清，并明确“截图不可用、一次有效”。

## 3. 产品事实（照抄，不要发明字段）

1. **状态栏**：`9:41` + 信号/电池。
2. **返回栏**：左侧 chevron；中间小标题 `接送`；右侧留空。
3. **页头**
   - H1：`接送码`
   - 副行：`在园门口出示给老师核验`
4. **接送码卡**（白卡，内容居中）
   - 220×220 的二维码占位（内联 SVG 方块矩阵，松绿；不要用外链图片）
   - 孩子：`乐乐 · 小一班`（15px / 600）
   - 核验码：小标签 `核验码` + 衬线 26px / 400 / 字距 .08em 的 `A7K2-9F3D`
   - 分隔线下方刷新行：左 `58 秒后自动刷新`（tabular-nums）；右文字按钮（刷新图标 + `立即刷新`）
5. **warning 提示条**（12% 橙底 + 三角图标）：`截图不可用，请在门口实时出示`
6. **使用步骤**（眉题 `使用步骤` + 3 步）
   - `1` `到园门口打开本页，把屏幕调亮一点。`
   - `2` `把二维码或下方核验码出示给老师。`
   - `3` `老师核验通过后，接送记录会自动生成。`
   - 序号用 24px sage 浅底圆形
7. **页脚**：`一次有效 · 核验后自动失效`（11.5px 弱文字，居中）

不要出现：倒计时进度条动画、分享、保存到相册、广告。

## 4. DNA 硬规则（必须遵守）

- 画布 `#ECE6D7`；白卡；主色松绿 `#173220`
- H1 衬线 30px / 400；核验码衬线 26px / 400
- 衬线永远 400，不得加粗
- 卡片无阴影、1px 发丝线；二维码本身不加卡片外框
- warning 条：橙 12% 底 + 松绿正文 + 橙色三角图标；不要用橙色文字
- 二维码/核验码必须在任何背景下保持高对比
- 小字颜色 `#55616F`（bone 上）/ `#5E6B7A`（白卡上），不得用 `#728173` 作小字
- 触控区不小于 44px

## 5. 输出要求

- 三件套：`index.html`、`styles.css`、`app.js`，每个文件 < 20KB
- `styles.css` 开头原样粘贴 `tokens.css` 的 `:root { ... }` 块；只写本页布局
- 不引外链字体、CDN、网络图片；二维码用内联 SVG 占位
- 390 × 844 无横向溢出；中文标题不得出现单字孤行
- 不写 lorem / TODO / “示例”
- 没有底部导航
