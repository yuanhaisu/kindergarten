# 页面：家长端 · 登录

## 1. 页面位置

- 路由：`pages/auth/login`
- 首次进入的全屏页：**没有**底部悬浮导航，**没有**返回栏
- 视口：390 × 844，单列，内容贴近上下两端，中间留白

## 2. 用户与场景

妈妈第一次打开小程序，或在退出后重新登录。她需要立刻明白“这是什么、为什么要登录、登录后能做什么”，并且只做一件事：用微信一键登录。页面要安静、可信、不催促；品牌感来自衬线标题和一幅简单插画，而不是营销堆叠。

## 3. 产品事实（照抄，不要发明字段）

1. **状态栏**：`9:41` + 信号/电池。
2. **品牌区**（距顶部约 28px）
   - DNA 版圆形 logo：`_shared/logo-dna.svg`（pine `#173220` / marigold `#DDB14A` / cream `#FCFAF4`），56×56，置于眉题上方；几何沿用官方 logo，只换色，不要重绘
   - 眉题：`养成星球 · NURTURE PLANET`（11px / 0.18em / 600）
   - H1（两行，手动断行）：`孩子的每一天` / `都值得被看见`
   - 导语（衬线 16px / 1.8）：`家园沟通、成长记录与接送，都在这一个地方。`
3. **插画**：120 网格、约 232×232 的内联 SVG。浅 sage 圆底 + 松绿星球 + 赤陶轨道环 + marigold 小星 + 简单笑脸；只用 DNA 填充白名单色，不贴边，不加渐变/阴影。
4. **操作区**（靠近底部）
   - 主按钮（通栏，松绿）：微信图标 + `微信一键登录`
   - 次按钮（白底 + 1px 松绿描边）：`手机号验证码登录`
   - 勾选行（默认已勾选）：方形勾选框 17px + `我已阅读并同意 用户协议 与 隐私政策，同意园所使用孩子信息开展家园沟通。`；两个协议名是松绿下划线链接
5. **底部说明**：`遇到问题？请联系园所老师协助绑定`（11.5px 弱文字，居中）

不要出现：手机号输入框、密码框、第三方登录图标墙、优惠/营销文案、跳过按钮。

## 4. DNA 硬规则（必须遵守）

- 画布 `#ECE6D7`；主按钮松绿 `#173220`；橙色 `#F97316` 只做角标/圆点，本页不用
- 标题衬线 400；H1 30px / 1.35 / 字距 0；导语衬线 16px / 1.8
- 衬线永远 400，不得加粗
- 卡片无阴影；本页可以没有卡片，内容直接排在暖纸底上
- 勾选框：17–18px 方形、4px 圆角、松绿实底 + 骨白对勾
- 小字颜色 `#55616F`（bone 上），不得用 `#728173`
- 插画只用 `#C36540` / `#8DA386` / `#DDB14A` / `#FCFAF4` / `#173220`，无渐变
- 触控区不小于 44px（按钮 52–56px；勾选行整行可点）

## 5. 输出要求

- 三件套：`index.html`、`styles.css`、`app.js`，每个文件 < 20KB
- `styles.css` 开头原样粘贴 `tokens.css` 的 `:root { ... }` 块；只写本页布局
- 不引外链字体、CDN、网络图片；插画用内联 SVG；DNA logo 用本地 `_shared/logo-dna.svg`，不要重绘/换色
- 390 × 844 无横向溢出；中文标题不得出现单字孤行
- 不写 lorem / TODO / “示例”
- 本页没有导航，不要补底部胶囊导航
