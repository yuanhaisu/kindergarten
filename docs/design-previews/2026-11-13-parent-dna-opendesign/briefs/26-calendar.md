# 页面：家长端 · 班级日历

## 1. 页面位置

- 路由：`pages/calendar/index`，从「我的 · 班级日历」或首页进入
- 二级页：返回栏（无边框 chevron + 小标题 `班级日历` + 右侧 `今天` 文字按钮），**没有**底部悬浮导航
- 视口：390 × 844，单列

## 2. 用户与场景

妈妈想知道这个月哪几天有活动、家长会或假期，以及今天/最近要准备什么。月历要一眼可扫，事件列表只展示选中日期的安排，不铺满整月。

## 3. 产品事实（照抄，不要发明字段）

1. **状态栏**：`9:41` + 信号/电池。
2. **返回栏**：左侧 chevron；中间小标题 `班级日历`；右侧文字按钮 `今天`。
3. **页头**：H1 `2026 年 11 月`
4. **月历卡**（白卡，内边距 14px 8px）
   - 周标题：`周一 周二 周三 周四 周五 周六 周日`
   - 7 列网格，日期数字 13px；今天 `12` 用松绿实心圆 + 骨白数字
   - 非本月日期（10/26–10/31、12/1–12/6）用弱文字
   - 事件圆点 5px，位于日期下方：
     - 11/6 假期（terracotta）
     - 11/12 两个活动点（marigold）
     - 11/13 活动（marigold）
     - 11/14 活动（marigold）
     - 11/18 家长会（sage-deep）
     - 11/24 活动（marigold）
5. **今天**（区块标题 + 右侧 `11 月 12 日 · 2 个安排`；白卡列表）
   - `18:00` `亲子运动会报名截止` / `线上提交回执 · 活动`（`活动` 行内高亮 marigold）
   - `15:30` `班级生日会` / `小一班教室 · 班级活动`（`班级活动` 行内高亮 marigold）
   - 时间列 44px，粗体 12.5px；标题 15px / 500
6. **图例**：`活动`（marigold）/ `家长会`（sage-deep）/ `假期`（terracotta）
7. **页脚**：`本月还有 3 场活动`

不要出现：添加事件、编辑、订阅、天气、其他班级日历。

## 4. DNA 硬规则（必须遵守）

- 画布 `#ECE6D7`；白卡；主色松绿 `#173220`
- H1 衬线 30px / 400；区块标题衬线 18px / 400
- 衬线永远 400，不得加粗
- 卡片无阴影、1px 发丝线
- 今天：松绿实心圆 + 骨白数字；不要用橙色
- 事件圆点：活动 marigold、家长会 sage-deep、假期 terracotta；不新增颜色
- 小字颜色 `#55616F`（bone 上）/ `#5E6B7A`（白卡上），不得用 `#728173` 作小字
- 触控区不小于 44px（日期格可点）

## 5. 输出要求

- 三件套：`index.html`、`styles.css`、`app.js`，每个文件 < 20KB
- `styles.css` 开头原样粘贴 `tokens.css` 的 `:root { ... }` 块；只写本页布局
- 不引外链字体、CDN、网络图片；图标用内联 SVG
- 390 × 844 无横向溢出；中文标题不得出现单字孤行
- 不写 lorem / TODO / “示例”
- 没有底部导航
