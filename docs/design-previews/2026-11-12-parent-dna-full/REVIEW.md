## 全局修订（评审中发现）

1. **返回钮统一为无边框 chevron**（`_shared/normalize.mjs`）
   原先部分页面用 36px 白底圆钮，部分用纯 chevron；统一为后者，减少二级页页头的视觉重量。

2. **次级文字全部使用文字安全色**
   - bone 上 `#55616F`（5.07:1）
   - 白卡上 `#5E6B7A`（5.44:1）
   - `#728173` 只用于图标、分隔线与 ≥24px 大字；输入占位符从 `#728173` 改为 `#5E6B7A`

3. **info banner 与 sage 卡片的对比度修正**
   `rgba(138,148,163,.14)` 底上 `#5E6B7A` 实测约 **3.9:1**，改为 bone 上的安全次级色 `#55616F`（约 4.9:1）；
   图标保留灰蓝。`card--sage` 上 14px 的 bone 正文约 **4.19:1**，正文/小字改用 `#FCFAF4`（约 5.0:1），
   大标题仍可用 bone。规则记录在 `dna.css` 注释。

4. **日期与星期按真实日历校正**
   2026-11-12 实际是**周四**（原稿多处写周三）。已统一：首页 11/12 周四；运动会为 **11/14（周六）**，
   首页与通知摘要同步为「本周六」；接送历史 11/7 周六、11/10 周二、11/11 周三；成长 11/8 周日；
   任务提交 11/11 周三；请假详情 11/12 周四。班级日历给 11/14 补活动点，页脚改为「本月还有 3 场活动」，
   并把 12 日的「报名截止」时间改为与详情一致的 18:00。

5. **交互热区补齐到 44px**
   视觉高度不变（chip 32 / icon-btn 36 / btn--sm 34），用伪元素把可点区域扩到 44px。
   对应 DNA 审查中「不照搬参考产品的过小触控区」这一条；
   小程序实现时同样需要补热区（`view` 外套或 padding 负边距），不能只按视觉高度做。

6. **空态 CTA 统一为主按钮**
   7 个空态中 `30-messages` 原先是 ghost，改为 `btn--primary`，与其他空态一致。

7. **长标题手动断行**
   `22-tasks-detail` 的 h1 原折成「…开心的 / 事」单字孤行，改为「给家人讲一件 / 今天开心的事」。

8. **照片网格**
   `12-growth-detail` 的 4 张照片（3 列 + 1 张落单）改为 2×2。

## 业务口径对齐（避免移植时返工）

- **请假状态**：`待审批 / 已同意 / 已拒绝 / 已取消`（`backend/api/api-parent/03-leave.md`）。
  08 的统计、筛选与标签已改；10 保留「待审批」，因为只有待审批可撤回。
- **接送授权人**：列表状态用 `review_status_label`（`已通过 / 待审核 / 已拒绝`），
  不再写「已授权」；`auth_type_label` 可显示「长期授权」。
- **积分**：API 只有累计与流水，没有「可用 / 已使用」。
  24 改为总分 1245、本周 +45、本月 +180、班级排名 3/28；流水显示发生后的余额；
  成就用 `earned 8 / total 20`，未获得徽章不编进度数字（进度字段 API 标注未实现）。
- **成长报告**：14 增加四格实时统计（出勤 48/50、本期积分 +128、任务 10/12、成长记录 32），
  与发展维度（`dimensions[]`）并存；高光照片注明来自本期成长记录，避免被理解为报告接口自带图片。
- **相册**：15 的相册按日期倒序；`page-bar` 小标题由「首页」改为「小一班」。

## 已知边界（不阻塞确认）

- **照片位是色块占位**：真实照片资产不在本阶段；移植时从 OSS 取图，保留相同裁切比例与圆角。
- **插画是内联 SVG 草图**：按 DNA 的 120 网格与填充白名单绘制，逐页确定；
  最终资产在移植阶段导出为 `.svg` 文件（WXML 不支持内联 SVG）。
- **没有暗色模式**：DNA v1 决策。
- **数据是设计用 mock**：人名、时间、积分、照片数均为演示数据，不代表接口返回。
- **动效未在截图体现**：按压 150ms、抽屉 300/200ms、Toast 200/150ms 等按 DNA 决策实现。
- **触摸热区是 CSS 伪元素方案**：设计稿里不可见，移植时需在小程序侧同样处理。
