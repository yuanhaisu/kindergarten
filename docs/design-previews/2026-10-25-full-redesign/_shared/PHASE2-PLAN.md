# 班级相册 Phase 2 · 切片计划

> Phase 1 已归档（`openspec/changes/archive/2026-11-01-class-album-parent-sharing/`）。
> Phase 2 的每条切片都沿用同一原则：**家长可见性由后端收敛**、班内共享/opt-out/自己的孩子始终可见
> 不因新能力放宽；后端先于前端上线；每个切片一个 worker + 一个 supervisor。

## 推荐顺序与依赖

```
A 全班视图 ──> B 发布通知 ──> C 视频 ──> D 园外分享/下载 ──> E 打包导出
                                                      └─> F 人脸模糊（仅评估，暂不编码）
```

A 是后续所有「家长能看到更多内容」能力的基础；D/E 涉及园外传播，必须最后做；F 依赖第三方人脸能力与合规决策，先出评估。

---

## A. 全班视图（先做）

**目标**：园所可开启「全班」视图；家长可在「我的孩子 / 全班」间切换；opt-out 与自己的孩子规则不变。

| 切片 | 范围 | 验收 |
| --- | --- | --- |
| A1 后端 | 园所级开关（`ExtraConfig` 或新列，推荐 `ExtraConfig.class_album_classwide_enabled`，默认 false）；`GET /parent/class-albums` 与 `/:id` 接受 `scope=mine|all`；关闭时 `scope=all` 返回 403；`all` 仍按 opt-out 整张隐藏、自己的孩子始终可见；契约更新；单测 | 开关关闭/开启、scope 默认 mine、all 过滤、跨班 404；无 N+1 |
| A2 管理端 | 园所设置页新增「允许家长浏览全班相册」开关；写设置 + 审计；无权限用户不可见 | admin 构建 + 无头 Chrome 实测开关读写 |
| A3 家长端 | 班级相册页增加「我的孩子 / 全班」分段；开关关闭时不显示全班；切换后重新拉取；空态/错误态 | DevTools 真实点击 + 真实后端 E2E |

**默认**：园所开关 **关闭**；家长默认 `mine`；`scope=all` 仅在开关开启时可用。任何 opt-out 孩子仍按 Phase 1 规则整张隐藏。

---

## B. 发布通知

**目标**：相册发布后通知符合条件的家长；Phase 2 只做站内消息，不做微信订阅消息推送。

| 切片 | 范围 | 验收 |
| --- | --- | --- |
| B1 后端 | 发布成功后在发布事务外写站内消息（复用 message service）；收件人=相册参与者对应家长（按班内共享过滤）；同一相册不重复发；单测 | 发布发 1 条、重复发布不重复、opt-out 家长不收 |
| B2 家长端 | 消息中心渲染相册消息并跳转班级相册详情；已读/未读沿用现有 | DevTools 真实点击；消息→详情 200 |

**默认**：不推送、不发周报；周报留到 B3（后续可选）。

---

## C. 视频

**目标**：班级相册支持视频；家长可播放；复用成长记录的视频上传链路。

| 切片 | 范围 | 验收 |
| --- | --- | --- |
| C1 后端 | `album_photos` 增加 `file_type`、`duration`；上传/创建/编辑接受视频；限制 ≤15s、≤50MB；详情返回视频字段；契约 | 视频创建/过滤/详情；超限 422 |
| C2 老师端 | 上传选视频、封面/时长展示、预览；仅图片/视频混排 | DevTools 真实点击 + 真实上传 |
| C3 家长端 | 视频封面 + 播放；流量提示；opt-out/我的孩子过滤同样生效 | DevTools + 真机播放（真机残余） |

**默认**：不做转码；视频封面取上传返回的 `thumb_url`；单条 ≤15s / ≤50MB。

---

## D. 园外分享/下载

**目标**：家长显式开启 `allow_external_share` 后，可下载原图/分享；不提供公开链接。

| 切片 | 范围 | 验收 |
| --- | --- | --- |
| D1 后端 | 受控下载：校验 `allow_external_share`、孩子可见性、opt-out；签名 URL（短 TTL）；写审计；限流；契约 | 关闭时 403；开启时下载 200；审计 1 条；跨班 404 |
| D2 家长端 | 保存原图/分享入口；未开启时引导去设置；错误态 | DevTools + 真机分享残余 |

**默认**：无水印、无公开链接、无批量下载；只允许单张原图；分享到微信由系统分享面板完成。

---

## E. 打包导出

**目标**：家长可对单个孩子导出班级相册 ZIP；异步任务 + 短期下载链接。

| 切片 | 范围 | 验收 |
| --- | --- | --- |
| E1 后端 | 复用 `export_task` 模式：创建导出任务、生成 ZIP、7 天有效链接；需 `allow_external_share`；审计 | 任务创建/完成/下载；过期 410 |
| E2 家长端 | 导出入口、任务状态、下载/复制链接；失败重试 | DevTools + 真机下载残余 |

**默认**：按孩子导出、不跨孩子打包；ZIP 只含可见照片；7 天过期。

---

## F. 人脸模糊（仅评估）

**目标**：评估在班级相册/全班视图中对未授权孩子人脸做模糊的可行性与成本。

- F1：供应商能力、误模糊风险、合规口径、成本评估；**不写代码**。
- 只有 F1 通过产品/合规决策后才排期实现；否则保持 Phase 1 的“整张隐藏”。

---

## 执行方式

- 每个切片：`slice-worker` 实现 + 自测；`slice-supervisor` 对抗性复核 + 真实 DevTools/admin 验证。
- 后端切片先跑 Go 真实 DB 测试；前端切片必须有真实后端 E2E 或明确的 mock 标注。
- 共享文件（`parent_album_service.go`、`album_repo.go`、`pages.json`、`album/index.vue`）一次只由一个切片改。
- 每切片一个 commit；开放规格（OpenSpec）按 epic 建 change，A/B/C/D/E 各自 propose → apply → archive。
