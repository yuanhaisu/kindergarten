## 这个页面真实的产品事实（照此设计，不要发明）

这是家长从首页「通知公告」入口 `uni.navigateTo` 进入的**子页**，自上而下 3 个区块：

1. **统计条**（源码 stats-card）：三个数字 ——「全部通知」（接口 `total`）、「未读」（当前列表里 `is_read === false` 的条数）、「今日新增」（`published_at` 是今天的条数）。源码是横向三段 + 细竖分隔线。
2. **类型分段**（源码 tab-row）：4 个胶囊「全部 / 任务 / 活动 / 通知」，默认「全部」。切「任务」= `category=task`，「活动」= `activity`，「通知」= homework + bring + health + other 的合集（前端过滤）。选中项填充品牌色，未选中白底。
3. **通知列表**：每条是一张可点卡片，字段只允许这些 ——
   - `title` 标题
   - 未读标记（`is_read === false`）
   - `content_preview` 两行预览
   - `creator.nickname` 发布人（如「李老师」）
   - `published_at` 时间（源码只取日期；原型可写「今天 08:30 / 昨天 16:40 / 10月23日」）
   - `category` 类型（展示文案：task=任务、activity=活动、homework=作业、bring=带物、health=健康、other=其他）
   - 点击整卡 → `uni.navigateTo` 到通知详情；详情页在 `onLoad` 里静默调 `markNoticeRead`，即**进入详情才置已读**。

**源码里没有、绝对不要画**：置顶/标星、搜索框、筛选下拉、批量已读、右上角「全部已读」、消息分组、下拉刷新控件、附件缩略图、需确认/已确认标记（`need_confirm` 有字段但列表不展示）。也不要画底部 tabBar（子页）。

## 视觉与结构硬约束

- `<html lang="zh-CN" data-surface="parent">`，390px 手机视口，单列纵向流，不做桌面布局。
- **外壳必须原样使用共享 shell**：先读 `D:/yuanhaisu/personal_projects/kindergarten/docs/design-previews/2026-10-25-full-redesign/_shared/shell.md` 与同目录 `shell.css`，照抄 `mp-statusbar` / `mp-time` / `mp-status-icons` / `mp-navbar` / `mp-back` / `mp-title` / `mp-capsule` / `mp-main` / `mp-demo` 的标记与 SVG，不许自造状态栏。
- 引入顺序：`tokens.css` → `../../_shared/shell.css` → `styles.css`；末尾先 `<script src="../../_shared/shell.js"></script>` 再 `<script src="app.js"></script>`（app.js 监听 `document` 的 `mp:state` 事件）。
- **禁止把 shell.css 复制进项目**，也不要改写状态栏 SVG；只写 `<link href="../../_shared/shell.css">`，文件在当前项目里不存在也没关系（由流程拼装）。
- **styles.css 里绝对不许出现任何 `.mp-*` 选择器或覆盖**（唯一例外是 `[data-state]` 状态选择器，如 `.mp-app[data-state="empty"] .notice-list`）。
- **子页：必须画返回箭头**（`mp-back`）；导航标题是 `pages.json` 的 `navigationBarTitleText` —— **「通知公告」**。
- **不画 tabBar**（家长端只有首页/成长/接送/我的四个页面画）。演示条 `mp-demo` 用默认位置即可，不要加行内 bottom 覆盖。
- **筛选行随页面滚动，不要做吸顶**（`.mp-main` 有 overflow-x 会破坏 sticky，视觉上也不要留半透明浮条）。

### 设计方向（必须遵守）

**「安静的收件箱」**：数字先说话，列表像信箱一样整齐；颜色只用来标记未读，不用来装饰。

- 整页底 `var(--bg)`；卡片 `var(--surface)` + `var(--radius-card)` + `var(--shadow-sm)`。暖色面积 ≤ 10%，唯一暖色是未读圆点、选中的筛选胶囊、统计条里的未读数字。
- **统计条**：一张白卡，`grid-template-columns: repeat(3, minmax(0, 1fr))`；数字 20px/600 `var(--fg)`（未读用 `var(--accent)`），标签 11px `var(--muted)`；三段之间 1px `var(--border)` 竖分隔。不要渐变底、不要大图标。
- **筛选胶囊**：一行 4 个等宽按钮，`grid-template-columns: repeat(4, minmax(0, 1fr))`，高 40–44px，圆角 `var(--radius-pill)`，12–13px/500；未选中白底 `var(--border)` 1px 描边 + `var(--fg-2)` 字；选中 `var(--accent)` 填充 + `var(--on-brand)` 字 + 600 字重。**不要带数量角标**。
- **列表卡片**：左侧 40px 圆角方图标位（`var(--radius-xl)`），里面 20px `currentColor` 线性图标，按类型换图形（任务=清单勾、活动=小旗、作业=书、带物=书包、健康=心形脉搏、其他=喇叭）；**已读项图标位用 `var(--bg)` 底 + `var(--muted)` 图标，只有未读项用 `var(--accent-wash)` 底 + `var(--accent-deep)` 图标**。右侧垂直居中一个 16px `var(--hint)` 的 `›` 箭头（提示可点）。
- 卡内文字：标题 14px/600 `var(--fg)`（已读 500 字重即可），后面跟 7px 的品牌色未读圆点（只有未读有，且**不要整行染色、不要左边框**）；预览 12px `var(--muted)` 两行截断；meta 一行 11px `var(--muted)`：「活动 · 李老师 · 今天 08:30」，用 `·` 分隔，日期在句末，**不要右对齐另起一列**。
- 逐条之间 `gap: 10px`，不要给每条加分隔线；列表为空时卡片区域整体换成空态块。
- 颜色只写 `var(--*)`，禁止裸 hex / rgb / hsl；无直角（最小 `var(--radius-sm)`）；阴影只用 `var(--shadow-*)`。
- 触控目标 ≥ 44×44px；正文 ≥ 13px（预览/meta 允许 11–12px）；`:active` 必须有反馈（`transform: scale(.99)` 或背景压暗）。
- 禁止 `white-space: nowrap` 用于可能超宽的文本（导航标题由 shell 处理，不用管）；统计条与筛选用 `minmax(0, 1fr)`；所有容器 `max-width: 100%`，页面不得横向滚动；长标题自然折行（最多 2 行）。
- 不用 `<select>`、alert、prompt；无 console 报错；不引用任何外部资源。

## 状态覆盖（`data-state` 驱动，演示条用 `mp-demo` 四芯片：正常 / 空态 / 加载 / 失败）

- **正常**：上面的 8 条数据完整渲染（默认）。
- **空态**：隐藏列表，换成空态块 —— 44px 线性图标位（`var(--bg)` 圆底 + `var(--hint)` 图标）+「暂无通知」+ 一句说明「老师发布通知后会出现在这里」+ 主按钮「刷新」。统计条显示 0 / 0 / 0。
- **加载**：统计条数字换成灰条占位；列表换成 3 张骨架卡（图标圆 + 两行骨架条 + meta 短条），骨架用 `var(--border)`/`var(--bg)` 呼吸动画，`prefers-reduced-motion` 下关掉动画。
- **失败**：隐藏列表，换成错误卡 —— `var(--danger-wash)` 圆底 + `var(--danger)` 图标（注意/圆形叹号）+「通知加载失败」+「下拉刷新或点击重试」+「重试」按钮（白底描边或品牌填充，只能有一个主按钮）。统计条保留但数字显示「—」。
- **禁用态（不占芯片）**：① 加载态下 4 个筛选胶囊不可点：`opacity: .5`、`pointer-events: none`，选中的那个仍保留品牌底但降透明度；② 失败态点「重试」后按钮立即 `disabled`、文案「重试中…」、降到 `var(--hint)` 视觉，约 1 秒后恢复并 toast「已重新加载」。

## 交互（app.js，全部真实可点）

- 点筛选胶囊：切换选中态，按分类过滤卡片（任务 2 条 / 活动 2 条 / 通知 4 条 / 全部 8 条），同时**重算统计条三个数字**（按当前可见列表），并更新 `aria-pressed`。若某分类为空，显示「该分类暂无通知」+ 按钮「查看全部」。
- 点任一通知卡：把该条置为已读（圆点消失、图标位从 brand 洗底变中性、未读统计 -1），并 toast「已读 · 打开通知详情」；已读的卡片点击 toast「已打开通知详情」。用 `data-read="false"` 标记驱动，不要真的跳页。
- 点空态「刷新」/ 失败态「重试」→ toast「已重新加载」。
- 演示条芯片切换四态由 `_shared/shell.js` 写 `data-state` 并派发 `mp:state`；app.js 监听该事件做收尾（进入正常态时重置重试按钮与统计数字）。
- toast 用页面自绘的轻提示（`var(--fg)` 底、`var(--on-brand)` 字、圆角胶囊、固定在中下部），2 秒自动消失；不用 alert。
- 所有按钮/卡片有 `:active` 反馈；无 console 报错。
