## 唯一任务

只做一个方向，不要 A/B 变体，不要多页面。写完 index.html / styles.css / app.js 即停止：不要读取自己的产物，不要自查循环，不要提问，不要联网。

## 这个页面真实的产品事实
- 数据来自 `GET /parent/tasks/:id?student_id=` 与 `GET /parent/tasks/:id/checkin-history?student_id=&page_size=50`；详情字段：title、description、intro、requirements[]（字符串数组）、learning_link、frequency（daily/weekly/once）、allow_public、target_student_id、star_scope（task/class）、star_goal、start_date、end_date、status、submitted_current_period、has_unread_supplement、responses[]。
- responses 每项：ritual（sticker/voice/class_star/text）、sticker_key（star/heart/thumb/flower/smile/clap）、content、media_url（语音）、my_reaction（child_happy/received/thanks，空串=未反馈）、supplements[]（老师又补了一句，同结构）。
- 打卡历史每项：date、content（空则显示「（一键完成）」）、media_url、student_name、public_* 五个公开字段。公开状态：未公开→「申请公开」；已申请→「已申请，等待老师审核」+「取消公开」；已通过→「老师已通过，本班家长可见」或「老师已通过，暂不对本班展示」+「取消公开」；已撤下→「未公开」+「重新申请」。**取消公开是两步点击**：第一次点变成「确认撤下？」，再点才执行。个体任务（target_student_id>0）或任务未开 allow_public 时无「申请公开」，但撤回始终可用。
- 提交：`POST /parent/tasks/:id/checkin`，可带 content（≤500 字）与 media_file_id（**只允许 1 张图片**，源码 `uni.chooseImage({count:1})`）；每日任务当天一次、每周滚动 7 天内一次、一次性任务周期内一次。另有「今天完成了（一键提交）」只发空 content。成功后 submitted_current_period=true，打卡区消失，历史刷新。
- 「给孩子看」：全屏遮罩，放大贴纸 / 老师的话 / 播放语音，轻触空白处关闭。
- 老师的回应可给三个反馈：孩子很开心 / 收到了 / 谢谢老师（单选，再点即切换为本条）。
- 未读：has_unread_supplement 为 true 时在任务卡下方提示「老师又给你留了一句悄悄话，往下面看 👇」，打开页面即调 read 标记清除。
- 加载失败：404 文案「任务已结束或不存在」，其它「加载任务失败」，带「重试」；未绑定孩子「未绑定孩子信息」。另一条独立提示条（任务对当前孩子不可见时仍要显示）：「这条消息是另一个孩子的任务，当前看到的是「乐乐」」+「切换查看」。
- 本页由列表页 navigateTo 进入：**导航栏必须有返回箭头**；**不是 tabBar 页，不画 tabBar**。
- 任务不发积分：禁止出现任何积分数值或「+N 积分」。

## 设计方向「一次提交的完整回路」
页面主轴是一条纵向回路：**任务是什么 → 我交了什么 → 老师回了什么 → 以前交过什么**。不是表单堆砌，而是把「本周期这一次提交」当成一张可翻阅的记录卡。
- 任务卡：标题最大（18px/600），频次与「星星罐 20 星」做成两枚 11px 中性 pill，不抢标题；要求列表用数字圆点（16px accent-wash 圆 + accent-deep 数字），不要项目符号；学习关联是一块 accent-wash 内嵌卡，只占一行高。
- 提交卡（已提交/待审核/已通过）：日期 + 一句话内容 + 一张 4:3 照片占位块（用 SVG 线条插画占位，不写字）+ 审核状态行（待审核=warning-wash、已通过=success-wash、未公开=中性）+ 老师回应块。状态行是这一段的视觉锚点，用 11px 徽标 + 一句解释，不要用大色块。
- 老师回应块：左侧 28px 圆形 emoji 贴纸位 + 右上是「贴纸 / 语音」11px 小标签与时间；内容 14px/1.6；语音做成一条 44px 高的 accent-wash 圆角条；「给孩子看」是右下 11px 文本按钮，不是主按钮；三个反馈 chip 等宽一行，选中态 accent 底 + on-brand 字。
- 打卡区（未提交）：白卡，标题「今日提交」+ 一行 12px 说明「每日任务每天可提交一次」；照片位是 96px 方形虚线圆角块（accent-wash 底、+ 号与「添加照片」11px），选中后显示占位图 + 右上移除小圆；「今天完成了」是 44px 高的次按钮样式（surface-warm 底 + accent-deep 字），不是主按钮；输入框 min-height 96px，12px 圆角；「打卡」是唯一橙底主按钮，内容与图片都为空时置灰禁用并给 11px 说明「填写内容或上传照片后可提交」。
- 打卡历史：竖线时间轴（1px border + 8px 圆点，最近一条 accent，其余 hint），每行「日期 + 公开状态徽标」在上、内容在下、右下是「申请公开 / 取消公开」文本按钮；条目之间不画卡片边框，只用 1px 分隔，密度低于上面两张主卡。
- 状态切换条 chips：未打卡 / 待审核 / 已通过 / 空态 / 加载 / 失败（默认「未打卡」）。
- 整体暖色占比控制在 10% 以内：橙色只出现在主按钮、选中反馈、时间轴最近圆点、要求数字、星星罐 pill。

## 视觉与结构硬约束
- `<html lang="zh-CN" data-surface="parent">`；390px 手机视口；单列纵向流；不做桌面布局。
- 外壳只链接 `../../_shared/shell.css` 并用 `mp-statusbar / mp-navbar / mp-title / mp-capsule / mp-back` 标记，**不许复制或改写 shell.css，不许自造状态栏**；引入顺序 tokens.css → ../../_shared/shell.css → styles.css；**styles.css 里不得出现任何 `.mp-*` 定义**（`[data-state]` 状态选择器除外）。
- 状态栏 20px（9:41 + 图标）+ 44px 导航栏（返回箭头 + 标题「任务详情」+ 右侧胶囊）；**无 tabBar**。
- 颜色只写 `var(--*)`，禁止裸 hex/rgb；无直角（最小 `--radius-sm`，卡片 `--radius-card`，按钮/标签 `--radius-pill`）；阴影只用 `--shadow-*`。
- 层级只靠字重 + 字号：标题 600、正文 400、标签 500；正文 ≥ 13px，辅助信息 ≥ 11px；触控目标 ≥ 44px。
- 禁止 `white-space: nowrap` 用于可能超宽的文本；多列统计用 `grid-template-columns: repeat(N, minmax(0, 1fr))`；所有容器 `max-width: 100%`，不得横向滚动。
- 点击只做 `:active` 缩放/压暗，不做 hover 才可见的信息；不用 `alert` / `prompt`；console 必须干净。
- 数据区必须覆盖：未打卡（默认）/ 待审核 / 已通过 / 空态（打卡历史为空 + 一个主行动）/ 加载骨架（2–3 块）/ 失败（一句话 + 重试；失败态同时显示「这条消息是另一个孩子的任务」提示条与「切换查看」）。
