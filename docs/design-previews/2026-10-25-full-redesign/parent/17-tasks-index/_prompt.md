## 这个页面真实的产品事实
- 数据来自 `GET /parent/tasks?student_id=`，列表项真实字段：title、description、intro、frequency（daily/weekly/monthly/once）、status（1=进行中，0=已结束）、submitted_current_period、responded、checkin_count、has_unread_supplement、start_date、end_date、star_scope（task/class）、star_goal。
- 页面不是 tabBar 页，由首页进入，**导航栏必须有返回箭头**；**不画 tabBar**。支持下拉刷新（真机行为，原型不模拟手势）。
- 区块顺序固定：
  1) 班级墙入口（点击去 `/pages/tasks/wall`）：标题「班级墙」+ 说明「看看本班孩子的分享」+ 右箭头。
  2) 三个分类：**进行中 / 已打卡 / 全部**。「进行中」带红点数量（本周期未提交数）；进行中 = status=1 且本周期未提交；已打卡 = submitted_current_period；全部 = 所有任务。
  3) 任务列表。
- 卡片真实内容：图标 + 标题 + 描述（最多两行）+ 三态徽标「待完成 / 已提交 / 已回应」+ 未读提示「老师又给你留了一句悄悄话」+ 本周期状态「本周期待提交 / 本周期已提交 / 老师已回应」+ 频次与累计「每日任务 · 累计打卡 3 次」+ 两个动作：主按钮「去提交」（已提交时改「查看记录」）+ 次按钮「查看详情」，两者都进任务详情。
- 批次要求补充展示的真实字段：`end_date` → 「截止 10月31日」；奖励只写星星罐机制：`star_scope=task && star_goal>0` → 「星星罐 20 星」，`star_scope=class` → 「班级星星罐」（不写数字）。**本产品任务不发放积分，禁止出现任何积分数值或「+10 积分」文案。**
- 已结束任务（status=0）：加中性「已结束」徽标，主按钮降级为不可点的「已结束」，次按钮仍可「查看详情」。
- 失败但已有列表时，源码保留旧列表并在顶部提示「加载失败，点击重试」；错误且无数据才整块换成错误态。
- 空态文案按分类区分：进行中「当前没有待完成的任务」、已打卡「暂无任务」、全部「暂无任务」；未绑定孩子时错误文案是「未绑定孩子信息」。

## 视觉与结构硬约束
- `<html lang="zh-CN" data-surface="parent">`；390px 手机视口；单列纵向流；不做桌面布局。
- 外壳只链接 `../../_shared/shell.css` 并用 `mp-statusbar / mp-navbar / mp-title / mp-capsule / mp-back` 标记，**不许复制或改写 shell.css，不许自造状态栏**；引入顺序 tokens.css → ../../_shared/shell.css → styles.css。
- 状态栏 20px（9:41 + 图标）+ 44px 导航栏（返回箭头 + 标题「亲子任务」+ 右侧胶囊）；**无 tabBar**。
- 颜色只写 `var(--*)`，禁止裸 hex/rgb；无直角（最小 `--radius-sm`，卡片 `--radius-card`，按钮/标签 `--radius-pill`）；阴影只用 `--shadow-*`。
- 暖色面积 ≤ 10%：橙色只用于选中分类、主按钮、未读点与少量图标底；大面积用 `--bg / --surface`。不用装饰性大渐变。
- 层级只靠字重 + 字号：标题 600、正文 400、标签 500；正文 ≥ 13px，辅助信息 ≥ 11px；触控目标 ≥ 44px。
- 禁止 `white-space: nowrap` 用于可能超宽的文本；多列统计用 `grid-template-columns: repeat(N, minmax(0, 1fr))`；所有容器 `max-width: 100%`，不得横向滚动。
- 点击只做 `:active` 缩放/压暗，不做 hover 才可见的信息。
- 数据区必须覆盖：正常 / 空 / 加载骨架（2–3 张卡）/ 错误；另做「原型演示」状态切换胶囊（复用 `mp-demo` + `data-mp-state`，默认收起）。禁用态体现在已结束卡的主按钮。

## 设计方向（按此执行，不要另起方向）
「任务节奏」：卡片的视觉主轴是**本周期是否已提交**，不是进度百分比。源码用 0%/100% 进度条表达一个二元事实，原型改为一条「本周期」状态行（待提交=空心圆点+accent；已提交=对勾+success；已回应=双勾+info），更诚实也更轻。每张卡三段：任务是谁（图标+标题+描述）→ 周期事实（频次/累计、截止/星星罐、本周期状态）→ 动作（主+次）。已结束卡整体降饱和，但文字仍达 AA。
- 班级墙入口做成一条低矮白卡（36px 淡橙圆图标 + 两行文字 + 箭头），不要源码那种整块橙色底。
- 分类做成白色胶囊容器内的三段等宽分段控件，选中段 `--accent-wash` 底 + `--accent-deep` 字；进行中的红点数量用 `--danger` 16px 小圆。
- 「进行中」列表上方加一行 12px 待完成提醒：「本周期还有 2 个任务待提交」，前面一个 6px 琥珀圆点；这是对真实 pendingCount 的呈现，不要写成营销文案。
- 列表底部一行 11px 灰字「任务由老师发布 · 下拉可刷新」，呼应真实下拉刷新。
- 所有文案克制，不写营销话术；按钮 2–4 字动词。
