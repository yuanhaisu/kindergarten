# 请假详情（parent）

> 生成方式：OpenDesign（run `c55cb43d`）。包装脚本在 `index.html` 稳定 30s 时提前判定结束，`styles.css` / `app.js` 为 run 结束后从项目目录补齐（`_run.json` 已注明），随后人工修了两处设计问题（见「与现状的差异」）。

- 源码：`parent/src/pages/leave/detail.vue`；接口 `parent/src/api/parent-leave.js`（`GET /parent/leaves/:id`、`PUT /parent/leaves/:id/cancel`）
- 设计系统：`user:nurture-planet-local`，`surface=parent`
- 方向：把「一条记录」讲成「一次审批的完整经过」——状态与时间线在头部交代结论和经过，下面才是请假信息与审批意见，撤销是待审批态唯一动作且必须二次确认。
- 信息层级：
  1. 状态头（图标 + 状态名；结论之外最多留一句极短说明，不再重复审批人与时间）
  2. 审批时间线（提交 → 审批，提交时间与审批人/时间只在这里出现一次）
  3. 请假信息（学生 / 日期 / 天数 / 接送人 / 事由；学生行带圆形首字头像）
  4. 审批信息（只放审批意见正文；无审批时为一行占位）
  5. 撤销申请（仅待审批）/ 终态说明（已驳回、已撤销）

## 覆盖状态

| 状态 | 表现 |
|---|---|
| 正常（已同意） | 默认渲染。绿色状态图标 + 两节点全绿时间线 + 绿色审批意见 |
| 待审批 | chip 切换。橙色时钟图标 + 第一节点完成、第二节点空心等待 + 「撤销申请」按钮出现 |
| 已驳回 | chip 切换。危险色图标 + 第二节点红点「王老师已拒绝」+ 浅红底审批意见 + 底部灰色终态说明 |
| 已撤销 | **无独立 chip**，由「待审批」点撤销并确认后真实进入。全中性灰：灰图标、灰空心节点「审批已终止」、审批卡占位「无审批记录」，撤销按钮消失 |
| 加载 | chip 切换。骨架卡（1 圆点 + 3 行胶囊条），无进度条 |
| 失败 | chip 切换。错误图标 + 「请假详情加载失败，请检查网络后重试。」+ 橙色「重试」；点重试先回骨架态再回已同意，并 toast「请假详情已重新加载」 |
| 禁用 | 终态不出现撤销按钮；失败态重试按钮按下时 `disabled` + `opacity .55` |

撤销确认对话框：微信原生 `showModal` 骨架（标题「确认撤销」/ 说明「确定要撤销此请假申请吗？」/ 取消 · 确定，底部双键带分隔线，圆角由面板裁切），遮罩压暗整屏含导航栏，确定按钮用危险色。支持 Esc 关闭、Tab 焦点循环、关闭后焦点回到触发按钮。

## 与现状的差异

1. **新增审批时间线**（源码没有）。用 `created_at` 与 `reviewed_at` 两个真实时间组两节点，把「什么时候提交、谁什么时候处理」从一段文字变成可扫读的经过。
2. **审批备注只出现一次**。源码把 `review_remark` 放在状态头部；本设计头部只留结论，意见正文放到「审批信息」卡，避免同一段话在首屏出现两次。审批人与审批时间同理，只由时间线承担，审批卡不再重复一行「王老师 / 时间」。
3. **撤销按钮降饱和**。源码是 `#EF4444` 实心红底全宽按钮；改为浅红底 + 红描边 + 深色文字，危险语义保留但不再抢走整屏注意力；下方补一行灰字说明不可恢复。
4. **终态补一行说明**（已驳回 / 已撤销）：「已结束的申请不可撤销，如需再次请假请重新提交」，替代源码中「按钮直接消失」的空白。
5. **重试按钮文字色**：原型初稿在橙色渐变上用了 `--fg`，改为 `--on-brand`，与批次其它页面一致。
6. **审批信息卡占位**：源码在 `reviewer` 为空时整块不渲染（待审批时该卡片消失，页面会跳动）；本设计固定保留卡片并显示占位，四态高度稳定。

## 遗留 / 需产品确认

- **撤销无时间可展示**：`leave_requests` 只有 `reviewed_at`，没有 `cancelled_at`，所以「已撤销」节点只能写「已撤销，审批终止」而没有时间戳。若要显示撤销时间，需加字段并改契约（建议并入 `_shared/findings.md`）。
- **撤销后审批字段仍存在**：取消只改 `status=3`，`reviewer_id` / `reviewed_at` / `review_remark` 保留。原型据此把审批卡降级为「申请已撤销，无需审批」占位，而不是继续展示审批人——是否保留原审批快照需产品定。
- **状态文案口径**：源码字典写「已拒绝」，请假记录列表页与本源型统一用「已驳回」，需产品确认统一叫法。
- **撤销按钮下的一行提示**（「撤销后审批将同时终止，且无法恢复」）与终态说明文字均为设计补充，源码无对应字段/文案。
- **`days` 与日期区间口径**：原型写「10月27日 ~ 10月29日 · 3 天」，天数直接取 `days` 字段，未在前端重算，若后端含非工作日需确认口径。
- 页面内容高度小于一屏（390×~830），底部保留安全区，无固定底栏，因此演示条未做底部偏移。
