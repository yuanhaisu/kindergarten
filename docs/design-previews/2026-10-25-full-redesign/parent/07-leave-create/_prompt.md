## 这个页面真实的产品事实（照此设计，不要发明字段）

家长在「请假记录」页点「+ 请假」进入本页（`uni.navigateTo`，**是子页，导航栏必须有返回箭头**）。页面是一个表单 + 底部固定提交栏，从上到下：

1. **当前孩子（只读上下文，不是可选项）**
   - 请假对象来自本地存的「当前孩子」（`getCurrentStudentId()`），**本页没有切换孩子的入口**，不要画切换器 / 下拉。
   - 只能用一行轻量的上下文条呈现：`乐乐 · 小一班`，前缀「为」或一个头像 + 名字，右侧不放假箭头。
   - 后端会校验孩子归属，不属于该家长直接 403。

2. **请假类型** `activeType`：三个单选卡片，**病假 / 事假 / 其他**，各自带一句说明：
   - 病假 ——「因病需要休息」
   - 事假 ——「个人或家庭事务」
   - 其他 ——「其他原因」
   - 横向三等分或纵向三行都可以，选中态为品牌色描边 + `--accent-wash` 浅底 + 加粗 + 右上角勾选标记。
   - ⚠️ 事实：源码里这个选择**只是前端视觉状态，没有提交进 payload**，后端也没有对应字段。原型里保留它（它是本页最主要的选择动作），但**不要给它加必填星号**，也不要让它参与阻断校验。

3. **请假时间**：开始日期 / 结束日期两个日期值，源码是原生 `mode="date"` picker，本原型改成**底部日期弹层**（见交互）。
   - 只能选**今天及以后**（今天 = 2026-10-26 周一）。
   - 结束日期不得早于开始日期；把开始日期改到已选结束日期之后时，结束日期自动跟随改成同一天。
   - 两行值下方或右侧给一行小字汇总：`共 2 天`（来源：后端 `days` 字段，含首尾两天）。

4. **请假原因** `reason`：多行文本，**必填**，占位「请详细描述请假原因...」，上限 500 字，右下角显示 `0/500` 实时字数。

5. **接送人信息**：两个单行输入
   - 接送人姓名，占位「接送人姓名」
   - 接送人手机号，占位「接送人手机号」，数字键盘、11 位
   - **选填**（源码校验只看原因与两个日期），卡片标题旁标「选填」。

6. **附件**（选填）：`病假条、就诊记录等照片`，一个「+ 添加照片」方块入口（微信上传图样式），不要做成文件选择框。
   - 说明文案：`选填，最多 3 张`。已选时显示缩略占位方块（浅色底 + 图片图标 + 右上角 ×）。

7. **底部固定提交栏**
   - **按钮上方常驻一行说明**（13px，这一行是硬要求）：必填没填齐时写「还需填写：开始日期、请假原因」这类阻断文案，用 `--danger` 或 `--warning`；填齐后换成中性事实「共 2 天 · 提交后进入待审批」。
   - 主按钮「提交申请」：填齐时品牌渐变可点；未填齐时置灰禁用（`--surface-warm` 底 + `--border` 边 + `--muted` 字，`aria-disabled="true"`），**不允许点了才弹 toast**。
   - 提交中：按钮内小转圈 +「提交中…」，整块不可点。
   - 安全区：`padding-bottom: calc(12px + env(safe-area-inset-bottom))`；内容区底部留出与栏等高的空白，最后一张卡片不被遮住。

**提交逻辑（原型必须真的按这个跑）**
- 必填 = 开始日期、结束日期、请假原因三项。任缺一项：就在字段下方就地显示 `--danger` 小字（如「请选择开始日期」「请填写请假原因」），同时底部那行常驻说明改成阻断文案、主按钮禁用。补齐后错误消失、按钮恢复。
- 校验通过点「提交申请」：按钮 loading，约 1.4 秒后顶部 toast「提交成功」，随后表单复位。
- 提交失败（失败态芯片或模拟失败）：**不要用 toast**，在提交栏上方挂一条 `--danger-wash` 底色失败条「提交失败，请重试」+「重试」按钮；表单内容全部保留。

**源码里不存在、绝对不要画的字段/控件**：班级选择、请假天数手动输入、审批人选择、紧急联系人以外的其他联系人、请假类型自定义、撤销/撤回、草稿箱、重复请假、上传视频、剩余假期余额、是否销假。

## 视觉与结构硬约束
- `<html lang="zh-CN" data-surface="parent">`，390px 手机视口，单列纵向流，不做桌面布局。
- **外壳必须原样使用共享 shell**：先读 `D:/yuanhaisu/personal_projects/kindergarten/docs/design-previews/2026-10-25-full-redesign/_shared/shell.md` 与 `shell.css`，照抄其中 `mp-statusbar` / `mp-time` / `mp-status-icons` / `mp-navbar` / `mp-back` / `mp-title` / `mp-capsule` / `mp-main` / `mp-demo` 的标记与 SVG，不许自造状态栏。
- 引入顺序：`tokens.css` → `../../_shared/shell.css` → `styles.css`；末尾先 `<script src="../../_shared/shell.js"></script>` 再 `<script src="app.js"></script>`（app.js 监听 `document` 的 `mp:state` 事件）。
- **禁止把 shell.css 复制进项目**，也不要改写状态栏 SVG；只写 `<link href="../../_shared/shell.css">`，文件在当前项目里不存在也没关系（最终由流程拼装）。
- **styles.css 里绝对不许出现任何 `.mp-*` 选择器或覆盖**（唯一例外是 `[data-state]` 状态选择器，可写成 `.mp-app[data-state="failed"] .xxx`）。
- 子页：导航栏**保留返回箭头**，标题「请假申请」。家长端本页**不画 tabBar**（请假申请不是首页/成长/接送/我的四个 tab 页）。
- 表单节奏参考小程序 cell：分组标题在卡片外（12px `--muted`，可带「选填」后缀），卡片 `var(--radius-card)` + `var(--shadow-sm)`；可点的日期行右侧显示当前值 + `›` 箭头，行高 ≥ 52px，整行可点。
- 输入类字段用「标签在上、输入在下」的堆叠式，标签 13px/500；不要用桌面端 label 右对齐表单项。
- 颜色只写 `var(--*)`，禁止裸 hex / rgb / hsl；**无直角**（最小 `var(--radius-sm)`）；阴影只用 `var(--shadow-*)`。
- **暖色克制（≤10% 面积）**：橙色只出现在选中的类型卡、日期值高亮、底部「提交申请」按钮、字数接近上限时的提示；大面积是 `var(--bg)` 与 `var(--surface)`。
- 触控目标 ≥ 44×44px；正文 ≥ 13px；`:active` 必须有反馈（缩放或压暗）。
- 禁止对可能超宽的文本用 `white-space: nowrap`；多列统计用 `grid-template-columns: repeat(N, minmax(0, 1fr))`；所有容器 `max-width: 100%`，页面不得横向滚动；长原因/姓名自然折行。
- 不用 `<select>`、alert、prompt；无 console 报错。

## 状态覆盖（`data-state` 驱动，演示条用 `mp-demo`，五个芯片：正常 / 必填未填 / 加载 / 提交中 / 失败）
- **正常**：上面的示例数据已填满，常驻行「共 2 天 · 提交后进入待审批」，主按钮可点。
- **必填未填（空态）**：类型未选、两个日期显示「请选择」、原因空、接送人空、无附件；三处必填下方各显示 `--danger` 就地提示；常驻行变成「还需填写：开始日期、结束日期、请假原因」；主按钮置灰禁用。
- **加载**：卡片内容换成骨架条（类型三格占位、两个日期行占位、原因多行占位、接送人两行占位），常驻行「正在加载…」，主按钮禁用。
- **提交中**：表单保持正常态内容但整体不可编辑（输入/类型卡/日期行 `pointer-events: none` + 视觉降级），主按钮内小转圈 +「提交中…」，常驻行「正在提交，请稍候」。
- **失败**：表单保持正常态内容，提交栏上方出现失败条「提交失败，请重试」+「重试」按钮；点「重试」→ 失败条收起、toast「已重新提交」、恢复可提交。
- 另外（与芯片独立）：正常态下手动清空原因再点「提交申请」，必须就地出现错误并阻止提交，`data-state` 不变。

## 交互（app.js，全部真实可点）
- 类型卡单选切换，切换时更新选中态与 `aria-pressed`。
- 开始日期 / 结束日期行 → 打开**底部日期弹层**：半透明遮罩 + 从底部升起的 `--surface` 面板（顶部圆角 `var(--radius-2xl)`），标题「开始日期」/「结束日期」，主体是一个**当月月历格**（7 列，周一…周日；`2026年10月`），今天之前的日子置灰不可点，结束日期弹层里早于开始日期的日子也置灰；底部「取消 / 确定」。选中日期后关闭并把值写回行内 + 刷新「共 N 天」。遮罩点击可关闭。
- 原因输入实时更新 `x/500` 字数。
- 「+ 添加照片」点击后追加一个缩略占位方块（最多 3 个），方块右上角 × 可删除。
- 「提交申请」按上面的校验与提交逻辑走；禁用态下点击无反应。
- 演示条芯片切换五态；`mp-demo` 需用行内 `style="bottom: calc(120px + env(safe-area-inset-bottom))"` 避让底部固定栏（这是唯一允许的行内外壳覆盖）。
- 所有按钮/行有 `:active` 反馈；无 console 报错。
