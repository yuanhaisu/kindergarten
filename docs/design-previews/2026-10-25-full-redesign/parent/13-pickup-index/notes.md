# 接送记录（家长端）

- 源码：`parent/src/pages/pickup/index.vue`（tabBar 第 3 项「接送」，`navigationBarTitleText` = 接送记录，`enablePullDownRefresh: true`；数据来自 `GET /parent/pickup/records`）
- 设计系统：`user:nurture-planet-local`，`surface=parent`
- 方向：把「今天」做成一张可出示的接送凭证 —— 状态、时间轴、二维码入口收在同一张卡里；「过去」退成按日期分组的安静流水，先看今天，再往下翻。

## 信息层级（从上到下）

1. 导航栏「接送记录」+ 胶囊；tab 页，**无返回箭头**
2. 今日接送凭证：日期「10月26日 周一」、孩子「乐乐 · 小一班」、主状态（默认「在园中」+ 07:52 妈妈（李丽）送入）
3. 今日轨迹时间轴：默认只列入园 07:52 妈妈（李丽）· 母亲；「已接走」态再追加接走 17:30 爸爸（王明）· 父亲
4. 凭证底栏：未接走时主按钮「出示接送二维码」+「核验后一次有效」；「已接走」终态换成不可点的「今日接送已完成」回执条
5. 历史记录：按日期分组（10月23日 → 10月20日），每组两行（入园 / 接走），行内是类型胶囊 + 姓名 + 关系 + 时间 + `›`
6. 底部 tabBar 4 项，「接送」高亮

## 覆盖状态

今日卡按当天记录派生三态（原型没有数据源，用演示芯片切换，结果写到 `.mp-app[data-day]`）：

- **在园中**（`正常`，默认）：当天最后一条是入园 → 状态「在园中 / 07:52 妈妈（李丽）送入」+ 只有入园节点的时间轴 + 二维码主按钮
- **已接走**（`已接走` 芯片）：当天最后一条是接走 → 状态「已接走 / 17:30 爸爸（王明）」+ 入园/接走两条时间轴 + 不可点的「今日接送已完成」回执条；此时不露出二维码按钮（接送已完成，再出示会与弹层的「今日接走人 / 有效期至 23:59」自相矛盾）
- **未入园**（`未入园` 芯片）：今天还没记录但历史仍在 → 状态「未入园 / 今天还没有入园记录」+ 直接给二维码主按钮，历史列表照常显示
- **空**：今天没记录且没有任何历史 → 插画位 +「今天还没有接送记录」+ 一句说明 + 主按钮「出示接送二维码」（历史区一并隐藏，「有历史但今天没记录」用「未入园」态表达）
- **加载**：凭证卡骨架 + 3 行列表骨架，`pickup-shimmer` 扫光；二维码按钮 `disabled`
- **错误**：「接送记录加载失败 / 网络好像不太稳定」+ 描边「重试」；点重试 → 正常态 + toast「已重新加载」
- **禁用**：加载/失败态下二维码按钮降透明度且不可点；重试点击中显示「重试中…」并禁用

## Token 映射

- 页面底 `--bg`；卡片 `--surface`；凭证头部 `--accent-gradient-soft`；主按钮 `--accent-gradient` + `--on-brand`
- 今日时间轴：入园 `--success`，接走 `--accent`；竖线 `--border`
- 今日封签：在园中/已接走 `--accent-deep`，未入园 `--muted`；完成回执条 `--success-wash` / `--success`
- 历史类型胶囊：入园 `--success-wash/--success`，接走 `--info-wash/--info`；异常 `--warning-wash/--warning`
- 圆角 `--radius-2xl`（卡片）、`--radius-pill`（按钮/胶囊/标签）、`--radius-xl`（弹层内人证卡）
- 阴影 `--shadow-sm/md/lg`；间距 `--space-*` / `--page-pad-x/y`；字号 `--text-xs…--text-3xl`

## 与现状的差异

1. **新增「今日接送凭证」**：源码只有一条条平铺记录；原型把当天记录聚合成状态卡与时间轴。数据仍来自同一个 `records` 列表（按 `date` 取今天），**没有新增接口**。
2. **历史记录按日期分组**：源码每条记录一张独立卡；原型改成日期组 + 行，降低重复视觉噪音。今天的两条不再在历史里重复出现。
3. **关系本地化**：源码直接渲染英文枚举 `pickup_relation`；原型显示「父亲 / 母亲 / 奶奶 / 爷爷」，建议源码补一层映射。
4. **异常标记**：接口返回 `is_abnormal`，源码未渲染；原型在 10月21日接走记录上加了 warning 色「异常」小标（不写原因）。
5. **二维码入口**：源码是页头文字按钮跳 `pages/pickup/qrcode`；原型改为凭证底栏主按钮 + 底部弹层预览（人证对照 / 二维码占位 / 有效期 / 刷新 / 更换接走人），弹层内容对齐 `qrcode.vue`。按钮只在未接走（未入园 / 在园中）时露出，已接走终态改为完成回执条。
6. **刷新**：源码靠 `enablePullDownRefresh`；原型在每个日期组头放了 44×44 刷新按钮，点击转圈 + toast「已刷新接送记录」（原型里等于下拉刷新）。
7. **四态**：源码只有「加载中... / 暂无接送记录 / 失败 toast」；原型补齐骨架屏、空态、错误态与禁用态，并把今日卡拆成未入园 / 在园中 / 已接走三态。

## 遗留 / 需产品确认

- 「今日接送凭证」里的孩子上下文「乐乐 · 小一班」来自当前学生（`getCurrentStudentId`），源码本页没有渲染学生姓名；是否常驻需产品确认。
- `is_abnormal` 是否要在家长端显性展示、文案用什么，需产品确认；原型只用了中性「异常」。
- `pickup_relation` 的中文映射表建议落到 i18n / 枚举层（源码当前直接显示英文）。
- 弹层里的二维码是 SVG 占位（非真实码），仅用于页面原型；真实流程仍走 `pages/pickup/qrcode`。「刷新二维码」「更换今日接走人」「tabBar 切换」「记录行点击」在原型中均为 toast，不做真实跳转。
- 默认示例取 09:41 的「在园中」时点（07:52 已入园、尚未接走）；「已接走」的 17:30 终态用演示芯片查看。微信状态栏固定 9:41 属批次外壳常量。
