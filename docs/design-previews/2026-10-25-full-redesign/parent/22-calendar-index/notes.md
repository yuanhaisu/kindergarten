# 班级日历（家长端）

- 源码：parent/src/pages/calendar/index.vue
- 设计系统：user:nurture-planet-local，surface=parent
- 方向：把老师端已定稿的月历语义原样搬到家长端——月历给「哪几天有事」的全貌，当日清单给「今天/这天要做什么」的细节，变更提示置顶且不随翻月消失。
- 信息层级：变更提醒卡（有修订才出现）→ 月份切换条（上月/下月 +「今天」pill）→ 月历卡（周标题、42 格日期、活动类型图例）→ 当日安排标题与计数 → 活动卡列表。翻月只换月历与当日清单，变更卡不动。
- 覆盖状态：
  - 正常：今天 = 品牌色粗体数字（无底色）；选中 = 品牌色实心圆 + 白字；今天且选中时加一圈 `--accent-soft` 外环，两种语义不混用。每日最多 3 个 4px 类型点，按类型上色；当天有活动时标题下计数为「N 个活动」。活动卡类型名只在元信息行出现一次（「类型 · 时间」），标题行不再重复渲染。
  - 空：分两级。当天无活动 → 月历下方「这一天暂无活动安排」卡，计数写「暂无活动」；整月无活动 → 「X月暂无活动安排」卡 +「回到今天」按钮，变更卡同时隐藏。
  - 加载：月历替换为骨架卡（周标题 + 42 个骨架格 + 图例骨架），当日区替换为三张活动卡骨架；月份条保留可读，不画假数据。
  - 错误：月历与当日区一起收起，只留错误面板（「日历加载失败 / 网络异常，未获取到本月活动」+ 重新加载）。
  - 禁用：相邻月的补格灰显且 `disabled`、不参与选中；「今天」pill 仅在已在今天（当前月且选中今天）时置灰禁用，当前月选中其他日期后仍可一键回到今天。
- token 映射：选中圆与「今天」pill 用 `var(--accent)` + `var(--on-brand)`；今天数字用 `var(--accent-deep)`；今天+选中的外环用 `var(--accent-soft)`；活动点按类型用 `var(--info)`（通知）/`var(--success)`（活动）/`var(--accent)`（假期）/`var(--muted)`（家长会）/`var(--danger)`（体检）；卡片与文字用 `var(--surface)` `var(--bg)` `var(--fg-2)` `var(--muted)` `var(--hint)` `var(--border)`；圆角 `var(--radius-lg)` `var(--radius-pill)`；动效 `var(--motion-fast)` `var(--ease)`。
- 与现状的差异：
  - 源码页**没有月历**，只有一条变更提示（最多 3 条 +「另有 N 条」）加平铺活动列表；本稿新增月历与按日筛选，依据是 `GET /parent/class/calendar` 已接受 `start`/`end`，可按月窗口拉取，不需要新接口。
  - 变更卡改为**全局展示**（不再按当前查看的月份过滤），每条补上日期；服务端只下发「近 7 天内修订且尚未发生」的条目，若按视图月份过滤，隔壁月的调整会被静默吞掉，而家长可能正按旧时间行动。
  - 点变更条目会跳到对应日期（必要时跨月）并高亮该卡 2.4s；这是源码 `locate()` 的延伸。
  - 新增加载骨架、错误重试、整月空态与「回到今天」，源码只有一行文字提示。
- 跨月行为：翻月时重建 42 格（固定 6 行，不因月份长短跳高）；选中日按「同号日」保留，目标月没有该号（如 1/31 → 2 月）时收敛到月末；翻回当前月自动选中今天，此时「今天」pill 因已在今天而置灰；跨年（2026-12 → 2027-01）正常；相邻月补格不可点，避免选中不在数据窗口内的日期。
- 遗留：
  - 月历依赖前端首次进页传 `start`/`end`（源码目前一个参数都不传），落地时要补；否则只能拿到默认窗口，翻月会是空的。
  - 「变更」的范围是否要限定在可见月份，需产品定：本稿按「家长不该漏掉临近调整」取全局，代价是翻到远期月份时顶部仍提示本月无关的变更。
  - 字典给「家长会」下发紫色 `#A855F7`，tokens 无紫色，本稿映射到 `--muted`；见批次 `_shared/findings.md` Token 缺口 #1。
  - 单日超过 3 个活动时只画 3 个点，不显示「+N」；是否需要溢出提示待产品确认。
  - 活动详情入口未做：源码列表卡也没有跳转，本稿保持只读展开（点卡片展开完整描述与地点/时间）。
