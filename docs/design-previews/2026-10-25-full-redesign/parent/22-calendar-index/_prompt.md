你是幼儿园管理平台「养成星球」的资深移动端设计师。为家长端做一个页面的高保真 HTML 原型。

## 唯一任务
页面：班级日历（家长端，源码 parent/src/pages/calendar/index.vue）
只做一个方向，不要 A/B 变体，不要多页面。写完 index.html / styles.css / app.js 即停止，不要提问，不要联网，不要读取自己的产物。

## 产品事实
- 入口：家长「我的」→ 班级日历，navigateTo 子页（要有返回箭头），无 tabBar。
- 接口 GET /parent/class/calendar：返回已发布的本班 + 全园事件，字段 id/title/description/event_type/event_type_label/event_date/start_time/end_time/location/is_all_day/color/change_summary，支持 start/end 按月取数。
- 事件类型 5 类：notice 通知 / activity 活动 / holiday 假期 / meeting 家长会 / checkup 体检。
- change_summary 只在「近 7 天修订且今天及以后」的事件上下发，形如「时间 10:00 → 10:30」「地点 多功能厅 → 小一班教室」。家长端将有变更的事件汇总成顶部「安排有变更」提示条：最多显示 3 条，其余收成「另有 N 条」可展开/收起；点某条跳到对应日期并短暂高亮那张卡。
- 家长只读：没有新建/编辑/删除，也没有事件详情页。不要画任何「+」或「编辑」按钮。
- 排序：全天在前，其余按 start_time。

## 页面结构（从上到下）
1. 变更提示条（有 change_summary 才显示）：蜜蜡黄浅底卡，标题「安排有变更」，最多 3 行（事件标题 + 变更要旨），底部「另有 1 条」。
2. 月份切换行：‹ 2026年10月 / 本月 9 个活动 ›，右侧「今天」胶囊（当前月时禁用变灰）。
3. 月历卡：周日–周六表头（周末 danger 色）+ 6×7 日期格 + 图例（只列本月出现的类型）。
4. 当日安排：标题 +「10月26日 周一」+「2 个活动」计数，下面是事件卡。
5. 事件卡：类型字图标 + 标题 + 类型胶囊 + 类型·时间 + 描述（2 行截断，点卡片展开/收起）+ 地点；有 change_summary 的卡片内加一行浅黄变更说明。
6. 空态 / 骨架 / 失败块（见四态）。

## 月历语义（必须与老师端定稿一致）
- 今天未选中：数字 var(--accent-deep) + 700 粗体，不填充。
- 选中：32px 实心圆 var(--accent) 底 + var(--on-brand) 字。
- 今天且选中：实心圆外再加 2px var(--accent-soft) 描边。
- 两者绝不混用：同屏最多一个实心圆。
- 活动标记只用 4px 圆点，一天最多 3 个，颜色按类型。
- 相邻月补位格变淡且不可点。
- 跨月真实日期计算：12月→1月、2月28天、选中日 31 日切到 2 月要收敛到最后一天，切回当前月回到今天；不能崩。

## 视觉硬约束
- <html lang="zh-CN" data-surface="parent">；样式顺序 tokens.css → ../../_shared/shell.css → styles.css。
- 外壳只用共享类：mp-statusbar / mp-navbar / mp-back / mp-title / mp-capsule。不要自己画状态栏导航栏，不要复制或改写 shell.css，styles.css 里不得出现 .mp-* 定义（唯一例外是 [data-state] 四态选择器）。
- 子页：有返回箭头；一律不画 tabBar。
- 390px 手机视口，单列纵向流；所有容器 max-width:100%；不许横向滚动。
- 颜色只写 var(--*)，禁止裸 hex/rgb；无直角（最小 var(--radius-sm)）；卡片 var(--radius-card)；按钮/胶囊/日期圆 var(--radius-pill)；阴影只用 var(--shadow-sm/md)。
- 暖橙面积 ≤10%：选中圆、主按钮、「今天」胶囊之外不要再铺橙色。
- 层级靠字重 + 字号；正文 ≥13px；触控目标 ≥44px；禁止 white-space: nowrap。

## 四态（.mp-app[data-state]，mp-demo 由 shell 提供）
- normal：默认如上。
- empty：整月无活动（演示切到 2026年12月）。月份副标题「本月暂无活动」、所有类型点消失、当日安排换成空态块：日历图标 +「12月暂无活动安排」+「园所还没发布这个月的安排」+ 主按钮「回到今天」（回 10月26日 正常态）。
- loading：月历卡与当日列表换骨架（7 列 × 6 行圆角块 + 3 张卡片骨架），月份切换行保持可读。
- error：隐藏月历与当日列表，显示「日历加载失败 / 网络异常，未获取到本月活动 / 重新加载」，点重试回正常。
- 禁用：「今天」胶囊在当前月不可点、补位日期不可点。

## 交互（app.js）
- 月份切换、点日期切换当日列表、「今天」跳转、变更条展开/收起、点变更条跳到对应日期并高亮 2.4s、点事件卡展开描述、重试。
- :active 有缩放/压暗；不用 alert/prompt；console 无报错。
- 右下角 mp-demo 状态胶囊（正常 / 空态 / 加载 / 失败）。
