## 这个页面真实的产品事实（照此设计，不要发明字段）
家长从「我的」页点「意见反馈」进入本页（`uni.navigateTo`，**是子页，导航栏必须有返回箭头**，标题「意见反馈」，**不画 tabBar**）。现状：顶部标题 +「+ 反馈 / 取消」折叠表单 → 反馈类型 + 内容 + 提交 → 下方反馈记录；无记录时显示「暂无反馈记录」。本原型把表单改为**常驻**（去掉折叠），提交按钮改为**底部固定提交栏**。

1. **反馈类型** `category`：单选，三个值——`suggestion`=建议 / `complaint`=投诉 / `bug`=问题，默认「建议」。源码是三个胶囊按钮。
2. **反馈内容** `content`：多行文本，**唯一必填项**，占位「请描述您的意见或问题...」，上限 500 字；提交前 trim 判空，为空提示「请填写反馈内容」。
3. **提交**：源码按钮文案「提交」/「提交中...」；成功后 toast「提交成功」、清空、收起表单、重新拉列表；失败 toast `err.message` 或「提交失败」。
4. **我的反馈**（GET）：按创建时间倒序，每条含 `category`（源码读 `category_label`，但后端未返回该字段，属已知漂移）、`status_label`（已提交 / 已回复 / 已关闭）、`content`、`reply`（园所回复，可能为空）、`created_at`。**列表项不可跳详情**，本页就是详情。
5. **源码没有、绝对不要画**：图片上传、联系方式输入、反馈详情页、撤回/删除、满意度评分、客服电话、FAQ、反馈类型多选。（接口契约里虽有 `contact` / `images` 字段，但页面完全没实现，原型不发明。）

## 设计方向（只做一个方向）
「一张便笺，回声可见」：上半页是一张安静的写反馈卡片，下半页把「我的反馈」做成一条带状态点的留言时间轴——提交后能在记录里读到园所的回复，形成闭环。橙色只落在选中的类型、主按钮、回复块竖线与状态点。

## 信息层级（从上到下）
1. 微信外壳：状态栏 + 导航栏（返回箭头 + 标题 + 胶囊）；无 tabBar。
2. **反馈类型**：三枚等宽胶囊（图标 + 建议 / 投诉 / 问题），单选；选中 = 品牌色描边 + `--accent-wash` 底 + 深色文字 + 小对勾；标题右侧标「必选」。
3. **反馈内容**：大 textarea（最小高度约 132px），保留占位，右下角实时 `x / 500`；下方一行小字「写明时间、地点或页面，园所处理更快」；标题右侧标「必填」。
4. **我的反馈**：标题 + 右侧「共 3 条」；三条倒序记录。每条左侧 7px 状态点 + 1px 竖向连线（已回复 = 实心品牌色点、已提交 = 空心品牌色点、已关闭 = 中性实心点）；右侧卡片：类别徽章 + 状态标签 + 日期（如 `10月19日 周一`）→ 内容（默认 3 行截断，点击展开）→ 有回复时显示「园所回复」块（`--surface-warm` 底 + 左侧 2px `--accent-soft` 竖线 + `--accent-deep` 小标题）。
   - 类别徽章用语义浅底：建议 = info、投诉 = warning、问题 = danger；状态标签只用文字 + 小圆点（已回复 = success 点、已提交 = accent 点、已关闭 = hint 点）。
5. **底部固定提交栏**：失败条（默认隐藏）/ 常驻说明行 / 48px 主按钮「提交」；安全区兜底。
6. **整页成功态（不是 toast）**：居中同心圆 + 对勾、「反馈已提交」、一行说明、类型/时间/内容摘要小卡、「查看我的反馈」（主）+「再提一条」（次）。

## 示例数据（中文，幼儿园语境；今天 = 2026-10-26 周一）
- 类型：建议（选中）
- 内容：`亲子任务的截止时间能改到晚上九点吗？下班路上经常来不及拍照提交。`
- 记录（倒序）：
  1. 问题 · 已提交 · `10月24日 周六` · `接送二维码刷新后偶尔提示过期，重新进入就好了。`
  2. 建议 · 已回复 · `10月19日 周一` · `希望成长记录里能看到孩子每天的午睡和进餐情况。`｜回复：`感谢建议！成长日报本周起增加午睡与进餐两栏，明天就能看到。`
  3. 投诉 · 已关闭 · `10月8日 周四` · `周三放学时门口排队比较久，孩子等了二十多分钟。`｜回复：`已与门卫沟通，本周起增开一个离园通道，欢迎继续监督。`
- 常驻说明行：`提交后可在记录里查看进展`

## 状态覆盖（`mp-demo` 六个芯片，`data-state` 值严格用 normal / required / empty / loading / submitting / failed）
- **normal**：上面的示例数据；说明行中性；主按钮可点。
- **required（必填未填）**：内容清空、计数 `0 / 500`；说明行用 `--danger` 写「还需填写：反馈内容」；主按钮灰底禁用（`aria-disabled="true"`），点击不提交、不弹 toast，只聚焦输入框；记录区保持三条。
- **empty（空列表）**：记录区换成空态（圆形图标 +「还没有反馈记录」+ 一句「提交后可以在这里查看园所回复」+ 次按钮「写下第一条」，点击聚焦 textarea）；表单与说明行保持正常。
- **loading**：记录区换成 2 条骨架卡（呼吸动画）；表单保持可编辑；说明行不变。
- **submitting**：表单整体降级不可编辑（`opacity` + `pointer-events: none`），按钮内小转圈 +「提交中…」，说明行「正在提交，请稍候」。
- **failed**：记录区换成「反馈记录加载失败」+「重试」；**同时**提交栏上方出现 `--danger-wash` 失败条「提交失败，请重试」+「重试」。「列表重试」→ 恢复列表 + toast「已刷新」；「提交重试」→ 收起失败条、按正常提交走（转圈 1.3s → 成功态）。
- 六态必须是真实 JS 分支，不能是静态截图。另外：normal 下手动清空内容再点「提交」，必须被常驻阻断拦住，`data-state` 不变。

## 交互（app.js，全部真实可点）
- 类型胶囊单选，更新 `aria-pressed`；提交中 / 成功态下不可改。
- 输入实时更新字数；空内容点「提交」→ 已在上方常驻阻断 + 聚焦输入框。
- 内容非空点「提交」→ `submitting`，约 1.3s 后进入整页成功态；成功态隐藏表单、记录区与固定提交栏。
- 成功态「查看我的反馈」→ 新记录插到列表首位（当前类型、已提交、`10月26日 周一`、刚写的内容），内容清空，回到列表并滚动到「我的反馈」，新卡带一次高亮描边；「再提一条」→ 回表单、清空内容、聚焦输入框。
- 记录卡点击展开 / 收起长内容（`aria-expanded` + 箭头旋转），不跳页。
- 演示条芯片切换六态；`mp-demo` 用行内 `style="bottom: calc(104px + env(safe-area-inset-bottom))"` 避让固定栏（唯一允许的行内外壳覆盖）。
- 不用 alert / prompt；console 干净。

## 视觉与结构硬约束
- `<html lang="zh-CN" data-surface="parent">`；390px 视口；单列纵向流；不做桌面布局。
- **外壳必须原样使用共享 shell**：先读 `D:/yuanhaisu/personal_projects/kindergarten/docs/design-previews/2026-10-25-full-redesign/_shared/shell.md` 与 `shell.css`，照抄 `mp-statusbar` / `mp-time` / `mp-status-icons` / `mp-navbar` / `mp-back` / `mp-title` / `mp-capsule` / `mp-main` / `mp-demo` 的标记与 SVG，不许自造状态栏。
- 引入顺序 `tokens.css` → `../../_shared/shell.css` → `styles.css`；末尾先 `../../_shared/shell.js` 再 `app.js`（app.js 监听 `document` 的 `mp:state` 事件）。
- 禁止把 shell.css 复制进页面目录，禁止改写状态栏 SVG，只写 `<link href="../../_shared/shell.css">`（该文件由流程提供）。
- **styles.css 里不许出现任何 `.mp-*` 选择器或覆盖**（唯一例外是 `[data-state]` 组合选择器，如 `.mp-app[data-state="failed"] .xxx`）。
- 颜色只写 `var(--*)`，禁止裸 hex / rgb / hsl；**无直角**（最小 `--radius-sm`）；阴影只用 `--shadow-*`。
- **暖色 ≤10% 面积**：大面积是 `--bg` 与 `--surface`；橙色只在选中类型、主按钮、回复块竖线、状态点、新卡高亮。
- 触控目标 ≥ 44×44px；正文 ≥ 13px；`:active` 必须有反馈（缩放或压暗）。
- 禁止 `white-space: nowrap`；多列用 `grid-template-columns: repeat(N, minmax(0, 1fr))`；所有容器 `max-width: 100%`；页面不得横向滚动；长文本自然折行。
- 固定底栏：内容区底部留 ≥ 150px + `env(safe-area-inset-bottom)`，失败条出现时也不遮住最后一条记录。
