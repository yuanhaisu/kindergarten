## 这个页面真实的产品事实

这是微信小程序里家长进入 App 的唯一入口。**没有账号密码表单**（源码里根本没有），全页只有一个动作：微信一键登录。

自上而下只有四条：

1. **品牌区**（BrandBlock 组件，两端共用）：星球 logo →「养成星球」→ 副标题「幼儿园数字化管理平台」。只有这三行，没有营销话术。
2. **登录卡**（白底卡片）：
   - **内联错误条**（仅登录失败时出现）：标题 + 一行说明，浅红底常驻在卡片顶部。源码注释明确说不再用 toast，因为 1.5 秒就消失、失败原因读不到。错误文案分档：`微信登录失败 / 请稍后重试`、`网络异常 / 请检查网络后重试`。
   - **主按钮**（品牌渐变胶囊，整宽，高 48px）：文案随状态变——`微信一键登录` → 登录中时 `登录中...`（禁用，透明度降到 0.55）→ 失败后 `重新登录`。
   - **协议勾选行**：20px 方形勾选框（选中为品牌橙底 + 白勾）+ 文案「我已阅读并同意《用户协议》和《隐私政策》」。**协议名是纯文本，不可点**（协议页还没落地，源码刻意不做死链）。整行是点击命中区，高度 ≥44px。
   - 未勾选就点登录：不进入登录中，弹一条轻提示「请先阅读并同意用户协议和隐私政策」。
3. **卡片外脚注**：「登录后需绑定园所已开通的家长账号」。这是前置告知——账号未开通的失败会发生在首页绑卡，所以先在这里说清楚需要什么。不要做成警告样式，它是脚注。
4. 底部留安全区，**没有 tabBar，也没有返回箭头**（本页由 `uni.reLaunch` 进入，是入口页，不是子页）。

登录成功后：关闭登录页，回到首页 `/pages/index/index`；从深链或 401 过来时回到原页面。这在原型里只表现为一次「登录成功」轻提示。

示例数据（真实感文案，不要出现账号密码字段）：
- 品牌名「养成星球」，副标题「幼儿园数字化管理平台」
- 协议：「我已阅读并同意《用户协议》和《隐私政策》」
- 脚注：「登录后需绑定园所已开通的家长账号」
- 错误示例：「微信登录失败」/「请稍后重试」

## 视觉与结构硬约束

- `<html lang="zh-CN" data-surface="parent">`
- 390px 手机视口；单列纵向流；不做桌面布局
- **微信小程序外壳不许自己画**：引入了 `../../_shared/shell.css`（唯一真相源），必须用它的 `mp-statusbar` / `mp-navbar` / `mp-title` / `mp-capsule` / `mp-main` / `mp-demo` 标记；状态栏 SVG 用 shell.md 里给的那三枚，尺寸 17×11 / 15×11 / 24×11；**不要把 shell.css 复制进页面目录，也不要改编它**
- 导航栏标题用 `家长登录`（`pages.json` 的真实 `navigationBarTitleText`）
- **不画返回箭头**（入口页）；**不画 tabBar**（本页不是四个 tab 页之一）
- 颜色只写 `var(--*)`，禁止裸 hex/rgb；无直角；阴影只用 `var(--shadow-*)`
- 家长端是冷雾白底：`--bg` / `--bg-gradient` 为冷灰白，主色 `--accent` 是鲜橙（比老师端更亮一点）。暖色面积 ≤ 10%：只有主按钮和勾选框选中态用橙色
- 字号层级靠字重+字号：品牌名 20px/700、副标题 14px/400、按钮 15px/700、协议与脚注 12px/400
- 触控目标 ≥ 44px；正文 ≥ 13px；`--muted` 压 `--bg` 需满足 4.5:1
- 数据区必须覆盖：正常 / 未勾选协议 / 登录中 / 失败；另做一个「原型演示」状态切换胶囊（`mp-demo` + `data-mp-state` 四枚 chip：正常 / 未勾选 / 登录中 / 失败）
- 点击必须有 `:active` 反馈（缩放或压暗）；不用 alert/prompt；无 JS 报错
- **禁止 `white-space: nowrap`** 用于可能超宽的文本；多列统计用 `grid-template-columns: repeat(N, minmax(0, 1fr))`
- 所有容器 `max-width: 100%`，页面不得出现横向滚动
- 页面 CSS 里不得出现 `.mp-*` 定义（唯一例外是 `.mp-app[data-state=...]` 状态选择器）
