# 成长相册（家长端）

- 源码：`parent/src/pages/growth/album.vue`
- 设计系统：`user:nurture-planet-local`，surface=parent
- 方向：一页「按月翻看的相册」。月份切换是唯一导航轴，日期分组把照片切成可扫读的段落，三列等宽网格保证缩略图密度，点任意照片在底部弹层里按「当天这一组」左右翻看。

## 信息层级

1. 导航栏：返回 + 「成长相册」+ 胶囊（子页面，无 tabBar）
2. 月份条：上/下月箭头夹住「2026年10月」，下方一行「18 张照片 · 10月9日 - 10月24日」
3. 日期分组：`10月24日` + 右侧 `3 张`，组内三列正方形网格
4. 照片缩略图：CSS 渐变占位（天空 / 叶子 / 沙 / 薄荷 / 暖五组色调 × 三种构图），无外链图片
5. 底部弹层：日期 + 「第 i / n 张」、大图占位、左右箭头、`共 n 张 · 左右切换查看`、关闭
6. 轻提示（toast）与「原型演示」状态条

## Token 映射

- 背景与卡片：`--bg`、`--surface`、`--border`
- 文字：`--fg`、`--fg-2`、`--muted`、`--hint`
- 品牌橙：`--accent`、`--accent-deep`、`--accent-wash`、`--accent-soft`、`--accent-gradient`、`--accent-gradient-soft`、`--on-brand`
- 语义色：`--success` / `--success-wash`、`--warning` / `--warning-wash`、`--info` / `--info-wash`、`--danger` / `--danger-wash`
- 占位图渐变：以上语义色与 `--accent` 经 `color-mix(in srgb, …)` 与 `--surface` 混合，未出现裸色值
- 圆角：`--radius-lg`（缩略图）、`--radius-card`、`--radius-2xl`（弹层）、`--radius-pill`（箭头 / 按钮 / 胶囊）
- 阴影：`--shadow-sm`、`--shadow-md`、`--shadow-lg`
- 间距与字号：`--space-xs`（网格与骨架间距）…`--space-xl`、`--text-xs`…`--text-3xl`、`--page-pad-x`
- 动效：`--motion-fast`、`--motion-base`、`--ease`；`prefers-reduced-motion` 下关闭骨架呼吸与弹层位移

## 与现状的差异

- **时间范围**：源码月份条只有「N张照片」；原型补了「最早日 - 最晚日」一行，由当前分组的日期派生，用于回答「这个月照片集中在哪几天」。属设计提案。
- **加载态**：源码是一行「加载中...」；原型改为骨架屏（月份条骨架 + 两组 3×3 骨架块），保持网格形状不跳动。
- **错误态**：源码只有 `try/finally`，请求失败会落到 `groups=[]`，即**把失败显示成「本月暂无照片」**；原型新增独立错误卡片与重试，避免误导。
- **空态分流**：源码所有空都是行内「本月暂无照片」；原型区分「整页无照片」（刷新）与「仅当前月无照片」（看上个月），后者月份条仍然可用。整页空态下月份条隐藏且换月冻结，避免「还没有照片」与可翻月份并存；空态是强制演示态，真实判定需要「是否曾经有过照片」的数据源（见遗留）。
- **预览**：源码用 `uni.previewImage`，作用域是**当天分组**；原型用底部弹层复刻同一作用域，支持左右循环、Esc 关闭、焦点回位，并显示「第 i / n 张」。
- **网格间距**：源码 `$spacing-xs`（8px 设计值 → 16rpx）；原型用 `--space-xs`（4px）收紧，贴近微信相册的密排观感。
- **月份切换**：源码每次切月重新请求；原型是静态双月面板 + 月内空态，切月只换视图并提示「已切换到 2026年9月」，不模拟网络。
- **返回**：源码 `navigateBack`；原型点击返回给出「已返回成长时光」提示，不真实跳转。

## 遗留 / 需产品确认

- **契约不一致（重要）**：`parent/src/pages/growth/album.vue` 读 `res.data.groups` / `res.data.total`，但 `server/internal/service/parent_portal_service.go` 的 `ListGrowthMedia` 返回 `{list, total, year, month}`，**没有 `groups`**。按现状接真机，相册页会永远走「本月暂无照片」。需后端补 `groups`（按 date 分组）或前端改按 `list` 自行分组。
- 时间范围目前是前端派生；若后端能直接返回 `first_date` / `last_date`，可省一次遍历，也避免「分组缺日」时口径不一致。
- 源码月份切换无上下界，可一直翻到任意年月；原型限定 2026-08 ~ 2026-12 以便演示，落地时以接口可查范围为准。
- 若媒体表将来混入视频，`image` / 缩略图网格需要单独的视频角标与播放态；当前源码只按图片处理。
- 原型照片全部为 CSS 渐变占位，不引用任何外链图片；真实缩略图走 `thumb_url`，预览走 `file_url`。
