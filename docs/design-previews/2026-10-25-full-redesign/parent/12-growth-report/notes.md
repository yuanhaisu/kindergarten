# 成长报告（parent）

- 源码：`parent/src/pages/growth/report.vue`（`onLoad` → `fetchGrowthReport({ type })`，`type` 为 `weekly` / `monthly` / `term`；页面按扁平字段读取 `student` / `period` / `attendance.rate` / `points_earned` / `tasks_completed` / `tasks_total` / `growth_media_count` / `dimensions` / `highlights` / `concerns` / `teacher_comment`）
- 设计系统：`user:nurture-planet-local`，surface=parent
- 生成方式：OpenDesign（run `1359df71-c8b9-4260-aabd-bc91a0b3e34e` 终态 succeeded，交付三件套与项目终态逐字节一致）
- 方向：**「一页成长册，不是五张卡片」**——儿童头像与周期做封面，四项数据压成一条统计带，能力评估用 7 根竖柱代替进度条，亮点/关注/评语顺着同一张纸往下读；橙色只留在封面底纹、选中分段、柱子和主按钮上。

## 信息层级

1. 微信外壳：20px 状态栏 + 44px 导航栏（返回箭头，标题「成长报告」，右侧胶囊）
2. 周期分段：周报 / 月报 / 学期（44px 胶囊轨道，选中项橙色实心）
3. 纸面封面：56px 圆形头像（姓名首字「乐」）+ 孩子姓名 + 周期徽标 + 日期范围（10月19日 – 10月25日）
4. 统计带：出勤率 80% / 获得积分 45 / 完成任务 8/12 / 成长记录 15，四列等分，列间 1px 分隔
5. 能力评估：7 根竖柱（语言 85 / 认知 78 / 社交 90 / 运动 72 / 艺术 95 / 自理 68 / 情绪 82），分数在柱顶、维度名在柱下，附「满分 100」与一句读图说明
6. 成长亮点（绿点 3 条）→ 需要关注（琥珀点 2 条）→ 老师评语（浅底引文块 + 左侧橙色短竖线）
7. 各区块之间用纸面内的 1px 通栏细线分隔，不另起卡片

## 覆盖状态

| 状态 | 表现 |
| --- | --- |
| 正常（默认周报） | 纸面封面 + 四格统计 + 7 柱能力评估 + 亮点 / 关注 / 评语；三个周期各自一套数据，切换时只换纸面内容 |
| 空态（本周期无报告，`data-state="empty"`） | 纸面与骨架隐藏，居中空态：96px 浅橙圆底 + 报告图标 +「这个周期还没有成长报告」+ 说明 + 主按钮；说明与按钮随当前周期生成——周报→「老师通常周五整理周报，先看看月报或学期报告」+「查看月报」、月报→「这个月的报告还没整理好，先看看学期报告吧」+「查看学期报告」、学期→「学期报告还在整理中，先回成长时光看看其他记录吧」+「返回成长时光」（只 toast，不模拟路由）。前两者点按钮切到对应周期并回正常态。空态下点周期分段也会切到该周期并回正常态（空态只属于当前周期） |
| 加载骨架 | 纸面隐藏，换同构骨架：封面圆 + 姓名/周期条 + 四格统计条 + 7 根空柱 + 两组文字条；`--border` 呼吸动画（1.6s），`prefers-reduced-motion` 下停用 |
| 加载失败 | 纸面隐藏，居中错误卡：48px `--danger-wash` 圆底 + 感叹号 +「成长报告加载失败」+「网络断开，或报告还在生成中」+ 主按钮「重试」；点重试回到失败前选中的周期并 toast「已重新加载」 |
| 禁用 | 加载 / 失败态下周期分段全部 `disabled` + `aria-disabled="true"`，颜色转 `--hint`，不可点击；正常 / 空态可切换 |

演示芯片：正常 / 空态 / 加载 / 失败（`data-mp-state` = normal / empty / loading / error），与批次其余页面一致，不另造第五态。

## 与现状的差异

- **从五张卡收成一张纸**：源码是「header-card + 4 个 stat-box + 能力卡 + 亮点卡 + 关注卡 + 评语卡」，每块各自圆角与阴影，层叠很重；原型把它们收进同一张 `--radius-card` 纸面，只用 1px 细线分区，读起来像成长册的一页。
- **统计从四张独立小卡改为一条统计带**：源码 `grid` + `gap` 四个独立卡片；原型四列等分、列间 1px 分隔线、`repeat(4, minmax(0, 1fr))`，在 390px 下「8/12」不换行不溢出。
- **能力评估从横条列表改为 7 根竖柱**：源码是「名称 + 横向进度条 + 分数」逐行；原型用 7 列竖柱（柱高 = 分数，柱顶标数值，柱下标维度），一屏能横向比较 7 个维度，也不引图表库。源码注释写「雷达图维度」，实际实现仍是横条，原型按竖柱处理。
- **周期切换从三个白底胶囊改为分段控件**：源码 `.type-tab` 三个独立胶囊，选中橙色；原型做成一条 44px 胶囊轨道 + 内嵌选中块，视觉上更像一个控件，也明确了切换中/失败时的禁用态。
- **空态从「空白页」改为明确空态**：源码没有空态分支，报告为空对象时仍渲染空姓名、空日期和 0 值统计；原型给出随当前周期变化的说明 + 周期出口（周报→月报→学期→返回成长时光），并支持空态下切换周期。
- **加载从一行文字改为骨架屏**：源码只有「加载中...」；原型用与纸面同构的骨架，减少切换周期时的跳动。
- **新增失败态与重试**：源码 `loadData` 只有 `finally`、没有 `catch`，失败时是未处理的 Promise rejection；原型补错误卡与重试（属设计补充）。
- **评语头像去蓝**：源码老师头像占位写死 `#DBEAFE` / `#2563EB`（token 体系外的蓝色）；原型改为 `--surface` 底 + `--accent-deep` 图标 + 左侧橙色引文线。
- **日期格式化**：源码直接输出 `start_date ~ end_date` 原始字符串；原型显示「10月19日 – 10月25日」，并使用 en dash。格式化逻辑在前端，不改契约。
- **演示数字自洽**：按日期区间反推——周报 7 天 45 分 / 15 条记录 / 8 个任务（日均 6.4 / 2.1 / 1.1）；月报 30 天 180 / 62 / 31（日均 6.0 / 2.1 / 1.0）；学期 55 天 340 / 115 / 58（日均 6.2 / 2.1 / 1.1），约等于月报加上 10 月 1–25 日按周报同速增长的 160 分 / 53 条 / 27 个任务。出勤按校历工作日：周报 5 天出席 4 天记 80%；月报 9 月 22 天出席 20 天记 91%；学期 39 天（9 月 22 + 10 月 1–25 日 17）出席 36 天记 92%。未引入源码四格之外的指标。

## 遗留

1. **接口口径冲突（批次级 A10）**：`GetGrowthReport` 实际返回 `{ report, dimensions }` 嵌套结构，而 `report.vue` 按扁平字段读 `student` / `period` / `attendance` / `points_earned` / `tasks_*` / `growth_media_count`；`server/internal/domain/growth.go` 的 `GrowthReport` 也没有这四项统计字段。**需产品/后端定口径**：要么后端补扁平统计，要么前端改读 `report` + `dimensions`。已同步记入 `_shared/findings.md` A10。
2. **维度字段名不一致**：源码用 `d.name` / `d.score` / `d.max_score`，domain 的 `GrowthReportDimension` 是 `dim_name` / `score` / `max_score`。落地前需在 DTO/契约层统一，否则维度名会空。
3. **封面没有班级与老师姓名**：源码 `student` 只有 `avatar` / `name`，没有班级、班主任字段；原型封面因此只放孩子姓名与周期。若要显示「小一班 · 李老师」，需补接口字段（产品确认）。
4. **空态文案与周期出口为设计补充**：源码无空态。文案为演示性说明，需产品确认口径；出口按钮按当前周期指向下一周期（周报→月报→学期→返回成长时光），该行为也需产品确认（也可改为「刷新」）。
5. **失败态为设计补充**：源码没有错误分支，原型按批次约束补齐；若后端实际用「报告生成中」状态码区分，文案应随之调整。
6. **演示数据为虚构**：孩子姓名「乐乐」、亮点/关注文案、老师评语、维度分数均为原型演示值，真实页面必须完全来自 `highlights` / `concerns` / `teacher_comment` / `dimensions`，不得保留占位文案。
7. **7 列竖柱的适用边界**：当前按固定 7 个维度设计（源码维度由后端下发，数量可变）。若某园所维度少于 5 或多于 8，7 列网格需改为自适应（如横向滚动或换行），否则标签会挤。
8. **未做**：下拉刷新、报告导出/分享、周期自定义（源码均无）；返回按钮只 toast「返回成长时光」，不模拟真实路由。
