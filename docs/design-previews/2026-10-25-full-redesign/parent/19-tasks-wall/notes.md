# 班级墙（家长端）

> 生成方式：OpenDesign run 89a2a548（succeeded）产出三件套；人工补齐加载骨架屏与空态插画，其余未改结构。

- 源码：`parent/src/pages/tasks/wall.vue`（接口 `GET /parent/tasks/public-wall`，契约见 `backend/api/api-parent/06-task.md`）
- 设计系统：`user:nurture-planet-local`，surface=parent
- 方向：**本班的墙：日期当钉子，照片当砖**。日期条吸顶，照片占满卡宽当主肌理，只有文字的那条分享变成一张暖色便签——两种卡片一眼能分，但都安静。

## 信息层级

1. 导航栏：返回箭头 + 标题「班级墙」（`uni.navigateTo` 进来的子页，无 tabBar）
2. 墙头：小锁 + 规则「老师确认后才会出现在这里 · 仅本班可见」，右侧「7 份分享」
3. 日期条：竖橙条 + 今天 / 昨天 / 10月24日 + 「N 份」，吸顶在导航栏下方（`top: 64px`）
4. 照片卡：4:3 照片占位 + 左下角任务胶囊 → 正文 → 首字头像 + 孩子名 + 时间
5. 一句话卡：暖底 + 引号 + 任务胶囊 → 正文（14px/1.7）→ 头像 + 孩子名 + 时间
6. 墙脚：「没有更多了」+ 底部安全区

## 覆盖状态

| 状态 | 表现 |
|---|---|
| 正常 | 7 条分享，跨今天 / 昨天 / 10月24日 三段（3 + 2 + 2）；2 条一句话卡，1 条只有图没有字 |
| 空 | 叠加照片线稿 + 「本班还没有分享」+「家长提交、老师确认之后，会出现在这里」+ 主按钮「去任务列表」；墙头与列表隐藏 |
| 加载 | 3 张同构骨架卡（图片区 + 两条文字占位 + 头像占位），灰阶，不显示真实内容 |
| 错误 | 「班级墙暂时打不开」+「网络好像不太稳定，请稍后再试。」+「重试」；点击后按钮进入「正在重试…」，900ms 回到正常态并提示「已重新加载」 |
| 刷新失败 | 列表**原地保留**，导航栏下方出现浅红提示条「网络开小差了，点击重试」；点击即回到正常态 |
| 禁用 | 重试按钮请求中 `disabled` 并降色；加载/错误态下无其它可点主操作 |

## 交互

- 点任意照片 → 全屏预览层（照片放大 + 任务名作说明），点遮罩 / 关闭按钮 / `Esc` 关闭，焦点回到原卡片
- 空态「去任务列表」、错误态「重试」、刷新失败提示条均有 toast 反馈；返回箭头提示「已返回任务列表」
- 演示条（`mp-demo`）可开合，五个 chip 切换 normal / empty / loading / error / stale

## 与现状的差异

- **墙头计数**：源码顶部只有规则文案；原型加「7 份分享」，数字取接口真实的 `total`，不新增请求。
- **日期条**：源码是普通行内 label；原型加「N 份」小计并吸顶，长列表里能一直知道在看哪天。吸顶依赖本页给 `main` 加的 `.wall-main { overflow-x: clip }`：shell 的 `.mp-main` 默认 `overflow-x: hidden` 会把 `overflow-y` 计算成 `auto`，形成不滚动的滚动容器，页内 sticky 会全部失效；`clip` 保留横向裁切但不建立滚动容器。外壳文件未改。
- **任务名位置**：源码放在卡片底部单独一行；原型把它做成胶囊——照片卡压在照片左下角，一句话卡放在正文上方，位置一致（都在内容块起始处），省一行又能在扫图时先看到「这是哪个任务」。
- **一句话卡**：沿用源码的浅品牌底区分，正文从 13px 提到 14px、行高 1.7，因为这类卡只有文字，值得多给一点阅读尺度。
- **空态按钮**：「去任务列表」是新增入口（源码空态无按钮），把「没内容」变成「可以去做点什么」。
- **错误文案**：源码直接显示接口 `err.message`；原型换成固定的两句人话 + 重试，避免把后端错误抛出给家长。
- **照片**：全部用 token 渐变 + 伪元素画的抽象占位（书 / 鞋带 / 拼图 / 叶子 / 秋天），不引用任何外部图片。

## 遗留 / 需产品确认

- **点赞、评论、按任务筛选**：`public-wall` 接口返回体（`checkin_id / task_id / task_title / student / date / content / media_url / created_at`）里都没有这些字段，`wall.vue` 也没有对应 UI。本页**未做**，若产品要，需先扩后端契约，不能只在前端画。同理，`reactResponse` 属于任务详情页的「周期汇总回应」，不是班级墙的能力。
- **空态「去任务列表」**：新增入口，需确认是回任务列表（当前实现）还是直接跳打卡。
- **下拉刷新 / 触底加载更多**：源码有 `onPullDownRefresh` / `onReachBottom`；原型演示数据不足一页（`page_size=20`，共 7 条），墙脚直接显示「没有更多了」，两个手势未做交互原型。`正在加载更多...` 的历史文案保留在说明里，未在页面出现。
- **头像**：接口返回 `student.avatar`，示例数据里用名字首字兜底（与源码 `avatar-fallback` 同逻辑）；真实头像样式待有素材时再验。
- **时间**：源码按设备本地时区把 `created_at` 转 `HH:MM`；原型写死示例时间，未做时区演示。
