# 接送管理（老师端）

- 源码：`teacher/src/pages/pickup/index.vue`
- 设计系统：`user:nurture-planet-local`，`data-surface="teacher"`
- 外壳：`_shared/shell.css` + `shell.js`
- 方向：园门口的登记台——概览一眼看清，学生行一键登记，扫码/手动两个入口。

## 信息层级

1. 今日概览：全班在读、已入园、未到园、已接走、未接走、曾滞留、异常
2. 筛选：未接走（默认）/ 全部 / 已入园 / 已接走 四段并排
3. 学生行：姓名、授权接送人、入园时间（后端已返回）、状态、放学时间、上次备注；动作按状态出现「入园」「接走 / 再接走」「通知」
4. 登记入口：扫码核验（核验中 / 未通过两态）与手动登记
5. 空 / 加载 / 失败三态占位

## 状态覆盖

- 正常：未接走 6 人列表
- 空：`data-state="empty"`，今天没有待接的孩子
- 加载：`data-state="loading"`，概览数字与列表换骨架
- 失败：`data-state="error"`，整页错误 + 重试
- 局部：扫码核验中、核验未通过
- 局部：手动登记提交失败（重复接走未填理由，按契约拒绝并保留弹层）
- 登记成功后就地更新卡片、筛选计数、概览数字与滞留条（对应源码动作后的 `loadPickup()`）

## token 映射

- 概览卡：`var(--surface)` / `var(--radius-card)` / `var(--shadow-md)`
- 状态色：已接走 `var(--success)`，滞留 `var(--warning)`，异常 `var(--danger)`，配套 `-wash` 浅底
- 主按钮：`var(--accent-gradient)`；禁用态用 `var(--border)` + `var(--hint)`
- 文本：`var(--fg)` / `var(--fg-2)` / `var(--muted)`

## 与现状的差异

- 筛选从「点一下循环切换」改为 4 个并排分段选项（同一组真实 status 参数）
- 补展示 `arrive_time`（后端已返回、原页面未显示）
- 未到园的学生「接走」置灰禁用——把后端「未入园不能接走」的规则前置到 UI
- 「手动登记」改为「选择学生 → 登记」两步弹层（源码只是把筛选切到「全部」）；未到园的学生在选人弹层里标注「需先入园」且不可选，与列表置灰同一条规则
- 登记成功后就地更新列表与概览数字，模拟源码动作后的 `loadPickup()`；已接走行只展示契约返回的授权接送人（`students` 无接走时间/接走人）
- 扫码核验做成底部弹层，含核验中与未通过两态

## 遗留

- 扫码为原型模拟，不接真实相机
- 「通知」只做 toast 反馈，未接通知接口
- 手动登记面板的字段以源码为准，未新增
- 演示数据是 `STUDENTS` 的内存可变副本，切换演示 chip 回到「正常」会重置回初始快照
- `styles.css` 24KB，超出 20KB 建议值
