# 活动详情（老师端）

- 源码：`teacher/src/pages/calendar/detail.vue`
- 设计系统：`user:nurture-planet-local`，`data-surface="teacher"`
- 外壳：`_shared/shell.css` + `shell.js`
- 方向：信息卡 + 家长视角预览。编辑为 toast 占位（源码 `goEdit()` 跳 `pages/calendar/create?id=`），删除走微信风格居中确认框。

## 信息层级

1. 事件头：类型标签 + 发布状态标签（已发布 / 草稿（家长不可见））+ 活动标题
2. 信息卡：活动日期 / 活动时间（含是否全天）/ 活动地点 / 参与范围（本班 / 全园）
3. 说明正文：长文本按空行分段，行宽受控；说明为空时换「暂无活动说明」+「补充说明」入口（toast 占位）
4. 提示条：草稿态标题下黄条「草稿 · 家长端暂时看不到这个活动，发布后才可见。」；全园态蓝条「全园事件（由园长 / 保健医发布），老师端只读。」
5. 家长看到的样子：底部弹层预览家长端呈现，减少「发出去才发现不对」
6. 操作：编辑活动（toast「打开编辑活动」占位）、删除（微信风格居中确认对话框，写明影响）

## 状态覆盖

- 正常：完整活动（已发布、本班）
- 空：活动说明为空，正文位置换「暂无活动说明」+「补充说明」入口
- 加载：整页骨架屏，正文区不渲染
- 失败：隐藏正文与骨架，只留整页错误块 + 「重新加载」
- 草稿：状态标签「草稿（家长不可见）」+ 标题下黄条 + 预览弹层「草稿 · 家长暂时看不到」；编辑 / 删除仍可用
- 全园只读：全园提示条 + 参与范围显示「全园」，底部操作区隐藏（`scope === "kindergarten"`）

## token 映射

- 信息卡：`var(--surface)` / `var(--radius-card)` / `var(--shadow-md)`
- 类型标签：`var(--accent-wash)` + `var(--accent-deep)`
- 危险操作：`var(--danger)` / `var(--danger-wash)`
- 文本：`var(--fg)` / `var(--fg-2)` / `var(--muted)`

## 与现状的差异

- 加载态：源码只有一行「加载中...」，原型升级为整页骨架屏（导航栏保持可读）
- 失败态：源码仅 toast、正文仍渲染空壳，原型改为整页错误块 + 「重新加载」
- 说明为空：源码在正文位置显示「暂无描述」，原型换成「暂无活动说明」+「补充说明」入口
- 信息卡：源码 3 行（日期 / 时间 / 地点），原型按设计稿增至 4 行，多出「参与范围」（本班 / 全园）
