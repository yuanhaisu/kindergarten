## 这个页面真实的产品事实（照此设计，不要发明功能）
老师从「班级日历」点某场活动进来，查看活动全貌：类型、发布状态、标题、说明、日期、时间、地点；可以打开「预览家长视角」看家长端实际看到的卡片；**本班**活动可编辑或删除，**全园**活动只读（没有编辑/删除按钮）。

页面区块顺序（从上到下，与源码一致）：

1. **加载态**：源码只有一行「加载中...」；原型升级为骨架屏（导航栏保持可读）。
2. **头部信息卡**（白卡）：
   - 标签行：左边**类型标签** = 类型名首字 + 类型名（如「活 活动」），底色用类型色浅底、文字用类型色；右边**状态标签**：
     - `status = published` → 绿点 +「已发布」
     - `status = draft` → 黄点 +「草稿（家长不可见）」
   - **活动标题**（大号、可折行，不许省略号裁切）
   - **活动说明**（`description`）：按空行拆成多段，段间留白；没有说明时显示占位「暂无描述」
   - **全园提示条**（仅 `scope = kindergarten`）：浅蓝底一行「全园事件（由园长 / 保健医发布），老师端只读。」
3. **信息卡**（与头部同宽的一张卡，纵向行，**不是表格**）：活动日期 / 活动时间 / 活动地点 / 参与范围
   - 每行：左侧 36×36 圆角方块图标位 + 右侧「小标签 + 值」
   - 活动日期：`event_date`，显示为「2026年10月26日 周一」这种中文写法
   - 活动时间：`is_all_day = true` →「全天」；否则 `start_time` + （有 `end_time` 时「 - 」+ `end_time`）；都空 →「未设置」
   - 活动地点：`location`，空 →「未设置」
   - 参与范围：`scope = class` →「本班」；`kindergarten` →「全园」
4. **「预览家长视角」按钮**：整宽浅橙底、深橙字、44px 高、胶囊圆角 → 打开底部弹层
   - 弹层标题「家长看到的样子」，右侧「关闭」；`status = draft` 时多一行黄色提示「草稿 · 家长暂时看不到」
   - 弹层内是一张**家长端样式**的活动卡（纯白底，比老师端卡片更冷）：标题 + 类型标签 + 一行元信息「2026-10-26 · 09:00-10:30 · 大操场」+ 说明（最多 2 行截断，没说明就不占位）
   - 点遮罩或「关闭」收起
5. **底部操作**（仅 `scope !== "kindergarten"` 时出现）：
   - 「编辑活动」主按钮（品牌渐变、白字、48px 高、胶囊）
   - 「删除」次按钮（浅红底、红字，与主按钮同一行，主按钮更宽）
   - 点「删除」→ **微信风格居中对话框**（不是底部弹层、不是 confirm）：
     - 标题「删除活动」
     - 说明「确定要删除该活动吗？删除后家长端将不再可见。」（一字不改）
     - 两个按钮「取消」/「确定」；确定后关闭对话框并 toast「已删除，即将返回班级日历」
6. 底部安全区留白；老师端**不画 tabBar**。

**源码里不存在、绝对不要画**：创建人、创建时间、提醒设置、参与班级名称/人数、报名、签到、费用、评论、附件、地图、二维码、参与者头像、重复日程、分享、右上下拉菜单。接口 `GET /teacher/calendar/events/detail/:id` 只返回：
`id, title, description, event_type, event_type_label, scope, status, event_date, start_time, end_time, location, is_all_day, color`
（没有 creator、没有提醒、没有班级名，不要脑补。）

## 类型色 token 映射（**不许写裸 hex**）
| 类型 | 文字色 | 浅底 |
|---|---|---|
| 通知 notice | `var(--info)` | `var(--info-wash)` |
| 活动 activity | `var(--success)` | `var(--success-wash)` |
| 假期 holiday | `var(--accent-deep)` | `var(--accent-wash)` |
| 家长会 meeting | `var(--muted)` | `var(--bg)` |
| 体检 checkup | `var(--danger)` | `var(--danger-wash)` |

本页示例用「活动 activity」绿色。状态：已发布 `var(--success)` + `var(--success-wash)`；草稿 `var(--warning)` + `var(--warning-wash)`；全园提示 `var(--info)` + `var(--info-wash)`。

## 视觉与结构硬约束
- `<html lang="zh-CN" data-surface="teacher">`，390px 手机视口，单列纵向流，不做桌面布局。
- **外壳必须原样使用共享 shell**：先读 `D:/yuanhaisu/personal_projects/kindergarten/docs/design-previews/2026-10-25-full-redesign/_shared/shell.md` 与 `shell.css`，照抄其中的 `mp-statusbar` / `mp-time` / `mp-status-icons` / `mp-navbar` / `mp-back` / `mp-title` / `mp-capsule` / `mp-main` / `mp-demo` 标记与 SVG。引入顺序：`tokens.css` → `../../_shared/shell.css` → `styles.css`；末尾引入 `../../_shared/shell.js` 再引入 `app.js`。
- **禁止把 shell.css 复制进项目**，也不要改写状态栏 SVG；只写 `<link href="../../_shared/shell.css">`。生成阶段这个文件可能 404，这是正常的（最终由流程拼装）——**绝对不要自己补画状态栏/导航栏/胶囊**。
- **styles.css 里绝对不许出现任何 `.mp-*` 选择器或覆盖**（唯一例外是 `[data-state]` 状态选择器，可写成 `.mp-app[data-state="empty"] .xxx`）。
- 子页：导航栏保留返回箭头，标题「活动详情」。老师端**不画 tabBar**。
- 颜色只写 `var(--*)`，禁止裸 hex / rgb / hsl；无直角（最小 `var(--radius-sm)`）；阴影只用 `var(--shadow-*)`。
- **暖色克制**：橙色只出现在「编辑活动」主按钮、「预览家长视角」按钮（浅橙底）和类型/状态小标签；大面积是暖奶白 `var(--bg)` 与 `var(--surface)`。说明和正文用 `var(--fg-2)` / `var(--muted)`，不要整段橙色字。
- 圆润：卡片 `var(--radius-card)`，按钮/标签 `var(--radius-pill)`，信息行图标方块 `var(--radius-xl)`，居中对话框 `var(--radius-2xl)`。
- 微信小程序语汇：提示用 toast，危险操作用居中对话框；不用 `<select>`、不用 alert / prompt、不做 hover 才可见的信息。
- 触控目标 ≥ 44×44px；正文 ≥ 13px；`:active` 必须有反馈（缩放或压暗）。
- 禁止对可能超宽的文本用 `white-space: nowrap`；所有容器 `max-width: 100%`，页面不得横向滚动；长标题、长地点、长说明必须自然折行。说明段落行高 ≥ 1.7，页边距保持 `var(--page-pad-x)`，不要贴边。
- 状态覆盖（`data-state` 驱动；演示条用共享 `mp-demo`，**6 个 chip**：正常 / 空态 / 加载 / 失败 / 草稿 / 全园只读）：
  - **正常**（默认）：完整头部卡 + 说明两段 + 信息卡 4 行 + 预览按钮 + 编辑/删除
  - **空**：只有**说明区**变成占位块（浅底圆角、文档图标 +「暂无活动说明」+ 文字按钮「补充说明」），其余区块保持完整——不要整页空掉
  - **加载**：头部卡与信息卡换成骨架屏（标签行 1 条、标题 2 条、说明 3 条、信息行 3 条、按钮 1 条），导航栏保持可读
  - **失败**：内容区换成错误块——图标 +「活动加载失败」+「网络异常，未获取到活动详情。」+「重新加载」主按钮
  - **草稿**：状态标签变黄点「草稿（家长不可见）」，标题下出现黄色提示条「草稿 · 家长端暂时看不到这个活动，发布后才可见。」；其余内容与操作保持；家长视角弹层里显示草稿提示
  - **全园只读**：显示全园提示条，参与范围变「全园」，底部编辑/删除整块消失
  - 禁用态：全园态下没有可点的编辑/删除入口（不是把按钮置灰，而是按源码直接不渲染）

## 交互（app.js，全部真实可点，无 console 报错）
- 返回箭头：toast「返回班级日历」（不要真的改 location）。
- 「预览家长视角」：打开底部弹层；点遮罩 /「关闭」收起；弹层打开时底部操作不可误触。
- 「编辑活动」：toast「打开编辑活动」。
- 「删除」→ 居中对话框；「取消」关闭；「确定」关闭并 toast「已删除，即将返回班级日历」。
- 空态「补充说明」：toast「打开编辑活动」。
- 「重新加载」：切回正常态并 toast「已重新加载」。
- 演示条 6 个 chip 全部可切换，样式与内容按上面定义变化（可用 `document.addEventListener('mp:state', ...)` 或直接读 `data-state`）。
- 所有按钮有 `:active` 反馈；无 console 报错。
