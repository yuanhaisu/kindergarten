# 我的（老师端）

- 源码：teacher/src/pages/profile/index.vue
- 设计系统：user:nurture-planet-local，surface=teacher
- 方向：把「我是谁」做成一张工牌——浅暖渐变身份卡 + 一行今日三段数字 + 微信设置页式的安静目录，退出登录单列一张克制的危险色卡。

## 信息层级

1. **身份卡**：56px 圆形头像（姓名首字「王」）→「王老师」18px/600 → 园所「阳光幼儿园」13px 弱化 → 两个胶囊标签「小一班」「主班老师」。高度 115px，不占半屏。
2. **今日班级**：区头 15px/600 + 右侧「小一班 · 共 28 人」12px；卡内三列等分 26 今日出勤 / 2 今日请假 / 3 待审批，只有「待审批」给浅橙胶囊底 + 深橙字（它是唯一需要动作的数字）。
3. **账号与设置**：弱组标题 + 一张卡三行（邀请码 / 账号安全 / 设置），行内 34×34 图标块 + 标题 14px/500 + 说明 12px + 右侧「开发中」弱化胶囊；分隔线内缩到文字起点，行高 62px。
4. **退出登录**：独立卡，居中，14px/500 危险红 + 描边退出图标，无红色大底。
5. 老师端无 tabBar，页面不画任何底部导航。

## 覆盖状态

- **正常**：如上，数字 26 / 2 / 3（26 + 2 = 全班 28，自洽）。
- **空态（= 未绑定园所，源码真实分支）**：园所显示「未绑定园所」，隐藏班级/职务标签；三个数字变「—」，区头右侧小字隐藏；数字带下方出现「还没有绑定园所，今日班级数据暂不可用」+「刷新资料」小按钮。**「刷新资料」重跑一次取数**（= 源码 `loadProfile()` 的 getUser + overview）：按钮转「刷新中…」并 `aria-busy`，页面进加载态（三列骨架 + 「同步中…」），900ms 后回落正常态，园所与三个数字回填，toast「资料已更新」；刷新期间手动切演示 chip 会作废这次刷新，定时器不会覆盖用户选的状态。
- **加载**：只让三个数字换成 28×20 骨架块（透明度脉冲，`prefers-reduced-motion` 下静态），区头右侧变「同步中…」；身份卡与 cell 列表保持正常可用，不整页遮罩——姓名与园所来自本地 storage，本来就不会转圈。
- **失败**：数字卡整块替换为「今日数据加载失败」+「重试」；身份卡与 cell 列表保持正常。
- **禁用**：本页无业务禁用控件。三个设置入口在源码里都没有落地页，用右侧「开发中」胶囊诚实表达，点击给 toast，不置灰。
- 四态由 `.mp-app[data-state]` 属性选择器接管，手动切换交给 `_shared/shell.js`；页面内的「重试」与「刷新资料」由 `app.js` 程序化切态，并同步演示 chip 的 `aria-pressed`。

## token 映射

- 底色 `var(--bg)`、卡片 `var(--surface)`、正文 `var(--fg)` / `var(--fg-2)`、弱化 `var(--muted)` / `var(--hint)`、描边 `var(--border)`。
- 身份卡底 `var(--accent-gradient-soft)`（全页唯一渐变），头像底 `var(--accent-gradient)` + 字 `var(--on-brand)`。
- 图标块 / 待审批胶囊 / 重试按钮底：`color-mix(in srgb, var(--accent) 18%, var(--surface))`，描边 `color-mix(in srgb, var(--accent) 30%, var(--surface))`，字 `var(--accent-deep)`。
  **原因**：老师端 `--accent-wash` 与 `--surface` 几乎同色，直接铺上去看不到块面，所以用 accent 与 surface 派生一层可辨识的浅底；没有引入任何裸色值。
- 「开发中」胶囊：`color-mix(in srgb, var(--fg-2) 8%, var(--surface))` 底 + 16% 描边 + `var(--muted)` 字。
- 失败态 `var(--danger)` / `var(--danger-wash)`；圆角 `--radius-2xl` / `--radius-card` / `--radius-pill`；阴影只用 `--shadow-sm` / `--shadow-lg`；动效 `--motion-fast` / `--motion-base` + `--ease`。

## 与现状的差异

- **顶部改成工牌卡**：源码是一整块高饱和蓝→渐变 header 压白字；改为浅暖渐变身份卡，暖色面积从近半屏压到 ≤10%。
- **统计数据去仪表盘化**：源码用蓝/绿/琥珀三色；改为单色数字，只给「待审批」保留浅橙胶囊。
- **三个功能入口统一图标底色**：源码绿/橙/灰各一种；改为统一的 accent 派生浅底，右侧补「开发中」胶囊说明真实状态。
- **删掉自绘底栏**：源码 `profile/index.vue` 里画了 4 项自绘底栏（首页/班级/消息/我的），但 `pages.json` 没有 `tabBar` 字段——`utils/nav.js` 的 `goTab` 靠 `navigateBack` / `redirectTo` 模拟，属于遗留实现。按批次规则老师端一律不画，本次未画。
- **静默归零改为可见失败态**：源码 `loadProfile()` catch 后把三个数字置 0；原型改成「今日数据加载失败 + 重试」，避免把「取数失败」显示成「今天没人来」。
- **头像不用外链**：源码 `avatar` 是 URL，原型按首字圆形头像处理（无外链资源）。
- **任务书与源码不一致处以源码为准**：任务描述里的设置项「消息提醒 / 隐私 / 关于」与统计「带班人数 / 发布记录」在源码中不存在，实际是「邀请码 / 账号安全 / 设置」与「今日出勤 / 今日请假 / 待审批」。已按源码实现，差异记入遗留。
- 外壳：状态栏 / 导航栏 / 胶囊 / 返回箭头全部原样使用 `_shared/shell.css` 的 `mp-*` 标记，`styles.css` 未定义任何 `.mp-*`（只有 `.mp-app[data-state=...]` 属性选择器）。

## 遗留

- **底栏是否恢复需产品确认**：源码自绘的 4 项底栏按批次规则删除；若产品希望「我的」仍承担导航作用，应先把 `pages.json` 的 `tabBar` 落下来，而不是继续自绘。
- **三个设置入口都是空壳**：源码 `featureItems` 的 `path` 全为空字符串，点击只 toast「功能开发中」。邀请码属于老师端已有能力（`teacher_invitation` + 二维码），账号安全 / 设置则是纯占位。需要产品给出优先级与落地页，再决定这三个 cell 的最终去向。
- **失败态是本次设计新增**：源码失败时静默归零，线上用户看到的是「0 出勤」。改成可见失败态需要后端错误码区分「真的 0」与「请求失败」，否则前端无法判断。
- **`overview` 还有第四个数未用**：接口返回 `unread_notices`，本页只取三个数字，未读通知在消息页承担，故未在「我的」重复展示——如需展示需产品确认。
- **空态「刷新资料」是新增动作**：源码没有这个按钮，也没有绑定园所入口（绑定走家长端）。原型点击 = 重跑 `loadProfile()`（加载 → 正常），演示的是「管理员刚绑好、刷新取到数据」这一条路径；真实接口下另两种结果（仍未绑定该给什么提示、是否改为跳绑定指引）需产品确认。
- **对比度是批次级 token 缺口（本页继承，未逐页打补丁）**：待审批「3」与「刷新资料 / 重试」的 accent-deep 压 accent 派生浅底实测 2.50:1、「开发中」徽标 4.01:1、退出登录与确认框危险红 3.62:1，均低于 WCAG AA（`brief.md:45`）。需回 `shared-design-tokens/tokens.json` 一次性加深 accent-deep / 新增 danger 文本 token 并重跑三端产物；本页 `tokens.css` 是生成产物（文件头禁止手改），逐页改字色会与同批次其余 49 页的同款组件不一致。
- **头像仍是首字**：真实 `avatar` 为 OSS URL，接图后需处理加载失败回退到首字，本原型未表达该分支。
- **统计数字的班级口径**：源码直接取 `/teacher/home/overview` 的数字，未校验 `roles[0]` 是否与「今日班级」标题一致；多班级老师场景下标题与数字可能不对应，需接口侧确认返回的是哪个班。
