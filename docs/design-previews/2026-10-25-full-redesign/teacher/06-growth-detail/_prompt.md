## 这个页面真实的产品事实（照此设计，不要发明功能）
老师从「成长记录」列表点进一条记录，查看正文、照片、家长评论，并就地评论。

页面区块顺序（从上到下）：
1. **作者区**：圆形头像（昵称首字，无图时用字占位）+ 昵称；第二行「发布于 10月24日 15:20」（源码格式「YYYY年M月D日 HH:mm」）。
2. **标题**：performance_tags 用「 · 」连接（如「户外活动 · 合作」），无则不显示。
3. **正文**：长文本，多段。
4. **照片区**：媒体九宫格。每张照片下方可能带：
   - 「点名」标签 + 孩子姓名小胶囊（如 乐乐、小雨）——这张照片关联了谁；
   - 大合影照片额外有一行按钮「大合影 · 一键全班（当日到场 18 人）」；
   - AI 识别建议块：标题「AI 识别建议」，每行「姓名 + 高置信/待确认 + 确认 + 拒绝」两个小按钮；
   - 照片区顶部可能有一条横幅：「3 条高置信建议」+「全部确认」按钮。
   点照片 = 预览大图（原型用底部弹层模拟预览，带关闭）。
5. **相关孩子**：区块标题「相关孩子（3人）」，头像+姓名胶囊，最多 6 个，超出显示「+2人」。
6. **互动统计 / 操作条**：「12 个点赞」「5 条评论」；右侧按钮：编辑、分享、授徽章（有徽章数据才出现）。
   授徽章点开是一个展开面板：选徽章（横向胶囊可多选一个）、授予给哪些孩子（不选则默认本班全部）、复选「本记录作为获奖见证」、主按钮「确认授予」。
7. **家长评论**：「家长评论（5条）」。每条：头像 + 昵称 + 角色标签（如「妈妈」）+ 时间（15:20）+ 评论内容 + 两个小操作（赞 0 / 回复）。老师对评论的回复以缩进卡片形式挂在该评论下方（老师名 + 时间 + 回复正文）。
8. **底部固定评论输入栏**：圆角输入框「请输入评论...」+ 圆形发送按钮。输入为空时发送按钮禁用（降级样式，不可点）。要给 `env(safe-area-inset-bottom)` 留白。

真实操作只有：编辑（整页跳转）、分享（toast「点击右上角分享」）、授徽章、确认/拒绝 AI 建议、一键全班、全部确认、发表评论、返回。**没有**删除、没有置顶、没有更多菜单，不要画。

## 视觉与结构硬约束
- `<html lang="zh-CN" data-surface="teacher">`，390px 手机视口，单列纵向流，不做桌面布局。
- **外壳必须原样使用 `_shared/shell.md` 里的 `mp-*` 标记**（mp-app / mp-statusbar / mp-time / mp-status-icons / mp-navbar / mp-back / mp-title / mp-capsule / mp-main / mp-demo），状态栏与胶囊的 SVG 照抄。引入顺序：`tokens.css` → `../../_shared/shell.css` → `styles.css`。
- **styles.css 里绝对不许出现任何 `.mp-*` 选择器或覆盖**（唯一例外是 `[data-state]` 状态选择器，写成 `.mp-app[data-state="empty"] .xxx`）。外壳样式一律来自 shell.css。
- 子页：导航栏保留返回箭头，标题「成长记录详情」。老师端**不画 tabBar**。
- 颜色只写 `var(--*)`，禁止裸 hex / rgb / hsl；无直角（最小 `var(--radius-sm)`）；阴影只用 `var(--shadow-*)`。暖色（橙）面积 ≤ 10%：橙色只用在发送按钮、点亮的徽章、少量标签，大面积保持中性底色。
- 微信小程序语汇：不用 `<select>`、不用 hover 浮层；底部弹层做图片预览；危险/确认用居中对话框；不用 alert / prompt。
- 触控目标 ≥ 44×44px；正文 ≥ 13px；`:active` 必须有反馈。
- 禁止对可能超宽的文本用 `white-space: nowrap`；多列统计用 `grid-template-columns: repeat(N, minmax(0, 1fr))`；所有容器 `max-width: 100%`，页面不得横向滚动。长昵称、长评论必须能换行。
- 数据区必须覆盖四态，用 `data-state` 属性驱动：
  - 正常（默认）：完整内容；
  - 空：无评论 → 评论区内显示空态（图标位 + 一句「还没有家长评论」+「写第一条评论」按钮，点了聚焦底部输入框）；
  - 加载：正文与评论区显示骨架屏（2–3 行 + 九宫格骨架）；
  - 失败：一句话「加载失败，请重试」+「重试」按钮。
  外加：媒体加载失败用一块带「重试」的占位替换单张照片（正常态下就展示其中一张为失败态，让人看得到设计）。
- 演示状态条用 `mp-demo` + `mp-demo-chip[data-mp-state]`，默认收起。
- 底部有自己的固定输入栏，`.mp-demo` 的 `bottom` 抬到 72px 以上，不要挡住输入栏。
