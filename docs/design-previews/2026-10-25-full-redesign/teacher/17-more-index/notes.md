# 更多功能（老师端）

- **源码**：`teacher/src/pages/more/index.vue`（另读 `teacher/src/pages.json` 的标题、`teacher/src/utils/auth.js` 的 `getUser().roles` 角色判断）
- **设计系统**：`user:nurture-planet-local`，`surface=teacher`
- **生成方式**：OpenDesign（第 1 次 run 只产出 `index.html`，按流程缩短 message 重跑一次，第 2 次产出完整三件套；随后手工修掉 28px 横向溢出与两处 token 语义）
- **方向**：微信「设置」式目录页——把平铺的 10 张等权卡片按职能收成 5 组，组标题只做弱提示，卡片内用 cell 行承担扫读与点击。

## 信息层级（从上到下）

1. **外壳**：20px 状态栏（9:41 + 信号/wifi/电池）+ 44px 导航栏（「更多功能」居中 + 右上胶囊）。本页由工作台 `navigateTo` 进入，导航栏画返回箭头；老师端无 tabBar，不画。
2. **通知与沟通**：发布通知、通知管理、消息中心。
3. **成长与相册**：成长记录、班级相册。
4. **接送管理**：接送管理、接送记录。
5. **班级事务**：班级日历、请假审批、亲子任务。
6. **保健（仅保健医）**：入园晨检。组标题右侧「仅保健医」小胶囊标注角色门控——源码对普通老师整行不渲染。

每行结构：36px 圆角图标块（线性 SVG）→ 15px/600 标题 + 12px `--muted` 说明 → 16px chevron。行高 56px，行间 1px 淡分割线。底部无版本号/退出登录（源码没有）。

## 与现状的差异

- **平铺 10 张卡 → 5 个分组**：现状每张卡独立投影、无分组，扫读要逐张读完；改为组标题 + 一张卡内多行，组间 16px、行间淡线，视线先落到职能再落到入口。
- **新增图标块**：现状只有文字与 `›`。图标为纯视觉识别辅助，语义与标题一一对应，不新增任何功能。
- **箭头 `›` 文字 → 16px chevron SVG**：统一视觉重量与基线，避免不同字号下的基线漂移。
- **触控行高 ≥56px**：现状卡片内边距 30rpx，可点区域随文案长度浮动；改为固定最小行高，整行可点。
- **角色差异显式化**：现状普通老师完全看不到「入园晨检」；原型保留该组并加「仅保健医」标签，让审阅者一眼看到角色门控，同时注明真实产品应仅对 doctor 渲染。
- **补三态**：现状无加载/空/失败（本地常量）；原型按批次约束补齐，仅演示用。
- **页面边距**：现状 28rpx（≈14px）→ 保持 14px 页边距，组间距 16px。

## 遗留 / 需产品确认

1. **分组名与归属是新设计语义**：源码是平铺列表，本稿的「通知与沟通 / 成长与相册 / 接送管理 / 班级事务 / 保健」分组与组内顺序需产品确认（尤其「班级相册」归入「成长与相册」、「消息中心」归入「通知与沟通」）。
2. **「仅保健医」标签是否该出现在普通老师界面**：真实产品应整组隐藏；原型为展示角色差异而保留，若审阅认为会误导可改为默认隐藏 + notes 说明。
3. **是否要分组折叠或搜索**：源码没有，未做。11 个入口在 390×844 上约一屏半，暂不必要。
4. **底部版本号/退出登录**：源码无，按任务要求未添加。
