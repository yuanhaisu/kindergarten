# 添加成长记录（teacher）

- 源码：`teacher/src/pages/growth/create.vue`（路由标题「添加成长记录」，由成长记录列表 `navigateTo` 进入）
- 接口：`teacher/src/api/teacher-growth.js`、`teacher/src/api/teacher-class.js`、`teacher/src/api/dict.js`、`teacher/src/api/teacher-achievements.js`
- 设计系统：user:nurture-planet-local，surface=teacher
- 方向：一张暖奶白的「今日观察单」——日期作锚点，观察项拆成 饮食 / 睡眠 / 情绪 / 表现 四条纵列，照片九宫格与正文收在同一列卡片里，固定底栏收口；所有阻断原因写在按钮上方，内容不丢。

## 信息层级（上→下）

1. **日期**：`10月24日 周六` + `2026年 · 今天`，左右箭头切前一天/后一天（到今天禁用右箭头）
2. **记录对象**：两段控件「全班记录 / 指定幼儿」——决定下面显示观察卡还是幼儿选择卡
3. **快速记录**（仅全班）：饮食（早/午/晚 × 😋😐😞）、睡眠（时长 1/2/3 小时、质量 很好/一般/不好）、情绪（上午/下午）、表现（9 个标签多选）
4. **选择幼儿**（仅指定）：已选摘要（头像堆叠 + 姓名 + 编辑）或空态插画 +「选择幼儿」，两者按实际选择人数互斥；同卡带表现标签
5. **照片 / 视频**：已点名 N 张（按有已确认名单的照片数统计）+ 批量点名；三列九宫格（完成 / 上传中百分比 / 失败重试 / ＋添加）；点照片进入「照片点名」，批量点名先勾照片再选学生；每张一句说明（可选）；拍照建议与 20 张上限
6. **记录内容**（必填，带字数）→ **授予徽章**（可选：徽章 + 授予给 + 作为获奖见证）
7. **底栏**：可见范围（全班 / 仅 N 位）+ 同步到班级动态开关 + 主按钮；编辑态换成只读可见范围提示，主按钮「保存修改」

## token 映射

- 页面底 `--bg`；卡片 `--surface` + `--border` + `--shadow-md`；录入控件底 `--bg`
- 选中态 `--accent-wash` 底 + `--accent` 边 + `--accent-deep` 字
- 主按钮 `--accent-gradient` + `--on-brand`；禁用 `--bg` + `--border` + `--hint`
- 错误 `--danger-wash` / `--danger`；提示文字 `--muted` / `--hint`
- 圆角 `--radius-card`(卡片) / `--radius-pill`(按钮、标签、开关) / `--radius-lg`(缩略图、emoji 键)
- 字号 `--text-xs`~`--text-xl`；字重 `--weight-medium/semibold`
- 遮罩用 `color-mix(in srgb, var(--fg) N%, transparent)`，不写裸 rgba

## 与现状的差异

1. **记录对象提升到顶部**：源码把「仅发送给指定家长」放在底栏的一个勾选框里，和「同步到班级动态」并排，二者互斥但视觉同级。改成顶部两段控件后，可见范围在填写前就明确，底栏只留结果。
2. **指定幼儿改底部弹层**：源码是页内搜索框 + 姓名 chip 平铺（28 人时页面很长）。弹层里搜索 + 全选 + 勾选，页面只留摘要。功能未增减。
3. **观察项从 2×2 卡片改单卡四行**：源码四个 template-card 各带图标底、边框、阴影，滚动时视觉噪音大；合并为一张卡 + 细分隔线，密度更高。
4. **禁用原因显性化**：源码三种阻断都靠 `uni.showToast` 事后告知；原型把原因常驻在按钮上方。
5. **提交失败可重试**：源码失败只 toast；原型加错误条 + 「重新发布」，内容保留。
6. **上传进度可见**：源码只有「上传中」遮罩；原型给到百分比 + 失败后重试入口（仍按 30s 超时语义）。
7. **徽章区保留但不喧宾夺主**：徽章 chip 与「授予给」保持源码结构，选中才展开授予对象与见证勾选。
8. **点名流程与源码对齐**：点照片（含角标）进入「照片点名」编辑完整名单；「批量点名」改为源码的两段式——先勾照片（支持全选），再选学生，确定后按并集追加并即时刷新角标与「已点名 N 张」。

## 遗留 / 需产品确认

- **「照片 / 视频」是否支持视频**：源码 `uni.chooseImage` 只能选图，标题却写「照片/视频」。原型按标题展示但没发明视频入口，**需产品确认**。
- **徽章「授予给」默认值**：源码不选时默认授予给本记录的目标学生；原型只保留提示文案（未做默认态演示），**需产品确认是否要在 UI 上显式回填**。
- **点名面板的高级能力**：源码单张点名含 AI 建议分级（AI·高 预勾）与「全班（当日到场）」一键；原型只做基础勾选，AI 建议仅以角标数量展示，**需产品确认是否展开**。
- **演示条位置**：共享 `shell.css` 没有「有固定底栏时抬升演示条」的实现（`shell.md` 第 6 条要求抬到 72px 但 CSS 未落地）。本页用元素内联 `style="bottom: calc(168px + env(safe-area-inset-bottom))"` 规避遮挡主按钮与错误条，**建议 shell.css 增加 `[data-dock]` 变体**。
- **preview.png 高度 1880**：本页是整页长表单，若按默认 1000 截取只能看到「快速记录」一半。为一次看全，用 `od-shot --height 1880` 整页截取（同批次其它页为 1000–1125）。
- **生成方式**：OpenDesign 两次运行均未产出可用三件套（第 1 次 agent 卡死 600s 无产物；第 2 次 463s 只写出 index.html，且引用了不存在的 `../../_shared/tokens.css`、缺 styles.css / app.js）。本页最终由人工按同一 tokens + 共享 shell 手写实现，`_run.json` 保留了第 2 次运行的原始记录（其 `files` 只有 index.html）。
