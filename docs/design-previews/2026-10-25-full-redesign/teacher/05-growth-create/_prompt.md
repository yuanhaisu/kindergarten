## 产品事实（照此设计，不虚构）
老师从「成长记录」列表点添加进入（子页，有返回箭头）；老师端**无 tabBar**。

自上而下：
1. **日期条**：‹ 2026年10月24日 星期六 ›，可切前一天/后一天，不能到未来。
2. **记录对象**：顶部两段控件「全班记录 / 指定幼儿」（源码是底栏勾选，这里提升为分段控件，同一功能）。
3. **快速记录**（仅全班，可选）：饮食（早/午/晚各三档表情 😋好 😐一般 😞不好，可取消）；睡眠（午睡时长 1/2/3 小时；睡眠质量 很好/一般/不好）；情绪（上午/下午三档表情）；表现（标签多选：乐于助人、积极发言、遵守纪律、动手能力强、专注力强、有礼貌、爱干净、团结友善、勇于尝试）。
4. **指定幼儿**：已选摘要（头像堆叠 + 姓名，如「乐乐、小雨 等 5 人」）+「选择幼儿」按钮；空态「还没有选择幼儿」+ 说明「小一班共 28 位孩子」；同样有表现标签。
5. **照片/视频**：3 列九宫格，最后一格是虚线「＋ 添加」；单张状态：上传中（遮罩 + 百分比）、上传失败（红遮罩「重试」）、完成（角标「点名 6」/「AI 建议 3」、右上 ×）。工具行「已点名 2 张 · 批量点名」。提示「拍照建议：尽量拍单人照（AI 自动点名更准）；集体照用「全班」一键点名」「最多 20 张，单张 ≤20MB」。每张可写一句说明（可选）。
6. **记录内容**：多行正文，必填。
7. **授予徽章（可选）**：徽章 chip（整理小能手、勇敢之星、分享达人、专注宝贝），选中后出现「授予给」幼儿 chip + 勾选「本记录作为获奖见证（家长将在该记录看到徽章）」。

**底部固定栏**：可见范围说明（全班→「小一班全体家长可见」+「同步发送到班级动态」开关；指定→「仅 N 位幼儿家长可见」）+ 主按钮（`发布班级记录` / `发布个体记录` / `发布中…`）。安全区 `padding-bottom: calc(12px + env(safe-area-inset-bottom))`。

**校验**：正文为空→按钮禁用+原因「请输入记录内容」；指定幼儿 0 人→禁用+「请先选择至少一位幼儿」；照片上传中→禁用+「1 张照片上传中」；照片失败→禁用+「有 1 张照片上传失败，请重试或移除」。

## 状态（由 data-state 驱动，不用自己写切换 JS）
- `normal`（默认）：表单填好 —— 正文「今天上午带孩子们去后院捡了落叶，回来做了树叶拓印。乐乐专注地试了三种颜色，小雨主动把胶棒分给旁边的小朋友。」；早餐 😋、午餐 😋；睡眠 2 小时 / 很好；情绪 上午 😋、下午 😐；表现标签「动手能力强、乐于助人」；2 张照片完成（一张「点名 6」一张「AI 建议 3」）+ 1 张上传中；徽章「整理小能手」已选。
- `empty`：指定幼儿模式、0 人已选、正文为空 → 选择区插画空态 + 「选择幼儿」；底栏禁用并写出两条原因。
- `loading`：观察卡显示 2–3 行 shimmer 骨架；第一张照片显示上传中 62%；按钮禁用，原因「1 张照片上传中，完成后可发布」。
- `error`：底栏上方错误条「发布失败：网络连接超时」+「重试」；按钮文案「重新发布」，内容保留。
