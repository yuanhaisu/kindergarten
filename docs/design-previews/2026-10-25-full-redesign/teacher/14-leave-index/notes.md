# 请假审批（老师端）

- 源码：`teacher/src/pages/leave/index.vue`；契约：`backend/api/api-teacher/05-leaves.md`
- 设计系统：`user:nurture-planet-local`，`surface=teacher`
- 方向：一张待办的课桌 —— 暖纸底上只放真正要处理的事，每条申请给出两个明确的决定。
- 信息层级：
  1. 请假统计（待审批 / 已同意 / 已拒绝为班级累计，第四项「本月总计」按提交时间统计）
  2. 状态分段（全部 / 待审批 / 已同意 / 已拒绝，各带数量，数量为最近 20 条内，滚动吸顶）
  3. 列表标题与排序说明（全部视图待审批优先，再按提交时间倒序）
  4. 申请卡：孩子 + 家长 + 状态 + 提交时间 → 请假时间 / 事由 → 动作或审批留痕
- 覆盖状态：
  - 正常：8 条示例（待审批 3 + 已同意 4 + 已拒绝 1），统计与分段计数同源；
  - 刷新后按状态筛选时若该状态为空：显示对应文案（如「暂无待审批申请」）与「查看全部」；
  - 空：统计与分段计数归零，隐藏列表头，显示「暂无请假申请」+「刷新列表」；
  - 加载：3 张骨架卡（shimmer，`prefers-reduced-motion` 下停动画），统计显示 `—`，分段控件整体淡化且不显示计数、移除选中高亮；
  - 失败：显示「请假列表加载失败」+「重试」，统计 `—`，分段同样锁定；
  - 禁用：审批动作进行中两键同时禁用，同意键显示「处理中…」+ 小圆环。
- 交互（已用 CDP 逐条跑通，无 console error）：
  - 分段筛选即时生效，计数与统计恒等；
  - 同意：900ms「处理中…」→ 状态变已同意 → toast「已同意」→ 统计与列表同步；
  - 驳回：微信语汇居中对话框，理由必填，空值「确定驳回」置灰禁用，字数 0/100，确定后卡片带驳回理由归档，toast「已拒绝」；
  - 已审批卡整卡点击展开/收起「审批留痕」（审批时间 + 审批意见，无意见显示「未填写审批意见」），`aria-expanded` 同步、`›` 旋转；
  - 空态「刷新列表」、失败态「重试」、返回箭头均有反馈。
- token 映射：页面 `var(--bg)`；卡片/统计 `var(--surface)` + `var(--radius-card)` + `var(--shadow-sm/md)`；主按钮 `var(--accent-gradient)` + `var(--on-brand)`；选中分段 `var(--accent-wash)` / `var(--accent-deep)`；状态胶囊 `var(--warning-wash)` / `var(--success-wash)` / `var(--bg)`；驳回 `var(--danger)`；骨架 `var(--bg)` ↔ `var(--accent-wash)`；字号 `var(--text-xs)`~`var(--text-lg)`。全部颜色经 `var(--*)`，无裸 hex/rgb。
- 实现备注（吸顶）：shell 的 `.mp-main` 用 `overflow-x:hidden` 裁横向溢出，但 `hidden` 会把 `overflow-y` 计算成 `auto`，使其成为「不滚动的滚动容器」，页面滚动时子级 sticky 全部失效。本页给 `<main>` 追加 `.leave-main` 并以 `overflow-x: clip` 覆盖：保留横向裁切，不建立滚动容器，筛选条才能相对文档吸顶（实测滚动 250/600 后 top 恒为 64）。
- 与现状的差异：
  - 现状是「待审批申请 / 最近已审批」两段纵向堆叠；原型改为「统计 + 状态分段 + 单列（待审批优先，再按提交时间倒序）」，把「现在要处理什么」提到第一屏，已审批内容仍可筛可查。
  - 现状拒绝用 `uni.showModal({editable:true})`；原型保留同一语汇（标题 + 说明 + 取消/确定），把理由必填、字数上限与禁用态做成了可见状态。
  - 现状整卡不可展开；原型为已审批卡补「审批留痕」，让 `review_remark` 不被埋在列表外。
- 遗留 / 需产品确认：
  - 老师端列表 payload 不含 `class_name`，故卡片不显示班级；老师自己带班，是否需要在卡片上标明班级请产品确认。
  - 模型与接口均无「请假类型」（病假/事假），故不做类型标签；若后续新增需同步 `server/internal/domain/leave.go` 与契约。
  - 老师端无请假详情页，附件/诊断证明无法查看；原型只做列表内审批，是否需要详情页由产品决定。
  - 驳回理由会展示给家长（对话框已明示）；若产品希望「驳回」也可不填理由，需同步改契约与文案。
  - 「本月总计」口径取自 `stats.monthly_total`；待审批 / 已同意 / 已拒绝取自同名字段，是班级累计而非本月数据。分段计数与列表都只覆盖最近 20 条，页脚已注明三者的口径差异，避免读成「列表共 8 条 = 全月 8 条」或「四项相加恒等于本月总计」。
