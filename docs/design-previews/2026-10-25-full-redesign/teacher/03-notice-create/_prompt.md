你是幼儿园管理平台「养成星球」的资深移动端设计师。为老师端做一个页面的高保真 HTML 原型。

## 唯一任务
页面：发布通知（源码：`teacher/src/pages/notice/create.vue`）
只做一个方向，不要 A/B 变体，不要多页面。写完文件即停止，不要提问，不要联网。

## 这个页面真实的产品事实

老师在这里写一条通知，发给任教班级的全体家长。源码实际字段与行为（**不要新增不存在的字段**）：

1. **通知类型** `category`：5 个互斥选项 —— 作业 `homework`（默认选中）/ 带物 `bring` / 活动 `activity` / 健康 `health` / 其他 `other`。
2. **标题** `title`：单行输入，`maxlength=80`，占位「请输入通知标题」。
3. **正文** `content`：多行输入，占位「请输入通知内容...」。
4. **图片/视频附件** `attachments`：`uni.chooseImage`，最多 9 张（`count = 9 - 已选`），可逐张删除。
5. **接收范围** `class_ids`：从 `GET /teacher/class/list` 取「任教班级」多选；进页面时**默认选中第一个班级**。摘要文案 = 选中班级名用「、」连接 + 「全体家长」，未选时是「请选择班级」。
6. **需要家长确认收到** `need_confirm`：开关，**默认开启**，副文案「开启后可查看已读未读状态」。
7. **定时发送** `scheduled_enabled` + `scheduled_at`：开关，**默认关闭**，关闭时副文案是「立即发送」；开启后出现两个原生 picker —— 日期（`mode="date"`）与时间（`mode="time"`），拼成 `YYYY-MM-DD HH:mm`。
8. **常用模板** `templates`（`GET /teacher/notices/templates`）：仅当列表非空才显示。每条有 `title`、`content`、`category`；点「使用」把三项写进表单。
9. **底部发布**：校验顺序 = 标题 → 正文 → 接收班级 → 定时时间（若开启）。校验失败 `toast` 提示，不发请求。成功 `toast「已发布」`，600ms 后返回上一页（无上一页则回工作台）。
10. 页面是工作台的子页（`uni.navigateTo`），**老师端没有 tabBar**，导航栏左侧必须画返回箭头。

注意：**源码里没有「置顶」这个字段**（`is_top` 只存在于管理端公告 Announcement），不要画。

## 这个页面要变成什么样（设计要求）

这是一个**表单页**，不是内容页。请把它组织成小程序表单节奏：

- **分组卡片**：类型 → 内容（标题 + 正文 + 附件，卡内用细分隔线分 cell）→ 接收范围 → 发送设置（两行开关 + 定时展开）→ 常用模板。
- **cell 行**：左侧标签（14px/500 `--fg`），右侧当前值 + `›` 箭头，整行可点，行高 ≥ 52px。
- **选择类字段一律用小程序底部弹层**（不用 `<select>`、不用右上角下拉）：
  - 接收班级 → 底部多选弹层（班级行 + 圆形勾选 + 顶部「取消 / 接收班级 / 完成」）
  - 发送日期 → 底部日期滚轮弹层（2026年 / 10月 / 27日 三列，中间行高亮）
  - 发送时间 → 底部时间滚轮弹层（09 时 / 00 分 两列）
  - 常用模板 → 底部列表弹层（模板标题 + 两行预览 + 右侧「使用」）
- **底部固定提交栏**：`position: sticky/fixed` 贴底，内容含一行浅灰摘要（例「小一班 · 立即发送 · 需家长确认」）+ 一个全宽主按钮「发布」；**必须** `padding-bottom: calc(12px + env(safe-area-inset-bottom))`，内容区底部要留出等高的空白，最后一屏卡片不能被遮住。
- **确认弹层**：点「发布」先弹微信风格居中对话框 —— 标题「确认发布这条通知？」、说明「发布后小一班全体家长会收到微信提醒。」、两行摘要（类型 / 发送方式）、底部「取消 | 确认发布」。确认后按钮进入「发布中…」并显示小转圈，完成后顶部 toast「已发布」。

## 示例数据（中文，幼儿园语境）

- 老师：王老师 · 小一班；任教班级：小一班（28 人）、中二班（26 人）。默认选中 **小一班**。
- 表单默认已填（让评审一眼看到完整形态）：
  - 类型：作业
  - 标题：`明天请带一盒 12 色水彩笔`
  - 正文：`明天上午的美术课要用，请家长今晚帮孩子放进书包。水彩笔请贴上名字，避免拿错。`
  - 附件：2 张（用 CSS 画的占位缩略图，不用图片文件），计数「2/9」
  - 需要家长确认：开
  - 定时发送：关（显示「立即发送」）
- 常用模板 3 条：
  1. `秋游通知` — `明天上午 8:30 幼儿园门口集合，请为孩子准备水杯、湿巾和一套换洗衣物。`
  2. `手足口病预防提醒` — `近期为高发期，请家长每天检查孩子手心、脚心和口腔，发现红点及时就医并告知老师。`
  3. `带物提醒` — `明天请带一包湿巾和一盒彩笔，谢谢配合。`
- 定时发送打开后的示例：2026年10月27日 09:00（周一）。

## 视觉与结构硬约束

- `<html lang="zh-CN" data-surface="teacher">`
- 390px 手机视口；单列纵向流；不做桌面布局
- 微信小程序外壳：20px 状态栏（9:41 + 信号/wifi/电池图标，用内联 SVG）+ 44px 导航栏（「发布通知」居中 + **左侧返回箭头 ‹** + 右侧 `···`｜`◎` 胶囊）
- **不画 tabBar**（老师端没有）
- 颜色只写 `var(--*)`，禁止裸 hex/rgb；无直角（最小 `var(--radius-sm)`，卡片 `var(--radius-card)`，按钮/标签/开关 `var(--radius-pill)`）；阴影只用 `var(--shadow-sm/md/lg)`
- 暖色面积 ≤ 10%：大面积中性底，`--accent-gradient` 只用在底部「发布」主按钮；选中的分类胶囊、开关、勾选圈用 `--accent` / `--accent-wash` / `--accent-deep`
- 层级只靠字重 + 字号（标题 600 / 正文 400 / 标签 500），不要靠颜色堆叠
- 触控目标 ≥ 44px；正文 ≥ 13px；对比度 WCAG AA
- **禁止 `white-space: nowrap`** 用于可能超宽的文本（班级名、模板标题、摘要行都要能换行或截断）
- 所有容器 `max-width: 100%`，页面不得出现横向滚动；多列统计用 `grid-template-columns: repeat(N, minmax(0, 1fr))`
- 点击必须有 `:active` 反馈（`transform: scale(.98)` 或背景压暗）；不用 `alert()` / `prompt()`；无 JS 报错

## 状态覆盖（必须真的能切）

右下角「原型演示」半透明小胶囊（可关闭），四个芯片切换 `data-state`：

| 芯片 | 表现 |
|---|---|
| **正常** | 默认。表单已填，接收范围「小一班全体家长」，发布按钮可点 |
| **空** | 表单清空：标题 / 正文都空，正文下方出现 `--danger` 提示「请输入通知内容」，标题下方提示「请输入通知标题」，底部摘要变成「还差标题和正文」，**发布按钮置灰禁用**（`aria-disabled="true"`，`--surface-warm` 底 + `--border` 边 + `--muted` 字） |
| **加载** | 接收范围行右侧变成骨架条，常用模板行右侧变成骨架短条；发布按钮禁用 |
| **错误** | 接收范围行右侧变成 `--danger` 文案「班级列表加载失败」+ 一个「重试」小按钮；底部摘要「班级信息未加载，暂不能发布」；发布按钮禁用。点「重试」回到正常并 toast「班级列表已更新」 |

另外（与状态芯片独立）：在「正常」态下手动清空正文再点「发布」，应看到正文下方出现同样的 `--danger` 提示 + toast「请输入通知内容」，**不弹确认框**。
