# 园级事件（老师端）

- 源码：`teacher/src/pages/doctor/calendar.vue`
- 设计系统：`user:nurture-planet-local`，surface=teacher
- 方向：把「长表单 + 最近发布列表」改成**按日期分组的议程**——暖奶白底上一列浮起的事件卡，日期组头负责定位与折叠；发布 / 编辑表单收进底部弹层。品牌橙只出现在今天、选中日与主按钮，类型不做彩色编码。老师端无 tabBar，本页是 `navigateTo` 子页，因此画返回箭头。
- 信息层级：
  1. 范围条：地球图标 + `全园家长可见` 胶囊 + 「发布后，全园老师与家长会在日历中同步看到。」
  2. 工具栏：`园级日程` + `共 5 场园级事件`（由列表派生）+ `+ 发布`
  3. 日期组头：月份小标签（`2026年10月`）+ 44px 日徽标 + `今天 · 周一` / `10月29日 周四` + `2 场` + 独立的 44px chevron 折叠按钮
  4. 事件卡：类型标签 + （草稿）+ 时间（`09:00–11:00` / `全天` / `未设`）→ 标题（≤2 行）→ 说明（≤2 行）→ 地点 + `全园` → 底部 `编辑` / `删除`
  5. 过去日期组沉底，前有 `已结束` 分隔
  6. 原型演示条（正常 / 空态 / 加载 / 失败）
- 覆盖状态：
  - 正常：今天 2 场（体检 09:00–11:00、草稿补检 14:30）+ 10/29、11/03、已结束的 10/20，共 5 场
  - 空：计数变「共 0 场」、工具栏发布按钮隐藏，列表换日历插画 + 「还没有园级事件」+「发布后全园家长都能在日历中看到。」+「发布第一条事件」；范围条保留
  - 加载：计数换骨架条，列表换日期圆 + 组头 + 2 张事件卡骨架（每张 2–3 行）；范围条与工具栏保留
  - 失败：计数变「园级事件未载入」，列表换「事件加载失败 / 网络异常，未获取到园级事件。/ 重新加载」；切入该态时 toast「加载事件失败」，重新加载回正常并 toast「已重新加载」
  - 禁用：提交中 800ms——`存为草稿` / `立即发布` 双按钮 `disabled` + `aria-disabled="true"`、透明度 0.55，按压的那颗文案变「保存中… / 发布中…」，表单 `aria-busy`；防重复提交
- token 映射：
  - 页面底 `var(--bg)`（#f7f3ea），范围条与事件卡 `var(--surface)`（#fffaf0），卡片圆角 `var(--radius-card)`，按钮/标签/日徽标 `var(--radius-pill)`，组头热区 `var(--radius-xl)`
  - 品牌橙：今天数字 `--accent-deep` + `--weight-bold`（不加实心底）；选中日实心圆 `--accent` + `--on-brand`；发布按钮与空态主按钮 `--accent-gradient`；按压态用 `--accent-deep`
  - 标签：类型 `--bg` / `--fg-2`；草稿 `--warning-wash` 浅底 + `--fg`（黄字对比度不足）；全园 `--border` 描边 + `--surface` + `--fg-2`
  - 次要文字 `--muted`，分隔线 `--border`；卡片 `--shadow-sm`，弹层与对话框 `--shadow-lg`
  - 动效 `--motion-fast` / `--motion-base` + `--ease`
- 与现状的差异：
  - 首屏结构：源码是「范围说明 → 表单卡 → 最近发布」；原型表单收进底部弹层，首屏让给按日期分组的议程（同一能力，不是新功能）
  - 排序：源码按 `event_date` 倒序；原型今天起升序，未来在前，过去组沉底并标注「已结束」
  - 今天 / 选中：与班级日历统一为「今天 = 橙色粗体数字、选中 = 实心橙圆」，同一时刻只有一个实心圆；组头拆成两个按钮——`day-select` 只负责选中（选中即展开该组），`day-toggle` 只负责折叠。源码班级日历把「选中 + 折叠」绑在同一个点击上，原型拆开是因为第一次点击就会把刚选中的事件藏起来
  - 范围说明：从表单卡顶部上移到页面顶部范围条，并在每张事件卡底部补 `全园` 标签（作用域固定园级）
  - 编辑已发布事件：保留源码逻辑——顶部提示「该事件已发布——保存时将让你确认是否通知家长（按变更内容预置建议）」、隐藏表单内的通知开关；保存时弹变更确认弹层（日期 / 时间 / 地点 / 标题已更新 / 内容已更新 / 类型已更新 + 「发布变更通知」开关，日期时间地点有变默认开），保存后 toast「已保存」。弹层开关即最终 notify 值，关掉后保存不再推送家长
  - 草稿：卡上 `草稿` 标签；编辑时提示「该事件仍为草稿——保存发布后，全园家长即可在日历中看到。」；编辑草稿时显示「通知家长」开关并默认关闭（对齐源码 `startEdit` 的 `notify=false`），`保存发布` 按开关当前值决定是否推送
  - 编辑态底部：`取消编辑` / `存为草稿` / `保存发布` 三键；`存为草稿` 直接以 draft 状态保存（不弹变更确认、notify 恒为 false），已发布事件也能借此退回草稿，toast「已存草稿」
  - 日期 / 时间输入：沿用源码的微信可编辑对话框形态（居中圆角、取消 / 确定、无 `prompt`），并加 `YYYY-MM-DD` 与 `HH:MM` 格式校验
  - 触控与截断：编辑 / 删除移到卡片底部右侧，触控高度 44px；标题与说明各 2 行截断，地点换行，无 `white-space: nowrap`
  - 类型不做色彩编码：5 类统一中性标签（班级日历用类型点，本页密度高，避免 5 色抢注意力）
  - 删除：微信居中 alertdialog，正文「确定删除「全园体检」吗？删除后全园家长不再可见。」，确认后移除卡片并同步组内计数与总数，toast「已删除」
- 遗留：
  - **家长会紫色**：字典 `calendar_event_type` 下发 `#A855F7`，token 无对应紫色。本页类型标签不依赖颜色，所以不阻塞；若后续要在本页做类型色彩编码，需先在 `tokens.json` 增补 `color.type.*`（含 meeting 紫）。
  - **`is_all_day`**：数据模型有字段但源码表单无控件，原型同样不加开关；时间位会显示「全天」，示例数据均为 false，未展示该形态。
  - **`notify`**：新建 / 草稿用表单内开关；编辑已发布事件按源码隐藏表单开关，改由变更确认弹层的「发布变更通知」控制。
  - **创建人**：接口与模型均无该字段，页面不展示。
  - **取数范围**：接口按 `event_date` 返回后前端分组，没有日期范围参数；数据量大时需要后端补范围查询，本原型按全量列表演示。
  - **月份标签**：按调度要求每组上方都标月份；跨月滚动时重复感较强，若要收敛可只在月份变化的首组显示。
  - **已结束**：只按日期判定，同一天内不区分单条事件是否结束（源码无单事件状态）。
