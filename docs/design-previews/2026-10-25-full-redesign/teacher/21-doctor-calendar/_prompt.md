## 这个页面真实的产品事实（不要虚构其它能力）

保健医（医生角色）在老师端小程序里发布**园级事件**（体检等），发布后全园老师与家长都能在日历里看到；页面同时也是已发布事件的清单，可编辑、删除、存草稿。

**页面区块（源码顺序）**：顶部范围说明 → 发布/编辑表单卡 → 「最近发布」事件列表。本原型把长表单收进底部弹层（发布按钮打开），首屏以**按日期分组的议程**为主，这是同一能力的呈现方式变化，不是新功能。

**表单字段（全部来自源码，一个不多一个不少）**
- `title` 事件标题，必填（占位「如：全园体检」）
- `event_type` 事件类型，字典 `calendar_event_type` 内置 5 类：体检 `checkup`（默认）、通知 `notice`、活动 `activity`、假期 `holiday`、家长会 `meeting`
- `description` 事件说明（多行，占位「如体检项目、注意事项、需家长配合的事项」）
- `event_date` 事件日期，必填；源码用微信可编辑对话框输入，格式 `YYYY-MM-DD`
- `start_time` 开始时间（默认 `09:00`）、`end_time` 结束时间（可空，空显示「未设」）
- `location` 事件地点（占位「如：医务室」）
- `is_all_day` 全天（源码数据模型有该字段，但当前表单没有对应控件——原型也不要加控件）
- `notify` 通知家长开关，默认开；开启时发布后向全园家长推送通知
- 操作：`存为草稿` / `立即发布`；编辑态标题变「编辑园级事件」，按钮变「保存发布」，并有「取消编辑」

**编辑已发布事件（源码真实逻辑）**
- 表单顶部提示：「该事件已发布——保存时将让你确认是否通知家长（按变更内容预置建议）。」此时不显示「通知家长」开关
- 点「保存发布」时若检测到变更，弹出底部确认弹层：标题「通知家长？」、副标题「将通知全园家长」、变更行列表（日期 / 时间 / 地点 / 标题已更新 / 内容已更新 / 类型已更新）、开关「发布变更通知」（副标题「家长端会在日历顶部看到此变更」，日期/时间/地点有变时默认开）、按钮「取消」「保存」
- 没有任何变更时直接保存，不弹确认；编辑已发布事件保存成功后 toast「已保存」

**删除**：微信风格居中对话框——标题「删除事件」，正文「确定删除「全园体检」吗？删除后全园家长不再可见。」，按钮「取消」「删除」；确认后 toast「已删除」。

**列表真实字段**：`title`、`status`（`draft` 时显示「草稿」标签）、`event_date`、`is_all_day`（显示「全天」）、`start_time`、`location`。每条有「编辑」「删除」。空列表文案「暂无园级事件」，加载中文案「加载中...」，加载失败 toast「加载事件失败」。作用域固定园级，所以每条都标「全园」。

## 本页特别要求（调度方指定，必须满足）

1. **按日期分组**：事件按 event_date 分组，组头是日期（日数字 + 星期），组内是事件卡。月份在每组上方以小标签标明（如「2026年10月」）。
2. **「今天 / 选中」语义与班级日历一致**：日数字是一个圆形徽标；**今天**用品牌色粗体数字（不加实心底）；**仅当选中某个日期组时**才用品牌色实心圆 + 白字。同一时刻最多一个实心圆。点击日期组头即选中/取消选中该组，并折叠/展开该组事件（aria-expanded 同步）。
3. 排序：从今天开始按日期升序（今天 → 未来 → 过去的日期组沉到底部，用「已结束」小分隔标注）。源码是日期倒序，原型调整理由写进 notes 由我们补，不写进页面。
4. **范围/对象**：顶部范围条用「全园家长可见」胶囊 + 一句话说明；每张事件卡底部也带「全园」小标签。

## 视觉与结构硬约束

- `<html lang="zh-CN" data-surface="teacher">`；390px 手机视口；单列纵向流；不做桌面布局、不做横向滚动、不做侧边栏
- **外壳（状态栏 / 导航栏 / 胶囊 / 返回箭头 / 原型演示条）由宿主页面提供，你的产物只写内容区**：`<body>` 下只放一个 `<div class="proto" data-state="normal">`，里面是页面内容；不要画状态栏、不要画导航栏、不要画胶囊、不要画 tabBar、不要画底部导航。内容区顶部从范围条开始。
- 颜色**只能**写 `var(--*)`，禁止裸 hex / rgb / hsl / 颜色名。需要 token 里没有的颜色就退回最接近的 token。
- 无直角：最扁平元素 ≥ `var(--radius-sm)`；按钮/标签/日期圆 `var(--radius-pill)`；卡片 `var(--radius-card)`。
- 阴影只用 `var(--shadow-sm|md|lg)`，禁止写黑色投影。
- 暖色（accent）面积 ≤ 10%：大面积是 `--bg` / `--surface` 中性底；渐变只允许出现在「发布」主按钮和空态主按钮上，不要整块渐变背景。
- 层级只靠字重 + 字号：标题 600，正文 400，标签 500。
- 触控目标 ≥ 44×44px；正文 ≥ 13px（`--text-base` 起）；对比度满足 WCAG AA。
- 点击反馈只做 `:active` 缩放/压暗（`transform: scale(.98)` 或背景压暗），**信息不能只在 hover 时可见**。
- 禁止 `white-space: nowrap` 用于可能超宽的文本；多列统计用 `grid-template-columns: repeat(N, minmax(0, 1fr))`。
- 所有容器 `max-width: 100%`，页面不得出现横向滚动。
- 事件标题最多 2 行截断；事件说明最多 2 行截断；长地点要能换行。
- 首屏（390×1000）要能完整看到：范围条、工具栏、今天组（2 张事件卡）；不要出现大片空白，也不要内容溢出被裁。

## 状态覆盖（数据区域必须有，默认渲染正常态）

用根容器 `.proto` 的 `data-state` 属性接管，CSS 属性选择器实现，不需要页内切换按钮（外壳会注入）：
1. **正常**：上面的完整数据（默认）
2. **空**：事件列表区替换为空态——日历插画位 + 「还没有园级事件」+ 一句说明「发布后全园家长都能在日历中看到。」+ 主按钮「发布第一条事件」（打开表单弹层）；范围条与工具栏保留，计数变「共 0 场」
3. **加载**：工具栏数字与列表换骨架屏（日期圆 + 2 张事件卡骨架各 2–3 行），不要转圈占满屏
4. **失败**：列表区显示「事件加载失败」+「网络异常，未获取到园级事件。」+ 「重新加载」按钮（点后恢复正常并 toast「已重新加载」）
5. **禁用**：提交中（点「立即发布」后的 800ms 内）两个提交按钮禁用态（降低不透明度 + `aria-disabled="true"`，文案「发布中…」），完成后恢复；同一时间只允许一次提交

## 交互必须真的能点（app.js）

- 点「发布」打开底部表单弹层（遮罩 + 圆角顶部 + 下拉把手 + 标题「发布园级事件」+ 关闭 ×）；点遮罩或 × 关闭
- 类型胶囊可切换（默认体检）；通知家长开关可切换；标题/说明/地点可输入
- 点日期行 / 开始时间 / 结束时间 → **微信风格可编辑对话框**（标题 + 单行输入 + 取消/确定，居中圆角卡片，不用 prompt）；点确定回填，未填保持原值
- 「存为草稿」→ 校验标题与日期（缺哪个 toast 对应提示，弹层不关）→ 通过后按钮进入禁用态 800ms → 关闭弹层 + toast「已存草稿」
- 「立即发布」→ 同样校验 → 关闭弹层 + toast「发布成功」
- 点「编辑」→ 打开编辑态弹层（预填该条数据、标题「编辑园级事件」、隐藏通知开关、显示已发布提示、「取消编辑」）；已发布事件点「保存发布」→ 打开变更确认弹层（变更行列表 + 通知开关 + 取消/保存）；点「保存」→ 关闭两层 + toast「已保存」
- 点「删除」→ 居中确认对话框 → 「删除」→ toast「已删除」并把该卡从列表移除、组内计数与总数同步
- 点事件卡主体 → toast「已打开 全园体检」
- 日期组头点击 → 选中（实心圆）/取消选中（今天回到品牌色粗体数字）+ 折叠/展开（组内事件隐藏、chevron 旋转）
- 空态「发布第一条事件」→ 打开表单弹层；失败态「重新加载」→ 恢复正常 + toast
- toast 用小程序风格深色小胶囊居中偏下，2 秒自动消失；**禁止 `alert()` / `prompt()` / `confirm()`**
- 控制台无报错
