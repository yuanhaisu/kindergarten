# 班级相册（老师端）

- 源码：teacher/src/pages/album/index.vue
- 设计系统：user:nurture-planet-local，surface=teacher
- 方向：按月份分组的相册书架——一张统计卡定总量，分类胶囊做客户端过滤，每册用三格渐变封面拼出「多张照片」的体感，点任意一格从底部升起大图层。

## 信息层级

1. 统计卡：照片总数 386 / 本月新增 42 / 相册数 12，3 等分，数字不被挤换行。
2. 分类筛选：全部 / 活动 / 日常 / 作品 / 节日，5 等宽胶囊，选中浅底 + 品牌色描边。
3. 月份分组头：`2026年10月 · 4 册` / `2026年9月 · 2 册`，右侧册数随筛选实时更新，空组整体隐藏。更早的 `2026年8月 · 3 册` / `2026年7月 · 3 册` 默认折叠，由列表尾部「查看全部 12 册」原位展开（展开后 4+2+3+3 = 12 册）。
4. 相册卡：三格正方形渐变封面 → 标题 + `12张` → 日期 + 分类标签。
5. 底部固定主按钮「＋ 上传照片」。
6. 大图弹层（按需出现）：相册名 + 日期 → 4:3 大色块 → 第 1 张 / 共 12 张 → 左右切换 + 关闭。

## 覆盖状态

- 正常：统计卡 + 筛选 + 两个月份分组共 6 册 + 尾部「已展示最近 6 册 · 共 12 册」与「查看全部 12 册」+ 底部上传按钮；点「查看全部」展开 8 月 / 7 月两组，共 12 册。
- 空态：隐藏统计与列表，居中「还没有照片」+「上传后家长可在成长时光里看到」+「上传照片」按钮；底部上传按钮保留。
- 加载：统计骨架（3 列）+ 筛选骨架（5 胶囊）+ 2 张相册卡骨架（三格方块 + 两行文本条），轻微呼吸动画，`prefers-reduced-motion` 下静态。
- 失败：「相册加载失败」+「网络异常，未获取到照片」+「重试」；重试 600ms 后回正常态。
- 禁用：大图弹层第一张的「上一张」、最后一张的「下一张」为真 `disabled`（降透明度 + 不响应）。
- 交互实测（无头 Chrome，390×900）：5 个分类过滤后可见册数 6/3/4/3/2（筛选覆盖全部 12 册，含折叠的更早月份）、空月份组隐藏；「查看全部 12 册」展开后 12 册、四组册数 4/2/3/3；大图弹层开/关、上一张/下一张边界、遮罩与关闭按钮、两处 toast、四态切换与重试、滚动后状态栏/导航栏吸顶，全部通过，无 console error。
- 背景滚动锁定实测：弹层打开时 `body` 计算样式 `overflow=hidden`，CDP 派发真实滚轮输入（deltaY 400）后 `scrollY` 不变；关闭后 `overflow=visible`，滚轮恢复可滚。

## token 映射

- 页面底色 `var(--bg)`，卡片 `var(--surface)`，正文 `var(--fg)`，弱化 `var(--muted)` / `var(--hint)`。
- 主按钮 `linear-gradient(... var(--accent) ... var(--accent-deep))` + `var(--shadow-md)`，圆角 `var(--radius-pill)`。
- 分类选中：`var(--accent-wash)` 底 + `var(--accent-deep)` 文字 + `var(--accent)` 描边。
- 标签：活动 `--success` / `--success-wash`；日常 `--info` / `--info-wash`；作品 `--accent-deep` / `--accent-wash`；节日 `--warning` / `--warning-wash`。
- 照片占位六组渐变全部由 `var(--accent|info|success|warning)`、对应 `-wash` 与 `color-mix()` 推导，无裸色。
- 失败态 `var(--danger)` / `var(--danger-wash)`；骨架 `var(--line)` 系；阴影只用 `var(--shadow-sm|md|lg)`。

## 与现状的差异

- **月份分组是展示层的组织方式**：源码 `albums[]` 只有 `date` 字段、没有月份字段，也没有分组接口。这里只按 `date` 把最近 6 册归到 10 月 / 9 月，不改接口形状。
- **筛选是客户端过滤**（与源码一致），不做新请求；筛选后同步更新分组册数并隐藏空组，这是源码没有的收尾。
- **上传入口移到内容区底部的固定主按钮**：源码 `openUpload()` 已实现（toast「上传功能开发中」），但模板里没有渲染任何入口；按批次要求补上，文案沿用源码 toast 原文。
- 相册信息点击沿用源码占位 toast「查看相册「…」」，不跳转；照片点击是新增的大图预览弹层（源码没有），用于表达「一格封面对应一整册照片」。
- **没有画搜索**：源码有 `openSearch()` 但模板未渲染入口，按「不虚构功能」处理。
- **更早 6 册补上可达入口**：8 月 / 7 月两组默认折叠（`hidden`），列表尾部「查看全部 12 册」一次展开并隐藏入口；分类筛选跨全部 12 册（先展开再算册数），避免筛选结果被折叠吞掉。册数与照片数因此全页自洽：10月 4 + 9月 2 + 8月 3 + 7月 3 = 12 册 = 统计卡「相册数」；12 册照片数合计 386 = 统计卡「照片总数」；「本月新增 42」仍等于 10 月 4 册 12+9+14+7。
- 修正：`.viewer[hidden]` 显式 `display:none`（否则作者 `display:flex` 压过 UA `[hidden]`，留一层看不见的全屏遮罩吞掉所有点击）；`.album-more[hidden]` 同理；底部操作栏 `width: min(100%, 390px)` + `box-sizing: border-box`（消除 418px 的横向溢出）。
- 修正：`body.is-locked { overflow: hidden }` 锁背景滚动（原先只有 `is-locked` 类名没有规则，弹层开着背景仍能滚），并删掉对非滚动容器 `.mp-main` 的 `scrollTop = 0` 空转；状态切换只保留 `window.scrollTo(0, 0)`。
- 外壳：状态栏/导航栏/胶囊/返回箭头均为共享 shell 原样标记，页面 `styles.css` 未定义任何 `.mp-*`；老师端无 tabBar，本页未画。

## 遗留

- **老师端相册 API 尚未提供**：`loadAlbums()` 目前恒置空数组，线上真实页面是「暂无相册」。原型默认展示的是样例数据，接入接口前不能当真数据看。
- **上传入口需产品确认**：源码只有 `openUpload()` 占位，没有入口也没有上传能力（老师端相册接口缺失）。若产品不打算在本页上传，底部主按钮应改为别的动作或移除。
- 封面目前是纯 CSS 渐变占位：源码 `cover` 字段为空，真实封面图（OSS URL）与三格布局的取图规则（封面 + 相邻图 or 重复封面）待接口确定。
- 12 册是样例数据，`查看全部` 一次性展开全部 DOM，没有分页 / 上拉加载；真实接口若分页返回，需把这次展开换成「加载更多」。
- 大图弹层里的照片是渐变放大，不含真实图片与手势缩放；若产品要「双指缩放 / 左右滑动切图」，需另行设计。
- 全页截图里右下角「原型演示」折叠胶囊与列表尾部「查看全部 12 册」按钮处在同一水平带：演示条是原型专属元素，按批次规定用行内 `bottom: calc(64px + 12px + env(safe-area-inset-bottom))`，实机没有它；实测按钮右边界 279px、胶囊左边界 308px，上传栏顶部 1646px 在按钮底部 1635px 之下，三者均不重叠。
