# 班级日历（老师端）

- 源码：`teacher/src/pages/calendar/index.vue`
- 设计系统：`user:nurture-planet-local`，surface=teacher
- 方向：月历是主角——暖奶白底上一张浮起的月历卡；品牌橙只用来标记「选中日」和「添加」，活动靠 4px 类型点和类型字图标说话。
- 信息层级：
  1. 月份切换条：上一月 / `2026年10月` + `本月 11 个活动` / 下一月 / `+ 添加`
  2. 月历卡：周日–周六表头（周末红）+ 6×7 日期格 + 五类图例
  3. 当日安排：标题 + `10月26日 周一` + `2 个活动` 计数
  4. 事件卡：类型字图标 + 标题 +（草稿 / 全园标签）+ 类型·时间 + 描述（≤2 行）+ 地点 + 编辑
  5. 原型演示条（正常 / 空态 / 加载 / 失败）
- 覆盖状态：
  - 正常：完整月历 + 当天 2 场活动
  - 空：副标题变「本月暂无活动」、所有类型点隐藏（`grid.is-empty`）、计数变「暂无活动」、列表换空态块（日历图标 + `10月26日暂无活动安排` + `添加活动`）
  - 加载：月历卡与列表换骨架（7 列 × 5 行占位 + 图例条 + 2 张事件卡骨架），导航栏与月份条保持可读；月份条副标题改「正在加载…」，数据未到达前不报数量
  - 错误：隐藏月历与列表，只留「日历加载失败 / 网络异常，未获取到本月活动 / 重新加载」，月份条副标题改「活动加载失败」并禁用左右箭头；点「重新加载」回正常并 toast「已重新加载」，箭头随之恢复
  - 禁用：上/下月补位日期格变淡且不可点（`disabled` + `aria-hidden`）；「全园」事件没有编辑按钮
- token 映射：
  - 页面底 `var(--bg)`，卡片 `var(--surface)`，卡片圆角 `var(--radius-card)`，按钮与日期圆 `var(--radius-pill)`，类型图标方块 `var(--radius-xl)`
  - 品牌橙：选中日实心圆 `var(--accent)`、今天数字 `var(--accent-deep)`、添加按钮 `var(--accent-gradient)`、空态/错误主按钮同
  - 类型色成对使用：通知 `--info/--info-wash`、活动 `--success/--success-wash`、假期 `--accent-deep/--accent-wash`、家长会 `--muted/--bg`、体检 `--danger/--danger-wash`（由 `[data-tone]` 局部变量驱动）
  - 标签：草稿 `--warning-wash/--warning`，全园 `--info-wash/--info`
  - 阴影只用 `var(--shadow-sm)` / `var(--shadow-md)`
- 与现状的差异：
  - 月份条：白卡一行改为品牌浅渐变条，月份与「本月 N 个活动」的主次更清楚
  - 今天/选中：源码是「今天=实心橙、选中=浅底」，两者同时出现时浅底几乎与卡片同色，容易被看成「两个都选中」。改为「选中=实心橙圆、今天=橙色粗体数字」，同一时刻只有一个实心圆（与 iOS 日历一致）；今天且选中时加一圈 `--accent-soft` 柔光描边
  - 事件标题：源码 `white-space: nowrap` + 省略号，改为 2 行截断（遵守共享约束禁止 nowrap）
  - 编辑按钮：从卡片右侧小按钮移到卡片底部右侧，触控区 44×44（源码约 28px）
  - 月份条新增「本月 N 个活动」计数（由当月事件列表派生，不新增接口字段）；加载态显示「正在加载…」、失败态显示「活动加载失败」并禁用月份箭头，避免与骨架屏/错误块自相矛盾
  - 当日空态新增「添加活动」主按钮（源码只有一行提示文字；按钮复用月份条的添加入口语义）
  - 事件排序：源码按接口顺序渲染；原型按「全天在前，其余按开始时间」排序
  - 全园事件不显示空的底部行（无地点且不可编辑时卡片收紧，避免尾部空白）
- 遗留：
  - **创建人**：源码模板没有渲染创建人，`/teacher/calendar/events` 也不返回该字段（`teacherCalendarEventMap` 只有 id/title/description/event_type/event_type_label/scope/status/event_date/start_time/end_time/location/is_all_day/color）。任务里的「创建人」需产品确认是否补接口字段。
  - **参与班级名称**：接口只给 `scope`（class / kindergarten），没有班名字段，所以只表达「全园 / 本班」语义（本班为默认值不额外标注），不显示「小一班」这类具体班名。
  - **家长会紫色**：字典 `calendar_event_type` 下发 `#A855F7`，token 里没有对应紫色，本版映射到 `--muted/--bg`。建议在 tokens.json 增补 `color.type.meeting` 与 wash，或让后端改下发 token 名。
  - 跨月切换时，若新月份没有原选中日（如 31 日 → 2 月），选中日收敛到该月最后一天；切回当前月则回到今天。月历只按整月取数，不预取相邻月份的日期点，补位日期不显示活动点。
