## 这个页面真实的产品事实（照此设计，不要发明功能）
老师从工作台点「班级日历」进入，按月查看本班/全园的活动安排：上面一个月历，下面选中那天的活动列表。老师可以添加活动，可以编辑「本班」的事件；「全园」事件只读（没有编辑按钮）。

页面区块顺序（从上到下，与源码一致）：

1. **月份切换条**（源码 `.month-bar`，一行四件）
   - 左箭头 `‹` 切上一月、中间月份文字 `2026年10月`、右箭头 `›` 切下一月
   - 右侧「+ 添加」按钮 → `uni.navigateTo('/pages/calendar/create')`
   - 切月时重新拉取该月事件（`GET /teacher/calendar/events?start=YYYY-MM-01&end=YYYY-MM-DD`）；月份可以一直往前/后翻，**跨月切换不能崩**（含 2 月、31 天的月、选中日在新月份不存在的情况）
2. **月历卡片**（源码 `.calendar-card`）
   - 星期表头：`日 一 二 三 四 五 六`（周日、周六为周末色）
   - 6 行 × 7 列日期格。当月日期正常；上/下月补位日期变淡、**不可点**（源码只在 `cell.type === 'current'` 时允许 `selectDay`）
   - 每个当月日期格下方最多 3 个「类型色小圆点」，表示当天有活动；没有活动就没有点
   - 三种状态必须一眼区分：**今天**（品牌色实心圆 + 白字）、**选中**（品牌浅底 + 品牌色描边 + 加粗）、**有活动**（数字下方的小圆点，颜色 = 事件类型色）。今天且被选中时仍显示实心圆，外加一圈品牌色柔光描边
   - 月历底部图例：5 个类型（通知/活动/假期/家长会/体检），每项一个类型色小圆点 + 名称（源码从园所字典 `calendar_event_type` 动态渲染，内置固定 5 类）
   - 日期格触控区 ≥ 44×44px
3. **「当日安排」列表**（源码 `.events-section`，标题原文是 `{{month}}月{{selectedDay}}日活动`）
   - 标题行：「当日安排」+ 右侧计数（如「2 个活动」）；下一行小字日期，如「10月26日 周一」
   - 事件卡片顺序（与源码字段一一对应，**不要加源码没有的字段**）：
     - 左侧类型图标方块：该类型名称的第一个字（通知→「通」、活动→「活」、假期→「假」、家长会→「家」、体检→「体」），底色用类型色的浅底
     - 标题（`title`，最多两行）
     - 状态 `draft` 时，标题右侧出现「草稿」小标签（源码只显示草稿；`published` 不显示任何状态标签）
     - 元信息行：类型名（`event_type_label`）+ 时间。`is_all_day=true` 显示「全天」；否则显示 `start_time`–`end_time`（如「09:00–10:30」），二者都没有就不显示时间
     - 描述（`description`，最多 2 行，没有就不占位）
     - 底部：地点（`location`，有才显示，带定位小图标）+ 范围（`scope`：`class` → 「本班」，`kindergarten` → 「全园」）+ 右侧「编辑」按钮
     - **「编辑」按钮只在 `scope !== 'kindergarten'` 时出现**（源码 `v-if="event.scope !== 'kindergarten'"`）；点击去 `/pages/calendar/detail?id=`
   - 选中日没有活动时显示空态：图标位 + 一句「10月24日暂无活动安排」+「添加活动」按钮（添加入口源码真实存在）
4. **右下角原型演示条**（共享 `mp-demo`，四态：正常 / 空 / 加载 / 失败）

**源码里不存在、绝对不要画的**：创建人、参与班级名称（接口只返回 `scope`，没有班级名字段）、地点地图、参与者头像、评论、点赞、置顶、重复日程、周视图/日视图切换、搜索、筛选器、右上下拉菜单。

## 数据形状（接口真实字段，照此造数据）
`GET /teacher/calendar/events` 返回 `{ list: [...], total }`，单条：
```
id, title, description,
event_type,          // notice | activity | holiday | meeting | checkup
event_type_label,    // 通知 | 活动 | 假期 | 家长会 | 体检
scope,               // class | kindergarten
status,              // draft | published
event_date,          // "2026-10-26"
start_time,          // "09:00" 或 null
end_time,            // "10:30" 或 null
location,            // 字符串，可为空
is_all_day,          // boolean
color                // 服务端按字典下发的十六进制色（原型里改用 token，见下）
```

### 类型色 token 映射（**不许写裸 hex**，用这组成对 token）
| 类型 | 文本/点色 | 浅底 |
|---|---|---|
| 通知 notice | `var(--info)` | `var(--info-wash)` |
| 活动 activity | `var(--success)` | `var(--success-wash)` |
| 假期 holiday | `var(--accent)` | `var(--accent-wash)` |
| 家长会 meeting | `var(--muted)` | `var(--bg)` |
| 体检 checkup | `var(--danger)` | `var(--danger-wash)` |

## 视觉与结构硬约束
- `<html lang="zh-CN" data-surface="teacher">`，390px 手机视口，单列纵向流，不做桌面布局。
- **外壳必须原样使用共享 shell**：先读 `D:/yuanhaisu/personal_projects/kindergarten/docs/design-previews/2026-10-25-full-redesign/_shared/shell.md` 与 `shell.css`，照抄其中的 `mp-statusbar` / `mp-time` / `mp-status-icons` / `mp-navbar` / `mp-back` / `mp-title` / `mp-capsule` / `mp-main` / `mp-demo` 标记与 SVG。引入顺序：`tokens.css` → `../../_shared/shell.css` → `styles.css`；末尾引入 `../../_shared/shell.js` 再引入 `app.js`。
- **禁止把 shell.css 复制进项目**，也不要改写状态栏 SVG；只写 `<link href="../../_shared/shell.css">`，文件在当前项目里不存在也没关系（最终由流程拼装）。
- **styles.css 里绝对不许出现任何 `.mp-*` 选择器或覆盖**（唯一例外是 `[data-state]` 状态选择器，可写成 `.mp-app[data-state="empty"] .xxx`）。
- 子页：导航栏保留返回箭头，标题「班级日历」。老师端**不画 tabBar**。
- 颜色只写 `var(--*)`，禁止裸 hex / rgb / hsl；无直角（最小 `var(--radius-sm)`）；阴影只用 `var(--shadow-*)`。
- **暖色克制**：橙色只出现在「今天」日期圆、选中态描边、选中日浅底、「+ 添加」按钮、空态主按钮；其余大面积是暖奶白 `var(--bg)` 与 `var(--surface)`。类型色只出现在 4–6px 的小圆点、类型标签、以及类型图标方块的浅底上，不做大面积铺色。
- 圆润：卡片 `var(--radius-card)`，按钮/标签/日期圆 `var(--radius-pill)`，类型图标方块 `var(--radius-xl)`。
- 微信小程序语汇：筛选/切换用胶囊或分段条，不用 `<select>`；提示用 toast；危险操作用微信居中对话框（本页没有危险操作，可不做）。不用 alert / prompt。
- 触控目标 ≥ 44×44px；正文 ≥ 13px；`:active` 必须有反馈（缩放或压暗）。
- 禁止对可能超宽的文本用 `white-space: nowrap`；所有容器 `max-width: 100%`，页面不得横向滚动；长标题/地点/描述必须自然折行或 2 行截断。
- 状态覆盖（data-state 驱动，演示条用 `mp-demo`，四个 chip 文案：正常 / 空态 / 加载 / 失败）：
  - **正常**（默认）：完整月历 + 当日 2 个活动；
  - **空**：月历保留但所有类型点消失、月份副标题变「本月暂无活动」、列表区显示空态块（图标位 + 「10月26日暂无活动安排」+ 「添加活动」按钮）；
  - **加载**：月历卡片与列表换成骨架屏（7 列 × 5 行圆形占位 + 图例条 + 2 张事件卡骨架），导航栏与月份条保持可读；
  - **失败**：一句话「日历加载失败」+ 说明「网络异常，未获取到本月活动」+「重新加载」按钮，点击回到正常态并 toast「已重新加载」。
  - 禁用态：上/下月补位日期格变淡不可点（`aria-disabled="true"`），「全园」事件没有编辑按钮。

## 交互（app.js，全部真实可点，无 console 报错）
- 左右箭头切换月份：用真实日期数学重建 6 行网格（首日星期 + 当月天数 + 补位），更新月份文字与「本月 N 个活动」副标题，重建类型点；切换后选中日 = 原选中日（若新月份没有这一天则取该月最后一天）；若切回当前月则选中今天。**任何月份（含 2 月、31 天月、1 月往前）都不能报错、不能出现空网格。**
- 点当月日期 → 选中该日，列表与标题日期同步刷新；点补位日期无反应。
- 点事件「编辑」→ toast「已打开「活动名」详情」；点「+ 添加」→ toast「打开新建活动」；空态「添加活动」→ 同样 toast。
- 演示条切换四态：正常/空/加载/失败，样式与内容按上面定义切换（可用 `document.addEventListener('mp:state', ...)` 或直接读 `data-state`）。
- 所有按钮有 `:active` 反馈；无 console 报错。
