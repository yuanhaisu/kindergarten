## 唯一任务
页面：成长记录列表（源码：`teacher/src/pages/growth/index.vue`）
只做一个方向，不要 A/B 变体，不要多页面。写完文件即停止，不要提问，不要联网，不要回头读自己的产物做自查循环。

## 这个页面真实的产品事实

老师查看自己发的成长记录，按月倒序排列。数据来自 `GET /teacher/growth/logs?page=1&page_size=20`，进页面 `onShow` 拉一次，**只拉第 1 页 20 条**，下拉刷新重拉；没有「加载更多」。

列表项字段（**只能用这些**）：
`id`、`date`（YYYY-MM-DD）、`content`、`performance_tags[]`（表现标签，仅个体记录显示）、`media_preview[{thumb_url,type}]`（有附件的记录才有）、`likes_count`、`comments_count`、`related_students_count`、`pending_suggestions_count`（AI 待确认建议数）、`sync_to_feed`（是否同步给家长）、`target_type`（1=全班 / 2=指定学生）、`creator{nickname}`、`created_at`。

源码已有区块（顺序照抄，不要打乱）：
1. **今日头部**：左边日期「10月24日 星期五」；右边两个数字 + 标签 —— 「今日已记 N」与「N 条待处理」。
   - 今日已记 = 当前这 20 条里 `date` 等于今天的条数。
   - 待处理 = `pending_suggestions_count > 0`，或「个体记录且 `sync_to_feed === false`」的条数。
   - 两个数字都只覆盖已加载的这一页，不是全量。
2. **快速记录按钮**：进创建页 `/pages/growth/create`。这是本页唯一主操作。
3. **搜索框**：过滤**已加载的 20 条**（内容或老师昵称），占位文案明说「仅最近 20 条」。
4. **按月分组**：组头 = 「2026年10月」+「（4条记录）」。
5. **记录卡片**：可选顶部缩略图 → 作者行（首字头像 + 昵称）→ 个体记录的二级行（表现标签用「 · 」连接）→ 正文（超长截断）→ 底部左：全班记录显示「相关 N 位小朋友」、个体记录显示「已同步给家长 / 未同步给家长」标签；若有待确认建议显示「AI建议 N 待确认」角标；底部右：赞数、评论数。
6. 点卡片 → 详情页 `/pages/growth/detail?id=<id>`。
7. 状态：加载「加载成长记录...」；空「暂无成长记录」；搜索无结果「未找到匹配的记录」；错误 → 错误信息 + 「重试」。

## 本次重设计的三个改动（只做这些，别扩）

1. **发布入口提到右上角**：原「快速记录」大按钮占一整行，且发布入口不够显眼。改成**首屏头部右侧一颗实心 `--accent-gradient` 胶囊按钮「＋ 发布」**（高 36–40px，圆角 pill），点击进创建页。页面上不再出现第二个同义按钮。
2. **顶部加筛选**：两颗 chip —— 「小一班 ▾」（班级）与「10月 ▾」（时间）。点任一颗从底部升起小程序风格选择面板（**不要** `<select>`、**不要**右上角下拉菜单）。选择面板底部一行小字说明真实范围：「筛选作用于已加载的最近 20 条」（与搜索框的诚实口径一致）。
   - 班级选项来自 `GET /teacher/class/list`（真实接口）：「全部班级 / 小一班 / 中二班」。
   - 时间选项：「全部时间 / 本月（10月）/ 上月（9月）」。
   - 筛选后如果 0 条，走「筛选无结果」状态，给一个「清除筛选」按钮。
3. **图片区**：原实现只显示第一张、且是固定 16:9 大图。改成按张数自适应（**只用 CSS 渐变占位块，不引用任何图片文件**）：
   - 1 张 → 16:9 大图
   - 2–3 张 → 等分横排（高 96px）
   - ≥4 张 → 2×2 网格（2 列，`grid-template-columns: repeat(2, minmax(0, 1fr))`），第 4 格盖半透明遮罩写「+N」
   - 图片区右上角一个半透明小角标写真实张数「3 张」
   - 占位块用 `--accent-wash` / `--surface-warm` / `--info-wash` 之类的 token 做柔和渐变，块与块之间有 `--space-xs` 间隙，圆角 `--radius-lg`

## 视觉与结构硬约束

- `<html lang="zh-CN" data-surface="teacher">`
- 390px 手机视口；单列纵向流；不做桌面布局；页面不得横向滚动
- 微信小程序外壳：20px 状态栏（9:41 + 信号/wifi/电池，内联 SVG）+ 44px 导航栏（标题「成长记录」居中 + **左侧返回箭头 ‹** + 右侧 `···`｜`◎` 胶囊）
- **不画 tabBar**（老师端没有）
- 颜色只写 `var(--*)`，禁止裸 hex / rgb；无直角（最小 `var(--radius-sm)`，卡片 `var(--radius-card)`，按钮/标签/头像/开关 `var(--radius-pill)`）；阴影只用 `var(--shadow-sm|md|lg)`
- 暖色面积 ≤ 10%：大面积中性底 `var(--bg)`，`--accent-gradient` 只用在「＋ 发布」按钮；选中态 chip / 今日数字用 `var(--accent)` + `var(--accent-wash)`
- 层级只靠字重 + 字号（标题 600 / 正文 400 / 标签 500），不要靠颜色堆叠
- 触控目标 ≥ 44px；正文 ≥ 13px；对比度 WCAG AA
- **禁止 `white-space: nowrap`** 用于可能超宽的文本（昵称、标签、月份、卡片正文都要能换行或截断）
- 所有容器 `max-width: 100%`；多列统计/网格一律 `repeat(N, minmax(0, 1fr))`
- 卡片正文**两行截断**：`display:-webkit-box; -webkit-box-orient:vertical; -webkit-line-clamp:2; overflow:hidden`（源码是 3 行，本次收紧到 2 行）
- 点击必须有 `:active` 反馈（`transform: scale(.98)` 或背景压暗）；不用 `alert()` / `prompt()`；无 JS 报错

## 状态覆盖（必须真的能切）

右下角「原型演示」半透明小胶囊（可关闭），5 个芯片切换：
