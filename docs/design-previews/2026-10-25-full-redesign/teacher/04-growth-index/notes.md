# 成长记录列表（老师端）

- 源码：`teacher/src/pages/growth/index.vue`（数据 `GET /teacher/growth/logs?page=1&page_size=20`，字段契约见 `backend/api/api-teacher/06-growth.md`）
- 设计系统：`user:nurture-planet-local`，`surface=teacher`
- 方向：**月度时间轴 + 图卡**。把「今天记了没」压成头部一行统计，筛选收进两颗 chip，卡片以图片为主视觉，月份是唯一的分组刻度。

## 信息层级（从上到下）

1. 导航栏「成长记录」+ 返回箭头 + 微信胶囊（本页由工作台 `navigateTo` 进入，是子页）
2. 头部：`10月24日 星期六` + 右侧「＋ 发布」实心胶囊（本页唯一主操作）
3. 统计行：`2 今日已记` / `3 条待处理` + 「仅统计已加载」小字
4. 筛选：`全部班级 ▾` `全部时间 ▾` 两颗 chip（底部弹层选择）
5. 搜索框：`搜索内容或老师 · 仅最近 20 条`
6. 月份分组 `2026年10月（4条记录）` → 记录卡片
7. 列表底：未筛选时 `已显示最近 7 条 · 下拉刷新`；筛选/搜索生效时改为 `已加载 7 条 · 当前显示 N 条`，把「加载了多少」与「显示了多少」分开

卡片内部顺序（与源码一致）：图片区（右上角「N 张」）→ 首字头像 + 昵称 + 日期 → 个体记录的表现标签行 → 正文（两行截断）→ 底部左：`相关 N 位小朋友` / `已同步给家长` / `未同步给家长` / `AI建议 N 待确认`；底部右：赞数、评论数。

## 覆盖状态

| 状态 | 表现 |
|---|---|
| 正常 | 7 条记录、两个月分组；三种图片排布（1 张大图 / 2–3 张等分横排 / ≥5 张 2×2 + 「+N」）同时出现 |
| 空 | 头部统计归零、发布按钮隐藏；星球插画 + 「还没有成长记录，从今天开始吧」+ 实心「发布第一条」 |
| 筛选/搜索无结果 | 独立状态 `noresult`（2026-10-27 起，不再并入空态）：列表与页脚隐藏，发布按钮与筛选条保留；空态标题「未找到匹配的记录」+ 按钮「清除筛选」/「清除搜索」；统计行补注「不受筛选影响」 |
| 加载 | 3 张骨架卡（图片块 + 圆形头像 + 两条文字条）+ 顶部小转圈「加载成长记录...」；同时搜索框、两颗 chip、「＋ 发布」全部进入禁用降级 |
| 错误 | 红色圆形感叹号 + 「加载失败，请检查网络」+ 「重试」（ghost 按钮，点击回正常态并 toast「已重新加载」） |
| 禁用 | 本页没有天然不可点的主操作，禁用样式统一在「加载/失败」态体现（`--border` 混色底 + `--hint` 字 + `border` 边） |

右下角 `mp-demo`（`_shared/shell.js`）提供 正常 / 空态 / 加载 / 失败 四个芯片，默认收起。

## 与现状的差异

1. **发布入口**：原来的整行大按钮「快速记录」→ 头部右侧 `＋ 发布` 胶囊。理由：列表页的主操作不该占据一整行、也不该在搜索框下面（滚动后消失）。文案由「快速记录」改为「发布」，是本次唯一改了语义的按钮。
2. **新增班级/时间筛选**：源码只有搜索（且只过滤已加载的 20 条）。新增两颗 chip 走底部弹层，**口径同样只作用于已加载的这一页**，弹层底部明写「筛选作用于已加载的最近 20 条」。
   - ⚠️ 后端 `GET /teacher/growth/logs` 目前只接受 `date`（单日）参数，没有 `class_id` / `month`。要做成真正的服务端筛选需改契约；原型按「已加载页内筛选」呈现，不伪造服务端能力。
   - 班级选项来自真实接口 `GET /teacher/class/list`（发布通知页已在用）。
3. **图片区多样化**：源码只用 `media_preview[0]` 铺一张 16:9 大图，其余图片在列表里完全不可见。改为按张数自适应（1 / 2–3 / ≥5），并在右上角给出真实张数。
4. **正文截断 3 行 → 2 行**：按本批次要求收紧，让同屏能看到更多条记录。
5. **AI 建议角标用 info 蓝**（源码即为 `--color-semantic-info-bg`），与「已同步/未同步」的绿/黄区分开。
6. **统计口径写在界面上**：「今日已记 / 待处理」都只覆盖已加载的一页，源码注释里已声明，原型把「仅统计已加载」显式画出来，避免老师误以为是全量。
7. 底部补一行「已显示最近 7 条 · 下拉刷新」，如实说明「只加载一页、没有加载更多」。

## 遗留

- **班级筛选的真实性**：需要产品确认。若坚持服务端筛选，要改 `backend/api/api-teacher/06-growth.md` + service 查询；若接受页内筛选，文案保持现状。
- **卡片上不显示班级名**：列表接口的 `class` 关系未下发（`GrowthDailyLog.ClassID` 存在但响应里没有），所以选「全部班级」时无法从卡片分辨记录属于哪个班。要补需在列表 payload 加 `class`。
- **「相关 N 位小朋友」的口径冲突**：源码在**全班记录**上显示 `related_students_count`，但 `backend/api/api-teacher/06-growth.md` 写明该字段「仅对个体记录有非零值」。原型按源码渲染（全班记录显示），需要后端确认到底哪个对。
- 未做「加载更多」：源码确实没有分页，只有下拉刷新，故不画。
- `styles.css` 26KB / `app.js` 22KB，仍略超共享约束建议的 20KB（外壳抽走后已比首版小 6KB），已验证无外部依赖。

## 外壳回归（2026-10-26）

按 `_shared/shell.md` 把自造外壳换成 canonical shell，**只换实现，不改设计**。

**换掉的类**

| 原来自造 | 现在 |
|---|---|
| `.app` | `.mp-app`（`data-state` 挂在它上面） |
| `.status-bar` / `.status-time` / `.status-icons` | `.mp-statusbar` / `.mp-time` / `.mp-status-icons`（SVG 原样用 shell.md 那份，尺寸 17×11 / 15×11 / 24×11） |
| `.nav-bar` / `.nav-title` / `.nav-back` | `.mp-navbar` / `.mp-title` / `.mp-back`（子页，保留返回箭头） |
| `.nav-capsule` / `.capsule-btn` / `.capsule-divider` | `.mp-capsule` / `.mp-capsule-dots` / `.mp-capsule-divider` / `.mp-capsule-ring` |
| `.page-scroll`（自己的滚动容器） | `.mp-main.mp-main--scroll`（滚动交还给 body，外壳 sticky 才有意义） |
| `.demo-dock` / `.demo-pill` / `.demo-panel` / `.demo-chip` | `.mp-demo` / `.mp-demo-toggle` / `.mp-demo-chips` / `.mp-demo-chip[data-mp-state]` |

**删掉的样式**：`.app`（固定高度 + overflow:hidden）、整套状态栏/导航栏/胶囊样式、`.page-scroll` 与它的滚动条规则、整套演示条样式、`body { display:flex; overflow:hidden }`、`.empty-state` / `.error-state` / `.loading-state` 的容器类（改名为 `.state-*`）、以及随「筛选无结果」并入空态后失效的 `.no-results` / `.result-icon` / `.result-title` / `.result-hint`。

**四态改为纯 CSS**：空/加载/失败三块由 HTML 静态持有（默认 `display:none`），由 `.mp-app[data-state="empty|loading|error"]` 属性选择器显示；`app.js` 不再拼这三块 DOM。演示芯片点击由 `shell.js` 写 `data-state` 并广播 `mp:state`，`app.js` 只监听它来同步统计数字与控件禁用态。

**「筛选无结果」并入空态（2026-10-26）**：不再有第 5 个芯片。筛选/搜索命中 0 条时页面把 `data-state` 置为 `empty` 并改写空态文案为「未找到匹配的记录 / 清除筛选」（服务端真空态仍是「还没有成长记录 / 发布第一条」）。顺带修掉一个因此暴露的问题：空态下 `.tools` 原本会被隐藏，导致无结果时看不到也改不了筛选——现在只隐藏列表与发布按钮，筛选条保留。**2026-10-27 起无结果改为独立 `noresult` 状态，不再复用 `empty`，详见文末「P1 修复」。**

**有无变形**：无。状态栏 20px、导航栏 44px、胶囊 87×32、返回 44×44 实测与规范一致；滚动 400px 后状态栏 top=0、导航栏 top=20（吸顶正常）；四态均无横向溢出、无 console 报错。唯一可见变化是预览图从「一屏」变成「整页」——滚动交还 body 后 `od-shot` 抓到整页高度（2477px），内容与密度未变。

## P1 修复（2026-10-27）

- **页脚计数**：不再用全量 `RECORDS.length`。筛选/搜索生效时显示「已加载 7 条 · 当前显示 N 条」，未筛选时仍是「已显示最近 7 条 · 下拉刷新」。
- **筛选/搜索无结果拆为独立状态 `noresult`**：`data-state="empty"` 只留给服务端真空态（仍隐藏发布按钮，由「发布第一条」CTA 承担入口）；`noresult` 只隐藏列表与页脚，保留发布按钮与筛选条。空态文案仍为「未找到匹配的记录 / 清除筛选」（搜索时为「清除搜索」）。
- **统计口径显式化**：统计仍按源码口径覆盖已加载的一页、不受筛选影响；筛选/搜索生效时统计行小字变为「仅统计已加载 · 不受筛选影响」，避免与「未找到匹配的记录」看起来互相矛盾。
- 演示芯片仍是 正常/空态/加载/失败 四个；`noresult` 只由页面自身筛选触发，不占芯片，也不改变 `empty` 的演示行为。
