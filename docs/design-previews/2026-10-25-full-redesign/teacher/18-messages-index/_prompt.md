## 这个页面真实的产品事实（照此设计，不要发明字段）

老师从工作台的铃铛、班级页、更多页、我的页通过 `uni.navigateTo` 进入本页（**子页，导航栏必须有返回箭头**）。页面把三类消息聚合在一条时间倒序的收件箱里。

**数据结构（`GET /teacher/messages`，全部真实存在）**
- `type`：`notice`（通知）/ `leave`（请假审批）/ `system`（系统）。**没有「任务」类型**，不要画。
- `title`：消息标题（如「秋游亲子活动通知」「乐乐妈妈提交的请假申请」「系统维护通知」）。
- `content`：内容摘要（最多 200 字，页面截取前 60 字展示）。
- `reference_id`：关联业务 ID。
- `created_at`：RFC3339 时间。
- `extra` 按类型不同：
  - notice：`category_label`（作业 / 活动 / 健康 等）、`status_label`（已发布 / 定时待发）、`read_count` / `total_count` / `read_rate`（已读家长数 / 班级人数 / 已读率）。
  - leave：`student_name`、`applicant_name`、`leave_dates`、`status_label`（待审批 / 已同意 / 已拒绝 / 已取消）。
  - system：空对象。

**源码里真实存在的交互**
- 顶部分类标签：全部 / 通知 / 审批 / 系统，纯客户端按 `type` 过滤，**没有「全部/未读」分段，不要画未读筛选**。
- 点击列表项：`leave` 跳转 `/pages/leave/index`（请假审批）；`notice` 与 `system` 源码只弹 toast `查看: <类型名>`，没有详情页。
- `markAllRead()` 存在但模板没有渲染入口（toast 文案「已全部标为已读」）。
- 下拉刷新整页；上拉加载更多（`page_size 20`）。
- 每行左侧有类型图标（notice 通知 / leave 审批 / system 系统），源码模板里还预留了未读红点与未读计数徽标；但当前 `mapMessage` 把 `isRead` 恒设为 `true`、`unread` 恒为 `0`，**未读态实际从未显示**。本原型按任务要求把未读态设计出来（品牌色小圆点，见下），并在 notes 里标注「源码未接线」。

**源码里不存在、绝对不要画的东西**：任务类消息、未读数筛选 tab、搜索、消息详情页、删除/清空、按日期分组、置顶、群聊/会话列表。不要造这些。

## 页面结构与要求（从上到下）

1. **导航栏**：共享 shell 的 `mp-navbar`，返回箭头 + 标题「消息」+ 右侧胶囊。老师端**没有 tabBar，不要画**。
2. **分类分段（吸顶）**：紧贴导航栏下方，一条圆角轨道里 4 个等宽按钮「全部 12 / 通知 5 / 审批 4 / 系统 3」，数字是当前分类条数（来自示例数据，自洽）。选中项 `--accent-wash` 底 + `--accent-deep` 文字 + 600 字重；未选中透明底 + `--muted`。整条 `position: sticky; top: 64px; z-index: 10;`，底色 `var(--bg)`，滚动时压在列表上方。触控高度 ≥ 44px。
3. **列表口径行**：左侧小字「共 12 条 · 4 条未读」（随分类切换更新为当前分类的条数与未读数）；右侧文字按钮「全部已读」（品牌色，44px 触控区）。未读数为 0 时该按钮进入禁用态（`--hint` 文字、降透明、`aria-disabled="true"`、不响应点击）。
4. **收件箱列表（cell 行，一张大卡里分隔线分栏，不要一行一张卡）**：`var(--surface)` 底、`var(--radius-card)`、`var(--shadow-sm)`，行间 1px `var(--border)` 分隔。
   - 每行三列：40×40 类型图标（圆角 12px，浅色 wash 底 + 描边图标，SVG 手绘；通知=info 系、审批=warning/success 系按状态、系统=中性）+ 中间内容 + 右侧 12px 的 `›`。
   - 中间第一行：标题（15px；未读 600 `var(--fg)`，已读 500 `var(--muted)`），右侧时间（11px `var(--hint)`）。
   - 第二行：摘要，13px `var(--muted)`，最多 2 行截断；已读行整体降一档灰度（置灰），但仍要满足 AA 对比度（标题/摘要都用 `var(--muted)`，不要用 `var(--hint)` 写正文）。
   - 第三行：类型标签胶囊（通知 / 审批 / 系统，11px）+ 该类型的次要状态文字：notice 显示「分类 · 状态 · 已读 X/Y」，leave 显示状态中文并按语义着色（待审批 warning、已同意 success、已拒绝/已取消 muted），system 不显示次要文字。
   - **未读标记：品牌色 8px 小圆点**（`var(--accent)`，2px `var(--surface)` 描边），放在类型图标右上角；**绝对不要给整行染色**。点击后圆点消失、标题降为 500 字重并置灰；行内不要出现未读数字徽标。
   - 行高 ≥ 44px，整行可点（`:active` 压暗 `var(--accent-wash)`），`aria-label` 用标题。
5. **底部留白**：`padding-bottom: calc(24px + env(safe-area-inset-bottom))`，最后一行不被演示条遮挡。

## 视觉与结构硬约束
- `<html lang="zh-CN" data-surface="teacher">`，390px 手机视口，单列纵向流，不做桌面布局。
- **外壳必须原样使用共享 shell**：照抄 `mp-statusbar` / `mp-time` / `mp-status-icons` / `mp-navbar` / `mp-back` / `mp-title` / `mp-capsule` / `mp-main` 的标记与 SVG，不许自造状态栏，不许复制或改写 shell.css。引入顺序：`tokens.css` → `../../_shared/shell.css` → `styles.css`；末尾先 `<script src="../../_shared/shell.js"></script>` 再 `<script src="app.js"></script>`。
- **styles.css 里绝对不许出现任何 `.mp-*` 选择器或覆盖**（唯一例外是 `.mp-app[data-state="…"] .xxx` 状态选择器）。
- 背景 `var(--bg)`，卡片 `var(--surface)`，层级靠字重 + 字号（标题 600 / 正文 400 / 标签 500）；颜色只写 `var(--*)`，禁止裸 hex / rgb / hsl；阴影只用 `var(--shadow-*)`；无直角（最小 `var(--radius-sm)`，胶囊用 `var(--radius-pill)`）。
- 暖色克制：品牌橙只出现在未读圆点、选中分段、已读按钮、审批图标 wash；大面积保持中性，暖色面积 ≤ 10%。
- 触控目标 ≥ 44×44px；正文 ≥ 13px；`:active` 必须有反馈；不要 hover 才可见的信息。
- **禁止对可能超宽的文本用未标注的 `white-space: nowrap`**；标题若必须单行省略，在该行行尾加注释 `/* od-audit-allow: nowrap */`。所有容器 `max-width: 100%`，页面不得横向滚动；长标题、长摘要自然截断/折行。
- 不用 `<select>`、alert、prompt；无 console 报错。

## 状态覆盖（`data-state` 驱动，演示条用共享 `mp-demo`，四个芯片：正常 / 空态 / 加载 / 失败）
- **正常**：12 条消息 + 分段 + 口径行 + 全部已读按钮。
- **空态**：隐藏口径行与列表，居中图标 + 一句「暂无消息」+ 副文案「收到的通知、审批与系统消息会汇总到这里」+ 主按钮「刷新消息」；分段条保留。
- **加载**：隐藏口径行与列表，显示 4–5 条骨架行（40px 方块 + 两行文本条 + 右侧短条），轻微呼吸动画；`prefers-reduced-motion` 下静态；分段条保留。
- **失败**：「消息加载失败」+「网络异常，请稍后重试」+「重试」按钮；分段条保留。
- **禁用**：未读为 0 时「全部已读」按钮禁用（`--hint` 文字 + 透明 + 不响应）。正常态初始有 4 条未读，点击「全部已读」后即可看到禁用态。

## 交互（app.js 必须全部实现，无 JS 报错）
- 4 个分段可切换，按 `type` 过滤行；切换后口径行更新为当前分类的「共 N 条 · U 条未读」；空分类时列表显示内联的「该分类暂无消息」（示例数据下四类都有数据，此分支仅兜底）。
- 点击任意消息行：若未读 → 立即标为已读（圆点消失、标题置灰），口径行未读数 -1；然后 `leave` 弹 toast「已打开请假审批」，`notice` / `system` 弹 toast「查看：<标题>」。已读行点击只弹 toast。
- 点击「全部已读」：所有行置灰、未读数归 0、按钮禁用、toast「已全部标为已读」（沿用源码文案）。
- 点击返回箭头：toast「返回上一页」。
- 空态「刷新消息」与失败态「重试」：切回正常态并同步演示条芯片的 `aria-pressed`（state 由共享 shell.js 写在 `.mp-app` 上）。
- toast 用页面内元素（底部居中小胶囊），不要 alert/prompt。
