# 添加活动（老师端）

- 源码：`teacher/src/pages/calendar/create.vue`
- 设计系统：`user:nurture-planet-local`，`data-surface="teacher"`
- 外壳：`_shared/shell.css` + `shell.js`
- 方向：把长表单收成三组卡片，选择类字段全部下沉到小程序底部弹层。

## 信息层级

1. 基本信息：活动标题、活动类型（胶囊单选）
2. 时间地点：日期、时间 / 是否全天、地点
3. 发布设置：参与班级、说明、提醒设置
4. 底部固定「发布活动」栏：安全区留白，必填未完成时常驻阻断说明

## 状态覆盖

- 正常：三类字段填好，按钮可用
- 编辑（`?id=`，已发布活动）：字段按详情预填，发布设置的通知开关换成「已发布」提示，主按钮变「保存发布」；保存前弹变更确认层（本次变更清单 + 「通知家长？」开关，日期/时间/地点类变更预置开启），无变更时不弹层、静默保存
- 空：必填未填，按钮禁用 + 按钮上方说明还差什么
- 提交中：按钮 loading，字段不可编辑
- 失败：底部错误条 + 重试，已填内容不丢
- 日期/时间/类型选择：底部 picker 弹层，带取消/确定

## token 映射

- 卡片：`var(--surface)` / `var(--radius-card)` / `var(--shadow-md)`
- 主按钮：`var(--accent-gradient)`；禁用：`var(--border)` + `var(--hint)`
- 字段错误：`var(--danger)` + `var(--danger-wash)`
- 文本：`var(--fg)` / `var(--fg-2)` / `var(--muted)`

## 与现状的差异

- 原生 picker 统一换成底部弹层（与其它表单页一致）
- 必填阻断从「提交后 toast」改为「按钮上方常驻说明」
- 编辑已发布活动：导航标题切「编辑活动」，发布设置的通知开关换成已发布提示，保存前走「通知家长？」变更确认层；无变更时跳过确认、不推送通知

## 遗留

- 时间冲突校验只做了同日重叠的提示，未覆盖跨天/全天规则
- 参与班级多选的候选用示例数据，未接班级接口
- `styles.css` 19.6KB / `app.js` 21.6KB
