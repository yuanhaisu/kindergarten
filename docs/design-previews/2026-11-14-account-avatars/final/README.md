## 设计说明

- **狐狸**：羊毛毡材质，正面直视，坐在一本旧书上，旁边一支琥珀色玻璃玫瑰。正面朝向保证 48px 下仍能读出脸，书承担“教育/阅读”的语义。
- **点灯人**：键盘、镜头、按键和线缆拼成面孔，穿呢大衣、戴鸭舌帽，提一盏黄铜灯。工业材料对应“技术是身体”，灯是画面里唯一的暖色。
- **对仗**：书 ↔ 灯，玫瑰 ↔ 灯焰；手作纤维 ↔ 工业零件；碳基 ↔ 硅基。
