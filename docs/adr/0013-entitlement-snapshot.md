# 0013 — 授权按成交快照，不跟随套餐定义

- Status: Accepted
- Date: 2026-11-06

## Context

套餐目录会改名、调价、增减模块；而园所已经签下的合同不能因为目录被修改而静默改变。同时，计划中的园长助理等新模块要以「新增可售项」的方式进入，不能污染存量合同。

## Decision

成交时把套餐内容冻结成不可变快照：模块清单、在园幼儿数档位、起止日期、金额。运行时授权由快照产生，园所不引用套餐定义。加购与升级一律新开订单、全价购买完整周期，不做按天折算。

## Consequences

- 每次调整套餐，销售拿到的是一份「新版本套餐」，老合同保持原样。
- 不做 proration，账单不会出现按天折算的争议。
- 多个授权各自独立到期，园所整体状态取「最早到期项」用于展示与催缴。

## Alternatives considered

- **园所关联 Plan 并跟随变更**：改一次定价就会改变所有存量客户的权益，在合同上站不住。
- **按剩余天数折算加购**：幼儿园加购频率极低，实现与解释成本远高于收益。
