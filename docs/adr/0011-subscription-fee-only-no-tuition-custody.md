# 0011 — 只向园所收取订阅费，不做学费代收

- Status: Accepted
- Date: 2026-11-06

## Context

两大竞品靠向家长收费活着（智慧树家长会员 30 元/月，掌通家园 50–150 元/学期）；但本项目把家长定义为价值的接受者而非付费方。代收园所学费、伙食费属于资金代收，牵涉支付牌照、二清合规、对账与退款争议，产品设计文档已把「在线支付 / 学费缴纳、园区财务 / ERP」列为范围外。

## Decision

平台方只向园所收取订阅费；家长端永久免费；不代收学费、伙食费等任何园所资金。订单与收款登记只服务于平台方与园所之间的这一笔收费关系。

## Consequences

- 没有 C 端收入兜底，商业模型完全押在园所付费意愿上。
- 支付通道只需服务园所（对公转账为主），不需要分账、结算与资金存管能力。
- 家长端的任何功能都不能被设计成收费入口。

## Alternatives considered

- **向家长收会员费**：与「家长不是付费方」的定位冲突，且会让园所担心平台绕过它与家长建立收费关系。
- **代收学费**：见上方合规成本，属于另一个产品。
