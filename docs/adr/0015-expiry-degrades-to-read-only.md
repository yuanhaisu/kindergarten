# 0015 — 到期降级为「停写保读」，不整站停服

- Status: Accepted
- Date: 2026-11-06

## Context

家长端已经形成每日查看成长记录与相册的习惯。到期直接断服会让这些内容消失，招致家长投诉——而园长最怕的正是家长投诉，这既是续费杠杆，也是用猛了会反噬的地方。

## Decision

订阅或试用到期后先给 15 天宽限期（全功能，界面提示续费）；宽限期结束进入降级状态：溢价功能模块停止新增但保留查看，园务底线继续可用。任何情况下都不整站停服。

## Consequences

- 前后端都需要实现「只读」语义：后端拒绝写接口，前端禁用入口并说明原因。
- 催缴压力小于硬停模式，需要运营侧主动跟进，不能只靠系统。
- 降级状态是可逆的，续费后立即恢复。

## Alternatives considered

- **到期立即全停**：转化快，但会制造差评与退单，且把家长变成压力传导的中介，损害园所对平台的信任。
