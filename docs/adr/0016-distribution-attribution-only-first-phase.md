# 0016 — 分销第一期只做归因与只读佣金台账

- Status: Accepted
- Date: 2026-11-06

## Context

目标阶段是 3–10 所园的精品路线，完整分销形态（分销商账号、多级分佣、提现、结算单）的工程量与收益不匹配。但佣金归因必须从第一张订单就记，否则历史订单无法补算。

## Decision

第一期只在订单上记录分销商归因，按实收回款生成只读佣金台账；分销商不登录系统、无提现。佣金基数取实收金额，计入时点为收款登记确认日，月结，只有到账满 30 天且无退款的部分才可结算；退款自动冲回。

## Consequences

- 佣金完全依赖收款登记的准确性，手工登记错误会直接传导到台账。
- 分销商是平台方维护的一份名单，不是账户主体。
- 第二期若要做分销商自助，需要新增账号体系，但订单侧的归因数据已经就位。

## Alternatives considered

- **一期就做分销商账号与提现**：在 2000 元/年的单价下渠道经济不成立，且会引入资金与提现合规问题。
- **不做归因，等第二期再补**：历史订单无法回溯，等于永久放弃这部分渠道数据。
