三天里，带回来五样东西

你不需要看懂他们的转型。你只需要带回 能变成产品里一张表、一个流程、一段数据 的做法。下面每一项都按「谁做 / 多久一次 / 用什么载体」问。

  1. 一张表 —— 观察记录 / 评估量表 / 一日流程 / 户外风险评估
  2. 一个微信 —— 教学主任或园长，回去还能追问
  3. 五个答案 —— 「如果上系统，最先解决什么」
  4. 十五个做法 —— 每园 3 条，写清谁做、多久一次、用什么
  5. 五个「居然」 —— 居然有 / 居然没有

听完答案再决定深挖哪一组。不用每组都问。

怎么选：强调课程与领域目标 → A 组；强调户外与自然 → B 组；强调家长满意与招生 → C 组；说不清、只讲服务细节 → D 组。D 组每园至少问两题。
