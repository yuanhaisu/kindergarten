## 1. 结论

主靶换人，结论跟着换。**亲小禾和智慧树 / 掌通是两种完全不同的对手**：

| | 智慧树 / 掌通 | 亲小禾 |
|---|---|---|
| 入口 | App | **硬件：AI 智能校徽** |
| 怎么赚钱 | 家长会员 / 广告 / 学期费 | 硬件 + 项目制；家长端**宣称**免费 |
| 渠道 | 品牌 + 地推 | **3 万所学校 + 600 家合作伙伴** `[C]` |
| 强项 | 内容 / 园务 | 无感考勤 / 放学 / 校园安全 |
| 与幼儿园的关系 | 主战场 | **从 K12 下探** |

**所以 v0 那条结论要作废一半**：「我们零广告、不向家长收费」对亲小禾**不构成差异**——它也宣称家长端零费用。真正能打的差异只有三条：

1. **零硬件成本、当天上线。** 亲小禾每生一枚校徽，还要校门感应区、门口音箱 + LED、通讯话机，部署 5–7 个工作日且含施工 `[C]`；我们两个小程序 + 一个后台，园所零采购、零施工。对预算紧的普惠园 / 民办园，这是硬门槛差异。
2. **幼儿园场景比它深。** 它的软件骨架是 K12 逻辑（考勤、放学、轨迹、危险区域），幼教模块是外壳。我们的**成长报告七维雷达、AI 照片点名、接送一次性动态码、任务-积分-成就闭环**，在公开资料里未见它有。
3. **可私有化。** 它的数据在阿里云（自述），我们自建 Go / MySQL / Redis，可部署到园所或区域教育云。对集团园、教育局是加分项。

但必须认清它的护城河：**硬件 + 渠道 + 合规**。它自述已取得等保二级、教育部备案、ICP、公安备案；我们四项全无。这不是产品差距，是**准入差距**。

> **一句话：产品我们不输，甚至更贴幼儿园；我们输在没有硬件入口、没有渠道、没有备案。**

### 2.4 可信度裂缝（可攻击，但别过早下结论）

1. **"家长端零费用" vs 实际收费。** 官网多篇文章强调家长端完全免费；但黑猫投诉有家长称交 **300 元半年费看监控**，开学后看不了，客服失联，平台显示"未匹配成功" `[B]`。
   → 单条投诉不足以定性，但它说明"免费"在执行层有灰区。**访谈园所时直接问：家长实际掏过哪些钱、以什么名目。**
2. **客服能力存疑。** 同一条投诉指向客服失联——对园所是运营风险，可作为对比点。
3. **K12 下探的适配度。** 校徽、轨迹、危险区域都是中小学逻辑。3–6 岁场景里，"无感考勤"的价值远低于"接送交接是否可信、家长是否看得见孩子"。

## 4. 行业背景（不是主靶，但决定叙事）

### 4.1 智慧树 / 掌通：靠家长变现，正在被反噬

- **智慧树**：2025-11 北京日报实测，**2 分钟内 10 条广告**，部分无关闭按钮、用"广告"水印盖住关闭键；客服承认"只有开通会员才能屏蔽"，会员 **30 元/月 / 90 元/6 月**。律师指出涉嫌违反《广告法》第 39 条、《互联网广告管理办法》、《个保法》、《未成年人保护法》第 74 条 `[B]`。历史上 2020-07、2022-10 被工信部通报，2024-05 被北京通信管理局要求整改 `[B]`。
- **掌通家园**：家长端 50–150 元/学期不等，名目为"系统维护费""门禁卡服务费" `[C]`；2024-12 黑猫投诉老人误扣 118 元、客服仅机器人 `[B]`；**武汉江汉区教育局认定某园收费违规并责令退还** `[B]`。
- **对我们的意义**：它们证明了"向家长收费"这条路正在被监管收紧。但**亲小禾走的是另一条路（硬件 + 项目制）**，不要用打智慧树的话术去打亲小禾。

### 4.2 贝聊：轻量免费的死法

曾与智慧树、掌通并称三巨头，母公司 **2025-03 注销**，月狐数据抓到的渗透率仅 **0.032%** `[C]`。教训：**只有"沟通"没有"园务"，园所不愿付费，最后只能靠资本输血。**
→ 我们如果只讲"干净免费"，会重走这条路。必须回答：**谁付钱、为什么付。**

## 5. 合规门槛（当前唯一阻断项）

`[A]` 依据教育部《教育移动互联网应用程序备案管理办法》（教技厅〔2019〕3 号）及各地细则：

- **小程序在范围内**：地方文件明确教育移动应用"含各类教育 APP、微信公众号、小程序、H5"。
- **幼儿园是"使用者备案"主体**：须从已备案应用中选择、经集体决策、在备案平台勾选；**未备案的应用原则上不得进校**。
- **提供者备案前置**：ICP 备案 + 等保定级备案（含测评），再向住所地省级教育部门备案；APP 内须公示备案编号。
- 北京 2024-10 印发实施细则（京教信〔2024〕13 号），2025 年持续执行。

| ICP 备案 | ❌ | ✅ |
| 等保定级/测评 | ❌ | ✅ 等保二级 |
| 教育移动应用备案号 | ❌ | ✅ |

   `server/internal/domain/task.go:15-23,39-52`；`service/point_service.go:161,255`
6. **租户隔离 + 双闸权限**：JWT 携带 `kindergarten_id`，仓储层全链路过滤；Casbin 路径判定 + 路由→权限码 fail-closed 校验，未登记路由启动即拒绝。
   `server/internal/auth/jwt.go:12`；`middleware/casbin.go:11-29`；`middleware/admin_perm.go:204-230`

## 10. 建议动作

### 快速（0–4 周，低成本）
0. **先补洞**：老师端"一键提醒未读家长"路由（§6.4）。亲小禾把"未读电话提醒"当卖点，我们连接口都没接上。
1. **对外话术改靶**：不要再讲"免费无广告"（它也这么讲）。改成：
   > **「不用买硬件、不用等施工，一个下午上线；孩子的成长看得见、接送有据可查。」**
2. **启动合规三件套**：ICP → 等保定级 → 教育移动应用备案；同步补 `PRIVACY.md` / `NOTICE`。这是唯一阻断项。
3. **实机对比**：同一任务（发通知→查已读→家长确认→接送），我们 vs 亲小禾，记步数与耗时。
4. **演示主镜头**：AI 照片点名（全班合影 30 秒分发）+ 接送一次性动态码——这两件事它没有。

### 中期（1–3 月）
5. **补一个低成本短板**：每日食谱。亲小禾有、我们没有，而它对家长是高频可感知项。
6. **老师效率专项**：批量发照片、成长记录模板、一键提醒未读；目标单条记录 ≤ 30 秒。
7. **定价与合同**：按在园人数分档，主打「零硬件投入、家长永久免费」；把"无硬件"从劣势翻译成价格优势。

### 战略（3–12 月）
8. **渠道**：区域代理 + 教育局集采资质（备案是前提）。不跟它拼 3 万校，拼单园交付质量。
9. **私有化作为差异化**：面向集团园、区域教育云，卖"数据在你自己手里"。
10. **不要碰校园安全硬件**（校徽、轨迹、危险区域）——那是 K12 逻辑，跟它打必输。
