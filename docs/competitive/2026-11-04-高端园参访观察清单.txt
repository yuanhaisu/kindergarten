三天里，带回来五样东西
2026.11.04—11.06 · 江浙五园

你不需要看懂他们的转型。你只需要带回能变成一张表、一个流程、一段数据的做法。每一条都按「谁做 / 多久一次 / 用什么载体」问。

要带回：
1. 一张表——观察记录 / 评估量表 / 一日流程 / 户外风险评估
2. 一个微信——教学主任或园长，回去还能追问
3. 五个答案——「如果上系统，最先解决什么」
4. 十五个做法——每园 3 条，写清谁做、多久一次、用什么
5. 五个「居然」——居然有 / 居然没有


━━ 0 · 开场三问（一分钟判断这园强在哪）━━

1. 你们课程体系是自己研发的，还是引进的？引进的哪一家？
2. 户外活动一周几次？有没有固定的外出日？
3. 你们最想让家长记住你们哪一件事？

→ 强调课程与领域目标：走 A 组
→ 强调户外与自然：B 组
→ 强调家长满意与招生：C 组
→ 只讲服务细节：D 组
D 组每园至少问两题。


━━ A · 儿童发展评估（观察→评估→计划）━━
这组最值钱。

1. 观察记录用什么表？多久填一次、谁来填、填完交给谁？（要一张空白表）
2. 写一条观察记录要多久？一周写几条？手写、Word，还是系统里录？
3. 有没有一套固定的发展目标库？EYFS 七大领域，还是《3-6岁儿童学习与发展指南》五大领域？条目固定还是老师自拟？
4. 观察记录最后怎么变成给家长的评估？学期末出报告吗？文字描述，还是等级、打分？
5. 家长看到的是什么形式？纸质报告、家长会、微信群，还是 App？
6. 评估结果会反过来改下周的课程计划吗？谁决定？留痕吗？
7. 如果要上一套系统，这条链路里最该被接管的是哪一步？

这组可以放弃其他一切，这张表不能丢。


━━ B · 户外与森林课程（只问安全与知情同意）━━

1. 走出园区一次，谁是安全第一责任人？出发前要签什么？
2. 家长知情同意怎么做？纸质签字、微信群接龙，还是系统？出园要不要单独签？
3. 有没有风险评估表、天气预案、撤退标准？谁填、谁批？（要一张表）
4. 孩子磕碰受伤怎么记录？怎么通知家长？有没有留痕要求，比如拍照、签字？
5. 师生配比多少？外出怎么点名？点名记录留痕吗？
6. 家长会要求实时看位置或照片吗？你们做不做？为什么？
7. 下雨、雾霾怎么改课？有成文预案吗？


━━ C · 品质呈现、收费与家长沟通 ━━

1. 家长第一次来参观，你带他看哪几个地方、按什么顺序？（这条动线就是品质）
2. 怎么向家长解释「为什么我们比隔壁贵」？有成文话术或物料吗？
3. 收费结构：保教费、伙食费、代收费分别怎么收、怎么公示？伙食费据实结算还是包干？
4. 家长最常问的三个问题是什么？谁负责回答？
5. 日常用什么渠道跟家长沟通？微信群、公众号、系统、家长会，各承担什么？
6. 有没有家长满意度调查？多久一次、什么形式、结果怎么用？
7. 家长投诉怎么处理？有台账吗、谁跟进、多久闭环？
8. 让家长「看见孩子一天」的方式是什么？照片、视频、日报，还是成长档案？谁生产、花多久？
9. 伙食和食谱家长看得到吗？在哪看？


━━ D · 工具与系统（暗线，每园至少两题）━━

1. 现在一共用几套工具在管园？含微信群、Excel、纸质表。
2. 哪件事至今还是纸质或 Excel？为什么没上系统？（最强的需求信号）
3. 每天必须打开的是哪个？谁在用？
4. 老师下班后还在做什么？形式主义，还是额外录入？
5. 用过亲小禾、智慧树、掌通家园、微幼通吗？为什么不用了，或者还在用？
6. 教育局对进园 App 有备案要求吗？来检查过？怎么应对？


━━ E · 临走三件事（每园必做）━━

1. 要一张表。优先级：儿童观察记录表 → 发展评估量表 → 一日流程表 → 户外风险评估表
2. 加一个微信。教学主任或园长。加完发一句「今天学到很多，回去可能还有两个小问题请教您」
3. 问一句话。「如果给你们园上一套管理系统，你最想它先解决哪件事？」

要表的话术：「你们这个观察记录表做得挺细的，能不能给我一张空白的？我回去参考一下格式。」

③ 居然有 / 居然没有：
④ 可下沉性：□ 低成本可抄  □ 要加人力  □ 要加预算
⑤ 照片：__ 张（只拍环境、表格、物料）

可下沉性怎么判断：
· 低成本可抄——改流程、改表格就能做，不增加人手和预算
· 要加人力——需要专人，或额外工时
· 要加预算——需要采购、外包、硬件


━━ G · 三条纪律 ━━

1. 不拍孩子。只拍环境、墙面、表格、物料、脱敏后的系统截图。
2. 问做法，不问评价。「你们这个好不好用」问不出东西；「上一次是什么时候做的、做了哪几步、花了多久」才问得出来。
3. 要表单，不要数据。表格模板、制度目录、量表结构可以要；具体孩子的数据、收费明细、教师工资不要开口。
