# 官网法务文本自查（2026-11-09）

范围：`website/pages/privacy.vue`、`website/pages/terms.vue`，对照 `server/internal/domain/` 与 `server/internal/service/` 的实际行为。本文是产品/合规工程视角的自查，**不是法律意见**。

## 结论

原文本最大的问题不是措辞，而是**披露范围明显小于实际处理范围**：

1. 幼儿的**身份证号、住址、健康备注**，接送授权人的**身份证号**，教师的**教师资格证编号**，账号的**昵称/头像/性别**，全部未披露。
2. **晨检体温与症状**、**人脸照片送腾讯云**、**操作日志含明文手机号/姓名**，未披露。
3. 隐私政策写了**短信**这个第三方，但代码里**没有接入任何短信服务商**（`SendSMS` 只写 Redis 并返回成功）。
4. 没有说明**园所与平台的角色分工**（园所是幼儿信息的处理者，平台受托处理）。
5. 「保存期限」笼统；实际存在 **90 天只读 / 180 天相册清理 / 72 小时导出临时文件** 三档明确期限。
6. **没有同意记录**：登录页的勾选框只在客户端，未落库；协议名还是纯文本，不是链接。

## 建议律师重点看

- 园所/平台的角色划分，以及与园所签署的**委托处理协议**是否覆盖幼儿信息。
- 敏感个人信息的必要性说明与**单独同意**机制（身份证号、健康、儿童、人脸）。
- 保存期限承诺与实际清理能力是否匹配（尤其 OSS 与人脸库）。
- 服务条款的**责任上限**、SLA、与订阅合同的一致性。
- 若未来接入百度统计，网站需要单独的 Cookie/统计说明。
