## 前置条件（贯穿所有模块）

所有测试用例都依赖以下前置条件，除非用例描述中特别说明：

1. **老师已登录**: 微信小程序 `wx.login()` → code2session 成功，持有有效 JWT token。**注意：老师端仅支持微信登录，无密码登录通道，API 测试需通过微信开发者工具或真实小程序获取 token。**
2. **老师已绑定班级**: 老师在 `class_teachers` 表中有 `status=1` 的有效关联
3. **园所已初始化**: 当前园所已完成基础数据初始化（年级、班级、学生已录入）
4. **网络正常**: 微信小程序网络状态正常，可正常访问后端 API
5. **Token 在有效期内**: access token 未过期（15 min），refresh token 未过期（7 d）

### 测试限制（2026-06-15 P0 首轮执行发现）

| 限制项 | 说明 | 影响用例 |
|--------|------|----------|
| 老师端仅微信登录 | 无密码登录，API 测试无法直接获取 teacher token | 所有需要老师 Token 的 API 测试 |
| 管理端仅密码登录 | 手机号+密码，可 curl 直接测试 | — |
| RBAC 严格隔离 | Admin token → Teacher API 返回 403，反之亦然 | GLB-005 ~ 008 |
| 管理端不可创建成长记录 | Admin API 无 `POST /growth/logs` 端点，仅可列表/审核 | 跨端数据流测试 |
| Nuxt SPA 路由 | 部分页面直接 URL 访问返回 404，需通过侧边栏导航 | Admin E2E |
