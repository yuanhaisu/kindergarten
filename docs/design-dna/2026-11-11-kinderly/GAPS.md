## 采集结果（2026-11-11 第二轮）

已完成：

- **A1** ✅ 破坏性确认是独立路由 `/settings/delete`，不是弹窗；主按钮 `#A8323A`
- **A2** ✅ 底部抽屉：上圆角 24px、`14px 20px 24px`、行 84px、Cancel 胶囊 14.5px、遮罩 `.55`
- **A3** ❌ 未观察到 toast：保存设置、刷新故事、切换语言都静默生效
- **A4** ✅ 校验靠禁用 CTA（`disabled` + `opacity .6`），无行内错误
- **A5** ✅ 原生 `<select>`，无自定义 picker
- **A6** ✅ 产品没有 switch 组件，两步验证用整行按钮
- **C1** ✅ 390×844 截了 Today / Kin / Settings / Invite
- **C2** ✅ 不支持深色（模拟后 body 仍为浅色）
- **E2** ✅ 破坏性色 `#A8323A`；E1 success 仍未观察到
- **G1** ✅ 参考只有英/法界面，没有中文排版证据——中文衬线是自定决策
- **Today 入口** ✅ 周切换（未来周禁用 .35）、星期切换、`i` 行内 tooltip、天气三选一（未点击，会写数据）、check-in 的 Send 与「That's all for today」、底栏 5 项
- **Today 卡片双入口** ✅ Read / Picks / Recipes 每张卡都是「主区域 + 底部文字链」两个独立链接，目标相同；底部链高仅 18px，低于 44px 触控建议
- **B2 空态（部分）** ✅ 按天无打卡：「Nothing was shared about Monday…」，白卡 20px/18px 内边距
- **H1/H5（部分）** ✅ Recipes：Saved/List 胶囊 tab、48px 搜索胶囊、28px 筛选胶囊（选中态 sage 20% + 1px 描边）、2 列卡片网格
- **筛选选中态** ✅ Learn：年龄用 sage 底，分类用松绿实底 + 骨白字；两套并存
- **集合页** ✅ Lunchbox ideas / After-school snacks：路由不变（客户端状态）、返回是按钮、筛选按集合定制且全部带 1px 描边、卡片与主列表同规格、每集合 20 张
- **详情页** ✅ Oven chicken tenders：客户端状态、无卡片容器、H2 24/20 两级、步骤序号圆、主按钮白字、保存 48 圆形描边
- **Picks 详情** ✅ 同一模板可带 `?item=&back=` 参数，也可纯客户端状态；元信息行动态（Brand 可选）

仍未完成：

- **B1–B4** 加载/空/错误/成功态（需弱网或空数据账号）
- **D1–D3** 组件过渡与 reduced motion
- **F1–F3** 全量图标/插画清单
- **H1–H5** 分段控件、图表、徽标、列表与输入变体（部分已在页面截图中，未逐项量）

证据：`evidence/gaps/`（bottom-sheet、destructive-confirm、mobile-*、dark-attempt）

## 采集总览（2026-11-11 完成）

已覆盖的页面/状态：

- **Today**：默认、按天切换、未来周禁用、`i` tooltip、按天无打卡空态、筛选后的内容
- **Children**：列表、添加孩子表单、空提交禁用态
- **Stories**：列表、详情、新建、`···` 底部抽屉
- **Settings**：首页、个人、邮箱、密码、两步验证、邀请、家庭、日历、导出、删除确认页
- **Learn**：列表、筛选（两套选中态）、文章页
- **Recipes**：主列表、Lunchbox / After-school 集合、商品详情
- **Picks**：列表（马赛克分类）、分类页、两个商品详情
- **Tools**：呼吸引导
- **登录/onboarding**：登录页、添加孩子页

仍未覆盖（不阻塞规则提炼）：

- Learn 的 Saved 空态、Stories 无故事空态（需要空数据账号）
- 组件过渡时长、页面转场、reduced motion（P2）
- 全站图标/插画全量清单（P2）
- 深色模式（已确认不支持）
- 中文排版（参考产品无中文界面，需自定）
