# 膳食管理切换 Runbook（目标产品 → 本项目）

> 适用对象：园所管理员、保健医、后勤主任、园长
> 目标：让工作人员用同一套词、同一套步骤完成每周带量食谱，并在可控范围内停用目标产品
> 数据基线：2026-11-03 已导入目标产品 151 条周食谱 / 22,346 行明细 / 807 份菜谱 / 1,790 种食物，导入错误 0、缺失食物 0

## 2. 角色与权限

角色管理页：`/roles`（需要 `admin:role`，园所管理员默认具备）。权限保存后对该角色名下管理员即时生效，并写入操作日志。

| 角色 | 建议权限 | 使用场景 |
| --- | --- | --- |
| 保健医 | `diet:view` + `diet:manage` + `diet:export` | 编制周食谱、维护食物/菜谱、导出营养分析 |
| 后勤主任 | `diet:view` + `diet:export` | 查看食谱、导出营养分析；采购暂用现有 Excel 模板 |
| 行政园长 | `diet:view` | 查看食谱与营养分析 |
| 园所管理员 | `*`（现状） | 授权/回收、账号管理、异常处理 |

当前事实：保健医、后勤主任、行政园长三个角色都还没有 diet 权限，且角色下没有账号；切换前必须先建账号并赋权。

### 临时授权（财务/班主任临时代管）

1. 园所管理员进入 `/roles`，找到该人员现有角色。
2. 勾选 `diet:view` + `diet:manage`，保存；**不要**改角色名称。
3. 临时接手结束当天，取消这两项权限并保存。
4. 在操作日志核对变更人/时间；若该角色下有多人，优先新建「膳食协管（临时）」角色再切换账号，避免影响同角色其他人。

> 为什么这样做：当前一个管理员只有一个角色，直接改角色权限最简单且保留其原有权限；代价是同角色其他人也会获得权限。角色人数多时改用临时角色。

## 3. 切换时间表

| 时间 | 动作 | 负责人 | 完成标志 |
| --- | --- | --- | --- |
| T-1 周 | 建账号、赋权、数据抽查、培训、速查卡 | 园所管理员 + 保健医 | 三个角色能登录并看到「膳食管理」菜单 |
| 第 1 周（试点） | 保健医在新系统做下一周食谱；目标产品照常作为主系统 | 保健医 | 新系统食谱保存成功，与目标产品并排核对无差异 |
| 第 2–3 周（并行） | 新系统为主，目标产品只读；后勤用新系统导出营养分析 | 保健医 + 后勤 | 连续两周按新系统排周，问题清单每日更新 |
| 第 4 周 | 成功评审；停目标产品，保留 1 个月只读导出 | 园所管理员 + 园长 | 评审签字，目标产品停用 |

## 4. 切换前数据验收

抽查 3 周（保健医签字）：

1. 当前学年：第九周（2026-10-26）、第八周（2026-10-19）、第七周（2026-10-12）。
2. 上一学年：第二十二周（2026-07-27）。

每周核对：

- 菜名数量与顺序；
- 每种食物的名称与一人均量克数；
- 餐次（早餐/早点/午餐/午点/晚餐）与日期；
- 营养分析页能打开，能量/蛋白质/钙等数值可解释（食物库口径可能不同，允许数值差异，但不得缺行）。

已知导入差异：149 行目标明细因日期落在计划周之外被跳过（占 0.66%），验收时以“菜名与克数不缺行”为准；若某周有缺行，记录到问题清单。

## 5. 成功标准（可观测）

连续 2 周满足以下全部条件，才算“工作人员已友好切换”：

- 保健医独立完成下一周食谱并保存成功，无需开发/管理员代操作；
- 后勤能从新系统导出营养分析（Excel）；
- 园长能查看食谱与营养分析；
- 3 周抽查数据由保健医签字；
- 无因数据错乱/功能缺失回退目标产品；
- 问题清单无未解决的 P1（阻断排周）问题。

辅助观察：首周完成时间不超过目标产品的 1.5 倍，第 3 周回落到 1.0 倍左右。

## 6. 回退方案

触发条件（任一）：

- 连续 2 次排周失败（保存报错/数据丢失）；
- 发现导入数据大范围错乱（同一周菜名/克数对不上）；
- 保健医连续 2 周无法在合理时间内完成排周。

回退动作：

1. 目标产品恢复为主系统，工作人员照常排周；
2. 从新系统导出问题周的数据作为参考，不删除已导入数据；
3. 记录触发原因、影响范围、修复项；修复并复验后再启动下一轮试点。

目标产品至少保留 1 个月只读，作为回退兜底。

## 7. 采购清单的过渡方案

本系统暂未实现采购清单（按餐次/一周汇总、斤/公斤、Excel）。切换期：

- 后勤按「周食谱一人均量 × 在册人数」在现有 Excel 模板计算采购量；
- 或由供应商直接按周食谱下单；
- 连续 2 周记录实际耗时；若采购清单是每周高频必需，列入下一批开发，不长期依赖手工。

## 8. 培训与物料

1 页速查卡（按目标产品的步骤顺序）：

1. 基本参数设置 → 选中集体对象 → 制定食谱；
2. 选自定义/模板/复制历史；
3. 编辑器：选日期与餐次 → 添加菜名 → 添加食物与克数 → 保存；
4. 菜谱库：同名菜保存为菜谱，下次可联想；
5. 资源库：新增食物时选择二级叶子分类；
6. 营养分析：查看 7 组表 → 打印/导出 Excel。

30 分钟实操：

- 0–5 分钟：登录与菜单；
- 5–15 分钟：用「全体幼儿」建下一周食谱，录入 1 天 3 餐；
- 15–25 分钟：保存菜谱、改克数、导出营养分析；
- 25–30 分钟：问题答疑与回退说明。

并排截图：基本参数设置、制定食谱向导、编辑器、营养分析各一张（目标产品 vs 本项目）。

## 9. 支持与反馈

- 问题清单：记录日期、操作人、页面、现象、严重级别（P1 阻断排周 / P2 影响效率 / P3 建议）。
- 试点期每日 10 分钟站会；并行期每周五评审。
- 负责人：园所管理员（权限/账号）、保健医（业务验收）、后勤主任（采购过渡）。
