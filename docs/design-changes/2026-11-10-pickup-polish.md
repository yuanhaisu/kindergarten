## 问题

当前接送页在「在园中 / 已接走」时，状态卡和「今日轨迹」重复展示同一组时间与接送人：状态卡说“07:52 · 妈妈 送入”，下面的轨迹又说一遍；接了孩子后轨迹仍然占一整块，完成态不够干净。

## 目标 / 非目标

- 目标：把「今日轨迹」收进状态卡，做成两步进度轨（送入 → 接走），状态卡副文案只描述状态，不再重复时间/接送人；完成态只留完成收口。
- 非目标：不改接口、不改历史记录分组、不改二维码核验逻辑。

## 状态覆盖

- `pre` 未入园：状态卡显示「截至 HH:mm 未入园」，不显示进度轨。
- `in` 在园中：进度轨「送入」完成（时间 + 接送人），「接走」等待中。
- `picked` 已接走：两步都完成，连线变成功色；二维码入口隐藏，显示「今日接送已完成」。
- `empty / loading / error` 保持现状。

## 验收标准

- 状态卡副文案只出现状态描述，不再重复时间/接送人。
- 进度轨在 `in` / `picked` 可见，`pre` 不可见；两步的时间/接送人与当天记录一致。
- `picked` 时不再出现「今日轨迹」块，二维码 CTA 不出现。
- 390px 视口无横向溢出，`od-check` 无 console error。
