## 状态说明

- `pending`：未开始
- `in_progress`：执行中
- `blocked`：被依赖或问题阻塞
- `done`：已完成

## 恢复执行规则

1. 从上表找到第一个 `in_progress`、`blocked` 或 `pending` 的模块。
2. 若状态为 `blocked`，先处理备注中的阻塞项；若无法处理，继续停在该模块并补充备注。
3. 执行模块时只加载对应 API 文件，避免一次性加载全量接口文档。
4. 完成模块后，把状态改为 `done`，填写更新时间和关键验收备注。
5. 开始下一个模块时，把状态改为 `in_progress`。
