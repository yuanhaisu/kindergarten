# 养成星球 · 设计思路

> 记录 2026-11 这一轮品牌视觉的来龙去脉：面向谁、为什么这样定、哪些路被否掉、还剩什么没决。
> 术语以 `GLOSSARY.md` 的「品牌」一节为准。

## 一、产品与人群

**产品**：面向民办幼儿园的家园共育与园务管理平台。三端——老师端（小程序）、家长端（小程序）、管理端（Web）。

**谁付钱、谁用、谁受益**：

| 角色 | 关系 | 对品牌的要求 |
|---|---|---|
| 园长 / 管理团队 | 付费与续费决策人 | 专业、可信、不像玩具 |
| 老师 | 日常使用者 | 快、不出错 |
| 家长 | 价值的接受者，不是付费方 | 温暖、放心 |
| 幼儿 | 服务对象，不直接读标识 | 所有内容围绕他们 |

这个结构决定了标识的**双重任务**：对园所是专业凭证，对家长是情感入口。二者不能只满足一个。

**产品定位（反面定义）**：不是幼教内容 / 玩具品牌，是管理平台。这条来自市场研究——幼教内容层的视觉语言（高饱和、吉祥物、卡通圆体、场景插画）一旦借进标识，品牌会被归到错误的那一层。

## 二、品牌气质：两次否定逼出来的一句话

- **第一版**（小王子 / 星辰之旅）：被否为「孤独」。判据是人群——面对的是老师与家长，不是读者。
- **第二版**（童趣、孩子、大窗）：被否为「太幼稚、太像小王子、构图太满、不像幼教产品」。

两次否定后不再凭直觉，转为市场研究：60 个幼教相关 logo（四层）+ 45 个「星球 / 养成 / 成长」语义样本。

**研究结论**：

1. 幼教品类的默认视觉是「蓝绿 + 圆角 + 横排黑体 + 吉祥物」，直接竞品层高度同质化。
2. 国际同类（L4）审美最成熟但温度最低；园所品牌（L2）信任最强但最陈旧。
3. **空位是「国际的克制 + 中国的温度」**，不是「更可爱」。
4. 「星球」最强的品牌不画星球（知识星球、纸条星球、圆桌星球）。
5. 「养成」几乎等于角色 / 吉祥物——用角色做主标，会被归入内容层。
6. 「成长」的默认符号是嫩芽，已是红海。
7. **元素越多，越像内容 / 玩具，越不像管理平台。**

于是得到一句话：**专业可信、温暖亲切、克制精致；童趣只做一个小细节，不做主调。**

## 三、三条贯穿始终的设计原则

**1. 标识负责信任，角色负责情感。**
两件事分级承载。标识不承担「好玩」，角色不承担「可信」。这也是为什么火箭、星球、星星可以活在插画里，但不进标识。

**2. 图形不画星球，名字承担星球。**
「养成星球」四个字已经把名字说完了，图形不必重复。可住人的星球这个读法保留在形里（圆、完整、有边），但不做行星环、不做星空。

**3. 颜色只做两件事。**
深墨负责结构，琥珀负责「那一个东西」。这条规矩在标识里是「琥珀只做一点」；在插画里是「琥珀永远只给角色」。

## 四、标识：A1 定稿，P2 作为备选

> **2026-11-04 决定**：在生成并对比了 15 个不同类型的替代方向（纯字标 3 / 单字标 3 / 抽象符号 3 / 徽章 3 / 角色 3）之后，最终选回 **A1（细弧 + 点）**。
> 这条决定的分量在于：它不是「没得选所以用 A1」，而是「看过全部替代之后仍然选它」。
> 已知代价：与知识星球的这一族相似（见下）。这个风险是已知的、被接受的，且上线前仍以第 9/41 类商标检索为放行条件。

### A1（细弧 + 点）

270° 圆头弧 + 缺口里一颗琥珀点。优点：留白多、克制、像记号。

**发现的问题**：与知识星球（单色开口环 + 环上一点）同属「粗开口环 + 缺口处一点」这一族。差异是真实的（缺口方向相反、双色 vs 单色、点在缺口内 vs 点在环上），但缩到 32px 两者都读成「C + 点」。

### 试过的所有替代（全部不如 A1）

| 方向 | 结果 |
|---|---|
| 孩子形象 8 版（头肩 / 双圆 / 巢中坐 / 举手 / 抱住 / 探头 / 张臂 / 扒着） | 小尺寸全退化；最好的也只活在 81px 以上 |
| 点内收 / 放大 | 焦点变弱（琥珀 1.52%→1.03%），相似度没真正降低 |
| 弧缩短到 200° | 点距两端 60→90，构图散 |
| 非环三版（积木 / 拱 / 字标） | 无一胜出；「成长」一画出来就掉进图表 |
| 笔锋（粗细变化） | 只在 ≥144 可见，32–81 完全看不出 |
| 椭圆弧 | 等宽笔画在椭圆上重量不均，读作「被压扁的圆」 |
| 螺旋 | 与笔锋同病：小尺寸看不见 |

**关键洞察**：A1 好看的原因，正是它像知识星球的原因——「点落在弧的半径上、被两端夹住」这个关系。拆开它构图就散，保留它又回到相似。**这不是设计问题，是二选一。**

### P2（世界 + 孩子）— 备选，不采用

> 放弃原因：它是为「绕开知识星球」而生的，在安全性上确实做到了；但 15 个方向逐一比过之后，A1 在气质、留白和小尺寸上都更好。P2 保留为**如果商标检索判定 A1 不可用时的第一备选**，文件与规范都在 `assets/logo-v2/p2/`。

放弃「线」，改「面」：实心圆盘 + 边缘一处凹陷 + 琥珀球坐在凹陷里。

- **构造上与知识星球没有任何共同点**（实心盘 vs 开口环；凹陷 vs 缺口；球嵌在凹陷里 vs 点在环上）。
- **双读**：一颗能住人的星球；也是一个无脸的小人（琥珀球是头，深色盘是身）。
- **尺寸稳定**：16px 时座线消失，自动并成剪影。
- 代价：从「轻」变「重」，琥珀从 1.52% 涨到约 3.2%，配色规矩要重立。

### 字标：字面率校正（2026-11-04）

Noto Sans SC 的四个字墨面积并不相等——「星」0.797，其余三个 0.898–0.908，**小 12%**。同一字号排下来，「星」明显偏小、两侧偏空。

校正规则：
1. 每个字等比缩放到四字中最大的墨面积（只放大不缩小）；实际缩放 养 ×1.006 / 成 ×1.000 / **星 ×1.067** / 球 ×1.002；
2. 缩放以基线为准；
3. 排版不用字体自带的 em 框前进宽度，改用**墨迹边缘 + 固定墨距**（150 字体单位），否则墨迹小的字会显得两侧更空。

已知副作用：等比放大让「星」的笔画也粗了 6.7%，比其余三字略重。要同时「等大 + 等粗」必须单独调细其笔画——那是改字形，不是调参数，本轮没做。

**字体的授权前提**：系统里能合法用于标识的中文字体只有 Noto 系列（SIL OFL）。微软雅黑 / 等线 / 黑体（微软专有）、华文系列（随系统）、方正系列（需商用授权）都不能直接用于标识。

### 术语（已写入 GLOSSARY.md）

**世界**（不是「星球」「圆盘」）/ **开口**（不是「咬口」）/ **孩子**（不是「种子」「卫星」）。
「壳 / 缺口 / 籽」只作语义类比，不作术语。

## 五、品牌角色：芽

**为什么标识之外还需要一个角色**：标识不能好玩，但产品需要温度。角色承担「养成」这个动词。

**形态**：水滴形身体（是种子，不是球）+ 双叶小芽 + 一张脸。

- 标识里的孩子**不能有五官**——有了就变成吉祥物，把品牌拉进内容层。
- 插画里的芽**必须有脸**——它靠表情传情绪。
- 两层不打架，因为用途不同。

**三个场景（等待 / 出发 / 抵达）**：分别对应产品的空状态、加载 / 进行中、完成 / 里程碑。三张共用同一条地平线，放进同一个容器高度齐平。

**语言纪律**：实心块、双色、不用线稿（线稿缩到 120px 会成一团线噪）。

## 六、做过的主要判断（速查）

| 判断 | 理由 |
|---|---|
| 不用吉祥物做标识 | 会把品牌归入内容 / 玩具层 |
| 不画行星环、星空 | 研究里「星球」品类最重复的符号 |
| 不画嫩芽 | 「成长」的默认符号，红海 |
| 不用房子 | 「嫩芽 + 房子 + 小孩」是明确禁区 |
| 不留奶油缝（最终版靠遮挡） | 缝会让孩子变成独立天体，破坏「被护住」 |
| 16px 单独切 | 1px 的缝会糊成灰晕，色差本身够分开 |
| 单色版用合并剪影 | 真孔在同色下会剩一条细缝，像裂痕 |

## 七、还没决的事

1. **商标检索未做，且现在是 A1 的放行条件**。A1 与知识星球同族，第 9 / 41 类的专业检索必须在接入三端之前做完。若检索判定不可用，第一备选是 P2。
2. **A1 与知识星球的相似是已知风险**。接受它，是因为 15 个替代方向没有一个在设计上站得住；不接受它，就等于用更差的标识去换一个尚未证实的问题。
3. **三端未接入**：teacher / parent 的 logo、shared-ui、admin 侧栏与 favicon、微信 app icon（需人工上传）。
4. **角色系统只做了 3 个场景**，5 个表情状态、4 档成长形态、使用规范还没做。
5. **中英双语锁图**已出，但英文是否需要定制字形（而非直接用 Noto Sans）待定。
