# 养成星球 · Logo 哲学（A1）

## 一句话

**一道开放的弧，托住一颗种子。**

## 为什么是弧

- 弧是平台 / 家 / 手：围住，但不封闭；缺口是留给成长的空间。
- 它不需要是字母 C、星球环或笑脸；它首先是一道有缺口的保护。
- 琥珀点是孩子、种子、那一点暖光；它是整枚标识唯一的暖色。

## 为什么选 A1，而不是 A2

- A2 的双弧更闭合、更像「抱住」；A1 的缺口更开放，和「养成」是留白、不是围住更一致。
- A1 在 16px 下更简；名字交给字标，图形只负责「弧 + 点」。

## 颜色

- **深墨 `#1B2A41`**：专业、可信、像一本放得住的书。
- **琥珀 `#E8A23A`**：温度、孩子、种子；只出现在那一点。
- **奶油 `#F7F3E8`**：纸感留白，不是纯白的冷。

## 字体

- **Noto Sans SC Bold**（SIL OFL），轮廓化；圆润人文无衬线，不卡通。
- 正式商用可在此基础上做定制中文字标，获得独占字形。

## 它不做什么

不做吉祥物、写实星球 / 行星环、嫩芽 + 房子 + 小孩、3D、渐变、超过 3 色、卡通圆体、盾徽。

## 和市场研究的关系

- 借 L1 / L2 的「信任」，借 L4 的「克制」，避开 L3 的「角色化」。
- 这是「品类求同」的方向：先让家长一眼认出这是幼教管理产品，再用琥珀点和一个缺口留下记忆点。
