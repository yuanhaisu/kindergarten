# growth-visibility Specification

## Purpose

定义家长端成长记录的可见性规则：任何一条成长记录能否被某位家长看到，只由「记录 → 孩子 → 家长」的关联链决定，且在家长端的所有入口保持不变。这是产品「儿童照片仅对授权家长可见」承诺的规格化表达。

## Requirements

### Requirement: 可见性由记录与孩子的关联链决定
家长端任何入口呈现一条成长记录或其媒体，MUST 同时满足：该记录属于家长某位孩子的班级（`target_type=1` 全班记录），或该记录明确发给了家长的某位孩子（`target_type=2` 个体记录）。两个条件都不满足的记录，MUST 在任何入口上不可见、不可访问。

#### Scenario: 全班记录对自己孩子所在班级可见
- **WHEN** 家长查看一条属于其孩子所在班级的全班记录
- **THEN** 该记录在所有家长端入口可见
- 参考: TC-NEW-VIS-0001

#### Scenario: 发给其他孩子的个体记录对家长不可见
- **WHEN** 存在一条按指定学生发布的个体记录，其目标学生不在该家长的孩子之中
- **THEN** 该记录与记录内媒体在所有家长端入口均不可见，直接访问其详情 ID 被拒绝
- 参考: TC-NEW-VIS-0002

#### Scenario: 非本班记录与媒体不可见
- **WHEN** 家长浏览相册，园所内存在其他班级的全班记录及其照片
- **THEN** 这些照片不出现，相册只包含其孩子所在班级的内容
- 参考: TC-NEW-VIS-0003

### Requirement: 首页动态遵守同一可见性规则
家长端首页返回的成长动态 MUST 遵守与成长时光详情完全一致的可见性规则——只包含家长孩子所在班级的全班记录、以及指向家长孩子的个体记录。未指定当前孩子时，MUST 按家长全部孩子的关联链聚合。

#### Scenario: 首页动态不出现其他孩子被记录的个体记录
- **WHEN** 老师向某位指定学生发布一条个体记录，该学生不是当前家长的孩子
- **THEN** 该记录的正文不出现于该家长首页的动态区块
- 参考: TC-NEW-VIS-0004

#### Scenario: 首页收到发给当前孩子的个体记录
- **WHEN** 老师向家长的孩子发布一条个体记录
- **THEN** 该记录出现在家长首页动态，不因它是指定学生记录而被过滤掉
- 参考: TC-NEW-VIS-0005

### Requirement: 成长相册只含可见记录的媒体
家长端相册 MUST 只返回其孩子所在班级的全班记录媒体、以及指向其孩子的个体记录媒体；MUST NOT 返回园所内其他班级的媒体。

#### Scenario: 相册按月份过滤时仍遵守可见性
- **WHEN** 家长按某年月查看相册
- **THEN** 结果集只含可见性允许范围内的记录媒体，其他班级的全班记录媒体不出现
- 参考: TC-NEW-VIS-0006

#### Scenario: 相册不包含其他孩子的个体记录媒体
- **WHEN** 一条个体记录指向的孩子不在该家长孩子之中，且该记录附有照片
- **THEN** 这些照片不出现在该家长相册
- 参考: TC-NEW-VIS-0007

### Requirement: 成长报告只能查看自己孩子的
家长查看成长报告时，系统 MUST 校验所请求的孩子属于该家长、且属于同一园所；不满足时 MUST 拒绝访问。请求未指定孩子时，MUST 回退到家长当前选中的孩子。

#### Scenario: 指定他人孩子 ID 被拒绝
- **WHEN** 家长请求一份属于其他孩子的成长报告
- **THEN** 系统返回无权限或不存在，不返回任何报告内容
- 参考: TC-NEW-VIS-0008

#### Scenario: 跨园所孩子 ID 被拒绝
- **WHEN** 家长请求一份属于其他幼儿园孩子的成长报告
- **THEN** 系统返回无权限或不存在，不返回任何报告内容
- 参考: TC-NEW-VIS-0009

#### Scenario: 未指定孩子时回退当前选中孩子
- **WHEN** 家长未携带孩子参数请求报告
- **THEN** 系统返回当前选中孩子的报告
- 参考: TC-NEW-VIS-0010

### Requirement: 报告仅呈现已生成完成的版本
成长报告必须在状态为「已生成」时才对家长可见。生成中或生成失败的报告 MUST NOT 返回给家长。

#### Scenario: 生成中的报告不可见
- **WHEN** 家长孩子的最新报告仍处于生成中或生成失败状态
- **THEN** 系统不返回该报告，也不以半成品内容呈现
- 参考: TC-NEW-VIS-0011

#### Scenario: 已生成报告正常返回
- **WHEN** 存在一份已生成完成的报告
- **THEN** 系统返回该报告及其能力维度数据
- 参考: TC-NEW-VIS-0012
