# Spec Delta

## MODIFIED Requirements

### Requirement: DRIs 目标值按班级人数加权

系统 SHALL 以 DRIs2000 的 3/4/5/6 岁四档为源，按该周食谱所属集体对象的就餐班级在读学生人数加权计算 11 项目标值（能量、蛋白质、脂肪、碳水化合物、维生素A、B1、B2、C、钙、锌、铁）。小班→3 岁、中班→4 岁、大班→5 岁、6 岁档默认 0；能量 MUST 取男值列。脂肪 MUST 由能量×30%÷9 推出，碳水 MUST 由剩余能量推出，千焦 MUST 由千卡×4.186 推出。对象内没有可用学生数据时 MUST 回退到 26.7%/32.6%/40.8%/0。视黄醇与胡萝卜素 MUST NOT 进入目标表。

#### Scenario: 按年龄段权重算出目标值

- **WHEN** 3/4/5/6 岁权重为 26.7%/32.6%/40.8%/0
- **THEN** 能量目标为 1485.95 千卡、蛋白质 50.76 克、钙 747.4 毫克；脂肪 49.53 克、碳水 209.29 克、千焦 6220.19
- 参考: TC-NEW-DIE-0048

#### Scenario: 只统计集体对象内的班级

- **WHEN** 集体对象只勾选小班，本园其他中班、大班学生不计入
- **THEN** 3 岁档权重为 100%，其余档为 0，目标值只按 3 岁档计算
- 参考: TC-NEW-DIE-0076
