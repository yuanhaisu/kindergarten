# Proposal

## Why

产品已就绪、商业化未开始：仓库里没有任何与套餐、订单、收款、授权、分销相关的表、接口或页面；园所连第二家都建不出来（`/system/init` 是全局一次性的），`Kindergarten` 也没有套餐、到期或状态语义。而 `GLOSSARY.md` 已经把园所定义为付费客户、园长定义为付费决策人。

当前最现实的缺口不是「收不到钱」，而是「卖出去的功能关不住、到期无人知道」。因此本次先建立一条可运行的商品与授权闭环，支付通道后置。

## What Changes

- **平台方身份与运营控制台**：平台方使用独立账号表与独立登录（`scope=platform`），与园所后台硬隔离；提供园所列表、开通园所（同时创建园长账号）、园所状态管理。
- **套餐目录**：套餐 = 名称 / 档位 / 年费 / 周期 + 一组功能模块；功能模块分 `base` 与 `premium` 两类，模块清单由服务端常量维护，不建表。
- **订单与收款登记**：成交时冻结套餐快照（模块清单、在园幼儿数档位、起止日期、金额），不引用套餐定义；一张订单可登记多笔收款，退款以负数收款登记表达；发票只记录开票信息，不跟踪开具状态。
- **园所级功能授权**：授权以「功能模块」为最小单位、按模块独立到期；运行时由中间件校验，未授权的 premium 模块拒绝访问；管理端、老师端、家长端按授权隐藏入口。
- **到期降级**：到期先给 15 天宽限期，宽限后 premium 模块「停写保读」，base 模块继续可用；任何情况下不整站停服。
- **试用**：平台方开通园所时发放 30 天全功能授权（可人工延长至 60 天），试用期数据永久保留。
- **分销归因与只读佣金台账**：订单可挂一个分销商；佣金按实收回款、以收款确认日计入，月结，到账满 30 天且无退款才可结算，退款自动冲回。分销商不登录系统。
- **契约变更声明**：本次新增 `backend/api/api-platform/`（平台方端点），并在 `api-admin/` 与 `api-common.md` 中新增「读取本园授权」端点。**不修改任何既有端点的请求 / 响应形状**。

## Capabilities

### New Capabilities

- `platform-console`: 平台方独立身份、跨园园所列表、开通园所与园长账号、园所状态。
- `subscription-catalog`: 套餐目录与功能模块目录，套餐快照语义。
- `billing-orders`: 订单成交快照、多笔收款登记、退款登记、发票信息。
- `feature-entitlement`: 园所级模块授权发放与到期、运行时校验、到期降级为「停写保读」。
- `distribution-commission`: 分销商归因、按实收回款计佣、只读佣金台账。

### Modified Capabilities

无。既有 `admin-rbac` 的权限码语义不变——本次新增的是与之正交的「授权」维度（见 ADR-0012）。

## Impact

- **Go 后端**：`server/internal/domain`（平台账号、分销商、套餐、订单、收款、授权、佣金台账）、`repository`、`service`、`handler/http`、`middleware`（模块授权校验与只读降级）、`app/router.go`、`app/provider.go`、`app/wire.go` + `wire_gen.go`、`configs/rbac_policy.csv`。
- **契约**：新增 `backend/api/api-platform/`；`backend/api/api-admin/` 与 `api-common.md` 各新增授权读取端点；`backend/api/api-admin/README.md` 索引同步。
- **admin（Nuxt）**：新增平台控制台路由树（园所 / 套餐 / 订单 / 收款 / 分销商 / 佣金台账）与独立登录态；园所后台新增「我的套餐」页。
- **teacher / parent（uni-app）**：按授权隐藏 premium 模块入口；到期与降级提示。不涉及 tabBar 结构变更。
- **数据库**：新增迁移文件，不修改既有业务表结构（仅 `kindergartens` 增加状态字段）。
- **测试**：`docs/tests/TEST_CATALOG.md` 新增模块缩写与 TC。
- **不涉及**：`backend/model/`（已停更）、现有业务表的字段与关联、design token 体系。

## Out of Scope

- 在线支付（微信支付 / 支付宝）、支付回调、自动对账。
- 发票开具与开具状态跟踪、退款流程自动化。
- 分销商登录账号、多级分佣、提现、结算单。
- 计量配额（AI 调用次数、存储、短信条数）。
- 园所自助注册。
- 营收报表与财务导出。
- 家长付费、学费或伙食费代收。
- 园长助理 agent：计划中功能，在可演示前不进入套餐目录。

## 已确认的产品决策

- **四组状态枚举已于 2026-11-06 由产品方确认，本文档即为这些取值的权威来源**（既有三处来源：`design-data/`、`server/internal/domain/dict.go`、代码常量中均不存在）：
  - 园所状态：`active` 在营 / `suspended` 停用
  - 授权来源：`trial` 试用 / `subscription` 订阅 / `gift` 赠送
  - 订单状态：`unpaid` 待收款 / `partial` 部分收款 / `paid` 已收清 / `expired` 已到期 / `cancelled` 已取消
  - 佣金台账状态：`pending` 待结算 / `settleable` 可结算 / `settled` 已结算 / `reversed` 已冲回
- **幼儿数超档位**：只提示升级，不阻断新增幼儿；在读幼儿的既有业务不受影响。
- **定价为占位**：基础 1000 元 / 学期、旗舰 1500 元 / 学期，按每所园每学期。所有金额 MUST 由套餐目录配置，不得硬编码进授权逻辑。
- **合规未办**：ICP、教育移动应用备案、等保。本变更不解决，仅记录为商业化前置条件；完成前不面向公办园与教育局集采。
- **零付费园所**：整套设计建立在尚未验证的园所付费意愿之上，验收以「闭环可运行」为准，不以收入为准。
