# Spec Delta

## MODIFIED Requirements

### Requirement: 可见性由记录与孩子的关联链决定
家长端任何入口呈现一条成长记录或其媒体，MUST 同时满足：该记录属于家长某位孩子的班级（`target_type=1` 全班记录），或该记录明确发给了家长的某位孩子（`target_type=2` 个体记录）。两个条件都不满足的记录，MUST 在任何入口上不可见、不可访问。同一文件被班级相册等其它业务独立引用时，该引用 MUST 按其所属业务的可见性规则判定；本要求只约束成长记录引用，不改变其它业务引用的可见性。

#### Scenario: 全班记录对自己孩子所在班级可见
- **WHEN** 家长查看一条属于其孩子所在班级的全班记录
- **THEN** 该记录在所有家长端入口可见
- **AND** 覆盖用例 `TC-NEW-VIS-0001`

#### Scenario: 发给其他孩子的个体记录对家长不可见
- **WHEN** 存在一条按指定学生发布的个体记录，其目标学生不在该家长的孩子之中
- **THEN** 该记录与记录内媒体在所有家长端入口均不可见，直接访问其详情 ID 被拒绝
- **AND** 覆盖用例 `TC-NEW-VIS-0002`

#### Scenario: 非本班记录与媒体不可见
- **WHEN** 家长浏览相册，园所内存在其他班级的全班记录及其照片
- **THEN** 这些照片不出现，相册只包含其孩子所在班级的内容
- **AND** 覆盖用例 `TC-NEW-VIS-0003`

#### Scenario: 同一文件的班级相册引用独立生效
- **WHEN** 同一张照片既被一条成长记录引用，又被一本已发布班级相册引用
- **THEN** 成长记录入口按成长记录可见性判定，班级相册入口按班级相册可见性判定，两者互不覆盖
- **AND** 覆盖用例 `TC-NEW-VIS-0013`
