# Spec Delta

## Purpose

家长端查看已发布的班级相册，并按班内共享设置只看到与自己孩子相关的照片；毕业后保留只读窗口，转园立即失去访问。

## ADDED Requirements

### Requirement: 只展示已发布相册
家长端班级相册列表与详情 MUST 只返回已发布且未软删除的相册；草稿、已下架与已删除相册 MUST 在任何家长入口不可见、不可访问。

#### Scenario: 已发布相册可见
- **WHEN** 家长查看本班一本已发布相册
- **THEN** 列表与详情都能返回该相册及其照片
- **AND** 覆盖用例 `TC-NEW-PCA-0001`

#### Scenario: 草稿与已下架相册不可见
- **WHEN** 本班存在草稿相册与已下架相册
- **THEN** 家长端列表不出现它们，直接访问详情也返回不存在
- **AND** 覆盖用例 `TC-NEW-PCA-0002`

### Requirement: 按我的孩子过滤
家长端班级相册默认 SHALL 只展示包含其孩子关联的照片；照片未记录任何幼儿关联时，MUST 按相册级参与幼儿兜底。该视图 MUST NOT 因分页把同一相册拆成重复条目。

#### Scenario: 不含自己孩子的照片被过滤
- **WHEN** 一本相册中既有自己孩子的照片，也有只包含其他孩子的照片
- **THEN** 「我的孩子」视图只返回包含自己孩子的照片
- **AND** 覆盖用例 `TC-NEW-PCA-0003`

#### Scenario: 未标记照片按相册级参与者兜底
- **WHEN** 照片没有逐张幼儿关联，但相册级参与者包含自己的孩子
- **THEN** 该照片在「我的孩子」视图中可见
- **AND** 覆盖用例 `TC-NEW-PCA-0004`

### Requirement: 班内共享撤回
幼儿家长关闭班内共享后，其他家长 SHOULD NOT 看到包含该幼儿的照片；该幼儿自己的家长 MUST 仍能看到这些照片。系统 MUST 以整张照片为单位隐藏，MUST NOT 以整本相册为单位隐藏。

#### Scenario: 关闭共享后其他家长看不到合影
- **WHEN** 幼儿 A 的家长关闭班内共享，另一家长查看包含 A 的合影
- **THEN** 该照片不出现在另一家长的视图中，同相册其他不包含 A 的照片仍可见
- **AND** 覆盖用例 `TC-NEW-PCA-0005`

#### Scenario: 自己家长仍能看到
- **WHEN** 幼儿 A 的家长关闭班内共享后查看包含 A 的照片
- **THEN** 该照片仍对其可见
- **AND** 覆盖用例 `TC-NEW-PCA-0006`

### Requirement: 班级与园所隔离
家长端班级相册 MUST 只返回其孩子所在班级、同一园所的已发布相册；其他班级或园所的相册 MUST 不可见、不可访问。

#### Scenario: 其他班级相册不可见
- **WHEN** 家长请求其他班级的已发布相册
- **THEN** 返回不存在/无权限，不泄露该相册是否存在
- **AND** 覆盖用例 `TC-NEW-PCA-0007`

### Requirement: 相册详情与照片顺序
家长端相册详情 SHALL 返回相册元信息与可见照片；照片 MUST 按相册创建时的排序返回，MUST NOT 因家长过滤改变相对顺序。

#### Scenario: 过滤后仍保持原顺序
- **WHEN** 家长查看一本包含 12 张照片、其中 5 张可见的相册
- **THEN** 返回 5 张照片，顺序与老师创建时的顺序一致
- **AND** 覆盖用例 `TC-NEW-PCA-0008`

### Requirement: 毕业后与转园访问
幼儿毕业后，家长端 SHALL 保留 90 天只读访问并支持导出；转园或退园后 MUST 立即失去班级相册访问。超过窗口后 MUST NOT 再返回相册内容。

#### Scenario: 毕业 90 天内只读可导出
- **WHEN** 幼儿毕业未满 90 天
- **THEN** 家长仍可查看班级相册并导出
- **AND** 覆盖用例 `TC-NEW-PCA-0009`

#### Scenario: 转园或超过 90 天
- **WHEN** 幼儿已转园/退园，或毕业超过 90 天
- **THEN** 家长端班级相册列表与详情均返回空/不存在
- **AND** 覆盖用例 `TC-NEW-PCA-0010`
