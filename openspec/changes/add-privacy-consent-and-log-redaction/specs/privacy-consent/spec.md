# Spec Delta

## Purpose

按隐私政策版本记录教师、家长与园所管理人员的同意，并在缺同意时阻断业务访问，使平台能够证明取得过同意，并在政策改版后要求重新同意。

## ADDED Requirements

### Requirement: 同意按用户与政策版本记录

系统 SHALL 为每位用户在同意某个政策版本时写入一条同意记录，包含同意时间、政策版本、来源端、IP 与 User-Agent。同一用户对同一政策版本 MUST 只有一条有效记录；重复提交 MUST 幂等，不新增记录、不改变首次同意时间。

#### Scenario: 首次同意写入记录
- **WHEN** 一位未同意过当前政策版本的用户提交同意
- **THEN** 系统写入一条该用户 × 当前版本的同意记录，并返回同意时间与版本
- **TC**: TC-NEW-CNS-0001

#### Scenario: 重复同意保持幂等
- **WHEN** 同一用户对同一政策版本再次提交同意
- **THEN** 系统不新增记录，返回首次同意时间，记录总数不变
- **TC**: TC-NEW-CNS-0002

#### Scenario: 多角色用户按实际端记录来源
- **WHEN** 一个同时拥有家长与老师角色的用户从家长端提交同意
- **THEN** 记录中的来源端为 `parent`，而不是令牌角色列表中的第一个角色
- **TC**: TC-NEW-CNS-0015

### Requirement: 登录响应告知同意状态

家长端、老师端与管理端的登录响应 SHALL 告知本次登录后是否需要同意当前政策版本，以及当前政策版本号。该信息 MUST 是增量字段，不得改变既有身份查找、令牌签发与角色逻辑。

#### Scenario: 未同意用户登录
- **WHEN** 一位从未同意当前政策版本的家长、老师或园所管理人员完成登录
- **THEN** 登录响应标记需要同意，并携带当前政策版本号
- **TC**: TC-NEW-CNS-0003

#### Scenario: 已同意用户登录
- **WHEN** 一位已同意当前政策版本的用户完成登录
- **THEN** 登录响应标记无需同意，并携带当前政策版本号
- **TC**: TC-NEW-CNS-0004

### Requirement: 缺同意时阻断业务访问

已登录但未同意当前政策版本的请求访问家长端、老师端或管理端业务接口时，系统 MUST 返回明确的「需要同意」错误；同意接口、登出接口与健康检查 MUST 保持可访问，避免用户无法完成同意或退出。

#### Scenario: 未同意访问业务接口
- **WHEN** 未同意当前版本的用户请求任一业务接口
- **THEN** 系统返回 403 且错误码可被客户端识别为「需要同意」，不执行业务逻辑
- **TC**: TC-NEW-CNS-0005

#### Scenario: 同意后恢复访问
- **WHEN** 该用户完成同意后再次请求同一业务接口
- **THEN** 请求正常执行，不再返回「需要同意」
- **TC**: TC-NEW-CNS-0006

#### Scenario: 同意与登出不被阻断
- **WHEN** 未同意用户请求同意状态、提交同意或登出
- **THEN** 这些请求不被「需要同意」拦截
- **TC**: TC-NEW-CNS-0007

### Requirement: 政策版本升级触发重新同意

当前政策版本变更后，仅有旧版本同意记录的用户 MUST 被视为未同意当前版本；旧版本记录 MUST 保留，不得覆盖或删除。

#### Scenario: 版本升级后要求重新同意
- **WHEN** 政策版本从旧版升级到新版，一位只有旧版同意记录的用户登录或访问业务接口
- **THEN** 系统判定其未同意新版，要求重新同意
- **TC**: TC-NEW-CNS-0008

#### Scenario: 旧版本记录保留
- **WHEN** 用户完成新版同意
- **THEN** 系统新增新版记录，旧版记录仍可查询
- **TC**: TC-NEW-CNS-0009

### Requirement: 三端缺同意时进入阻断页

家长端、老师端与管理员端在登录后判定需要同意时，MUST 在进入业务页面前展示阻断页；阻断页 MUST 显示当前政策版本、政策内容入口与明确的同意操作。完成同意后 MUST 进入本端首页或后台首页，不得停留在阻断页。

#### Scenario: 家长端静默登录缺同意
- **WHEN** 家长端静默登录返回需要同意
- **THEN** 应用进入阻断页，不展示 tabBar 业务页
- **TC**: TC-NEW-CNS-0010

#### Scenario: 老师端静默登录缺同意
- **WHEN** 老师端静默登录返回需要同意
- **THEN** 应用进入阻断页，不展示工作台
- **TC**: TC-NEW-CNS-0011

#### Scenario: 管理端登录缺同意
- **WHEN** 园所管理人员密码登录返回需要同意
- **THEN** 管理端进入阻断页，不展示后台业务页
- **TC**: TC-NEW-CNS-0012

#### Scenario: 同意后进入首页
- **WHEN** 用户在阻断页完成同意
- **THEN** 应用写入同意记录并进入本端首页或后台首页
- **TC**: TC-NEW-CNS-0013

### Requirement: 暂不同意可退出且不写记录

阻断页 MUST 提供「暂不同意」或等价的退出路径；选择后 MUST NOT 写入同意记录，且 MUST 退出到登录页、关闭小程序或保持不可访问状态，不得绕过门禁进入业务页。

#### Scenario: 暂不同意不写记录
- **WHEN** 用户在阻断页选择暂不同意
- **THEN** 系统不写入同意记录，用户无法进入业务页
- **TC**: TC-NEW-CNS-0014
