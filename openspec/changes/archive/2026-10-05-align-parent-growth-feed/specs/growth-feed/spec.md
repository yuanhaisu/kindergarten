# Spec Delta

## Purpose

让家长在「成长时光」看到真实完整的成长瞬间：谁发的、什么时候、写了什么、有哪些照片、自己点过赞没有、有多少评论。此前卡片虽然渲染了框架，但这些内容全是空的。

## ADDED Requirements

### Requirement: 列表卡片呈现发布者与时间
家长在成长时光列表查看任一条记录时，MUST 能看到该记录的发布者昵称与发布时刻。

#### Scenario: 卡片显示发布者昵称
- **WHEN** 家长打开成长时光列表
- **THEN** 每条记录卡片显示发布该记录的老师昵称
- 参考: TC-GRW-080

#### Scenario: 卡片显示发布时刻
- **WHEN** 家长查看某条记录卡片
- **THEN** 卡片显示该记录的发布时间（含时分）
- 参考: TC-GRW-081

### Requirement: 列表卡片呈现正文与照片
家长在成长时光列表查看任一条记录时，MUST 能看到记录正文；记录附带照片时 MUST 能看到照片缩略图。

#### Scenario: 卡片显示正文
- **WHEN** 家长查看某条记录卡片
- **THEN** 卡片显示该记录的文字内容
- 参考: TC-GRW-082

#### Scenario: 有照片的记录显示照片
- **WHEN** 一条记录附带了照片
- **THEN** 卡片上呈现这些照片的缩略图，数量与实际附件一致
- 参考: TC-GRW-083

#### Scenario: 无照片的记录不渲染照片区
- **WHEN** 一条记录没有任何照片或视频附件
- **THEN** 卡片不渲染照片区域，正文下方直接是互动栏
- 参考: TC-GRW-084

### Requirement: 列表卡片呈现互动状态
家长在成长时光列表查看任一条记录时，MUST 能看到自己是否已点赞，以及该记录的评论条数。

#### Scenario: 点赞态正确反映本人操作
- **WHEN** 家长已对某条记录点过赞
- **THEN** 该卡片的点赞按钮呈现「已点赞」态；未点过则呈现「点赞」态
- 参考: TC-GRW-085

#### Scenario: 评论数真实
- **WHEN** 一条记录下有 N 条评论
- **THEN** 卡片显示「N条评论」；无评论时显示「评论」
- 参考: TC-GRW-086

### Requirement: 时间线按月分组
成长时光列表 MUST 按月份把记录分组，每组给出月份标记，组内记录按时间倒序。

#### Scenario: 同月记录归入同一分组
- **WHEN** 列表中有多条记录落在同一个自然月
- **THEN** 它们出现在同一个月份标记下，且该月内最新记录在前
- 参考: TC-GRW-087

#### Scenario: 跨月记录分组隔离
- **WHEN** 列表跨越多个自然月
- **THEN** 每个月份标记只包含该月的记录，不串月
- 参考: TC-GRW-088

### Requirement: 列表不承载详情页才需要的内容
成长记录列表 MUST 只携带卡片渲染所需的信息。仅详情页展示的内容（如这条记录涉及哪些孩子）MUST 出现在详情，而非列表。

#### Scenario: 个体记录的列表项不含相关孩子
- **WHEN** 一条记录是发给指定孩子的个体记录
- **THEN** 列表中该卡片不展示相关孩子信息，也不在列表响应中携带该信息
- 参考: TC-GRW-089

#### Scenario: 详情给出相关孩子
- **WHEN** 家长打开一条个体记录的详情
- **THEN** 详情展示这条记录涉及的孩子
- 参考: TC-GRW-090

#### Scenario: 全班记录详情无相关孩子
- **WHEN** 家长打开一条发给全班的记录的详情
- **THEN** 详情不展示「相关孩子」区块（该记录不针对特定孩子）
- 参考: TC-GRW-091

### Requirement: 契约不返回设计未呈现的冗余信息
成长时光列表的对外契约 MUST 只包含卡片实际呈现的信息。设计稿从未呈现、且无法由已返回内容派生的信息 MUST NOT 出现在列表响应中。

#### Scenario: 列表响应不含冗余字段
- **WHEN** 客户端请求成长时光列表
- **THEN** 响应条目不含点赞总数、媒体条数计数、发送范围标识、班级名等卡片不渲染的内容
- 参考: TC-GRW-092
