## 1. 家长端 · 日历页顶部「变更提示」条（`parent/src/pages/calendar/index.vue`）

**岗位**：家长在通勤间隙/晚间刷手机，打开日历想知道「接下来要准备什么」。变更提示打破的是**旧认知**——按记忆里的时间去门口扑空。

**形态**：月份选择栏之下、日历卡之上插入提示条。

- **聚合**：列出全部处于窗口内的事件变更，每条一行：`事件标题` + 要旨（`change_summary`，如「时间 10:00 → 10:30」）
- **点击定位**：点某行 → 日历选中该事件日期并滚动到当日事件列表（复用既有 `is-selected` 选中态）
- **生命周期**：服务端只下发窗口内（近 7 天修订且未发生）的要旨；事件发生或超窗后自然消失。**条本身不可关闭**（「会被看到」是设计目的；窗口有限，不会长期占位）
- **数据**：`GET /parent/class/calendar` 响应中的 `change_summary`（非空 = 展示）

**视觉（token）**：
- 底：`$color-semantic-warning-bg`（蜜蜡黄浅底）——「注意」语义，不用 danger
- 左侧竖条 + 标题「安排有变更」用 `$color-semantic-warning`；要旨正文 `$color-text-body`
- 圆角 `$border-radius-lg`（较卡片低一档，表次级容器）；内边距 `$spacing-lg $spacing-xl`
- 最多展开 3 条，其余折叠「另有 N 条」

**边界**：无变更整条不渲染；不用 toast/弹窗（打断过强）。

## 2. 老师端 · 「是否通知家长」保存确认弹窗（`teacher/src/pages/calendar/detail.vue`）

**岗位**：老师在详情页改完一条**已发布**事件点保存——需要一个「打扰家长与否」的当场决定。

**形态**：底部弹层（小程序惯例，非居中弹窗）。

- **标题**：「通知家长？」；副文案一行：「将通知小一班全体家长」（受影响范围）
- **变更要旨预览**：本次 diff（如「时间 10:00 → 10:30；地点 音乐教室 → 美术教室」），老师看着要旨做决定
- **默认勾选（按实质预勾选）**：日期/时间/地点变化 → 开关默认**开**；仅标题/描述/类型变化 → 默认**关**
- **开关文案**：「发布变更通知（家长端会在日历顶部看到此变更）」
- **按钮**：胶囊形品牌渐变主按钮「保存」（`$gradient-brand`）+ ghost 次按钮「取消」
- **不弹层的情况**：草稿保存（草稿不产生通知）；**无实质变更**时不弹（没有要通知的内容）

**视觉**：弹层云白底、顶部圆角 `$border-radius-2xl`、`$shadow-lg`；开关用原生 switch（brand 色）；要旨行前缀 `$color-semantic-warning` 小圆点。

## 3. 管理端 · 「园级日历管理」页（`admin/pages/calendar/index.vue`）

**岗位**：园长在办公桌电脑前安排假期/体检/家长会——频次低、单次慎重，需要「排布全景 + 精确定位」。

**形态**：左右两栏（Operate，信息密度优先）。

- **左（主）**：Element Plus `el-calendar` 月历；有园级事件的日期按类型色圆点（**数据驱动色**，取自字典，与老师端同源）；点日期 → 右栏当日列表
- **右（侧）**：当日园级事件列表卡（标题/时间/地点/状态 Pill「草稿/已发布」）+「新建园级事件」按钮
- **新建/编辑**：el-dialog 表单——标题、类型（字典下拉，含园所自定义类型）、日期、时间、地点、全天、状态（草稿/发布）、通知家长开关（与组 2 同规则）；对**已发布**事件的保存走二次确认（el-messagebox，默认值按实质）
- **头部**：页面标题 + 状态筛选（全部/草稿/已发布）

**视觉**：管理端晴空蓝体系；卡片 `bg-bg-card` + 圆角 + 暖琥珀阴影；状态 Pill 语义色类名。**Front-Back：管理端不出现暖橙**（类型色圆点属数据驱动色，不在此列）。

## 4. 管理端 · 「课表管理」页（`admin/pages/timetable/index.vue`）

**形态**：单页三区。

- **顶部设置条**：课表开关（el-switch）+「立即同步」按钮 + 同步结果回显（created/updated/deleted/skipped）
- **年级模板网格**：年级 tab（小班/中班/大班）+ 7 列（周一~周日）× 行（第 1~8 节）网格；点格子编辑（标题/地点/起止时间）；保存 = 全量提交
- **班级微调**：班级下拉 + 同款网格（呈现「模板叠加微调」后的结果，微调格子带「已微调」角标 + 清除操作）

**交互约束**：网格空态「尚未维护课表，点格子添加」；保存后 el-message 回显同步计数；**开关关闭时网格仍可维护**（数据准备），但顶部提示「当前未开启，日历不呈现课表」。

**视觉**：网格线浅线（token 级）；格子两行（课名 + 时间）；模板格白底、微调格 `bg-brand-primary` 极淡底 + 角标。

## 5. 老师端小程序内 · 医生端「园级事件发布」页（新增 `teacher/src/pages/doctor/calendar.vue`）

**岗位**：保健医在晨检间隙发布体检安排。

**入口**：`pages/doctor/checkin`（晨检页）顶部按钮「发布园级事件」→ `navigateTo` 独立页（老师端无 tabBar，无 switchTab 场景）。

**形态**：复用老师端 `calendar/create.vue` 表单骨架，差异点：

- 类型默认「体检」；受众固定为「全园家长可见」（不可选班级），用 `$color-semantic-info` Pill 明示区别于班级事件
- 状态/通知开关、保存确认逻辑与组 2 一致
- 页内列表：最近发布的园级事件（含草稿），可进编辑/删除

**视觉**：老师端暖橙体系不变。

## 状态与内容范围（组 7/8/9 验收核对）

| 面 | 空态 | 边界态 | 最大范围 |
|---|---|---|---|
| 家长端提示条 | 不渲染 | 折叠「另有 N 条」 | 窗口内 ≤10 条（展开 3） |

## 约束与不可自创项

- 色/间距/圆角/字号/阴影**一律 DESIGN.md token**；类型色是**数据驱动色**（字典 Extra），不进 tokens
- 小程序端不出现蓝色主按钮；管理端不出现橙色主按钮（Front-Back）
- 可点击元素全胶囊、暖琥珀阴影、无直角 —— Tender Cosmos 铁律
- 组 7/8/9 实现完成后，按技能指令跑一次机械检测：`impeccable.cmd detect --json <changed targets>`（任务 6.5 的关闭条件）
