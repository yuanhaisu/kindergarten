# Spec Delta

## Purpose

老师端手动接送登记的交互行为——包括按学生查看有效授权人、选人/标例外二选一、送入快捷登记、错误提示可操作性。

## ADDED Requirements

### Requirement: 老师可查看指定学生的有效授权接送人

老师在手动登记弹窗中选择「选授权人」模式时，系统应展示该学生当前有效（已审核通过、未撤销、未过期）的授权接送人列表，供老师选择。

#### Scenario: 显示有效授权人列表

- **WHEN** 老师点击某学生的「登记」按钮并切换到「选授权人」模式
- **THEN** 系统展示该生的有效授权接送人列表，每人显示姓名、关系、脱敏手机号与头像

#### Scenario: 无有效授权人时提示

- **WHEN** 该学生当前没有任何有效授权接送人
- **THEN** 显示「暂无有效授权接送人」，并提示老师可切换到「标例外」模式

#### Scenario: 仅返回有效授权人

- **WHEN** 该学生存在未审核通过、已撤销或已过期的授权人
- **THEN** 这些授权人不出现在列表中

### Requirement: 老师可在手动登记中选择授权人

老师在弹窗中选择某位授权人后，系统记录该授权人的标识，提交时将其作为本次接走的归因对象。

#### Scenario: 选人后提交成功

- **WHEN** 老师选中一位授权人并点击「确认登记」
- **THEN** 系统创建接走记录，记录归因到该授权人，且记录的「是否授权例外」为 false

#### Scenario: 未选人时提交被拒

- **WHEN** 老师在「选授权人」模式下未选中任何授权人就点击「确认登记」
- **THEN** 系统提示需要先选择一位授权接送人

#### Scenario: 切换模式时清空选人状态

- **WHEN** 老师从「选授权人」切换到「标例外」，再切回「选授权人」
- **THEN** 之前选中的授权人被清空，需要重新选择

### Requirement: 送入可一键登记

老师对学生进行送入（入园）登记时，不需要经过弹窗表单——送入不记交接人、不要理由。

#### Scenario: 未到园学生显示入园按钮

- **WHEN** 学生状态为「未到园」（not_arrived）
- **THEN** 学生卡片显示「入园」按钮，点击后直接创建送入记录（不弹窗）

#### Scenario: 送入登记成功后状态更新

- **WHEN** 老师点击「入园」按钮且登记成功
- **THEN** 学生状态从「未到园」变为「已入园」，统计卡的「已入园」计数 +1

### Requirement: 错误提示应可操作

当手动登记被后端校验拒绝时，前端提示应告诉老师下一步该做什么，而非只复述错误原因。

#### Scenario: 未入园时提示先登记送入

- **WHEN** 老师尝试对未入园的学生登记接走，后端返回「先登记入园再接走」类错误
- **THEN** 前端提示「该生今日尚未入园，请先登记入园（送入）后再登记接走」

#### Scenario: 重复接走缺理由时提示

- **WHEN** 老师提交重复接走但未填写理由
- **THEN** 提示「重复接走需填写理由」，不产生记录
