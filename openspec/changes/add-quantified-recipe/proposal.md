# Proposal

## Why

园所目前没有膳食管理能力：竞品分析已把「每日食谱」列为竞品强项、我方缺失。园所此前使用育健（oyujian）的膳食管理，真正依赖的是其内置的 1,700+ 条食物成分数据，以及一套已经用熟的带量食谱工作流。要在 admin 补上这块能力，并让既有使用者无需重新学习，必须按参考产品的字段、流程、按钮文案与报表口径复刻，而不是重新设计。

## What Changes

- 新增 admin「膳食管理」模块：基本参数（供餐配置）、膳食计划（周食谱）、菜谱库、资源库（食物库）、营养分析。
- **供餐配置**：园所单例；托管形式、餐次与时间、各餐供能占比、重量口径（仅市品重量）；比例校验对齐参考产品（时间递增 + 相邻餐次上限）。
- **食物库**：新园初始化复制约 1,700 条预置食物；每条含 27 项营养（每 100g 可食部）、食部比例、两级分类；支持增删改、批量删除、搜索与分类筛选。
- **菜谱库**：菜谱 = 一组「食物 + 一人均量克数」的命名快照；周食谱编辑器内按名称联想复用；新增菜谱库管理页（列表 / 查看配料 / 改名 / 删除 / 合并重复）。
- **周食谱**：按学年管理；7 天 × 餐次的网格编辑器；单元格内「菜 → 食物 → 克数」；支持添加/移除菜谱、添加/移除食物、同类替换、位置调整、保存菜谱、清空、实时营养小计；新建三选一（自定义 / 选用模板 / 复制历史）。
- **模板食谱**：平台内置 2~4 套整周模板，只读；选用后复制成园所周食谱。
- **营养分析**：完整复刻参考产品的 4 页签 / 7 组报表数据（营养分析、三大营养素供能、三餐供能比、膳食构成、钙铁来源、蛋白质来源、脂肪来源）+ 自动结论 + 打印 + Excel 导出。
- **契约变更声明**：本次将新增 `backend/api/api-admin/` 膳食契约，属于契约变更。
- 只改 admin + server + backend/api；teacher / parent 小程序不改。

**明确不做**：餐后调查、膳食会议、月伙食计划、采购清单、就餐人数、分析图、草稿箱、家长端/老师端展示、智能配餐。

## Capabilities

### New Capabilities

- `diet-meal-config`: 园所供餐配置（餐次、时间、供能占比、重量口径）及其校验规则。
- `diet-food-library`: 预置食物库与菜谱库的维护、复制与检索语义。
- `diet-meal-plan`: 周食谱的创建方式、网格编辑、模板与历史复制、菜谱联想与保存规则。
- `diet-nutrition-analysis`: 营养聚合、DRIs 对比、7 组报表（4 页签）、自动结论与导出。

### Modified Capabilities

（无：现有 capability 的行为不变；学年复用 `academic_years`，不改其需求。）

## Impact

- **Go**：新增 domain / repository / service / handler；`app/router.go`、`app/provider.go`（AutoMigrate）、`app/seeder.go`；Wire 三处；`middleware/admin_perm.go` 路由权限登记（fail-closed）；`service/role_catalog.go` 权限模块；`cmd/` 食物数据导入命令。
- **契约**：新增 `backend/api/api-admin/` 膳食契约文件与 README 模块索引。
- **Admin**：新增 `api/diet.ts`、`types/api.d.ts`、`pages/diet/*`、`constants/menus.ts` 菜单与权限码。
- **Teacher / Parent**：不改。
- **数据**：新增表；AutoMigrate 只增不改，生产变更需手工 SQL + `dbcheck`；种子数据含 DRIs 年龄档目标（3/4/5/6 岁）、食物分类、2~4 套模板；食物 CSV 导入走离线命令。
- **测试**：service / repository 单测、router 权限回归、admin E2E；新增 TC 编号补录 `docs/tests/TEST_CATALOG.md`。

## Risks & Open Facts

- **数据许可（硬门槛）**：Sanotsu 数据集仅本地开发验证，不提交、不分发；ncmi.cn 只有元数据、实体数据暂不共享，上线前必须取得中国疾控中心营养与健康所《中国国家食物成分数据授权使用协议》（合同需覆盖入库、终端展示、SaaS 分发、衍生作品、续期五项）。
- **微量营养素缺失**：公开数据缺失 30~50% 的微量项，必须存 NULL、显示「—」，不能当 0，否则 VA/VC/硒会系统性低估。
- **膳食构成 12/16 类与钙铁来源归类**：参考产品仅能从明细反推，官方映射仍在核实；未确认前不固化枚举取值。
- **DRIs 2000 全表与年龄口径**：已观测 11 项 `fullRecom`，需校准完整目标表后才能声称与旧报表逐项一致。
- **参考报表的非标准口径**：三个能量总量、视黄醇列复用维生素A、胡萝卜素列「-」、膳食构成页面 10/16 列、脂肪来源页面 2/3 列、钙来源重复计入、蛋白质来源非穷尽、三餐比 85.88% 已实证；按 ADR-0004 刻意保留，不在本变更修 bug。retinol/carotin 不进入页面与契约，不再作为未闭合项。
