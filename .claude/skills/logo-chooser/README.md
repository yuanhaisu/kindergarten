# logo-chooser

**不要让没有设计能力的人描述想要什么，让他指认哪个不对。**

前者是生成，他做不到；后者是辨别，不需要会设计也能做。

> 本文每条主张的证据等级见 [`EVIDENCE.md`](EVIDENCE.md)。写在这里的是**能被证据支持的版本**，不是最想说的版本。

---

## 先看这一条

这套工具**不能让人独立完成**。它把专家从「画 logo」挪到了两个位置，但没有取消专家：

| 谁 | 做什么 | 一次要多久 |
|---|---|---|
| **你（不需要会设计）** | 指认：哪几张、哪几句、哪几格不对 | **未计时**（唯一数据：三站合计约 70 分钟，含等待） |
| **AI（找不到 AI 时才需要会写会画的人）** | 生产：站 2 的 15 句、站 3 的示意、站 4 的黑稿 | **未计时**（估 1–2 小时） |

> 这一格之前只写「需要会写会画的人」。`SKILL.md` 一直允许「人写或 AI 写」，
> 但这份 README 没提 AI——**两份文档对同一件事说反话，而人读的是错的那份**。
> 实测代价：测试者读完以为身边没有设计师就走不下去。

开工前先自检，别走到一半才发现缺料：

```bash
python -I scripts/preflight.py --brand 养成星球
```

## 五分钟跑一遍

```bash
cd .claude/skills/logo-chooser

# 站 1 气质：8 张同名试排
python -I scripts/typeset.py --brand 养成星球
#   打开 runs/养成星球/round-1.html，点 2–3 张，复制编号
python -I scripts/narrow.py --pick 01,04,06 --note "他说：06 太重了"

# 站 2 意象：15 句
python -I scripts/draft.py --brand 养成星球
python -I scripts/narrow.py --station 2 --pick S01,S07,S09

# 站 3 类型：3 句 × 2 形态 + 1 张全局字标
python -I scripts/matrix.py --brand 养成星球
python -I scripts/narrow.py --station 3 --pick S01-pictorial,wordmark

# 站 4 构造：每轮只动 1–2 条轴
python -I scripts/construct.py --brand 养成星球 --round 4.1
python -I scripts/narrow.py --station 4 --pick d1,d3,d4

# 站 5 验收：全自动
python -I scripts/audit.py --brand 养成星球
```

每一步都是同一件事：**打开页面点卡片 → 复制编号 → 一条命令记账**。

## 六站

| 站 | 发散物 | 收敛 | 机器做 | 谁生产 |
|---|---|---|---|---|
| 0 名片 | — | — | — | 你填三个空 |
| 1 气质 | 同名试排 8 张 | 2–3 | 排版 · 覆盖断言 · 记账 | 机器排版，你指认 |
| 2 意象 | 5 词 × 3 具象 = 15 句 | 3 | 校验（长度/抽象词/形位连）· 记账 | **AI 写**（没有 AI 才由人写） |
| 3 类型 | 3 句 × 2 形态 + 1 张全局字标 | 2–3 | 矩阵 · 16px 实测 · 记账 | **AI 画** |
| 4 构造 | 每轮 3–9 个黑稿；二选一的对决轮 2 个 | 2–3 | 轴覆盖 · 形状校验 · 同轮查重 · 记账 | **AI 画** |
| 5 验收 | — | — | 16px / 纯黑 / 反白 / 禁用元素 / 形状 | 货架 + 一句话 |

「收敛」不是建议，是硬规则：选多了页面会拦，选少了也拦。
站 4 用相对规则：**留不超过 40%，最多 3 张**；标了 `duel` 的对决轮留 2 张。

## 四条规矩（都是踩出来的）

**1. 规则必须能真的拦下东西。**
写校验前先举一个它真会拦下的例子。举不出来，这条规则就是装饰——写进文档反而给人「已经防住了」的错觉。
曾经有两条：站 1 的「必须来自 2 个不同 mood 分支」、站 2 的「必须是 3 个不同物件」，都是永远成立的废话。

**2. 每个取值至少出现一次。**
缺一个取值，正确答案可能根本不在桌上。A1 是 `figure_ground=line`，只出实心版它就永远进不来。
由 `coverage_check.py` 强制；裁掉一个取值可以，但必须在 `axes.json` 里申报理由。

**3. 测不了的就写「测不了」。**
锚定、过渡、货架、一句话——脚本做不到，页面上标「人工核对」。
给个假分数比不给更糟。

**4. 记录是派生的，上游改了要标脏。**
`picks.json` 是唯一真相源，`brief.md` 由它生成。改站 1 不会让站 2 失效（它选的是句子），但会让站 3 失效。
过期记录保留在 brief 里并带警告，但绝不会被当成有效结论。

## 常见拦截

| 报错 | 意思 |
|---|---|
| `❌ 站 1 · 气质 覆盖检查失败` | 少摆了一档，那一档永远选不到 |
| `❌ 这几张是同一个分量` | 站 1 三张全挑重的，等于只选了一次 |
| `❌ 三句都在同一个词下` | 站 2 的三句其实是同一个想法 |
| `❌ 都在同一种类型里` | 站 3 没在比较类型 |
| `❌ 元素数 1 ≠ 申报的 2` | 站 4 两块粘在一起了 |
| `❌ 缺 N 张示意` | 站 3 的图要人画，脚本不生成 |
| `❌ N 个取值不过` | 全路径覆盖：这些取值既没摆出来，也没申报理由 |
| `不过 反白后结构不变 —— 含彩色` | 先出单色轮廓版再验 |

> **H-a**：它是**偏好采集器**，不是决策器。选出来的东西仍然需要一个人来解释它是什么。

反方同样成立：设计师也凭感觉做判断，「必须能说清理由」这条标准本身未经验证。
在拿到 n≥3 的数据之前不选边。详见 `EVIDENCE.md` §2.4。
