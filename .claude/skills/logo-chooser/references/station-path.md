# 六站路径 · 话术与卡规格

每一站只问一个问题。问句必须是**指认题**，不能是**填空题**。

---

## 站 0 · 名片

**做**：把三个空填掉，其余什么都不做。

| 栏 | 例子 | 不合格 |
|---|---|---|
| 名字 | 养成星球 | — |
| 给谁 | 民办园园长（买）、老师（用）、家长（感知） | 「所有人」 |
| 解决什么 | 家园共育的记录与沟通，顺带园务管理 | 「提升效率」 |

**退回规则**：一句话里出现「专业 / 高端 / 有温度 / 国际化」，退回重写。形容词在这一站是噪音。

---

## 站 1 · 气质

**问**：「这 8 张里，哪两三张让你觉得『对，是这个感觉』？先不用管图形。」

**卡规格**：每张卡不是形容词，是**同名试排**——

```
┌──────────────────┐
│   养成星球        │  ← 名字用该字型排，实际字号
│   ┌──┐ ┌──┐ ┌──┐ │
│   │  │ │  │ │  │ │  ← 3 个该 mood 的真实 exemplar 缩略图
│   └──┘ └──┘ └──┘ │
│ 温暖 · 像被照顾    │  ← 一句「它意味着什么」
└──────────────────┘
```

**为什么必须试排**：只给形容词，用户是在选词；给同名试排，他是在选感觉。这两件事的准确率差一个数量级。

**收敛**：留 2–3 张，且**不能全部落在同一个（字族 × 重量档）里**。

- 重量档：轻 `< 450` / 中 `450–650` / 重 `> 650`，阈值在 `axes.json → zh.weight_tiers`
- 用户说「我全都要重的」→ 追问：「如果只能留一张重的，另一张你愿意接受什么分量的？」

> ⚠️ 原规则写的是「必须来自 2 个不同 `mood` 分支」，但站 1 的 8 张卡**每张就是一个 mood**，任意选两张都会自动满足——这条规则是空转的，`narrow.py` 里换成了上面的分量校验。

**记录**：`mood[]` + `type_style[]`

---

## 站 2 · 意象

**问**：「这 15 句里，哪三句是你愿意指着说『就是这个』的？」

**方法**：三步，全在纸上，不画。

1. 拆词 → 动词 + 名词（养成 / 星球）
2. 列具象 → 每个词 3 个**能画出来的东西**
3. 写成句子 → `这是一个 ______`

**合格句**：

> 「一个深色的圆，边上开一道口，里面露出一颗琥珀色的东西。」

**不合格句**（出现即作废）：

> 「象征孩子在这里自由成长」← 没有可画的物件
> 「体现家园共育的温暖生态」← 三个抽象词叠在一起

**硬规则**：≤20 字；必须含至少一个**名词性物件**或**具体动作**（开、顶、托、包、伸出）。

**收敛**：留 3 句，且必须来自**至少 2 个不同的词**。

> ⚠️ 原规则写的是「三句不能是同一个物件的三种说法」。但词库里 15 个物件本来就不重名，按名字判重永远不会触发——**又一条空转的规则**。
> 真正能拦下的是「三句全出自同一个词」（比如都来自「养成」），那才说明用户只有一个想法。`narrow.py --station 2` 按 `word` 校验。

用户说「我就要这三句」但都在同一个词下 → 追问：「如果只能留一句，你愿意再从别的词里挑一句吗？」
用户说「三句都留着，进站 3 再看」→ **不允许**。站 3 是 3 句 × 5 类型 = 15 张，句子一多矩阵就废了。

**记录**：三句原文，不改写。

---

## 站 3 · 类型

**问**：「同一个想法，用这几种方式做出来，哪种最像你们？」

**卡规格**：真实世界里标志只有三种形态，站 3 就只摆这三种。

```
┌─────────────────────────────┐
│ 只用名字（全局卡，不随想法变） │
└─────────────────────────────┘

        只用图形     图形 + 名字
第 1 句   ▢            ▢
第 2 句   ▢            ▢
第 3 句   ▢            ▢
```

**为什么只有三类**：`literalness`（具象 / 隐喻 / 抽象）在 `axes.json` 里标的是 **station 4**——
它是构造轴，不是锁图类型。曾经把它做成「具象」「抽象」两列，结果是矩阵的列互不互斥：
字标、字母、具象、抽象里有四个都是「符号」，只差画法。列不互斥，比较就没有意义。

**字标为什么是全局卡**：它只画名字，不随句子变化。做成每行一格的话，三格逐像素相同，
用户点哪行纯属偶然，编号里的行号是假的，后面的「至少跨 2 种类型」也会被绕过。

每格下方两个数字：

- **16px 存活率**：`survive.py` 实测（缩到 16×16 与 96×96 比连通块 / 洞 / 墨占比），不是目测
- **文字依赖度**：由格子构成决定（含名字 = 强，纯符号 = 弱）

**砍类型**：8 种里只放 3 种进场，其余 5 种在 `axes.json → station3.cut` 里逐条申报理由。
未申报的裁剪会被 `coverage_check.py` 判为缺失并退出。

**示意从哪来**：站 3 不画形。每句需要两份手绘示意，放在 `runs/<品牌>/sketches/`：

```
S07.svg            具象：把物件画出来的样子
S07.abstract.svg   抽象：只留几何关系的样子（可缺省）
```

抽象版**不是删细节，是换一条构造轴**。S07 的具象是「断开一圈 + 一颗点」，抽象版是「实心盘挖掉一个圆 + 缺口里放点」——同一个想法，两种造法。缺省时格子上标注「无更简版」，那本身是个有用的信号。

**收敛**：留 2–3 **格**，不是 2–3 列。

> 原规则写的是「留 2–3 类」。但同一句在不同类型下的可行性差别极大——「一条竖线 + 三道短线」做字标没有意义。按列收会强行让一个想法套上不适合的类型。所以选的是（句子 × 类型）的格子。

且必须跨 **≥2 种类型**，否则等于没在比较类型。

**记录**：`mark_type[]` + `cells[]`

## 站 4 · 构造

**问**：「这几个里，哪个你会想再看一眼？」

**不做全笛卡尔积。** 每轮 4–9 个，只动 1–2 条轴：

| 轮 | 固定 | 变 | 产出 |
|---|---|---|---|
| 4.1 | 站 3 的类型、意象 | `figure_ground` × `geometry`(2–3 值) | 6–9 |
| 4.2 | 4.1 选中 | `literalness` × `symmetry` | 6 |
| 4.3 | 4.2 选中 | `container` × `geometry`(2 值) | 4–6 |

**一轮的声明写成 JSON**（`runs/<品牌>/round-4.1.json`）：固定哪几条轴、变化哪几条、
每张稿子的坐标是什么。`construct.py` 会校验：

- `vary` 超过 2 条轴 → 退出
- 某个稿子的坐标不在本轮允许值里 → 退出
- 变化轴的某个取值一张稿子都没有 → 退出（coverage：缺一档就永远选不到）
- 两张稿子坐标完全相同 → 退出

**稿子必须申报 `elements`（这个想法有几个独立元素）**。量出来的连通块数对不上，
说明两块粘住了或细节丢了——先报这一条，后面的比值就没意义了。

**优先级**：上一轮没定过的轴先动。已定死的轴不再变，**除非用户主动回退**。

**回退是一等操作**：用户说「还是上一版好」，直接回到那一版，不要重新生成，也不要问「确定吗」。回退后把该轴的取值锁住，标记为「已定」。

**每轮结束后跑关系校验**（`axes.json` → `relations`）：

```
锚定  □ 附属元素落在半径/切线/角平分线上     人工核对
过渡  □ 相接处夹角 ≥ 45°                     人工核对
层级  □ 主元素面积 ≥ 次元素 3 倍             自动量
呼吸  □ 最小间隙 ≥ 主元素短边 1/12           自动量
```

**只有后两条能从像素独立测出来。** 锚定需要知道「该落在哪条线」，过渡要求曲线交点角度，
脚本做不到。所以页面上前两条标成「人工核对」——**测不了的就不假装测了**，
给个假分数比不给更糟。

任一项不过，**先修再给用户看**——不要让他替你发现「看着怪」。
自动检查不过的稿子仍然显示，但会标红并写明原因；记录时也会带上 `failed` 标记。

**收敛**：留 3 个。

## 站 5 · 验收

**不问用户任何问题。**

```bash
python <logo-design>/scripts/svg_audit.py final/*.svg
python <logo-design>/scripts/render_png.py final/*.svg --out-dir png --size 16 32 48 256
```

必过项：

| # | 检查 | 不过的处理 |
|---|---|---|
| 1 | 16px 认得出主体 | 做简化版，或删细节 |
| 2 | 纯黑成立 | 去掉靠颜色撑的结构 |
| 3 | 反白（深底白）清楚 | 反向版单独减细 5–8% |
| 4 | 无 `<text>` / 无位图 / 无滤镜 | 轮廓化 |
| 5 | 与 5 个同行并排，最先被记住 | 回去加记忆锚点 |
| 6 | 一句话说得清是什么 | 概念太绕，回站 2 |

**报告格式**：一条一行，只写「过 / 不过 + 原因」。不写分数，分数会让人讨论分数。

### 哪些能测，哪些不能

| # | 检查 | 谁能做 |
|---|---|---|
| 1 | 16px 认得出主体 | ✅ 实测：连通块 / 洞 / 墨占比，16px 对 96px |
| 2 | 纯黑成立 | ✅ 解析 fill / stroke，数颜色 |
| 3 | 反白后结构不变 | ✅ 渲到深底上比连通块与洞 |
| 4 | 无 `<text>` / 位图 / 滤镜 | ✅ 解析标签 |
| 5 | 与 5 个同行并排最先被记住 | ❌ 需要同行样本，人工 |
| 6 | 一句话说得清是什么 | ❌ 语义判断，人工 |

第 3 项只能验「结构有没有塌」。**「反白看起来偏重、该减细 5–8%」是光学错觉，
像素数完全一样——测不了就不写，硬给一个数值等于编。**

彩色或含文字的稿子，第 3 项直接判不过并说明「先出单色轮廓版再验」——
拿彩色稿硬做颜色替换，会得出「结构变了」这种假结论。

## 全程记录格式

`runs/<品牌>/brief.md`：

```markdown
# <品牌> · 选型记录

## 名片
名字：
给谁：
解决什么：

## 站 1 气质
候选：8 张
选中：warm（「像被照顾」）、solid（「站得住」）
淘汰理由：playful「太像儿童玩具，园长不会买」

## 站 2 意象
1. 一个深色的圆，边上开一道口，里面露出一颗琥珀色的东西
2. 一颗种子顶开外壳
3. 一圈年轮，右侧断开，断口处有新芽

## 站 3 类型
选中：combination、abstract
砍掉：mascot（16px 存活率低）、emblem（园长觉得像校徽，太旧）

## 站 4 构造
4.1 figure_ground：line / negative / solid → 选 negative
4.2 回退：negative → line（「还是细的那版好」）
锁定：figure_ground=line, geometry=circle, symmetry=asymmetric
4.3 container：none / circle → 选 none

## 站 5 验收
16px ✅ 单色 ✅ 反白 ✅ 无文字 ✅
货架 ⚠️ 与某同行同构，需加独有转折
```

**回退必须写进记录**，并注明原因。回退的原因往往比选择本身更有信息量。
