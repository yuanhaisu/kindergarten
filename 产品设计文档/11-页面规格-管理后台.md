# 11. 页面规格说明 · 管理后台

> 最后更新 2026-05-26 · 状态 draft

**适用端**: PC 浏览器（1920×1080 典型分辨率），Nuxt 3 SPA  
**UI 框架**: Element Plus  
**全局布局**: 左侧可折叠侧边栏 + 顶部导航栏 + 右侧内容区

---

## 11.1 数据看板 (Dashboard)

- **路由**: `/`
- **文件**: `admin/pages/index.vue`
- **权限**: `dashboard:view`
- **复杂度**: ★★★ 复杂

```

│                                                       │
│  ┌─ 近30日出勤趋势 ───────────────────┐ ┌ 今日待办 ─┐  │  ← 图表+待办行

│  │  1  大(1)  97.3%       │ │ 总媒体:  1,280     │  │

│  └─────────────────────────┘ └──────────────────────┘  │
└──────────────────────────────────────────────────────┘
```

### 内容分区

| 区域 | 显示内容 | 数据来源 |
|------|----------|----------|
| 统计卡片行 | present_count, leave_count, attendance_rate, picked_up_count | `GET /admin/dashboard/overview` → `.realtime` |
| 出勤趋势图 | 30天日期的 present/leave/absent/rate 折线 | `GET /admin/dashboard/attendance-trend?period=30d` |
| 今日待办 | new_notices, pending_leaves, growth_logs, new_tasks | `GET /admin/dashboard/overview` → `.today` |
| 班级出勤排行 | 班级排名、出勤率 | `GET /admin/dashboard/class-ranking` |
| 成长统计 | total_logs, total_media, total_likes, total_comments | `GET /admin/dashboard/growth-stats?period=30d` |

### 交互行为

| 交互元素 | 触发方式 | 行为逻辑 | 关联 API |
|----------|----------|----------|----------|
| 页面加载 | onMounted | Promise.all 并行请求 4 个 API | 上述 4 个 API |
| 任一 API 失败 | — | ElMessage.error(e.message) 弹错误提示 | — |

### 页面状态

- **加载态**: 4 个区域分别显示 Element Plus 的 v-loading 骨架
- **空数据**: 趋势图无数据时显示 `<el-empty description="暂无趋势数据" />`，排行同理
- **错误态**: ElMessage.error 弹出
- 本页无用户可触发的操作按钮，为纯展示页

- **导出中**: 浏览器下载进度

### 交互行为

| 交互元素 | 触发方式 | 行为逻辑 | 关联 API |
|----------|----------|----------|----------|
| 导出按钮 | 点击 | 创建异步导出任务 → 轮询状态(每1.5s最多60次) | `POST /admin/export/{type}` → `GET /admin/export/:taskId` |
| 下载 | 点击 | 完成后触发浏览器下载 | `GET /admin/export/download/:taskId` |
