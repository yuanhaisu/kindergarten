### 内容分区

| 区域 | 显示内容 | 数据来源 |
|------|----------|----------|
| 头部 | currentStudent(name+avatar+class_name), 问候语 | `GET /parent/home/overview` |
| 今日在校 | attendance_label/arrive_time, meal_label, sleep_label/nap_duration, mood_label, performance_tag | `overview.today_summary` |
| 多子女切换 | students[] (name, id, relation) | `overview.students` |
| 快捷入口 | 8 个固定入口 | 本地常量 `quickActions` |
| 最新通知 | 最多 2 条通知 (标题/is_read/creator/时间) | `GET /parent/home/feeds` → 过滤 type=notice |
| 成长动态 | 最多 1 条成长日志 (作者/内容/图片预览/点赞数/评论数/is_liked) | `GET /parent/home/feeds` → 过滤 type=growth |

### 交互行为

| 交互元素 | 触发方式 | 行为逻辑 | 关联 API |
|----------|----------|----------|----------|
| 设置按钮 | 点击 ⚙ | 跳转设置页 | — |
| 切换孩子 | 点击孩子名 | 切换当前学生 → 刷新首页 | `PUT /parent/home/switch-student` → `loadHome()` |
| 快捷入口 | 点击 | `navigateTo(action.path)` | — |
| 通知-查看全部 | 点击 | 跳转通知列表 | — |
| 成长-查看全部 | 点击 | 跳转成长动态 | — |
| 点赞按钮 | 点击 🤍 | 切换点赞状态 | `POST/DELETE /parent/growth/feed/{id}/like` |
| 下拉刷新 | 手势 | 重新加载首页 | `GET /parent/home/overview` + `/feeds` |
| 错误重试 | 点击 [重试] | 重新加载 | 同上 |

### 页面状态

- **加载态**: loading 文字提示

- **空动态**: "暂无新动态"
- **错误态**: 错误信息 + [重试] 按钮
- **单子女**: 无切换器

## 13.9 成长动态 (`/pages/growth/index`)

- **文件**: `parent/src/pages/growth/index.vue`
- **权限**: parent 角色
- **复杂度**: ★★ 中等

### 统一信息流设计

成长动态采用**单一信息流**：班级记录和个体记录在同一流中混合展示，后台根据 `target_type` 和 `growth_log_students` 关联自动过滤。

- **班级记录卡片**：教师头像 + 教师姓名 + 班级名称 + 内容 + 互动数据（所有家长可见）
- **个体记录卡片**：教师头像 + 教师姓名 + 学生姓名 + 表现标签 + 内容 + 互动数据（仅目标学生家长可见）

家长在同一个流中既能感知班级全貌，也能收到针对自己孩子的专属反馈，无需切换入口。

**API**: `GET /parent/growth/feed?student_id=&year=&month=&page=&page_size=`

### 布局
