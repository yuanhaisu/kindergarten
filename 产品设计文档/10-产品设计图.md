```mermaid
        R["Repository 层"]
    end

    subgraph Storage["数据层"]

    Admin -.->|"Cookie: admin_token"| Nginx
    Teacher -.->|"Bearer JWT (role=teacher)"| Nginx
    Parent -.->|"Bearer JWT (role=parent)"| Nginx
    Nginx --> MW --> H --> S --> R
    R --> MySQL
    R --> Redis
    R --> OSS
    H --> Wechat
```

## 10.6 核心用户流程

### 10.6.1 老师发布通知流程

```mermaid
sequenceDiagram
    participant T as 老师
    participant App as 老师端小程序
    participant BE as 后端
    participant P as 家长

    T->>App: 进入发布通知页
    App->>BE: GET /teacher/notices/templates
    BE-->>App: 返回模板列表

    T->>App: 选择分类 + 填写标题/内容
    T->>App: 上传图片(最多9张)
    T->>App: 选择接收班级
    T->>App: 可选: 设置定时发送 / 需要确认

    App->>BE: POST /teacher/notices
    BE->>BE: 保存通知(status=published/scheduled)
    BE->>BE: 生成家长站内消息
    BE->>BE: 触发微信订阅消息推送
    BE-->>App: 发布成功

    P->>P: 收到微信服务通知
    P->>App: 打开小程序查看通知详情
    App->>BE: PUT /parent/notices/:id/confirm (确认已读)
    BE-->>App: 确认成功

    T->>App: 查看已读统计
    App->>BE: GET /teacher/notices/:id/read-status
    BE-->>App: 已读/未读家长列表
```

### 10.6.2 老师记录成长 → 家长互动流程

```mermaid
sequenceDiagram
    participant T as 老师
    participant App as 老师端
    participant BE as 后端
    participant P as 家长

    T->>App: 进入添加成长记录
    T->>App: 选择日期
    T->>App: 快速填写: 饮食/睡眠/情绪/表现标签
    T->>App: 拍照上传(最多20张)
    T->>App: 选择目标: 全班 / 指定学生

    App->>BE: POST /teacher/growth/logs
    BE->>BE: 保存结构化数据
    BE->>BE: 关联学生(GrowthLogStudent)
    BE->>BE: 保存媒体(GrowthMedia + GrowthMediaStudent)
    BE->>BE: [若开启审核] 创建 ContentAudit
    BE->>BE: 推送家长端消息
    BE-->>App: 创建成功

    P->>App: 成长动态流刷新
    App->>BE: GET /parent/growth/feed
    BE-->>App: 返回新的成长日志

    P->>App: 查看详情 + 点赞
    App->>BE: POST /parent/growth/feed/:id/like
    BE-->>App: 点赞成功

    P->>App: 发表评论
    App->>BE: POST /parent/growth/feed/:id/comments
    BE-->>App: 评论成功

    T->>App: 查看评论列表
    App->>BE: GET /teacher/growth/logs/:id/comments
    BE-->>App: 家长评论列表
```

### 10.6.3 接送流程

```mermaid
sequenceDiagram
    participant P as 家长
    participant PApp as 家长端
    participant BE as 后端
    participant T as 老师
    participant TApp as 老师端

    Note over P,TApp: === 入园签到 (早上) ===
    P->>PApp: 打开接送二维码
    PApp->>BE: GET /parent/pickup/qrcode
    BE-->>PApp: 返回有效二维码

    T->>TApp: 点击"扫码接送"
    TApp->>TApp: 调用 wx.scanCode()
    TApp->>BE: POST /teacher/pickup/scan
    BE->>BE: 验证二维码有效性
    BE->>BE: 创建 PickupRecord(type=送入)
    BE->>BE: 更新 Attendance(check_in_time)
    BE->>BE: 推送家长接送通知
    BE-->>TApp: 签到成功
    P->>P: 收到"孩子已入园"通知

    Note over P,TApp: === 放学接走 (下午) ===
    alt 家长/授权人扫码接走
        T->>TApp: 扫码
        TApp->>BE: POST /teacher/pickup/scan
        BE->>BE: 创建 PickupRecord(type=接走)
    else 手动登记
        T->>TApp: 从未接走列表选学生
        TApp->>BE: POST /teacher/pickup/manual
        BE->>BE: 创建 PickupRecord(type=接走, method=手动)
    end
    BE->>BE: 推送家长"已接走"通知
    BE-->>TApp: 登记成功
```

### 10.6.4 请假审批流程

```mermaid
sequenceDiagram
    participant P as 家长
    participant PApp as 家长端
    participant BE as 后端
    participant T as 老师
    participant TApp as 老师端

    P->>PApp: 填写请假申请
    Note over PApp: 选择子女<br/>填写原因<br/>选择起止日期
    PApp->>BE: POST /parent/leaves
    BE->>BE: 创建 LeaveRequest(status=待审批)
    BE->>BE: 推送老师端消息
    BE->>BE: [可选] 同步更新 Attendance(请假)
    BE-->>PApp: 提交成功

    T->>TApp: 查看待审批列表
    TApp->>BE: GET /teacher/leaves
    BE-->>TApp: 待审批请假列表

    alt 同意
        T->>TApp: 点击"同意"
        TApp->>BE: PUT /teacher/leaves/:id/approve
        BE->>BE: status = 已批准
    else 拒绝
        T->>TApp: 填写拒绝原因 → 点击"拒绝"
        TApp->>BE: PUT /teacher/leaves/:id/reject
        BE->>BE: status = 已拒绝, 记录原因
    end

    BE->>BE: 推送家长端审批结果消息
    P->>PApp: 查看审批结果
```

### 10.6.5 亲子任务打卡闭环

```mermaid
sequenceDiagram
    participant T as 老师
    participant BE as 后端
    participant P as 家长

    T->>BE: POST /teacher/tasks
    Note over BE: 创建任务<br/>(标题/描述/频率/积分/日期)
    BE->>BE: 推送家长任务通知

    P->>BE: GET /parent/tasks
    BE-->>P: 待完成任务列表

    P->>BE: 进入任务详情 → 打卡
    Note over P: 上传文字+照片
    P->>BE: POST /parent/tasks/:id/checkin
    BE->>BE: 创建 TaskCheckIn
    BE->>BE: 增加 PointTransaction(积分流水)
    BE->>BE: 更新 PointAccount(total_points)
    BE->>BE: 检查是否触发 Achievement
    BE-->>P: 打卡成功 + 获得积分

    P->>BE: GET /parent/points/overview
    BE-->>P: 积分变化 + 可能的新成就

    T->>BE: GET /teacher/tasks/:id/stats
    BE-->>T: 打卡完成率统计
```
