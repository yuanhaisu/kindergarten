# 1. 产品概述

> 最后更新 2026-05-24 · 状态 draft

## 1.1 产品愿景

"让老师从重复沟通中解放出来，让家长真正看见孩子的每一天，让园所管理有据可查。"

养成星球是一套专为幼儿园设计的数字化管理平台，覆盖**老师**、**家长**、**园所管理者**三个角色，通过三个独立客户端 + 一个统一后端，形成从日常通知、成长记录、出勤接送到积分激励的完整闭环。

## 1.2 核心解决的问题

### 老师端：减少重复沟通，聚焦教育本身

- 通知发到微信群无法确认家长是否看到 → **通知模板 + 已读确认 + 未读提醒**
- 每日成长观察散落在手机相册 → **结构化成长记录（饮食/睡眠/情绪/表现标签）+ 班级动态流**
- 接送环节手工登记易出错 → **扫码接送 + 授权接送人管理**
- 请假信息零散难以统计 → **在线请假审批流，自动汇总统计**

### 家长端：建立持续可见的信任感

- 孩子在园一整天发生什么几乎不知道 → **每日成长日志推送 + 相册流 + 班级动态**
- 接送环节缺少安全记录 → **接送实时通知 + 授权接送人管理**
- 沟通渠道混乱 → **统一通知中心 + 亲子任务打卡**

### 管理端：让园所运营有数据支撑

- 出勤、请假、接送靠手工记录 → **多维度数据看板 + 趋势图表**
- 班级事务无法统一追踪 → **21 个功能模块覆盖全业务流程**
- 家长满意度难以量化 → **内容审核 + 反馈管理 + 操作审计日志**

## 1.3 目标用户画像

### 主班老师（Primary User）

- 负责一个班级的日常管理和家校沟通
- 每日核心操作：登记出勤 → 发布动态 → 发通知 → 接送登记
- 使用设备：微信小程序（Android/iOS 手机）

### 家长

- 关注自己孩子在园的一日活动和成长变化
- 每日核心操作：看通知 → 刷成长动态 → 接送出示二维码 → 打卡亲子任务
- 使用设备：微信小程序（Android/iOS 手机）

### 园长 / 教务主管

- 统筹管理整个幼儿园的教学质量和运营效率
- 核心操作：查看数据看板 → 审批请假 → 管理师生信息 → 导出报表
- 使用设备：PC 浏览器（管理后台）

## 1.4 核心术语表

| 术语 | 英文 | 说明 |
|------|------|------|
| 园所 | Kindergarten | 幼儿园主体，多租户隔离的基本单位 |
| 班级 | Class | 按年级划分（小班/中班/大班），学生和通知的基本归属 |
| 成长日志 | GrowthDailyLog | 老师记录的每日学生成长观察，包含饮食、睡眠、情绪、表现标签 |
| 亲子任务 | ParentTask | 老师布置、家长在家配合完成的周期性任务 |
| 打卡 | Check-in | 家长完成亲子任务后的签到确认 |
| 星星积分 | Points | 学生通过完成打卡、全勤等获得的积分奖励 |
| 成就 | Achievement | 达到特定条件后自动获得的徽章（如"全勤小达人"） |
| 接送 | Pickup | 入园签到和放学接走的全流程记录 |
| 授权接送人 | Authorized Person | 家长委托接送的亲友，需经审核 |
| 通知模板 | NoticeTemplate | 预设的通知格式，老师可快速套用发布 |
| 定时发送 | Scheduled Publish | 通知/公告的预约定时发布 |
| 内容审核 | Content Audit | 管理员对通知/成长日志/评论的合规审核 |
| 学年 | Academic Year | 按春/秋季学期划分的教学周期 |
| 多租户 | Multi-tenancy | 通过 `kindergarten_id` 实现的数据隔离机制 |

## 1.5 产品边界

**在范围内的功能：**
- 幼儿园日常运营的全部数字化流程（通知、成长、出勤、接送、请假、任务）
- 家园共育的基础互动（点赞、评论、打卡）
- 园所管理的数据分析和权限管控

**明确不在范围内的：**
- 在线支付 / 学费缴纳
- 课程排课系统
- 第三方智能硬件集成（如人脸识别闸机）
- 园区财务 / ERP 功能
