## 12.5 添加成长记录 (`/pages/growth/create`)

- **文件**: `teacher/src/pages/growth/create.vue`
- **复杂度**: ★★★ 复杂

### 双模式设计

页面默认进入**班级记录模式**（`target_type=1`），可通过底部开关切换为**个体记录模式**（`target_type=2`）。两种模式的表单内容不同：

| 区域 | 班级模式 (target_type=1) | 个体模式 (target_type=2) |
|------|:---:|:---:|
| 饮食评分卡片 | ✅ | ❌ 隐藏 |
| 睡眠记录卡片 | ✅ | ❌ 隐藏 |
| 情绪评分卡片 | ✅ | ❌ 隐藏 |
| 表现标签 | ✅ | ✅ |
| 学生选择器 | ❌ 隐藏 | ✅ 班级花名册多选 |
| 照片上传 | ✅ | ✅ |
| 文字内容 | ✅ | ✅ |
| "同步到班级动态" | ✅ 默认开启 | ❌ 隐藏（替换为提示文字） |
| "仅发送给指定家长" | □ 可选 | ☑ 已选（不可取消） |
| 发布按钮文案 | "发布班级记录" | "发布个体记录" |
