## 9.1 通知体系概述

平台的消息通知覆盖三个渠道：

| 渠道 | 载体 | 适用场景 |
|------|------|----------|
| **站内消息** | `messages` 表 + 小程序消息页面 | 请假审批结果、系统通知、任务提醒 |
| **微信订阅消息** | 微信小程序订阅消息模板 | 接送通知、新通知提醒、审批结果实时触达 |
| **管理后台待办** | Dashboard 待办事项列表 | 内容审核提醒、请假待批提醒 |

## 9.2 站内消息 (`messages`)

### 消息类型

| 类型 | type 值 | 触发场景 |
|------|---------|----------|
| 通知 | `notice` | 老师发布新班级通知 |
| 请假 | `leave` | 请假审批结果（通过/拒绝） |
| 接送 | `pickup` | 子女被接送 |
| 成长 | `growth` | 成长日志新增评论/点赞 |
| 任务 | `task` | 新亲子任务发布/任务截止提醒 |
| 系统 | `system` | 园所公告、系统通知 |

### 消息状态

```
未读(is_read=false) → 用户打开消息详情 → 已读(is_read=true, read_at=now)
```

### API

| 端点 | 说明 |
|------|------|
| `GET /common/messages?page=&type=` | 消息列表（分页，按类型筛选） |
| `PUT /common/messages/:id` | 标记单条消息已读 |
| `GET /common/messages/unread-count` | 获取未读消息总数（用于角标展示） |

### 客户端表现

- **老师端**: `/pages/messages/index` — 当前为占位页面，功能待实现
- **家长端**: `/pages/messages/index` — 消息列表 + 未读数角标

## 9.3 微信订阅消息

### 推送流程

```
后端事件触发 → 查 WechatPushLog 表防重 → 调用微信 subscribeMessage.send 
→ 记录 WechatPushLog(status=1成功/-1失败) → 用户微信收到服务通知
```

### 推送记录 (`wechat_push_logs`)

| 字段 | 说明 |
|------|------|
| user_id | 接收用户 |
| template_id | 微信订阅消息模板 ID |
| content | 消息内容（JSON 格式） |
| status | 0=待发送, 1=成功, -1=失败 |
| error_msg | 失败原因 |
| sent_at | 实际发送时间 |

### 典型推送场景

| 场景 | 触发方 | 接收方 | 说明 |
|------|--------|--------|------|
| 新通知发布 | 老师 | 班级全部家长 | 提醒查看通知 |
| 请假审批完成 | 老师 | 请假家长 | 通知审批结果 |
| 子女被接送 | 老师扫码 | 家长 | 安全提示（谁、何时接走） |
| 新任务发布 | 老师 | 班级家长 | 提醒完成亲子任务 |
| 任务即将截止 | 系统定时 | 未完成家长 | 截止提醒 |
| 内容审核结果 | 管理员 | 老师 | 通知/成长日志审核情况 |

## 9.4 管理后台待办事项

Dashboard 页面的"待办事项"区块展示当前需要管理员处理的事项：

| 待办类型 | 触发条件 | 操作 |
|----------|----------|------|
| 内容待审核 | 通知/成长日志/评论提交审核 | 前往审核 |
| 请假待审批 | 老师已同意但超时未处理 | 查看请假 |
| 授权待审核 | 家长添加授权接送人 | 审核通过/拒绝 |

## 9.6 通知偏好与设置

### 系统设置（管理后台 `/admin/settings`）

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| 通知需审核 | 否 | 开启后所有通知发布前需管理员审核 |
| 自动提醒时间 | 2h | 通知发布 N 小时后提醒未读家长 |
| 成长记录需审核 | 否 | 开启后所有成长日志发布前需审核 |
| 允许家长评论 | 是 | 成长日志下是否允许家长评论 |
| 允许家长点赞 | 是 | 成长日志下是否允许家长点赞 |
| 授权接送需审核 | 是 | 家长添加授权接送人是否需要管理员审核 |
| 二维码有效期 | 24h | 接送二维码的有效时长 |

### 家长端设置（小程序 `/parent/settings`）

- 可自定义通知偏好（接收哪些类型的推送）
- 可管理授权接送人的通知开关
