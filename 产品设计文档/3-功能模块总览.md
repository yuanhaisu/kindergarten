## 3.2 三端功能分工

### 管理后台（Admin）—— 管理型操作
- 数据管理（师生家长的增删改查、导入导出）
- 流程审核（内容、请假、授权接送人）
- 数据看板（Dashboard、趋势图表、统计报表）
- 系统配置（权限角色、园所设置、学年管理）

### 老师端 —— 生产型操作
- 内容生产（发通知、记成长、创建任务和日历事件）
- 现场操作（出勤登记、扫码接送）
- 审批操作（同意/拒绝请假）
- 本班数据查看（学生名册、接送统计、任务完成情况）

### 家长端 —— 消费型操作
- 信息消费（看通知、看成长动态、看公告）
- 事务提交（请假申请、打卡签到、添加授权接送人）
- 安全工具（出示接送二维码、查看接送记录）
- 成长追踪（积分排名、成就墙、AI 报告）

## 3.3 关键数据流

### 通知流
```
老师(创建通知) → [可选:管理员审核] → 家长(查看 + 确认已读)
                                          ↓
老师(查看已读统计 + 提醒未读)
```

### 成长记录流
```
老师(创建日志:饮食/睡眠/情绪/表现/照片) → [可选:管理员审核] → 家长(点赞/评论)
```

### 请假流
```
家长(提交请假申请) → 老师(同意/拒绝) → 自动统计 + 与出勤关联
```

### 接送流
```
家长(出示二维码/授权接送人) → 老师(扫码/手动登记) → 家长(收到接送通知)
```

### 积分闭环
```
老师(布置亲子任务) → 家长(打卡完成) → 自动加积分 → 解锁成就
                                              ↓
家长(积分排行榜 / 成就墙查看)
```
