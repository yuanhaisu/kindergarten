> 版本 v1.1 · 最后更新 2026-05-26 · 状态 draft

## 文档说明

本文档集是"养成星球"幼儿园数字化管理平台的完整产品设计文档，覆盖管理后台（admin）、老师端小程序（teacher）、家长端小程序（parent）三个客户端应用的全部功能模块。

文档编写原则：**基于已实现代码，不发明未落地功能**。每个功能描述均引用实际代码路径和 API 端点。
