# 4. 管理后台功能

> 最后更新 2026-05-24 · 状态 draft

**技术栈**: Nuxt 3 + Vue 3 + Element Plus + Pinia + ECharts + Tailwind CSS
**路由**: `admin/pages/` 下共 21 个页面
**API 模块**: `admin/api/` 下 23 个模块文件

---

## 4.1 数据看板 (Dashboard)

- **路由**: `/`
- **权限**: `dashboard:view`
- **参考**: `admin/pages/index.vue`, `admin/api/dashboard.ts`

**页面组成：**
- 顶部统计卡片：今日出勤人数、请假人数、出勤率、已接送人数
- 出勤趋势图（ECharts 折线图）：近 30 日出勤/请假/缺勤/出勤率曲线
- 班级出勤排行表
- 成长数据卡片（总日志数/媒体数/点赞数/评论数）
- 待办事项列表

**API：**
| 端点 | 说明 |
|------|------|
| `GET /admin/dashboard/overview` | 概览数据（园所信息/实时统计/今日汇总/月度统计） |
| `GET /admin/dashboard/attendance-trend?period=30d` | 出勤趋势 |
| `GET /admin/dashboard/class-ranking` | 班级出勤排行 |
| `GET /admin/dashboard/growth-stats?period=30d` | 成长统计 |

## 4.19 系统设置

- **路由**: `/settings`
- **权限**: `system:kindergarten`
- **参考**: `admin/pages/settings.vue`, `admin/api/settings.ts`

**功能**: 三大设置模块——
- **基础设置**: 学年、学期(spring/fall)、学期起止日期
- **功能开关与参数**: 出勤（入园/放学时间、迟到阈值）、通知（需审核、自动提醒时间）、成长记录（需审核、允评、允赞）、接送（二维码有效期、授权需审核）、积分（打卡积分、周/月全勤奖励）
- **园所信息**: 名称/地址/电话/园长/Logo/许可证号/容量/成立日期

**API**: `GET|PUT /admin/settings`、`GET|PUT /admin/kindergarten/info`、`GET|POST /admin/settings/academic-years`

## 4.21 数据导出

- **路由**: `/export`
- **权限**: `attendance:export`
- **参考**: `admin/pages/export.vue`, `admin/api/export.ts`

**功能**: 三类数据导出（出勤记录 / 学生信息 / 成长记录），异步任务模式——
1. 点击导出按钮 → 创建导出任务
2. 轮询任务状态（每 1.5 秒，最多 60 次）
3. 完成后下载 Excel 文件

**操作权限**: 创建任务 + 下载

**API**: `POST /admin/export/{attendance|students|growth}`、`GET /admin/export/:taskId`、`GET /admin/export/download/:taskId`
